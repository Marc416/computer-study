스프레드시트 함수와 셀 참조

엑셀 함수(문자열·수학·논리·찾기참조·재무) · 셀 참조 방식 · PART 08. 스프레드시트

핵심 요약

계리직 시험은 VLOOKUP/HLOOKUP/INDEX/MATCH 같은 찾기함수와 절대·상대·혼합 참조를 압도적으로 많이 묻는다.

수식을 손으로 풀 때는 "안쪽 함수부터 계산 → 바깥 함수에 대입" 순서만 지키면 아무리 중첩돼도 풀린다.

🎯이 단원을 왜 배우나

거의 전부 계리직 문제 — 그리고 100% "손으로 풀 수 있는" 문제다

이 단원은 출제 이력이 특이하다. 기출을 보면 거의 전부 계리직이고, 매년 1~2문항이 고정으로 나온다. 국가직·지방직에는 거의 안 나오므로, 계리직 준비생에게는 반드시 챙겨야 할 파트이고 다른 직렬이면 우선순위를 낮춰도 된다.

중요한 건 이 단원의 문제가 암기가 아니라 "따라 계산하기"라는 점이다. 워크시트 그림과 수식이 주어지고 "결과값은?"을 묻는다. 엑셀을 켜본 적이 없어도 함수의 형식(인수 순서)과 규칙만 알면 종이 위에서 그대로 재현할 수 있다. 즉 외울 게 적고 확실히 맞힐 수 있는, 가성비 좋은 단원이다.

모든 문제를 푸는 단 하나의 원칙

중첩 함수는 반드시 안쪽(괄호 깊은 쪽)부터 계산해서 결과를 바깥에 대입한다. 예를 들어 =HLOOKUP(INDEX(A2:C5,2,2), B7:E9, 2)가 나오면, 먼저 INDEX를 풀어 "C123"을 얻고, 그 값을 넣어 =HLOOKUP("C123", B7:E9, 2)를 다시 푼다. 아무리 복잡해 보여도 이 순서로 한 겹씩 벗기면 예외 없이 풀린다.

틀리는 지점도 정해져 있다 — ①VLOOKUP과 HLOOKUP의 방향 혼동(세로냐 가로냐), ②MATCH가 값이 아니라 "위치"를 돌려준다는 것을 잊음, ③$ 위치를 착각(행 고정인지 열 고정인지), ④검색유형 0(정확히 일치)과 1/TRUE(근사값)의 차이. 이 네 가지만 조심하면 된다.

💡주요 개념

셀 서식 표시 형식 코드 📖 기출문제집 p.799

셀에 저장된 실제 값은 그대로 두고 보이는 모양만 바꾸는 것이 표시 형식이다. 핵심은 자리표시자 두 개(0과 #)의 차이다.

코드의미입력 1234.5 → 출력
G/표준기본 형식 (그대로 표시)1234.5
#,##0정수부만, 천단위 구분, 빈자리는 0으로 채움1,235 (소수 첫째에서 반올림)
#,###정수부만, 천단위 구분, 빈자리는 생략1,235
#,###.#소수 첫째 자리까지 표시1,234.5
#,###.#0소수 둘째 자리까지, 빈자리는 0으로 채움1,234.50

0과 #은 뭐가 다른가

둘 다 "여기에 숫자 한 자리"라는 뜻이지만, 그 자리에 표시할 숫자가 없을 때 행동이 다르다.

  • 0 — 숫자가 없어도 0을 강제로 찍는다. 예) 값 7에 00 서식 → 07
  • # — 숫자가 없으면 자리 자체를 생략한다. 예) 값 7에 ## 서식 → 7

그래서 #,##0은 값이 0일 때 "0"이라고 찍히지만, #,###은 아무것도 안 보인다. 금액 표시에 #,##0을 주로 쓰는 이유다.

반올림 포인트: 서식에 소수 자리가 없으면(#,##0) 소수는 버려지는 게 아니라 반올림된다. 1234.5 → 1,235. 단, 셀에 저장된 실제 값은 여전히 1234.5다(보이는 것만 바뀜).

문자열 함수 — LEFT / RIGHT / MID / LEN / FIND 📖 기출문제집 p.800

함수형식예시결과
LEFT=LEFT(문자열, 자릿수)=LEFT("KOREA", 2)"KO"
RIGHT=RIGHT(문자열, 자릿수)=RIGHT("KOREA", 2)"EA"
MID=MID(문자열, 시작위치, 자릿수)=MID("KOREA", 3, 2)"RE"
LEN=LEN(문자열)=LEN("KOREA")5
FIND=FIND(찾을문자, 대상텍스트)=FIND(")", "(02)000-0000")4 (몇 번째인지)
&문자열 연결 연산자="AB" & "CD""ABCD"
중첩 예제: =RIGHT(C4, LEN(C4)-4) & "****" (C4 = 019-2119-9019)
  1. 안쪽부터: LEN(C4) = 13 — 하이픈(-)도 한 글자로 센다 (019=3, -=1, 2119=4, -=1, 9019=4 → 총 13)
  2. RIGHT(C4, 13−4) = RIGHT(C4, 9) → 오른쪽 끝 9글자 = "2119-9019"
  3. &로 이어붙이기: "2119-9019" & "****" = "2119-9019****"
FIND 활용 예제: (02)000-0000 에서 국번 "02"만 뽑기
  1. 국번은 2번째 문자부터 시작한다 (1번째는 여는 괄호) → MID의 시작위치 = 2
  2. 몇 글자를 뽑을지는 지역번호마다 다르다(02는 2자리, 032는 3자리) → 고정값을 쓸 수 없다
  3. 닫는 괄호 위치를 FIND로 찾는다: FIND(")", "(02)000-0000") = 4
  4. 추출할 글자 수 = (닫는 괄호 위치) − 2 = 4−2 = 2 → 최종 =MID(B2, 2, FIND(")",B2)−2)

왜 −2인가: 앞의 여는 괄호 1칸과 닫는 괄호 자신 1칸, 합쳐 2칸을 빼야 순수 숫자만 남는다.

셀 참조 방식 — 상대·절대·혼합 참조 📖 기출문제집 p.801~802

$ 기호가 붙은 부분은 수식을 복사해도 바뀌지 않고 고정된다. $가 열 문자 앞에 있으면 열 고정, 행 번호 앞에 있으면 행 고정이다.

암기: "$ 바로 뒤에 오는 것이 고정된다." $B2는 $ 뒤가 B이므로 열 고정, B$2는 $ 뒤가 2이므로 행 고정, $B$2는 둘 다 고정.
계산 예제: [D1]에 =$A$1+$B2 입력 후 [D5]에 복사하면? (A1=1, B6은 빈칸)
  1. D1 → D5는 열은 그대로(D→D), 행만 4칸 아래로 이동
  2. $A$1: 행·열 모두 $로 고정 → 복사해도 그대로 $A$1 = 1
  3. $B2: 열(B)만 고정, 행은 상대 → 4칸 내려가 2+4 = $B6
  4. B6은 빈칸이므로 계산에서 0으로 취급 → [D5] = 1 + 0 = 1
실무형 예제: C열과 E열에 같은 수식을 복사해 쓰려면?

C2에는 B2/B7(수주량 비율), E2에는 D2/D7(판매금액 비율)이 필요하다. 열은 B→D로 바뀌어야 하고(고정하면 안 됨), 분모의 행 7만 고정돼야 한다. 따라서 열에 $를 붙이면 안 되고 행에만 붙인다 → =B2/B$7*100

만약 $B$7로 절대참조하면 E열로 복사했을 때도 분모가 B7로 남아 판매금액 비율이 엉뚱하게 계산된다.

수학·통계 함수 📖 기출문제집 p.802~803

함수기능예시결과
MEDIAN중앙값 (정렬 후 가운데, 짝수개면 두 값의 평균)=MEDIAN(3,7,5,3,0,1)3
MODE최빈값 (가장 자주 나온 값)=MODE(3,7,5,3,0,1)3
GCD최대공약수=GCD(3,1)1
POWER거듭제곱 (=밑, 지수)=POWER(3,3)27
FACT계승(팩토리얼)=FACT(5)120 (5×4×3×2×1)
INT더 작은 정수로 내림=INT(-3.14)−4 (❗ −3 아님)
MOD나머지 (=피제수, 제수)=MOD(3,4)3 (3÷4는 몫0 나머지3)
PRODUCT모든 인수의 곱=PRODUCT(3,6,2)36
ROUNDDOWN0에 가까운 방향으로 내림=ROUNDDOWN(1145443, −1)1,145,440

자주 틀리는 세 가지

  • INT(음수): "소수점 버림"이 아니라 수직선에서 왼쪽(더 작은 쪽) 정수로 내림이다. INT(3.14)=3이지만 INT(−3.14)=−4. 단순히 소수부를 잘라내면 −3이라 착각하기 쉽다.
  • MOD(3,4): 앞이 나눠지는 수, 뒤가 나누는 수다. 3÷4 = 몫 0, 나머지 3. 순서를 바꿔 MOD(4,3)=1과 헷갈리지 말 것.
  • ROUNDDOWN의 자릿수(num_digits): 양수면 소수점 아래 자리, 0이면 정수, 음수면 소수점 위(왼쪽) 자리에서 내린다. −1은 1의 자리를 버려 10원 단위로, −2는 10의 자리까지 버려 100원 단위로 만든다.

논리 함수 — IF / OR / AND 📖 기출문제집 p.803~804

=IF(조건, 참일때값, 거짓일때값) — 조건 자리에 OR·AND를 넣어 여러 조건을 묶는다.

함수참이 되는 조건
OR(조건1, 조건2, …)조건 중 하나만 참이어도 참
AND(조건1, 조건2, …)전부 참이어야 참
판정 예제: =IF(OR(B3<1%, C3>=500), "합격", "재작업")
행오차율(B)생산량(C)B<1%C≥500OR결과
31.05%495거짓거짓거짓재작업
41.10%510거짓참참합격
50.90%537참참참합격

→ D3:D5 = 재작업, 합격, 합격. 이렇게 표를 그려 조건별 참·거짓을 하나씩 채우면 실수가 없다.

찾기/참조 함수 📖 기출문제집 p.804~805

함수형식기능
VLOOKUP=VLOOKUP(검색값, 범위, 열번호, 검색유형)범위의 첫 열(세로)에서 검색값을 찾아, 지정한 열 번호의 같은 행 값을 반환
HLOOKUP=HLOOKUP(검색값, 범위, 행번호, 검색유형)범위의 첫 행(가로)에서 검색값을 찾아, 지정한 행 번호의 같은 열 값을 반환
LOOKUP=LOOKUP(검색값, 검사범위, 대응범위)검사범위에서 찾은 위치와 같은 위치를 대응범위에서 반환
MATCH=MATCH(검사값, 검사범위, 검사유형)검사값이 범위에서 몇 번째인지(위치) 반환 — 값이 아니다!
INDEX=INDEX(범위, 행번호, 열번호)범위에서 지정한 행·열 위치의 값을 반환
CHOOSE=CHOOSE(인덱스, 값1, 값2, …)인덱스 번호에 해당하는 값을 선택
OFFSET=OFFSET(기준, 행수, 열수)기준 셀에서 지정한 만큼 떨어진 셀 값을 반환
LARGE=LARGE(범위, k)범위에서 k번째로 큰 값 (동일 값이 여러 개면 중복을 각각 센다)
검색유형(마지막 인수): 0 또는 FALSE = 정확히 일치하는 값만 / 1 또는 TRUE 또는 생략 = 검색값보다 작거나 같은 값 중 가장 큰 값(근사값, 범위가 오름차순 정렬돼 있어야 함). MATCH는 여기에 더해 −1(검색값보다 크거나 같은 값 중 최소, 내림차순 정렬)도 있다.

INDEX + MATCH 조합 — 행·열을 동시에 찾기 📖 기출문제집 p.808

VLOOKUP은 "첫 열에서만" 찾을 수 있다는 한계가 있다. 표에서 행과 열을 모두 조건으로 값을 찾으려면 INDEX와 MATCH를 조합한다. MATCH가 "몇 번째 행인지·몇 번째 열인지"를 알아내고, INDEX가 그 좌표의 값을 꺼내오는 역할 분담이다.

재무 함수 — FV / ROUNDDOWN 📖 기출문제집 p.809

=FV(rate, nper, pmt, [pv], [type]) — 고정 이자율 기반의 미래가치(Future Value)를 계산한다.

인수의미주의
rate기간별 이자율월복리면 연이율 ÷ 12
nper총 납입 기간 수월납 3년이면 3×12 = 36
pmt각 기간의 납입액저축(나가는 돈)은 음수로 입력
pv현재가치 (선택)생략하면 0
type납입 시점 (선택)0=기간 말, 1=기간 초
예제: 연이율 4%, 3년 월복리 적금의 만기지급금 (10원 미만 절삭)
  1. rate와 nper의 단위를 맞춘다 — 월복리이므로 둘 다 "월" 기준으로: rate = 4%/12, nper = 3*12
  2. 월 적립액은 내 지갑에서 나가는 돈이므로 음수: pmt = −B2
  3. 10원 단위 미만 절삭 → ROUNDDOWN의 자릿수는 −1 (1의 자리를 버림)
  4. 최종: =ROUNDDOWN(FV(4%/12, 3*12, −B2), −1)

오답 포인트: rate에 4%를 그대로 쓰면(연이율 × 36개월) 완전히 틀린 값이 되고, 자릿수에 −2를 쓰면 100원 단위로 잘려버린다.

데이터 분석·시각화 도구 📖 기출문제집 p.810

도구설명
스파크라인 (Sparkline)단일 셀 안에 그리는 미니 차트. 선(꺾은선형)·열(세로막대형)·승패(음수/양수) 세 방식으로 추세를 표현
슬라이서 (Slicer)버튼 클릭만으로 데이터를 직관적으로 필터링하는 시각적 도구
피벗 테이블 (Pivot Table)복잡한 데이터를 표로 재구성해 합계·평균·개수·최대/최소 등 통계를 확인
파워 쿼리 (Power Query)여러 데이터 원본에서 데이터를 가져와 변환·정리한 뒤 시트에 로드
구별 요령: "셀 안에 들어가는 작은 차트" = 스파크라인 / "버튼으로 거르기" = 슬라이서 / "재구성해서 집계" = 피벗 테이블 / "가져와서 변환" = 파워 쿼리.

📌시험 빈출 포인트

  • VLOOKUP = 세로(첫 열 기준, 열번호 지정), HLOOKUP = 가로(첫 행 기준, 행번호 지정) — V/H로 암기
  • 열·행 번호는 지정한 범위의 왼쪽/위쪽 끝을 1로 세며, 시트의 A열·1행 기준이 아니다
  • MATCH는 값이 아니라 위치(순번)를 반환 / INDEX는 좌표의 값을 반환
  • INDEX+MATCH 조합 시 INDEX 범위에 제목 행·열을 포함하지 않는다
  • 검색유형 0/FALSE = 정확히 일치, 1/TRUE/생략 = 작거나 같은 값 중 최대(근사값)
  • 다른 시트 참조는 Sheet1!A2:D6처럼 시트명 뒤에 !, 여러 셀에 복사할 땐 절대참조 권장
  • 절대($A$1)·상대(A1)·혼합($A1, A$1) — $ 바로 뒤가 고정된다
  • 중첩함수는 반드시 안쪽부터 계산해 바깥에 대입
  • INT(−3.14) = −4 (버림이 아니라 더 작은 정수로 내림)
  • MOD(3,4) = 3 / FACT(5) = 120 / POWER(3,3) = 27 / PRODUCT(3,6,2) = 36
  • ROUNDDOWN 자릿수가 음수면 소수점 왼쪽에서 내림 (−1 = 10원 단위)
  • OR은 하나만 참이어도 참, AND는 전부 참이어야 참

수식 =VLOOKUP(LARGE(C4:C11, 3), C4:F11, 4, 0) 에 의해 표시될 결과는? (C열=초과/부족수량, F열=판매금액. C열 값은 위에서부터 10, 13, −5, 13, 5, 20, 8, 10이고, 두 번째 13이 있는 행의 판매금액은 2,380)

  1. 58
  2. 2,380
  3. 8,700
  4. 16,500
해설 보기

정답 ② 2,380

  1. 안쪽 LARGE(C4:C11, 3) — C열에서 3번째로 큰 값. 정렬하면 20, 13, 13, 10, 10, 8, 5, −5 → 3번째 = 13 (같은 값도 각각 하나로 센다)
  2. 수식이 =VLOOKUP(13, C4:F11, 4, 0) 로 바뀐다
  3. 범위 C4:F11의 첫 열(C열)에서 13을 찾는다 → 13이 두 개지만 VLOOKUP은 위에서부터 처음 만나는 것을 쓴다
  4. 그 행의 4번째 열(C=1, D=2, E=3, F=4) = 판매금액 = 2,380

두 가지 함정: ① LARGE에서 중복값을 하나로 합쳐 세면 3번째가 10이 되어 다른 답이 나온다 — 중복도 각각 센다. ② 열 번호 4를 시트의 D열로 착각하면 안 된다. 범위가 C열부터 시작하므로 C가 1열, 4번째는 F열이다.

문제 132015 상업정보 · 기출문제집 p.808

G3에 분기, G4에 지역을 입력하면 해당 매출액이 G6에 출력되도록 INDEX와 MATCH만 사용해 G6에 넣을 수식은? (A3:A6 = 1~4분기, B2:D2 = 유럽·미국·일본, B3:D6 = 매출 데이터)

  1. =INDEX(B3:D6, MATCH(G3,A3:A6,0), MATCH(G4,B2:D2,0))
  2. =INDEX(A1:D6, MATCH(G3,A3:A6,0), MATCH(G4,B2:D2,0))
  3. =INDEX(B3:D6, MATCH(G4,A3:A6,0), MATCH(G3,B2:D2,0))
  4. =INDEX(A1:D6, MATCH(G4,B2:D2,0), MATCH(G3,A3:A6,0))
해설 보기

정답 ① =INDEX(B3:D6, MATCH(G3,A3:A6,0), MATCH(G4,B2:D2,0))

세 가지를 차례로 확인하면 선택지가 하나씩 걸러진다.

  1. INDEX 범위는 제목을 뺀 데이터 영역만 → B3:D6. A1:D6은 제목 행·열을 포함해 좌표가 어긋난다 → ②④ 탈락
  2. 행 위치는 분기(G3)를 분기 목록(A3:A6)에서 찾아야 한다 → MATCH(G3, A3:A6, 0). ③은 G4(지역)를 분기 목록에서 찾고 있어 틀렸다 → ③ 탈락
  3. 열 위치는 지역(G4)을 지역 목록(B2:D2)에서 찾는다 → MATCH(G4, B2:D2, 0)
  4. 예) G3="3분기", G4="유럽" → MATCH 결과 3과 1 → INDEX(B3:D6, 3, 1) = 3분기 유럽 매출

기억할 규칙 두 개: ① INDEX 범위에 제목을 넣지 않는다, ② 행을 찾는 MATCH가 먼저, 열을 찾는 MATCH가 나중(INDEX의 인수 순서가 행→열이므로).

문제 142016 계리직 · 기출문제집 p.809

3년간 연이율 4%로 매월 적립하는 월 복리 정기적금의 만기지급금을 구하려 한다. 셀 C2에 들어갈 수식은? (월적립액은 B2, 만기지급금은 10원 단위 미만 절삭)

  1. =ROUNDDOWN(FV(4%, 3*12, −B2), −1)
  2. =ROUNDDOWN(FV(4%, 3*12, −B2), −2)
  3. =ROUNDDOWN(FV(4%/12, 3*12, −B2), −1)
  4. =ROUNDDOWN(FV(4%/12, 3*12, −B2), −2)
해설 보기

정답 ③ =ROUNDDOWN(FV(4%/12, 3*12, −B2), −1)

  1. rate와 nper의 단위를 맞춘다 — nper를 3*12=36개월로 잡았으므로 rate도 월 단위여야 한다 → 4%/12. 연이율 4%를 그대로 쓴 ①②는 탈락
  2. pmt는 음수 — 적금은 내 통장에서 빠져나가는 돈이므로 −B2
  3. 절삭 자릿수 — "10원 단위 미만 절삭"은 1의 자리를 버린다는 뜻 → num_digits = −1. −2는 10의 자리까지 버려 100원 단위가 되므로 ④ 탈락

ROUNDDOWN 자릿수 정리: 양수 = 소수점 아래 그 자리까지 남김 / 0 = 정수로 / 음수 = 소수점 왼쪽 그만큼 버림(−1은 10원, −2는 100원, −3은 1000원 단위).

검산: 예시 결과가 ₩1,145,440 처럼 끝자리가 0인 것을 보면 10원 단위로 절삭됐음을 알 수 있다. 100원 단위(−2)였다면 ₩1,145,400이 됐을 것이다.

문제 152025 계리직 · 기출문제집 p.810

다음 설명에 해당하는 것은?
셀 안에 표시하는 작은 차트로, 데이터의 추세를 시각적으로 확인할 수 있다. 선(꺾은선형), 열(세로 막대형), 승패(음수 혹은 양수)의 방식으로 표현할 수 있다.

  1. 슬라이서(slicer)
  2. 스파크라인(sparkline)
  3. 파워 쿼리(power query)
  4. 피벗 테이블(pivot table)
해설 보기

정답 ② 스파크라인

결정적 단어는 "셀 안에 표시하는 작은 차트"다. 일반 차트는 시트 위에 떠 있는 개체지만, 스파크라인은 한 셀 내부에 들어가는 미니 차트라 표 옆에 나란히 붙여 추세를 보여줄 때 쓴다. 종류는 선·열·승패 세 가지.

나머지 보기 정리:

  • 슬라이서 — 드롭다운 대신 버튼 클릭으로 필터링하는 도구
  • 파워 쿼리 — 외부 데이터를 가져와 변환·정리해 로드
  • 피벗 테이블 — 데이터를 재구성해 합계·평균 등 집계

네 개 모두 "데이터를 다루는 도구"라 헷갈리지만, 스파크라인만 유일하게 "그림(차트)"이라는 점으로 구분하면 쉽다.
