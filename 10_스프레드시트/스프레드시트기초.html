스프레드시트 함수와 셀 참조

엑셀 함수(문자열·수학·논리·찾기참조·재무) · 셀 참조 방식 · PART 08. 스프레드시트

핵심 요약

계리직 시험은 VLOOKUP/HLOOKUP/INDEX/MATCH 같은 찾기함수와 절대·상대·혼합 참조를 압도적으로 많이 묻는다.

수식을 손으로 풀 때는 "안쪽 함수부터 계산 → 바깥 함수에 대입" 순서만 지키면 아무리 중첩돼도 풀린다.

💡주요 개념

셀 서식 표시 형식 코드 📖 기출문제집 p.799

코드의미1234.5 입력 시 출력
0유효하지 않은 자리도 0으로 채워서 표시#,##0 → 1,235
#유효하지 않은 자리는 표시 안 함 (무시)#,### → 1,235 (소수부 반올림)
,천 단위 구분 기호#,##0 → 1,235
.소수점 표시 위치#,###.# → 1,234.5
함정 주의: 0과 #은 둘 다 숫자 자리표시자이지만, 0은 빈자리를 0으로 채우고 #은 자리 자체를 생략한다는 점이 다르다. 정수부만 표현하는 서식(#,##0)에 소수점이 있는 값을 넣으면 반올림되어 정수로 표시된다.

문자열 함수 — LEFT / RIGHT / MID / LEN 📖 기출문제집 p.799~800

함수형식예시결과
LEFT=LEFT(문자열, 자릿수)=LEFT("KOREA", 2)"KO"
RIGHT=RIGHT(문자열, 자릿수)=RIGHT("KOREA", 2)"EA"
MID=MID(문자열, 시작위치, 자릿수)=MID("KOREA", 3, 2)"RE"
LEN=LEN(문자열)=LEN("KOREA")5
중첩함수 예제: D4 = RIGHT(C4, LEN(C4)-4) & "****" (C4="010-2109-8765", 문자열 길이 13)
  1. 안쪽부터 계산: LEN(C4) = 13 ("-"도 문자로 포함해서 센다)
  2. RIGHT(C4, 13-4) = RIGHT(C4, 9) → C4의 오른쪽 끝 9글자 추출 = "2109-8765"
  3. & 는 문자열을 이어붙이는 연산자 → "2109-8765" & "****" = "2109-8765****"

셀 참조 방식 — 상대·절대·혼합 참조 📖 기출문제집 p.801~803

$ 기호가 붙은 부분은 수식을 복사해도 바뀌지 않고 고정된다. $가 열 글자 앞에 있으면 열이 고정, 행 번호 앞에 있으면 행이 고정된다.

계산 예제: [D1]=$A$1+$B2 를 [D5]에 복사하면? (A1=1, B6=빈칸=0)
  1. $A$1은 행·열 모두 $로 고정 → D5에 복사해도 그대로 $A$1
  2. $B2는 열(B)만 고정, 행은 상대참조 → 4행 아래로 복사했으니 2+4=6행 → $B6
  3. [D5] = $A$1 + $B6 = 1 + 0(빈칸) = 1
실무 예제: 여러 열에 같은 수식을 채우기 핸들로 복사할 때 — C2(수주량 비율)=B2/B7*100, E2(판매금액 비율)=D2/D7*100 처럼 열 이름은 바뀌지만 분모 행(7)은 고정돼야 하는 상황이면, C2에 =B2/B$7*100을 입력해 오른쪽(E열)으로 복사해도 분모 행만 고정되게 만든다 — 행만 고정하는 혼합참조(B$7)가 정답.

수학·통계 함수 📖 기출문제집 p.803

함수기능예시 (A1~A6 = 1,7,5,3,0,8)
MEDIAN중간값(정렬 후 가운데 값)=MEDIAN(A1:A6) → 3
MODE최빈값(가장 많이 나온 값)=MODE(A1:A6) → 3
GCD최대공약수=GCD(A1,A6) → 1
POWER거듭제곱=POWER(A1,A6) → 1⁸=1
FACT계승(팩토리얼)=FACT(5) → 120
INT소수점 이하 버림, 음수는 더 작은 정수로=INT(-3.14) → -4 (❗ -3 아님)
MOD나머지=MOD(3,4) → 3
PRODUCT곱셈=PRODUCT(3,6,2) → 36
함정 주의: INT(-3.14)는 "소수점 버림"이 아니라 더 작은 정수로 내림이라 -4가 나온다 (단순히 소수부를 잘라내면 -3이라고 착각하기 쉬움).

논리 함수 — IF / OR / AND 📖 기출문제집 p.803~805

=IF(OR(B3<1%, C3>=500), "합격", "재작업") — OR은 조건 중 하나만 참이어도 전체가 참이 된다 (AND는 전부 참이어야 참).

판정 예제: B3=1.05%(1%보다 큼), C3=495(500보다 작음)
  1. OR(B3<1%, C3>=500) → 두 조건 다 거짓 → OR 결과 = 거짓
  2. IF의 조건이 거짓이므로 세 번째 인수 실행 → "재작업"

찾기/참조 함수 📖 기출문제집 p.805~807

함수형식기능
VLOOKUP=VLOOKUP(검색값, 범위, 열번호, 검색유형)범위의 첫 열(세로)에서 검색값을 찾아, 지정한 열 번호의 같은 행 값을 반환
HLOOKUP=HLOOKUP(검색값, 범위, 행번호, 검색유형)범위의 첫 행(가로)에서 검색값을 찾아, 지정한 행 번호의 같은 열 값을 반환
LOOKUP=LOOKUP(검색값, 검사범위, 대응범위)검사범위에서 찾은 위치와 같은 위치를 대응범위에서 반환
MATCH=MATCH(검사값, 검사범위, 검사유형)검사값이 범위에서 몇 번째 위치인지 반환 (값이 아니라 위치!)
INDEX=INDEX(범위, 행번호, 열번호)범위에서 지정한 행·열 위치의 값을 반환
CHOOSE=CHOOSE(인덱스, 값1, 값2, ...)인덱스 번호에 해당하는 값을 선택
OFFSET=OFFSET(기준, 행수, 열수)기준 셀에서 지정한 만큼 떨어진 셀 값을 반환
검색유형: 0(또는 FALSE)=정확히 일치하는 값만 찾음, 1(또는 TRUE·생략)=검색값보다 작거나 같은 값 중 가장 큰 값을 찾음(범위가 오름차순 정렬돼 있어야 함)
중첩함수 예제: =HLOOKUP(INDEX(A2:C5, 2, 2), B7:E9, 2) 📖 기출문제집 p.807
  1. 안쪽 INDEX(A2:C5, 2, 2)부터 계산: A2:C5 범위에서 2행 2열의 값 = "C123"
  2. 바깥 HLOOKUP("C123", B7:E9, 2) 계산: B7:E9의 첫 행에서 "C123"을 찾고, 2번째 행(같은 열)의 값을 반환
  3. 결과 = "알고리즘"
계산 예제: =VLOOKUP(LARGE(C4:C11,3), C4:F11, 4, 0) 📖 기출문제집 p.808
  1. 안쪽 LARGE(C4:C11, 3): C4:C11 중 3번째로 큰 값을 찾음 → 13 (동일값이 여러 개면 먼저 나오는 것을 사용)
  2. 바깥 VLOOKUP(13, C4:F11, 4, 0): C열(1열 기준)에서 13을 찾고, 같은 행의 4번째 열(판매금액) 값을 반환
  3. 결과 = 2,380

재무 함수 — FV / ROUNDDOWN 📖 기출문제집 p.809

=FV(rate, nper, pmt, [pv], [type]) — 고정 이자율로 미래가치를 계산. rate(기간별 이자율)와 nper(총 납입기간)는 같은 단위로 맞춰야 한다 (연이율을 월단위 기간에 쓰려면 12로 나눈다).

예제: 연이율 4%, 3년 월복리 적금의 만기지급금 (10원 미만 절삭)
  1. 월 이자율로 환산: rate = 4%/12
  2. 총 납입 개월 수: nper = 3*12 = 36개월
  3. 월 적립액은 저축(지출)이므로 음수로 입력: pmt = -B2
  4. 10원 단위 미만 절삭 → ROUNDDOWN(FV(4%/12, 3*12, -B2), -1) (num_digits가 음수면 소수점 왼쪽 자리에서 내림 — "-1"은 1의 자리를 버려 10원 단위로 만듦)

데이터 시각화 도구

도구설명
스파크라인 (Sparkline)단일 셀 안에 표시되는 미니 차트. 선형·열(막대)·승패 방식으로 추세를 빠르게 파악
슬라이서 (Slicer)버튼 클릭만으로 데이터를 직관적으로 필터링하는 도구
피벗 테이블 (Pivot Table)복잡한 데이터를 표로 재구성해 합계·평균·개수 등 통계를 확인
파워 쿼리 (Power Query)여러 데이터 원본을 가져와 변환·정리 후 엑셀에 로드

📌시험 빈출 포인트

  • VLOOKUP=세로(첫 열 기준), HLOOKUP=가로(첫 행 기준) — 이름의 V(Vertical)/H(Horizontal)로 암기
  • MATCH는 값이 아니라 위치(순번)를 반환한다는 점을 항상 헷갈림
  • 절대참조($A$1)·상대참조(A1)·혼합참조($A1, A$1) 구분 — 복사했을 때 뭐가 바뀌고 안 바뀌는지
  • 중첩함수는 반드시 안쪽 함수부터 계산해서 바깥에 대입
  • INT(음수)는 소수점 버림이 아니라 더 작은 정수로 내림 (INT(-3.14)=-4)
  • OR은 하나만 참이어도 참, AND는 전부 참이어야 참
  • FV 함수에서 rate·nper 단위를 반드시 맞춰야 함 (연이율→월이율 변환 등)
