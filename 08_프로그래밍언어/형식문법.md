# 형식 문법 (Formal Grammar)

## 핵심 요약
> 형식 문법은 프로그래밍 언어의 문법을 수학적으로 정의하는 체계이다.
> **G = (V_N, V_T, P, S)** 4가지 구성요소로 이루어진다.

## 주요 개념

### 형식 문법의 4가지 구성요소

**G = (V_N, V_T, P, S)**

| 기호 | 이름 | 의미 | 비유 |
|------|------|------|------|
| **V_N** | 비단말 기호 (Non-terminal) | 다른 기호로 대체될 수 있는 기호 | 레시피의 "반죽" → 세부 단계가 있음 |
| **V_T** | 단말 기호 (Terminal) | 더 이상 대체할 수 없는 최종 기호 | 레시피의 "소금 1g" → 최종 재료 |
| **P** | 생성 규칙 (Production) | 비단말을 어떻게 변환하는지의 규칙 | "반죽 → 밀가루 + 물 + 소금" |
| **S** | 시작 기호 (Start) | 문법의 출발점 (V_N의 원소 중 하나) | 레시피의 "완성 요리" |

### 예시로 이해하기

```
G = ({S, A}, {a, b}, P, S)

생성 규칙 P:
  S → aA
  A → b

생성 과정: S → aA → ab
```
- V_N (비단말): {S, A} — 바꿀 수 있는 것
- V_T (단말): {a, b} — 최종 결과물
- 시작 기호 S에서 출발하여 규칙을 적용하면 최종 문자열 "ab"가 생성됨

## 오토마타 (Automata) 쉽게 이해하기

### 오토마타란?
**문자열을 넣으면 "이 문법에 맞아? ✅ / 안 맞아? ❌"를 판단하는 자동 기계**

놀이공원 키 측정기처럼, 입력을 받아서 통과/불합격을 자동으로 판별한다.

---

### 3형 → 유한 오토마타 (FA: Finite Automata)

**가장 단순한 기계. 기억 장치가 없다.**

비유: **자동 개찰구** — 카드를 찍으면 열리고 안 찍으면 안 열림. 이전에 누가 지나갔는지 기억 못 함. 오직 "지금 상태"만 보고 판단.

- 할 수 있는 것: `aaa`, `ababab` 같은 단순 반복 패턴
- 할 수 없는 것: "a가 3개면 b도 3개" → 개수를 세려면 기억이 필요한데 없음!

---

### 2형 → 푸시다운 오토마타 (PDA: Pushdown Automata)

**유한 오토마타 + 스택(Stack) 1개를 가진 기계**

비유: **접시 쌓기 기계** — 접시를 쌓고(push) 빼면서(pop) 개수를 셀 수 있음.
"a 나올 때마다 접시 쌓고, b 나올 때마다 빼서, 끝에 0개면 OK!"

- 할 수 있는 것: `aabb`, `aaabbb` (a 개수 = b 개수) → 스택으로 셀 수 있음
- 할 수 없는 것: `aabbcc` (a, b, c 개수 모두 같아야 함) → 스택 하나로 두 개를 동시에 못 셈

---

### 1형 → 선형 한정 오토마타 (LBA: Linear Bounded Automata)

**유한 오토마타 + 입력 길이만큼의 메모리(테이프)를 가진 기계**

비유: **줄 노트에 메모하며 검사하는 사람** — 여러 가지를 적어가며 동시에 확인 가능. 단, 메모 공간이 입력 길이만큼만 제한됨.

- 할 수 있는 것: `aabbcc` (a, b, c 개수 모두 같음) → 메모하면서 동시에 셀 수 있음

---

### 0형 → 튜링 머신 (TM: Turing Machine)

**무한한 메모리(테이프)를 가진 최강 기계**

비유: **무한 메모장을 가진 천재** — 뭐든 적고, 지우고, 왔다 갔다 하며 계산 가능. 이론상 컴퓨터가 할 수 있는 모든 것을 할 수 있다.

---

### 오토마타 능력 비교

```
약한 기계 ←――――――――――――――――→ 강한 기계

3형           2형              1형             0형
유한오토마타   푸시다운오토마타   선형한정오토마타  튜링머신
(기억 없음)   (스택 1개)       (제한 메모리)    (무한 메모리)
단순패턴      괄호짝 맞추기     복잡한 조건      뭐든 가능
```

## 촘스키 문법 분류 (Chomsky Hierarchy)

### "제한"이란?
생성 규칙 `α → β`를 쓸 때 **어떤 조건을 지켜야 하는가**가 제한이다.

| 타입 | 제한 | 쉬운 말 | 예시 |
|------|------|--------|------|
| **0형** | 없음 | 아무렇게나 바꿔도 됨 | `aAb → cd` ← 자유 |
| **1형** | \|α\| ≤ \|β\| | 바꾼 결과가 원래보다 짧으면 안 됨 | `aAb → aXYb` (3→4 ✅) |
| **2형** | 좌변이 비단말 1개 | `A → ...` 형태만 가능 | `A → aBC` ✅ |
| **3형** | A → aB 또는 A → a | 단말 + 비단말 하나, 또는 단말 하나만 | `A → aB` ✅ |

### 전체 매칭 표

| 타입 | 문법 이름 | 인식 기계 (오토마타) | 기계의 특징 | 생성 규칙 제한 |
|------|----------|-------------------|-----------|--------------|
| **0형** | 무제한 문법 | 튜링 머신 (TM) | 무한 메모리 | 제한 없음 |
| **1형** | 문맥 의존 문법 (CSG) | 선형 한정 오토마타 (LBA) | 제한 메모리 | 결과가 짧아지면 안 됨 |
| **2형** | 문맥 자유 문법 (CFG) | 푸시다운 오토마타 (PDA) | 스택 1개 | 좌변 비단말 1개 |
| **3형** | 정규 문법 (RG) | 유한 오토마타 (FA) | 기억 없음 | A→aB 또는 A→a |

### 포함 관계
```
0형 ⊃ 1형 ⊃ 2형 ⊃ 3형
(무제한) (문맥의존) (문맥자유) (정규)
```
- 3형이 가장 제한적이고 단순
- 0형이 가장 자유롭고 강력
- **상위 타입은 하위 타입을 모두 포함**

### 암기법
- 문법: **"무문문정"** (무제한 → 문맥의존 → 문맥자유 → 정규)
- 오토마타: **"튜선푸유"** (튜링 → 선형한정 → 푸시다운 → 유한)

## 실제 프로그래밍 언어는 몇 형?

**일반적인 프로그래밍 언어(C, Java, Python 등)는 2형(문맥 자유 문법)에 속한다.**

컴파일러가 코드를 처리할 때 두 단계로 나뉜다:

| 처리 단계 | 하는 일 | 사용 문법 | 비유 |
|----------|--------|----------|------|
| **어휘 분석** (Lexical Analysis) | 글자를 단어(토큰)로 분리 | **3형 (정규 문법)** | 국어의 "맞춤법 검사" |
| **구문 분석** (Syntax Analysis) | 단어들이 문법에 맞는지 검사 | **2형 (문맥 자유 문법)** | 국어의 "문장 구조 검사" |

예시: `int x = 10;`
1. 어휘 분석(3형): `int`, `x`, `=`, `10`, `;` → 단어 하나하나 인식
2. 구문 분석(2형): `int x = 10;` → 이 문장이 문법 규칙에 맞는지 검사

## 시험 빈출 포인트

- **G = (V_N, V_T, P, S)** 4요소를 묻는 문제 → 각 요소의 이름과 의미 암기
- 촘스키 분류에서 **타입 번호 ↔ 문법 이름 ↔ 오토마타** 매칭 문제
- 문맥 자유 문법(2형)은 **프로그래밍 언어 구문 분석(Syntax Analysis)**에 주로 사용
- 정규 문법(3형)은 **어휘 분석(Lexical Analysis)**에 사용
- BNF(배커스-나우르 표기법)는 **문맥 자유 문법**을 표현하는 방법
- 0형 ⊃ 1형 ⊃ 2형 ⊃ 3형 **포함 관계** 문제
- "프로그래밍 언어의 구문 정의에 사용되는 문법은?" → **문맥 자유 문법 (2형)**
- "컴파일러의 어휘 분석에 사용되는 문법은?" → **정규 문법 (3형)**

## 헷갈리는 개념 비교

| 구분 | 비단말 기호 (V_N) | 단말 기호 (V_T) |
|------|-----------------|----------------|
| 대체 가능 | O (다른 기호로 바뀜) | X (최종 기호) |
| 표기 관례 | 대문자 (A, B, S) | 소문자 (a, b, c) |
| 역할 | 중간 과정 | 최종 결과 |

| 구분 | BNF | EBNF |
|------|-----|------|
| 정식명 | 배커스-나우르 표기법 | 확장된 BNF |
| 반복 표현 | 재귀로 표현 | { }, [ ], ( ) 사용 |
| 가독성 | 낮음 | 높음 |
| 표현력 | 동일 | 동일 (편의성 향상) |
