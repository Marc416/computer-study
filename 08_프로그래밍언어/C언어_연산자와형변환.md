# C언어 연산자와 형변환

## 핵심 요약
> **정수 ÷ 정수 = 정수** (소수점 버림!)
> float 변수에 넣어도, 계산이 먼저 끝난 뒤 대입되므로 이미 잘린 후다.
> 비트 연산(&, |)과 논리 연산(&&, ||)을 구별하자.

---

## 주요 개념

### 1. 정수 나눗셈 (가장 빈출!)

```c
float i;
i = 100 / 300;  // → i = 0.0
```

**왜 0.0일까?**
- `100`과 `300` 둘 다 **정수(int)**
- C에서 정수끼리 나누면 → **결과도 정수** → `100/300 = 0`
- 그 다음 float 변수 `i`에 대입 → `0` → `0.0`
- 🍕 비유: 피자 1판을 3명이 나눌 때, "정수 세계"에서는 한 명당 0판. 이미 0판으로 결정된 뒤에 소수점 그릇(float)에 담아도 0.0판.

**실수 나눗셈이 되려면?** → 한쪽이라도 실수여야 함

```c
i = 100.0 / 300;   // → 0.333...  (100.0이 float)
i = 100 / 300.0;   // → 0.333...  (300.0이 float)
i = (float)100/300; // → 0.333...  (캐스팅)
```

### 2. 비트 연산자 (& , |)

비트 단위로 한 자리씩 비교하는 연산

```
1 = 01 (2진수)
2 = 10 (2진수)
```

| 연산 | 방법 | 예시 (1과 2) | 결과 |
|------|------|-------------|------|
| `&` (AND) | 둘 다 1이면 1 | `01 & 10` = `00` | **0** |
| `\|` (OR) | 하나라도 1이면 1 | `01 \| 10` = `11` | **3** |
| `^` (XOR) | 서로 다르면 1 | `01 ^ 10` = `11` | **3** |

### 3. 논리 연산자 (&& , ||)

참/거짓을 판단하는 연산 (0이면 거짓, 나머지는 참)

| 연산 | 의미 | 예시 |
|------|------|------|
| `&&` | 둘 다 참이어야 참 | `0 && 3` → **0(거짓)** |
| `\|\|` | 하나만 참이면 참 | `0 \|\| 1` → **1(참)** |

**우선순위**: `&&`가 `||`보다 **먼저** 계산됨!

```c
j && k || i
= (j && k) || i    // &&가 먼저!
= (0 && 3) || 0
= 0 || 0
= 0 (거짓) → else 실행
```

### 4. printf 서식 지정자

| 서식 | 의미 | 예시 |
|------|------|------|
| `%.1f` | 소수점 1자리 실수 | `0.0` |
| `%d` | 정수 | `0`, `3` |
| `%03d` | 3자리, 빈자리 0채움 | `003` |
| `%5d` | 5자리, 빈자리 공백 | `    3` |
| `%-5d` | 5자리, 왼쪽정렬 | `3    ` |

## 기출 문제 풀이 (2010 계리직)

```c
#define VALUE1  1
#define VALUE2  2
main() {
    float i;
    int j, k, m;

    i = 100/300;          // 정수/정수 = 0 → i = 0.0
    j = VALUE1 & VALUE2;  // 1 & 2 = 01 & 10 = 00 → j = 0
    k = VALUE1 | VALUE2;  // 1 | 2 = 01 | 10 = 11 → k = 3

    if (j && k || i)      // (0&&3)||0 = 0||0 = 0 → 거짓
        m = i + j;
    else
        m = j + k;        // 0 + 3 = 3

    printf("i=%.1f j=%d k=%d m=%03d\n", i, j, k, m);
}
```

**출력: `i=0.0 j=0 k=3 m=003`** → **정답: ①**

## 시험 빈출 포인트

- `정수/정수 = 정수` 함정 (float 변수여도 소용없음!)
- 비트연산 `&`, `|`와 논리연산 `&&`, `||` 구분
- `&&`가 `||`보다 우선순위 높음
- printf 서식: `%03d`(0채움), `%.1f`(소수점자리)

## 헷갈리는 개념 비교

| 구분 | 비트 연산 | 논리 연산 |
|------|-----------|-----------|
| 기호 | `&`, `\|` | `&&`, `\|\|` |
| 대상 | 각 비트(0/1) 하나씩 | 값 전체의 참/거짓 |
| 결과 | 숫자 | 0 또는 1 |
| 예시 | `1 & 2 = 0` | `1 && 2 = 1` |

| 구분 | `100/300` | `100.0/300` |
|------|-----------|-------------|
| 연산 타입 | 정수 나눗셈 | 실수 나눗셈 |
| 결과 | `0` | `0.333...` |
| float에 저장 | `0.0` | `0.333...` |

## 기출 문제 풀이 (2023 국가직)

```c
#include <stdio.h>
void main() {
    int x = 0x15213F10 >> 4;
    char y = (char) x;
    unsigned char z = (unsigned char) x;
    printf("%d, %u", y, z);
}
```

### 풀이 과정

**1단계: 비트 시프트**
```
0x15213F10 >> 4 = 0x015213F1
```
> 16진수에서 >>4는 끝자리 하나를 지우는 것과 같다 (16진수 1자리 = 4비트)

**2단계: `char y = (char) x` — signed 캐스팅**
- char는 1바이트(8비트)만 저장 → x의 마지막 1바이트만 취함
- 0x015213F1 → **0xF1**
- char는 signed → 2의 보수로 해석
```
0xF1 = 1111 0001
       ↑ 최상위비트 1 → 음수!
비트반전: 0000 1110 → +1 → 0000 1111 = 15
∴ y = -15
```

**3단계: `unsigned char z = (unsigned char) x` — unsigned 캐스팅**
- 마찬가지로 마지막 1바이트 0xF1
- unsigned이므로 부호 없이 그대로: 0xF1 = **241**

**4단계: printf 출력**
| 변수 | 포맷 | 의미 | 결과 |
|------|------|------|------|
| y | %d | 부호 있는 정수 | **-15** |
| z | %u | 부호 없는 정수 | **241** |

**출력: `-15, 241`** → **정답: ③**

### 핵심 포인트
> 같은 비트 0xF1이라도 **signed(-15)** vs **unsigned(241)** 해석이 다르다!

| 타입 | 0xF1 해석 |
|------|-----------|
| `char` (signed) | -15 |
| `unsigned char` | 241 |
