# C언어 특징

## 핵심 요약
> C는 1972년 데니스 리치가 만든 **절차지향 언어**로, 하드웨어에 가까운 저수준 제어가 가능하면서도 고급 언어 문법을 갖춘 **중급 언어**이다.

## 주요 특징

### 1. 절차지향 언어
- 위에서 아래로 순서대로 실행 (함수 단위로 구성)
- Kotlin/Java는 **객체지향**, C는 **절차지향**
- 비유: 객체지향 = 역할 분담, 절차지향 = 레시피 순서대로

### 2. 중급 언어 (고급 + 저급)
- 고급 언어 문법(if, for, 함수) + 저급 언어 기능(포인터, 비트 연산, 메모리 직접 접근)
- 하드웨어를 직접 제어할 수 있어서 **운영체제(OS), 임베디드** 개발에 사용

### 3. 이식성(portability)이 높다
- 다양한 플랫폼에서 컴파일 가능
- 한 번 작성하면 여러 OS에서 사용 가능 (단, 재컴파일 필요)

### 4. 전처리기(Preprocessor) 지원
- `#include`, `#define`, `#ifdef` 등 **컴파일 전 텍스트 가공** 단계가 있음
- Java/Kotlin에는 없는 C/C++만의 특징
- 빌드 순서: **전처리기 → 컴파일러 → 어셈블러 → 링커** (전컴어링)

### 5. 포인터 사용 가능
- 메모리 주소를 직접 다룰 수 있음
- 강력하지만 실수하면 위험 (메모리 누수, 잘못된 접근)
- Kotlin/Java에는 포인터 개념 없음 (JVM이 자동 관리)

### 6. String 타입이 없다
- 문자열 = `char` 배열 + null 문자(`\0`)
- 문자열 여러 개 = char 2차원 배열
- **"문자 배열은 다차원으로 구성할 수 있다"** (O)

### 7. 수동 메모리 관리
- `malloc()`으로 할당, `free()`로 해제
- Kotlin/Java는 **가비지 컬렉터(GC)**가 자동 관리

## Kotlin/Java와 비교

| 구분 | C | Kotlin/Java |
|------|---|-------------|
| 패러다임 | 절차지향 | 객체지향 |
| 수준 | 중급 언어 | 고급 언어 |
| 메모리 관리 | 수동 (malloc/free) | 자동 (GC) |
| 포인터 | 있음 | 없음 |
| 문자열 | char 배열 | String 클래스 |
| 전처리기 | 있음 (#include, #define) | 없음 (import, const로 대체) |
| 빌드 단계 | 4단계 (전컴어링) | javac가 한 번에 바이트코드 생성 |
| 실행 방식 | 기계어로 직접 실행 | JVM 위에서 실행 |

## 시험 빈출 포인트

- C는 **절차지향** 언어 (객체지향 아님!)
- C는 **중급 언어** (고급 + 저급 특성 모두)
- C의 **이식성이 높다** = 여러 플랫폼에서 사용 가능
- **전처리기**는 C/C++의 고유 특징
- C에서 문자열은 **null 문자(`\0`)로 끝나는 char 배열**
- **포인터**로 메모리 주소 직접 접근 가능
- 메모리는 개발자가 **수동으로 관리** (malloc/free)
- C로 만든 대표적인 것: **유닉스(UNIX) 운영체제**
