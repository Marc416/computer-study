프로그래밍 언어의 특징

고급/저급언어, 번역 프로그램, 컴파일 단계, 객체지향 패러다임 · PART 07. 프로그래밍언어론

핵심 요약

컴퓨터는 기계어(0과 1)만 이해한다. 사람이 쓰기 편한 고급언어를 기계어로 바꿔주는 게 번역 프로그램(컴파일러/인터프리터)이다.

객체지향 언어의 4대 특성은 캡슐화·상속·다형성·추상화다.

💡주요 개념

고급언어 vs 저급언어 📖 기출문제집 p.673

구분저급언어 (Low-level)고급언어 (High-level)
예시기계어, 어셈블리어C, Java, Python, COBOL, Fortran 등
이해하기 쉬운 대상컴퓨터(하드웨어)사람
이식성낮음 (하드웨어 종속적)높음
함정 주의: 자바·코볼·포트란은 전부 고급언어다. "저급언어를 고르시오" 문제에서 어셈블리어만 저급언어로 분류된다.

언어 번역 프로그램 — 누가 기계어로 바꿔주나 📖 기출문제집 p.676~678

종류번역 대상번역 단위
어셈블러어셈블리어 → 기계어-
컴파일러고급언어 → 기계어(목적 프로그램)파일(전체) 단위 한꺼번에 번역
인터프리터고급언어 → 즉시 실행문장(줄) 단위로 번역하며 바로 실행
프리프로세서(전처리기)컴파일 전 원시 프로그램을 가공매크로 치환, include 처리 등

컴파일러는 "번역 후 실행"이라 목적 프로그램을 저장할 공간이 더 필요하지만, 한 번 번역해두면 반복 실행이 빠르다. 인터프리터는 저장 공간은 적게 들지만 실행할 때마다 매번 다시 해석하므로 반복문이 많은 프로그램에서는 느리다.

객체지향 프로그래밍의 4대 특성

특성의미
캡슐화 (Encapsulation)데이터와 메소드를 하나로 묶고, 외부에서 직접 접근 못하게 숨김(정보 은닉)
상속 (Inheritance)기존 클래스의 속성·기능을 물려받아 새 클래스를 만듦 (여러 클래스 조합이 아님)
다형성 (Polymorphism)같은 이름의 메소드가 상황에 따라 다르게 동작 (오버로딩·오버라이딩으로 구현)
추상화 (Abstraction)공통 특징만 뽑아 추상 클래스/인터페이스로 표현, 추상 클래스는 직접 객체 생성 불가
함정 주의: "상속이란 여러 클래스를 조합해 새 클래스를 만드는 것" → ❌ 틀림. 상속은 기존 클래스 하나(또는 그 계층)의 속성을 물려받는 것이다. Java 클래스 자체 재사용(다중 상속)과 헷갈리지 말 것 — 자세한 오버로딩/오버라이딩 예제는 JAVA 기초와 객체지향 문서 참고.

웹 스크립트 언어 — 서버 측 vs 클라이언트 측 📖 기출문제집 p.674

구분실행 위치대표 언어
서버 측 스크립트웹 서버에서 실행 후 결과(HTML)만 전송ASP, JSP, PHP, CGI
클라이언트 측 스크립트사용자의 웹 브라우저에서 실행JavaScript, VBScript
함정 주의: "CGI 프로그램은 클라이언트에서 실행된다" → ❌ 틀림. CGI·ASP·JSP·PHP는 모두 서버 측에서 실행된다.

📌시험 빈출 포인트

  • 고급언어(자바·코볼·포트란 등) vs 저급언어(기계어·어셈블리어) 구분
  • 컴파일러(파일 단위, 목적 프로그램 생성) vs 인터프리터(문장 단위, 목적 프로그램 미생성) 차이
  • 반복문이 많으면 컴파일러 방식이 더 효율적 (인터프리터는 매번 재해석)
  • 컴파일 7단계 순서: 어휘분석→구문분석→의미분석→중간코드생성→코드최적화→목적코드생성→링킹
  • 객체지향 4대 특성(캡슐화·상속·다형성·추상화) 정의 구분
  • 서버 측 스크립트(ASP/JSP/PHP/CGI) vs 클라이언트 측 스크립트(JavaScript) 구분
