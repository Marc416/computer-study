Python 기초

자료형·슬라이싱·재귀·클래스·예외처리 · PART 07. 프로그래밍언어론

핵심 요약

Python은 변수 선언 시 자료형을 지정하지 않는다 — 값을 넣는 순간 타입이 정해진다(동적 타이핑). 그리고 인터프리터 방식으로 한 줄씩 실행되는 플랫폼 독립적 언어다.

자료구조 4형제 — 리스트(변경 O, 중복 O), 튜플(변경 X, 중복 O), 집합(변경 O, 중복 X, 순서 X), 딕셔너리(key-value) — 이 성격 차이를 묻는 문제가 압도적으로 많다.

💡주요 개념

Python 언어의 특징 📖 기출문제집 p.789~790

  • 변수 선언이 없다 — 다른 언어처럼 int a; 처럼 타입을 미리 정하지 않고, a = 10처럼 값을 넣는 순간 "아, 이건 정수구나"하고 타입이 결정된다. (동적 타이핑, Dynamic Typing)
  • 인터프리터 언어 — C처럼 통째로 컴파일한 뒤 실행하는 게 아니라, 한 줄씩 번역하면서 바로 실행한다. 그래서 대화식(interactive)으로 한 줄씩 테스트해볼 수 있다.
  • 플랫폼 독립적 — 윈도우에서 짠 코드가 맥·리눅스에서도 그대로 돌아간다.
  • 객체지향 지원 — class 키워드로 클래스를 정의하고 객체(인스턴스)를 만들 수 있다.
함정 주의: "변수 선언 시 변수명 앞에 데이터형을 지정해야 한다" → ❌ 틀렸다. 그건 C/Java 얘기고, Python은 타입을 안 적는다.

리스트 인덱싱과 슬라이싱 📖 기출문제집 p.790

바보도 이해하는 인덱싱 규칙: 리스트의 첫 번째 칸은 0번부터 시작한다. "3번째 칸"이 아니라 "인덱스 3"이라고 부르면 헷갈리지 않는다. range(시작, 끝, 간격)은 "끝"에 해당하는 숫자는 포함하지 않는다.

예제 풀이: val=[1..12]일 때 for i in range(2,len(val),3): rst += val[i] 의 결과는?
  1. len(val) = 12 → range(2, 12, 3)이 만드는 i 값: 2, 5, 8, 11
  2. i=2 → val[2]=3 → rst = 0+3 = 3
  3. i=5 → val[5]=6 → rst = 3+6 = 9
  4. i=8 → val[8]=9 → rst = 9+9 = 18
  5. i=11 → val[11]=12 → rst = 18+12 = 30

튜플 슬라이싱 📖 기출문제집 p.793

함정 주의: 튜플(tuple)은 ()로 표현하고 값을 바꿀 수 없다. 리스트처럼 .pop()이나 값 대입이 불가능 — "data2는 갱신되지 않는다"가 자주 나오는 정답 포인트.

재귀 함수(Recursion) 📖 기출문제집 p.792

재귀함수는 "자기 자신을 다시 호출하는 함수"다. 종이인형 뽑기처럼 계속 안으로 들어갔다가(호출), 맨 안쪽에서 멈추는 조건(base case)을 만나면 답을 하나씩 곱하면서 다시 밖으로 나온다.

계산 순서:
  1. cals(4) 호출 → 4는 1이 아니므로 4 × cals(3) 을 계산해야 함 (일단 보류)
  2. cals(3) 호출 → 3 × cals(2) (보류)
  3. cals(2) 호출 → 2 × cals(1) (보류)
  4. cals(1) 호출 → 기저조건! 1을 반환 (더 이상 호출 안 함)
  5. 되돌아가며 계산: cals(2)=2×1=2 → cals(3)=3×2=6 → cals(4)=4×6=24

자료구조 4형제: 리스트·튜플·집합·딕셔너리 📖 기출문제집 p.793~794

구분기호중복순서변경(mutable)예시
리스트 (list)[ ]허용있음가능 (append, pop 등)[1,3,5,7]
튜플 (tuple)( )허용있음불가능(1,3,5,7)
집합 (set){ }불허(자동 제거)없음가능 (add 등){1,3,5,7}
딕셔너리 (dict){key:value}key는 불허있음(3.7+)가능{'name':'nam'}
예제: a=[1,3,5,7], b={1,3,5,7}, c=(1,3,5,7) 에 a.append(3), b.add(3) 실행 후 len(a)+len(b)+len(c)는?
  1. a는 리스트 → 중복 허용 → append(3) 하면 [1,3,5,7,3] → len(a) = 5
  2. b는 집합 → 중복 불허 → add(3) 해도 이미 3이 있어서 그대로 {1,3,5,7} → len(b) = 4
  3. c는 튜플 → 애초에 변경 자체가 불가능, 그대로 (1,3,5,7) → len(c) = 4
  4. 5 + 4 + 4 = 13

집합(set)으로 중복 제거하기: set(['apple','banana','orange','apple','apple','banana']) → 중복이 사라져 {'apple','banana','orange'} 3개만 남는다. "리스트에서 서로 다른 값이 몇 개인지 세라"는 문제는 항상 set으로 감싸고 len()을 쓰면 풀린다.

클래스와 객체 📖 기출문제집 p.791~792

비유: 클래스 = 붕어빵 틀, 객체(인스턴스) = 붕어빵. 틀(class Student)은 하나지만, 그 틀로 여러 개의 붕어빵(학생 객체 3명)을 찍어낼 수 있고, 각 붕어빵(객체)은 자기만의 팥(id, kor, eng 값)을 담고 있다.
문법의미
class Student:Student라는 이름의 클래스(틀) 정의
def __init__(self, id, kor, eng):생성자 — 객체를 만들 때 자동으로 실행되어 초깃값을 채움
self.id = id이 객체(self) 자신의 id 속성에 값을 저장
Student("ok", 90, 100)Student 틀로 새 객체(붕어빵) 1개 생성
self가 뭔가요: "지금 이 붕어빵(만들어지고 있는 바로 그 객체)"을 가리키는 자기참조 변수. 메소드를 정의할 때는 항상 첫 번째 매개변수로 self를 적어줘야 한다.

예외처리 (try / except) 📖 기출문제집 p.794~795

키워드역할
try:에러가 날 수도 있는 위험한 코드를 일단 실행해본다
except:try 안에서 에러(예외)가 발생했을 때만 대신 실행된다
비유: try는 "일단 해보고", except는 "터지면 이렇게 처리해" — 안전벨트 같은 것. 문자열('92')과 숫자(90)를 >=로 비교하면 파이썬은 에러를 내는데, 그 순간 except가 받아서 프로그램이 죽지 않고 계속 돈다.

📌시험 빈출 포인트

  • "변수 선언 시 데이터형을 지정해야 한다" → ❌ Python은 타입을 안 씀 (동적 타이핑)
  • range(시작,끝,간격)은 "끝"을 포함하지 않는다 — 슬라이싱 [a:b]도 마찬가지로 b는 미포함
  • 리스트[변경O,중복O] / 튜플[변경X,중복O] / 집합[변경O,중복X,순서X] / 딕셔너리[key-value] 성격 구분
  • 재귀함수 문제는 기저조건(base case)까지 내려갔다가 값을 곱하며 되돌아오는 과정을 손으로 그려서 풀 것
  • 클래스의 생성자는 __init__, 첫 매개변수는 항상 self
  • 중복 제거 개수를 물으면 → set()으로 감싸고 len()
  • try/except: try에서 에러 나면 except로 넘어가고, 프로그램은 죽지 않는다
