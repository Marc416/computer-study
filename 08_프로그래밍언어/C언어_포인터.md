# C언어 포인터

## 핵심 요약
> 포인터는 **메모리 주소를 저장하는 변수**. `*`(역참조)를 붙이면 그 주소에 있는 **실제 값**에 접근한다.

## 주요 개념

### 포인터란?
변수의 **주소를 담는 변수**. 비유하면 "집 주소가 적힌 메모지"

```c
int x = 100;
int *px = &x;   // px에 x의 주소를 저장
```

### 핵심 연산자 2가지

| 연산자 | 이름 | 의미 | 비유 |
|--------|------|------|------|
| `&` | 주소 연산자 | 변수의 주소를 꺼냄 | "이 집 주소 알려줘" |
| `*` | 역참조 연산자 | 그 주소에 가서 값을 꺼냄 | "그 주소로 가서 문 열어봐" |

```c
int x = 100;
int *px = &x;

// px  → x의 주소 (예: 0x7fff...)
// *px → 100 (x의 실제 값)
// &x  → x의 주소
```

### ⚠️ `*`의 두 가지 의미 (시험 함정!)

**선언할 때와 사용할 때 의미가 완전히 다르다!**

| 상황 | 코드 | `*`의 역할 |
|------|------|-----------|
| 선언 | `int *ptr;` | "이 변수는 포인터입니다" (타입 표시) |
| 사용 | `*ptr = 100;` | "가리키는 곳에 가서 값을 넣어라" (역참조) |

```c
int x = 50;
int *ptr;         // 선언: ptr은 포인터다

ptr = &x;         // ptr에 x의 주소를 저장 (주소를 넣는 것)
*ptr = 100;       // ptr이 가리키는 곳(x)에 100을 저장 (값을 넣는 것)
// → x는 100이 됨
```

**핵심 구분:**

| 코드 | 의미 | 대상 |
|------|------|------|
| `ptr = &x` | ptr에 **주소**를 넣음 | 포인터 자체를 변경 |
| `*ptr = 100` | ptr이 가리키는 곳에 **값**을 넣음 | 가리키는 변수를 변경 |

```c
// ✅ 올바른 사용
int *ptr = &x;      // 선언+초기화 (ptr이 x를 가리킴)
ptr = &x;           // ptr에 x의 주소를 저장
*ptr = 100;         // x의 값을 100으로 변경

// ❌ 잘못된 사용
*ptr = &x;          // 틀림! "가리키는 곳에 주소를 넣어라"가 됨
```

### `(*px)` 괄호의 의미
- 이 문제에서 `(*px) -= 10`의 괄호는 **가독성 용도** (없어도 결과 동일)
- `*`가 `-=`보다 우선순위가 높아서 `*px -= 10`도 같은 동작
- 단, **배열 포인터**에서는 괄호 유무로 의미가 완전히 달라짐

| 표현 | 의미 |
|------|------|
| `(*p)[3]` | p가 가리키는 **배열**의 3번째 원소 |
| `*p[3]` | 포인터 **배열** p의 3번째가 가리키는 값 |

### 배열과 포인터의 관계

배열 이름은 **첫 번째 원소의 주소**를 의미한다.

```c
int array[] = {100, 200, 300, 400, 500};
int *ptr;
ptr = array;     // ptr = &array[0] 과 같은 의미
```

배열은 메모리에 **연속으로** 저장되기 때문에, 시작 주소 하나만 알면 나머지는 +1, +2로 찾아갈 수 있다. (아파트 101호 위치만 알면 102호, 103호는 바로 옆)

```
메모리 (연속된 공간)
[100][200][300][400][500]
  ↑
 ptr는 여기(시작점)만 저장
```

| 인덱스 | array[0] | array[1] | array[2] | array[3] | array[4] |
|--------|----------|----------|----------|----------|----------|
| 값 | 100 | 200 | 300 | 400 | 500 |
| 포인터 | ptr | ptr+1 | ptr+2 | ptr+3 | ptr+4 |

**동일한 표현 3가지 (반드시 암기!):**

```
*(ptr + i)  =  ptr[i]  =  array[i]
```

### 기출 문제: 배열 + 포인터 (51번)

```c
int array[] = {100, 200, 300, 400, 500};
int *ptr;
ptr = array;
printf("%d\n", *(ptr+2)+10);
```

풀이:
1. `ptr+2` → array[2]의 주소
2. `*(ptr+2)` → array[2]의 값 = **300**
3. `*(ptr+2) + 10` → 300 + 10 = **310**

**정답: ④번 310**

## 시험 빈출 포인트

### 1. 포인터 교환 (가장 자주 출제!)
포인터끼리 교환하면 **가리키는 대상만 바뀌고, 실제 변수 값은 안 바뀜**

```c
int x = 100, y = 200;
int *px = &x, *py = &y, *tmp;

// 포인터 교환
tmp = px;    // tmp → x
px = py;     // px → y (원래 x를 가리켰는데 이제 y를 가리킴!)
py = tmp;    // py → x (원래 y를 가리켰는데 이제 x를 가리킴!)

// 교환 후: px는 y를, py는 x를 가리킴
(*px) += 50;  // y에 50 더함 (px가 이제 y를 가리키니까!)
(*py) -= 10;  // x에서 10 뺌 (py가 이제 x를 가리키니까!)
```

### 2. 기출 문제 풀이 추적법 (2025 지방직 48번)

```c
int x = 100, y = 200;
int *px = &x, *py = &y, *tmp;
```

| 단계 | 코드 | x | y | px→ | py→ |
|------|------|---|---|-----|-----|
| 초기 | | 100 | 200 | x | y |
| 1 | `(*px) -= 10` | **90** | 200 | x | y |
| 2 | `(*py) += 50` | 90 | **250** | x | y |
| 3 | `tmp=px; px=py; py=tmp` | 90 | 250 | **y** | **x** |
| 4 | `(*px) += 50` | 90 | **300** | y | x |
| 5 | `(*py) -= 10` | **80** | 300 | y | x |

**출력: x: 80, y: 300 → 정답 ①번**

### 3. 포인터 문제 풀이 팁
- 항상 **표를 그려서** 추적
- 포인터 교환이 나오면 → **화살표 방향이 바뀐다**고 생각
- `*`가 붙으면 → "가서 열어봐", 안 붙으면 → "주소만 봐"

## 헷갈리는 개념 비교

| 구분 | 값 교환 (swap) | 포인터 교환 |
|------|---------------|-------------|
| 코드 | `tmp=*px; *px=*py; *py=tmp` | `tmp=px; px=py; py=tmp` |
| 효과 | x, y **값이** 바뀜 | 포인터가 **가리키는 대상**이 바뀜 |
| 결과 | x=200, y=100 | x=100, y=200 그대로 |

| 구분 | `px` | `*px` | `&x` |
|------|------|-------|------|
| 의미 | 포인터 변수 (주소 저장) | 역참조 (가리키는 값) | 주소 연산 (x의 주소) |
| 비유 | 메모지 자체 | 그 주소 가서 물건 꺼내기 | 집 주소 알아내기 |

## 2차원 배열과 포인터 (심화)

### 핵심 요약
> 2차원 배열에서 `darr`은 **행 단위 포인터**, `*darr`은 **열 단위 포인터**. 별(`*`) 하나 붙일 때마다 한 단계 안으로 들어간다고 생각하면 된다.

### 2차원 배열의 구조

{% raw %}
```c
int darr[3][3] = {{1, 2, 3}, {4, 5, 6}, {7, 8, 9}};
```
{% endraw %}

비유: **아파트 건물**
- `darr` = 건물 전체 (행 단위)
- `darr[0]`, `darr[1]`, `darr[2]` = 각 **층** (행의 시작 주소)
- `darr[1][2]` = 1층의 2호실 (특정 값)

```
         [0]열  [1]열  [2]열
darr[0]:  1      2      3     ← 0층
darr[1]:  4      5      6     ← 1층
darr[2]:  7      8      9     ← 2층
```

### 포인터 표현 완벽 정리 (⭐시험 필수 암기!)

| 표현 | 의미 | 비유 | 값 |
|------|------|------|-----|
| `darr` | 전체 배열의 시작 주소 (행 포인터) | "건물 주소" | 주소값 |
| `darr[i]` | i번째 행의 시작 주소 | "i층으로 가!" | 주소값 |
| `*darr` | = `darr[0]` = 0번째 행의 시작 주소 | "1층 입구" | 주소값 |
| `*darr + n` | 0번째 행에서 n칸 이동 | "1층에서 옆으로 n호실" | 주소값 |
| `*(*darr + n)` | 0번째 행 n번째 값 = `darr[0][n]` | "1층 n호실 문 열기" | **실제 값** |
| `darr[i]` | i번째 행의 시작 주소 | "i층 입구" | 주소값 |
| `*darr[i]` | i번째 행의 첫 번째 값 = `darr[i][0]` | "i층 맨 앞 호실 문 열기" | **실제 값** |

### 동일한 표현 변환표 (암기!)

```
darr[i][j]  =  *(darr[i] + j)  =  *(*(darr + i) + j)
```

| 표현 | 동일 표현 | 설명 |
|------|-----------|------|
| `*darr` | `darr[0]` | 0행 시작 주소 |
| `*(darr+1)` | `darr[1]` | 1행 시작 주소 |
| `**darr` | `darr[0][0]` | 0행 0열의 값 |
| `*(*darr+1)` | `darr[0][1]` | 0행 1열의 값 |
| `*darr[1]` | `darr[1][0]` | 1행 0열의 값 |
| `*(darr[1]+2)` | `darr[1][2]` | 1행 2열의 값 |

### 기출 문제: 2차원 배열 포인터 (60번, 2015 지방직)

{% raw %}
```c
int darr[3][3] = {{1, 2, 3}, {4, 5, 6}, {7, 8, 9}};
int sum1, sum2;

sum1 = *(*darr+1) + *(*darr+2);
sum2 = *darr[1] + *darr[2];
printf("%d, %d", sum1, sum2);
```
{% endraw %}

**sum1 풀이:**

| 단계 | 표현 | 변환 | 값 |
|------|------|------|-----|
| 1 | `*darr` | `darr[0]` (0행 시작 주소) | 주소 |
| 2 | `*darr + 1` | `&darr[0][1]` (0행에서 1칸 이동) | 주소 |
| 3 | `*(*darr+1)` | `darr[0][1]` | **2** |
| 4 | `*(*darr+2)` | `darr[0][2]` | **3** |
| 결과 | sum1 | 2 + 3 | **5** |

**sum2 풀이:**

| 단계 | 표현 | 변환 | 값 |
|------|------|------|-----|
| 1 | `darr[1]` | 1행 시작 주소 | 주소 |
| 2 | `*darr[1]` | `darr[1][0]` | **4** |
| 3 | `*darr[2]` | `darr[2][0]` | **7** |
| 결과 | sum2 | 4 + 7 | **11** |

**출력: 5, 11 → 정답 ③번**

### ⚠️ 가장 헷갈리는 함정

| 표현 | 의미 | 핵심 차이 |
|------|------|-----------|
| `*(*darr + n)` | 0행의 **n번째 열** 값 | `*darr`이 0행 시작 → 거기서 n칸 이동 → 역참조 |
| `*darr[n]` | **n행의 0번째 열** 값 | `darr[n]`이 n행 시작 → 바로 역참조 |

쉽게 외우기:
- `*` 안에 `+n` → **옆으로(열)** 이동
- `[]` 안에 `n` → **아래로(행)** 이동
