# CSS 동적 의사 클래스 (Dynamic Pseudo-Class)

## 핵심 요약
> 의사 클래스 = HTML에 class를 안 써도 **특정 상태**일 때 자동 적용되는 선택자
> 동적 의사 클래스 = **사용자의 행동**(마우스, 클릭, 포커스)에 따라 실시간으로 스타일이 바뀌는 선택자

## 주요 개념

### 의사 클래스(Pseudo-Class)란?
- "의사(Pseudo)" = **가짜**라는 뜻
- HTML에 직접 class를 작성하지 않아도, **특정 상태/조건**에서 자동으로 적용되는 선택자
- 콜론(`:`) 한 개를 사용: `선택자:의사클래스`

### 동적 의사 클래스 종류

| 의사 클래스 | 의미 | 쉬운 설명 |
|------------|------|----------|
| `:link` | 방문하지 않은 링크 | 아직 안 눌러본 링크 |
| `:visited` | 방문한 링크 | 이미 눌러본 링크 |
| `:hover` | 마우스를 올렸을 때 | 커서가 요소 위에 있는 순간 |
| `:active` | 클릭하는 순간 | 마우스 버튼을 누르고 있는 동안 |
| `:focus` | 포커스를 받았을 때 | 입력창을 클릭해서 커서가 깜빡이는 상태 |

### 문법
```css
선택자:의사클래스 {
    속성: 값;
}
```

### 실제 사용 예시
```css
/* 방문 안 한 링크 = 파란색 */
a:link    { color: blue; }

/* 방문한 링크 = 보라색 */
a:visited { color: purple; }

/* 마우스 올리면 빨간색 */
a:hover   { color: red; }

/* 클릭 순간 주황색 */
a:active  { color: orange; }

/* 입력창 포커스 시 테두리 강조 */
input:focus { border: 2px solid blue; }
```

### 동작 원리
```
사용자 행동 발생 (예: 마우스 올림)
    │
    ▼
브라우저가 해당 상태 감지 (:hover)
    │
    ▼
매칭되는 CSS 규칙 적용 (스타일 변경)
    │
    ▼
행동 종료 시 (마우스 벗어남) 원래 스타일로 복귀
```
→ JavaScript 없이 **브라우저가 자동으로** 처리

## LVHA 순서 (시험 필수 암기!)

링크 관련 의사 클래스는 **작성 순서**가 중요하다!

```
L → V → H → A
:link → :visited → :hover → :active
```

> 암기법: **"LoVe HAte"** (사랑과 증오)

순서를 지키지 않으면 스타일이 덮어씌워져서 제대로 동작하지 않음 (CSS 캐스케이딩 원리)

### LVHA 순서가 필요한 이유 (캐스케이딩)

CSS는 같은 우선순위일 때 **나중에 쓴 스타일이 이전 스타일을 덮어쓴다.**

**잘못된 순서 (hover가 무시됨):**
```css
a:hover { color: red; }    /* 먼저 씀 */
a:link  { color: blue; }   /* 나중에 씀 → red를 덮어씀! */
/* 결과: 마우스 올려도 계속 파란색 */
```

**올바른 순서 (정상 동작):**
```css
a:link    { color: blue; }    /* ① 기본 상태 */
a:visited { color: purple; }  /* ② 방문 후 상태 */
a:hover   { color: red; }     /* ③ ①②를 덮어씀 → 마우스 올리면 빨간색 */
a:active  { color: orange; }  /* ④ ③을 덮어씀 → 클릭 순간 주황색 */
```

> 클릭(:active) 순간에는 마우스도 올라가 있으므로(:hover) 두 상태가 동시에 해당됨
> → :active가 나중에 써져 있어야 클릭 스타일이 보임

4개를 전부 쓸 필요는 없지만, **같이 쓸 때는 반드시 L→V→H→A 순서 유지**

## 헷갈리는 개념 비교

### 동적 vs 구조적 의사 클래스

| 구분 | 동적 의사 클래스 | 구조적 의사 클래스 |
|------|----------------|------------------|
| 변화 | 사용자 행동에 따라 **실시간 변화** | HTML 구조에 따라 **고정** |
| 예시 | `:hover` `:active` `:focus` | `:first-child` `:nth-child(n)` `:last-child` |
| 트리거 | 마우스, 키보드 등 사용자 입력 | DOM 트리에서의 위치 |

### 의사 클래스 vs 의사 요소

| 구분 | 의사 클래스 (Pseudo-Class) | 의사 요소 (Pseudo-Element) |
|------|--------------------------|--------------------------|
| 기호 | 콜론 1개 (`:`) | 콜론 2개 (`::`) |
| 대상 | 요소의 **상태**를 선택 | 요소의 **특정 부분**을 선택하거나 가짜 요소 생성 |
| 예시 | `:hover` `:focus` `:first-child` | `::before` `::after` `::first-line` |

### 의사 요소(Pseudo-Element) 상세 설명

**의사 요소** = HTML을 수정하지 않고 CSS만으로 요소의 **특정 부분을 꾸미거나**, **가짜 내용을 삽입**하는 선택자

| 의사 요소 | 의미 | 설명 |
|----------|------|------|
| `::before` | 요소 앞에 내용 삽입 | HTML 안 고치고 앞에 가짜 내용 추가 |
| `::after` | 요소 뒤에 내용 삽입 | HTML 안 고치고 뒤에 가짜 내용 추가 |
| `::first-line` | 첫 번째 줄만 선택 | 문단의 첫 줄만 스타일 변경 |
| `::first-letter` | 첫 글자만 선택 | 문단의 첫 글자만 크게/색상 변경 |

**예시 — HTML:**
```html
<p class="news">오늘 날씨가 좋습니다.</p>
```

**예시 — CSS:**
```css
.news::before       { content: "★ "; color: gold; }
.news::after        { content: " [끝]"; color: gray; }
.news::first-letter { font-size: 40px; color: red; }
.news::first-line   { font-weight: bold; }
```

**결과 (개념적):**
```
★ 오늘 날씨가 좋습니다. [끝]
↑                       ↑
::before               ::after
"오" ← 크고 빨간색 (::first-letter)
```

> `::before`와 `::after`는 반드시 **`content` 속성**이 있어야 동작한다 (빈 값이라도 필요: `content: "";`)

## 시험 빈출 포인트

1. **동적 의사 클래스** = 사용자 행동(마우스, 키보드)에 따라 **실시간 변하는** 선택자
2. **LVHA 순서** (:link → :visited → :hover → :active) 반드시 지킬 것 → 암기: **LoVe HAte**
3. `:hover`는 마우스를 **올렸을 때**, `:active`는 **클릭 중일 때**
4. `:focus`는 **입력 요소에 커서가 위치**했을 때
5. 의사 클래스는 콜론 **1개(`:`)**, 의사 요소는 콜론 **2개(`::`)** — 구분 문제 빈출
6. JavaScript 없이 **CSS만으로** 사용자 인터랙션 스타일링 가능
