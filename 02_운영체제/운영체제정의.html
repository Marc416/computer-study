운영체제 정의

운영체제의 역할·목적·구조 · PART 02. 운영체제론

핵심 요약

운영체제(OS)는 시스템 소프트웨어의 핵심으로, 사용자에게는 편리성을, 시스템에는 자원의 효율적 관리를 제공한다.

운영체제의 목적은 처리량↑, 응답시간↓(감소), 신뢰도↑, 사용가능도↑ — "응답시간 증가"는 틀린 표현이다.

💡주요 개념

시스템 소프트웨어 vs 운영체제 📖 기출문제집 p.185

운영체제(Windows, 유닉스, 리눅스, 안드로이드 등)는 시스템 소프트웨어에 속하며, 하드웨어와 응용 소프트웨어 사이의 매개체 역할을 한다. 컴파일러·언어번역기도 시스템 소프트웨어지만 운영체제는 아니다. 워드프로세서·MS오피스는 응용 소프트웨어다.

정보처리 시스템의 분류 (응답시간·입력방식 기준)

종류특징
일괄처리 (Batch)작업을 모아두었다가 한꺼번에 처리. 처리량(throughput)·반환시간(turnaround time)으로 효율 평가
대화식 (Interactive)터미널로 직접 명령 입력, 즉각적인 피드백 제공
실시간 (Real-time)결과가 현재 결정에 즉시 영향을 주므로 매우 빠른 처리 필요
하이브리드 (Hybrid)대화형 + 일괄처리 결합. 대화형 작업이 없을 때 백그라운드에서 배치 작업 수행
분류 근거: "응답 시간"과 "데이터 입력 방식"이 기준 — 고급언어 사용 여부나 버퍼링 여부가 아니다.

운영체제의 목적

  • 처리량(Throughput) 향상
  • 응답 시간(Response Time) 감소 (증가 X — 자주 나오는 오답 함정)
  • 신뢰도(Reliability) 향상
  • 사용 가능도(Availability) 향상

운영체제의 기능 분류

구분내용
자원관리주기억장치 관리, 보조기억장치 관리, 프로세스 관리, 입출력장치 관리, 파일 관리
시스템관리시스템 보호(사용자 권한 부여), 네트워킹, 명령 해석기
함정 주의: "사용자 권한 관리"는 자원관리가 아니라 시스템관리에 속한다.

운영체제 구조 — 커널과 인터페이스

  • 커널(Kernel): 운영체제의 핵심 기능을 모아둔 부분 (프로세스 관리, 메모리 관리 등)
  • 인터페이스: 사용자·응용프로그램과 인접해 커널에 명령을 전달하고 실행 결과를 돌려줌
  • 디바이스 드라이버: 다양한 장치를 효율적으로 쓰기 위한 하드웨어 인터페이스
  • 시스템 호출(System Call): 사용자 프로그램이 하드웨어에 직접 접근할 수 없으므로, 커널 기능을 대신 요청하도록 해주는 인터페이스
커널 구조특징
단일형 구조 커널초창기 구조, 모듈이 거의 분리되지 않음 → 모듈 간 통신비용은 적지만 유지보수·확장에는 불리
계층형 구조 커널기능을 계층별로 분리
마이크로 구조 커널핵심 기능만 커널에 남기고 나머지는 별도 프로세스로 분리
함정 주의: 커널의 프로세스 관리는 CPU 배분·작업공간 배치가 핵심이며, 가상 메모리 제공은 메모리 관리 기능에 해당한다 (프로세스 관리 아님).

프로세스의 종류

종류설명
운영체제 프로세스시스템 관리 기능 담당, 사용자 프로세스가 다른 영역을 침범하지 못하게 감시
사용자 프로세스사용자 응용프로그램을 수행
병행 프로세스여러 프로세스가 동시에 실행 중인 상태
독립 프로세스다른 프로세스에 영향을 주지도 받지도 않음
협동 프로세스다른 프로세스와 서로 영향을 주고받음 (통신·동기화 수단 필요)
함정 주의: "여러 프로세스가 동시에 수행 상태에 있다 = 교착상태"라는 설명은 틀렸다. 동시 수행은 병행 프로세스이며, 교착상태는 자원을 서로 기다리며 멈춰버린 상태를 말한다.

📌시험 빈출 포인트

  • 운영체제 목적: 응답시간은 감소가 맞음, "증가"라고 나오면 오답
  • 정보처리 시스템 분류 기준 = 응답시간 + 데이터 입력방식
  • 사용자 권한 관리는 자원관리(X), 시스템관리(O)
  • 단일형 구조 커널은 모듈 분리가 안 돼 있어 통신비용이 적은 것이지, "효율적 운영"이 장점의 핵심은 아님 (유지보수 어려움이 단점)
  • 커널의 가상메모리 제공 = 메모리 관리 기능 (프로세스 관리 아님)
  • 시스템 호출 = 사용자 프로그램이 하드웨어에 직접 접근 못하니 커널에 요청하는 인터페이스

⚖️헷갈리는 개념 비교

구분병행 프로세스교착상태(Deadlock)
의미여러 프로세스가 동시에 정상 실행 중서로 자원을 기다리며 영원히 멈춤
구분자원관리시스템관리
포함 기능기억장치·프로세스·입출력·파일 관리사용자 권한(보호), 네트워킹, 명령 해석기
