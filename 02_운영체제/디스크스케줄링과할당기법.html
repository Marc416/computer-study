디스크 스케줄링과 할당 기법

헤드 이동을 최소화하는 스케줄링과 파일을 블록에 배치하는 방법 · PART 02. 운영체제론

핵심 요약

디스크 스케줄링은 헤드가 어떤 순서로 요청을 처리할지 정하는 것(FCFS·SSTF·SCAN·C-SCAN·LOOK·C-LOOK).

디스크 할당은 파일을 디스크 블록에 어떻게 배치할지 정하는 것(연속·연결·색인 할당).

💡주요 개념 — 디스크 스케줄링

디스크 스케줄링 기법 비교

기법동작 방식
FCFS요청 도착 순서대로 처리. 공평하지만 성능은 가장 좋지 않음
SSTF현재 헤드 위치에서 가장 가까운 트랙부터 처리 (방향 무관). 특정 요청이 계속 밀리는 기아현상 가능
SCAN한쪽 끝까지 이동하며 만나는 요청 모두 처리 → 반대로 방향 바꿔 왕복
C-SCANSCAN처럼 이동하되 한쪽 방향으로만 서비스, 끝에 도달하면 서비스 없이 반대쪽 끝으로 되돌아가 다시 그 방향으로만 처리
LOOKSCAN과 비슷하지만 맨 끝(0번/최대트랙)까지 가지 않고 마지막 요청에서 방향 전환
C-LOOKC-SCAN처럼 한쪽으로만 서비스하되, 맨 끝까지 가지 않고 마지막 요청에서 바로 반대쪽 시작점으로 복귀
비유: SCAN·LOOK은 "엘리베이터"처럼 양방향 왕복 운행, C-SCAN·C-LOOK은 "지하철 순환선"처럼 한 방향으로만 돌고 반대편으로 순간이동해 다시 그 방향으로만 돈다.

계산 방법: 매 순간 "지금 헤드 위치에서 남은 요청 중 가장 가까운 트랙이 어디인가"만 반복해서 확인하면 된다. 방향은 상관없이 오직 거리만 비교한다.

SSTF 계산 예제 (2022 국가직): 헤드 위치 50, 요청 큐 = 80,20,100,30,70,130,40 📖 기출문제집 p.263
  1. 현재 50 → 남은 요청 중 가장 가까운 트랙은 40 (거리 10) → 이동
  2. 현재 40 → 가장 가까운 트랙은 30 (거리 10) → 이동
  3. 현재 30 → 가장 가까운 트랙은 20 (거리 10) → 이동
  4. 현재 20 → 남은 건 80,100,70,130뿐, 가장 가까운 트랙은 70 (거리 50) → 이동
  5. 현재 70 → 가장 가까운 트랙은 80 (거리 10) → 이동
  6. 현재 80 → 가장 가까운 트랙은 100 (거리 20) → 이동
  7. 현재 100 → 마지막 남은 130 (거리 30) → 이동
  8. 총 이동 거리 = 10+10+10+50+10+20+30 = 140
C-LOOK 계산 예제: 헤드 위치 50, 이동방향 0→199, 큐 = 65,112,40,16,90,170,165,35,180
진행 방향(50보다 큰 것 오름차순)부터 처리 후 맨 앞(작은 값)으로 순간이동: 50→65→90→112→165→170→180 → (맨 앞으로 복귀) →16→35→40
총 이동 거리 = 318
함정 주의: "N-Step-SCAN이 한 방향으로 움직이는 요구만 처리" 같은 설명은 사실 C-SCAN의 특징을 잘못 붙인 오답 패턴이다. 기법 이름과 설명을 서로 바꿔치기한 선택지에 주의.

🗄️주요 개념 — 디스크 할당 기법

데이터 단위 계층

필드 < 레코드 < 파일 < 데이터베이스 (필드의 집합=레코드, 레코드의 집합=파일, 파일의 집합=데이터베이스)

연속·연결·색인 할당 비교

구분연속 할당 (Contiguous)연결 할당 (Linked)색인 할당 (Indexed)
저장 방식디스크의 연속된 공간에 저장블록들이 디스크 전체에 흩어지고 포인터로 연결색인(인덱스) 블록이 각 블록 주소를 관리
탐색 속도빠름 (탐색 횟수 최소화)느림 (포인터 따라가야 함)보통 (색인만 보면 됨)
단편화외부 단편화 발생 → 주기적 압축 필요외부 단편화 없음외부 단편화 없음
직접 접근가능불가능 (순차 접근만)가능
추가 공간불필요포인터 저장 공간 필요색인 블록 저장 공간 필요
디렉터리 정보시작주소 + 길이(또는 끝주소)첫 블록과 마지막 블록 포인터색인 블록 주소
함정 주의: "연속 할당은 디스크 공간 사용 효율이 높다" → 오답. 검색은 빠르지만 단편화 때문에 공간 효율은 오히려 낮다. "블록 할당 방식은 단편화 해결을 위해 압축이 필요하다" → 압축이 필요한 건 연속 할당이다.

📌시험 빈출 포인트

  • SSTF·C-SCAN·C-LOOK 등 주어진 요청 큐로 헤드 이동 순서·총 이동거리 계산 문제 매년 출제
  • SCAN vs C-SCAN vs LOOK vs C-LOOK 이름과 설명 짝짓기 문제 (설명을 서로 바꿔서 오답 유도)
  • FCFS는 공평하지만 성능이 가장 좋은 기법은 아니다
  • 연속 할당 = 빠른 검색 + 외부 단편화 + 압축 필요 / 연결 할당 = 직접접근 불가 + 단편화 없음
  • 색인 할당은 색인(인덱스) 블록이 파일을 구성하는 블록 주소를 관리
  • 자료 단위 크기 순서: 필드 < 레코드 < 파일 < 데이터베이스
