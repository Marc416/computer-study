트리와 이진트리 순회

전위·중위·후위 순회 · 힙(Heap) · PART 04. 자료구조론

핵심 요약

순회 3형제는 루트를 언제 방문하냐로 구분한다: 전위=먼저, 중위=가운데, 후위=마지막.

왼쪽 서브트리는 항상 오른쪽보다 먼저 — 세 방식 모두 공통이다.

🎯이 단원을 왜 배우나

한 줄로 세우면 느리고, 나무 모양으로 쌓으면 빨라진다

데이터 1,000개를 한 줄(배열·리스트)로 두고 찾으면 최악의 경우 1,000번을 봐야 한다. 그런데 같은 데이터를 나무 모양으로 쌓으면 어떨까? 한 단계 내려갈 때마다 후보가 절반으로 줄어 10번만에 찾을 수 있다(2¹⁰ = 1024). 이것이 트리를 배우는 이유다 — 계층 구조로 쌓으면 탐색 비용이 n에서 log n으로 떨어진다.

게다가 현실의 많은 데이터가 원래 계층적이다. 폴더 안의 폴더, 조직도, HTML 문서 구조, 가계도 모두 트리다. 데이터베이스 인덱스(B-트리), 파일 시스템, 컴파일러의 수식 해석(수식 트리) 전부 트리로 돌아간다.

시험에서 이 단원은 계산 문제가 대부분이다 — ① 노드 수와 간선 수·높이 세기, ② 전위·중위·후위 순회 순서 적기, ③ 주어진 값을 순서대로 넣어 이진탐색트리 만들고 단말노드 세기, ④ 힙 조건 판별. 전부 직접 트리를 그려보면 풀리고, 안 그리면 거의 틀린다. 문제 풀 때 반드시 손으로 그리는 습관을 들여라.

💡주요 개념

트리 용어 📖 기출문제집 p.468~469

용어의미
루트 (Root)트리의 맨 꼭대기 노드 (부모가 없는 유일한 노드)
단말 노드 (Leaf, 잎)자식이 없는 노드
부모 / 자식 노드바로 위 노드가 부모, 바로 아래 노드가 자식
형제 (Sibling) 노드같은 부모를 가지는 노드들 (자식 노드의 정의와 헷갈리는 함정!)
차수 (Degree)한 노드의 자식 수. 트리의 차수 = 트리 안의 모든 노드 중 가장 큰 차수
레벨 (Level)트리 각 층의 번호 (보통 루트를 레벨 1 또는 0으로 둠 — 문제 조건 확인 필수)
높이 (Height)트리의 최대 레벨 = 가장 깊은 곳까지의 층 수
서브트리 (Subtree)어떤 노드를 루트로 삼는 부분 트리
이진트리 (Binary Tree)모든 노드가 자식을 최대 2개(왼쪽·오른쪽)까지만 가질 수 있는 트리

트리와 그래프의 차이: 트리는 사이클(순환)이 없는 비선형 자료구조이고, 그래프는 사이클이 있을 수 있다. 트리도 그래프의 일종(사이클 없는 연결 그래프)이다.

반드시 외워야 하는 세기 공식 3개

  • 간선(edge) 수 = 노드 수 − 1. 루트를 제외한 모든 노드가 자기 위로 가는 간선을 정확히 하나씩 갖기 때문이다. 노드 11개 → 간선 10개. (이보다 많으면 사이클이 생겨 트리가 아니다.)
  • n개 노드 이진트리의 최대 높이 = n. 모든 노드를 한쪽으로만 쭉 늘어뜨리면(편향 트리) 사실상 연결리스트가 되어 높이가 n이 된다. 이때 탐색은 O(n)으로 최악이 된다.
  • n개 노드 이진트리의 최소 높이 = ⌈log₂(n+1)⌉. 각 층을 빈틈없이 꽉 채웠을 때(포화에 가까울 때) 가장 납작해진다. 레벨 k까지 꽉 채우면 노드가 2ᵏ−1개이므로 역으로 구한 것이며, 소수점이 나오면 올림한다.

왜 "+1"이 붙나: 높이 h인 포화 이진트리의 노드 수는 1+2+4+…+2^(h−1) = 2ʰ−1이다. 여기서 n = 2ʰ−1을 h에 대해 풀면 h = log₂(n+1)이 된다.

예: 노드 60개 → 최대 높이 60, 최소 높이 ⌈log₂61⌉ = ⌈5.93⌉ = 6 → 차이는 54.

이진트리 순회(Traversal) 3형제 📖 기출문제집 p.470~476

아래의 학습용 예제 트리 하나로 세 가지 순회를 전부 손으로 따라가 본다.

① 전위 순회 (Preorder) — 루트 → 왼쪽 → 오른쪽

  1. 루트 A 방문 → A
  2. 왼쪽 서브트리(B 기준)로 이동: B 방문 → 왼쪽 자식 D 방문 → 오른쪽 자식 E 방문 → B, D, E
  3. 오른쪽 서브트리(C 기준)로 이동: C 방문 → 왼쪽 자식 F 방문 → 오른쪽 자식 G 방문 → C, F, G
  4. 전체 결과: A - B - D - E - C - F - G

② 중위 순회 (Inorder) — 왼쪽 → 루트 → 오른쪽

  1. 왼쪽 서브트리(B 기준) 먼저 전부 순회: D 방문 → B 방문 → E 방문 → D, B, E
  2. 루트 A 방문 → A
  3. 오른쪽 서브트리(C 기준) 순회: F 방문 → C 방문 → G 방문 → F, C, G
  4. 전체 결과: D - B - E - A - F - C - G

③ 후위 순회 (Postorder) — 왼쪽 → 오른쪽 → 루트

  1. 왼쪽 서브트리(B 기준) 순회: D 방문 → E 방문 → B 방문 → D, E, B
  2. 오른쪽 서브트리(C 기준) 순회: F 방문 → G 방문 → C 방문 → F, G, C
  3. 마지막으로 루트 A 방문 → A
  4. 전체 결과: D - E - B - F - G - C - A
암기 비유: 이름표(루트)를 먼저 부르면 전위, 가운데서 부르면 중위, 맨 마지막에 부르면 후위. 왼쪽부터 보는 건 셋 다 공통.
함정 주의: "이진탐색트리를 중위 순회하면 오름차순 정렬 결과가 나온다"는 참(자주 출제). 순회 순서를 헷갈리면 절대 못 푸니, 위 3단계를 실전에서 매번 손으로 직접 그려서 확인할 것.

이진탐색트리 (BST, Binary Search Tree) 📖 기출문제집 p.477~479

이진트리에 "왼쪽 자식 < 부모 < 오른쪽 자식"이라는 규칙 하나를 추가한 것이다. 이 규칙 덕분에 값을 찾을 때 한 번 비교할 때마다 한쪽 서브트리를 통째로 버릴 수 있어 탐색이 빨라진다.

BST 만드는 법 — 기계적으로 따라가기만 하면 된다

  • 첫 번째로 입력된 값이 루트가 된다.
  • 그 다음 값부터는 루트에서 출발해, 현재 노드보다 작으면 왼쪽, 크면 오른쪽으로 내려간다.
  • 내려가다 빈자리(자식이 없는 곳)를 만나면 거기에 붙인다.

중요한 성질 3가지

  • 중위 순회(inorder)하면 오름차순 정렬이 된다 — 왼쪽(작은 것) → 루트 → 오른쪽(큰 것) 순서로 방문하기 때문. 시험 단골.
  • 입력 순서에 따라 모양이 완전히 달라진다. 이미 정렬된 값(1,2,3,4,5)을 순서대로 넣으면 오른쪽으로만 뻗은 편향 트리가 되어 높이가 최대(=n)가 되고 탐색이 O(n)으로 나빠진다.
  • 탐색·삽입·삭제 모두 평균 O(log n), 최악(편향) O(n).

만들기 예제: 44, 36, 62, 3 을 순서대로 삽입

  1. 44 — 첫 값이므로 루트가 된다
  2. 36 — 44보다 작다 → 루트의 왼쪽 자식
  3. 62 — 44보다 크다 → 루트의 오른쪽 자식
  4. 3 — 44보다 작아 왼쪽(36)으로, 36보다도 작으므로 → 36의 왼쪽 자식

힙 (Heap) 📖 기출문제집 p.480~482

힙은 완전이진트리이면서, "부모가 자식보다 크거나 같다(최대힙)" 또는 "부모가 자식보다 작거나 같다(최소힙)"는 조건을 만족하는 자료구조다. 정렬된 트리가 아니다 — 형제 노드끼리는 크기 비교가 안 된다, 오직 부모-자식 관계만 보장된다.

힌트: "힙을 중위 순회하면 정렬된 순서가 나온다"는 거짓이다(이진탐색트리와 헷갈리는 함정). 힙에서 정렬된 순서를 얻으려면 루트를 계속 꺼내며 재구성하는 힙 정렬(Heap Sort) 과정이 필요하다.

📌시험 빈출 포인트

  • 전위=루트→왼쪽→오른쪽, 중위=왼쪽→루트→오른쪽, 후위=왼쪽→오른쪽→루트 — 순서만 정확히 외우면 어떤 트리든 손으로 풀림
  • 순회 문제는 반드시 그려서 풀 것 — 암산으로 하면 서브트리 경계를 놓치기 쉽다
  • 이진탐색트리(BST)를 중위 순회 → 오름차순 정렬 결과 (힙과 헷갈리지 말 것)
  • 힙은 완전이진트리 + 부모자식 대소관계만 보장, 형제 간 순서는 무관
  • 트리 vs 그래프: 트리는 사이클 없음, 그래프는 사이클 가능
  • 간선 수 = 노드 수 − 1 (루트만 부모가 없으므로)
  • n개 노드 이진트리의 최대 높이 = n(편향), 최소 높이 = ⌈log₂(n+1)⌉(포화) — 두 값의 차를 묻는 계산 문제 빈출
  • BST는 입력 순서에 따라 모양이 달라진다 — 정렬된 값을 순서대로 넣으면 편향 트리(최악 O(n))
  • BST 단말 노드 개수 세기 문제는 직접 그려야 풀린다 (자식이 양쪽 모두 없어야 단말)
  • 용어 바꿔치기 함정: 자식 노드 ↔ 형제 노드, "모든 노드는 부모가 있다"(→ 루트 예외)

문제 12021 지방직 · 기출문제집 p.469

노드(node)가 11개 있는 트리의 간선(edge) 개수는?

  1. 10
  2. 11
  3. 12
  4. 13
해설 보기

정답 ① 10개

트리의 간선 수 = 노드 수 − 1 이므로 11 − 1 = 10.

왜 그런가: 루트를 제외한 모든 노드는 자기 부모와 연결되는 간선을 정확히 하나씩 가진다. 노드 11개 중 루트 1개를 빼면 10개이므로 간선도 10개다.

거꾸로 생각하면: 간선이 노드 수와 같아지는 순간(11개) 반드시 사이클이 생겨 더 이상 트리가 아니게 된다. 이 성질은 그래프 단원의 신장트리(spanning tree)에서도 그대로 쓰이니 확실히 기억할 것.

문제 22022 계리직 · 기출문제집 p.470

노드의 수가 60개인 이진 트리의 최대 높이에서 최소 높이를 뺀 값은? (단, 노드 1개짜리 트리의 높이는 1)

  1. 53
  2. 54
  3. 55
  4. 56
해설 보기

정답 ② 54

  1. 최대 높이: 모든 노드를 한 줄로 늘어뜨린 편향 트리일 때 → 높이 = 노드 수 = 60
  2. 최소 높이: 각 층을 꽉 채웠을 때 → ⌈log₂(n+1)⌉ = ⌈log₂61⌉
  3. 2⁵ = 32, 2⁶ = 64 이므로 log₂61은 5와 6 사이(약 5.93) → 올림하여 6
  4. 60 − 6 = 54

함정: ①번 53은 최소 높이를 7로 잘못 구했거나(올림을 두 번 적용), 최대 높이를 59로 본 경우다. 공식에 n+1을 넣는 것과 올림(⌈ ⌉)을 잊지 말 것. 검산법: 높이 6인 포화 이진트리는 2⁶−1 = 63개까지 담을 수 있으므로 60개가 들어간다. 높이 5는 31개까지라 부족하다 → 최소 높이 6이 맞다.

문제 32022 국회 · 기출문제집 p.468

이진 트리에 대한 설명으로 옳지 않은 것은?

  1. 일반 트리와 다르게 공집합을 허용한다.
  2. 모든 노드에게 유일한 부모 노드가 존재한다.
  3. 각 노드는 최대 2개의 자식 노드를 갖는다.
  4. n개의 노드를 가진 이진 트리는 n−1개의 간선을 갖는다.
해설 보기

정답 ② 모든 노드에게 유일한 부모 노드가 존재한다 (틀린 설명)

루트 노드에는 부모가 없다. 정확한 표현은 "루트를 제외한 모든 노드는 유일한 부모를 갖는다"이다. "모든 노드"라고 단정한 순간 틀린 문장이 된다.

나머지는 옳다 — ① 이진트리는 노드가 하나도 없는 공집합 트리도 인정하지만 일반 트리는 최소 1개(루트)가 있어야 한다, ③ 이진트리의 정의 그 자체, ④ 트리의 기본 성질.

출제 패턴: "모든 ~", "항상 ~", "반드시 ~" 같은 전칭 표현이 나오면 예외(루트·단말노드)를 먼저 의심하라. 트리 문제에서 예외는 거의 항상 루트 아니면 단말 노드다.

문제 42025 소방경채 · 기출문제집 p.469

트리에 대한 설명으로 옳지 않은 것은?

  1. 1:n 관계의 비선형 자료구조이다.
  2. 자식 노드(Child node)는 같은 부모 노드를 가지는 노드를 의미한다.
  3. 부모 노드(Parent node)는 임의의 노드 바로 위에 있는 노드를 의미한다.
  4. 레벨(Level)은 트리 각 층의 번호를 의미한다.

정답 ② 자식 노드는 같은 부모를 가지는 노드 (→ 이것은 형제 노드의 정의)

용어를 바꿔치기한 전형적인 함정이다.

  • 자식 노드: 임의의 노드 바로 아래에 연결된 노드
  • 형제(Sibling) 노드: 같은 부모를 가지는 노드들

나머지는 옳다 — ① 부모 하나에 자식이 여럿 달리므로 1:n 비선형, ③ 부모 노드의 정의, ④ 레벨의 정의.

대비법: 트리 용어 문제는 자식 ↔ 형제, 차수 ↔ 레벨, 높이 ↔ 깊이처럼 짝지어 바꿔치기하는 방식으로 나온다. 용어를 외울 때 항상 "헷갈리는 짝"과 함께 묶어서 외워라.

문제 52021 국회 · 기출문제집 p.478

다음 데이터를 순서대로 입력하여 이진 탐색 트리를 만들었을 때, 이 트리의 단말 노드(leaf)의 수는?
12 16 7 28 60 31 23 5 35 25 2 10 15 6

  1. 4개
  2. 5개
  3. 6개
  4. 7개
해설 보기

정답 ③ 6개 (단말 노드: 2, 6, 10, 15, 25, 35)

차근차근 삽입하며 트리를 그려야 한다. 루트는 첫 값 12.

  1. 16(>12) → 12의 오른쪽 / 7(<12) → 12의 왼쪽
  2. 28(>12,>16) → 16의 오른쪽 / 60(>28) → 28의 오른쪽
  3. 31(>28, <60) → 60의 왼쪽 / 23(>16, <28) → 28의 왼쪽
  4. 5(<7) → 7의 왼쪽 / 35(>31) → 31의 오른쪽 / 25(>23) → 23의 오른쪽
  5. 2(<5) → 5의 왼쪽 / 10(>7, <12) → 7의 오른쪽 / 15(>12, <16) → 16의 왼쪽 / 6(>5, <7) → 5의 오른쪽

문제 62017 서울시 · 기출문제집 p.479

빈 이진탐색트리에 7, 5, 1, 8, 3, 6, 0, 2 순서로 값을 삽입한 뒤 중위 순회(Inorder Traversal)했을 때 방문 순서는?

  1. 0 1 2 3 5 6 7 8
  2. 0 2 3 1 6 5 8 7
  3. 7 5 1 0 3 2 6 8
  4. 8 6 2 3 0 1 5 7
해설 보기

정답 ① 0 1 2 3 5 6 7 8

트리를 그릴 필요조차 없는 문제다. 이진탐색트리를 중위 순회하면 항상 오름차순 정렬 결과가 나온다. 주어진 값을 그냥 작은 순으로 나열하면 끝.

왜 그런가: 중위 순회는 왼쪽 → 루트 → 오른쪽 순서로 방문한다. BST에서 왼쪽 서브트리는 전부 루트보다 작고, 오른쪽 서브트리는 전부 크므로, 이 순서로 방문하면 자동으로 작은 값부터 나온다.

오답 분석: ③번(7 5 1 0 3 2 6 8)은 전위 순회(루트부터) 결과이고, ②번은 후위 순회 형태다. 문제에서 "Inorder"인지 "Preorder"인지 반드시 확인할 것 — 순회 종류만 바꿔서 같은 트리로 여러 해 출제된다.

문제 72014 국회 · 기출문제집 p.481

최대 힙(max heap)에 대하여 올바르게 설명한 것은?

  1. 두 개의 자식 노드를 갖는 노드는 좌측 자식보다 크고 우측 자식보다는 작은 키 값이 저장된다.
  2. 힙을 중위 순회(in-order traversal)하면 정렬된 순서로 데이터를 얻을 수 있다.
  3. 완전 그래프(complete graph)에 해당된다.
  4. 루트 노드는 트리에 저장된 키 값 중 가장 큰 값을 갖는다.
해설 보기

정답 ④ 루트 노드가 가장 큰 값을 갖는다

최대 힙은 "부모 ≥ 자식" 조건을 만족하는 완전 이진트리다. 이 조건이 모든 부모-자식 쌍에서 성립하므로, 맨 위 루트는 트리 전체에서 가장 큰 값이 된다.

오답 분석 — 전부 다른 자료구조와 헷갈리게 만든 함정:

  • ① "좌측보다 크고 우측보다 작다"는 이진탐색트리(BST)의 설명이다. 힙은 형제·좌우 간의 대소관계를 전혀 보장하지 않는다.
  • ② 중위 순회로 정렬 결과가 나오는 것도 BST의 성질이다. 힙에서 정렬된 순서를 얻으려면 루트를 꺼내고 재정렬하는 힙 정렬 과정을 반복해야 한다.
  • ③ 힙은 완전 이진트리(complete binary tree)이지 완전 그래프(complete graph)가 아니다. 용어가 비슷해 보이지만 완전 그래프는 모든 정점이 서로 연결된 그래프로 전혀 다른 개념이다.

한 줄 정리: BST는 좌우 순서를 보장하고, 힙은 위아래 순서만 보장한다.
