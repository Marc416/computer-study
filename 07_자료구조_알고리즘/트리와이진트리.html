트리와 이진트리 순회

전위·중위·후위 순회 · 힙(Heap) · PART 04. 자료구조론

핵심 요약

순회 3형제는 루트를 언제 방문하냐로 구분한다: 전위=먼저, 중위=가운데, 후위=마지막.

왼쪽 서브트리는 항상 오른쪽보다 먼저 — 세 방식 모두 공통이다.

💡주요 개념

트리 용어

용어의미
루트 (Root)트리의 맨 꼭대기 노드 (부모가 없음)
단말 노드 (Leaf)자식이 없는 노드
서브트리 (Subtree)어떤 노드를 루트로 삼는 부분 트리
이진트리 (Binary Tree)모든 노드가 자식을 최대 2개(왼쪽·오른쪽)까지만 가질 수 있는 트리

트리와 그래프의 차이: 트리는 사이클(순환)이 없는 비선형 자료구조이고, 그래프는 사이클이 있을 수 있다. 트리도 그래프의 일종(사이클 없는 연결 그래프)이다.

이진트리 순회(Traversal) 3형제 📖 기출문제집 p.470~476

아래의 학습용 예제 트리 하나로 세 가지 순회를 전부 손으로 따라가 본다.

① 전위 순회 (Preorder) — 루트 → 왼쪽 → 오른쪽

  1. 루트 A 방문 → A
  2. 왼쪽 서브트리(B 기준)로 이동: B 방문 → 왼쪽 자식 D 방문 → 오른쪽 자식 E 방문 → B, D, E
  3. 오른쪽 서브트리(C 기준)로 이동: C 방문 → 왼쪽 자식 F 방문 → 오른쪽 자식 G 방문 → C, F, G
  4. 전체 결과: A - B - D - E - C - F - G

② 중위 순회 (Inorder) — 왼쪽 → 루트 → 오른쪽

  1. 왼쪽 서브트리(B 기준) 먼저 전부 순회: D 방문 → B 방문 → E 방문 → D, B, E
  2. 루트 A 방문 → A
  3. 오른쪽 서브트리(C 기준) 순회: F 방문 → C 방문 → G 방문 → F, C, G
  4. 전체 결과: D - B - E - A - F - C - G

③ 후위 순회 (Postorder) — 왼쪽 → 오른쪽 → 루트

  1. 왼쪽 서브트리(B 기준) 순회: D 방문 → E 방문 → B 방문 → D, E, B
  2. 오른쪽 서브트리(C 기준) 순회: F 방문 → G 방문 → C 방문 → F, G, C
  3. 마지막으로 루트 A 방문 → A
  4. 전체 결과: D - E - B - F - G - C - A
암기 비유: 이름표(루트)를 먼저 부르면 전위, 가운데서 부르면 중위, 맨 마지막에 부르면 후위. 왼쪽부터 보는 건 셋 다 공통.
함정 주의: "이진탐색트리를 중위 순회하면 오름차순 정렬 결과가 나온다"는 참(자주 출제). 순회 순서를 헷갈리면 절대 못 푸니, 위 3단계를 실전에서 매번 손으로 직접 그려서 확인할 것.

힙 (Heap) 📖 기출문제집 p.480~482

힙은 완전이진트리이면서, "부모가 자식보다 크거나 같다(최대힙)" 또는 "부모가 자식보다 작거나 같다(최소힙)"는 조건을 만족하는 자료구조다. 정렬된 트리가 아니다 — 형제 노드끼리는 크기 비교가 안 된다, 오직 부모-자식 관계만 보장된다.

힌트: "힙을 중위 순회하면 정렬된 순서가 나온다"는 거짓이다(이진탐색트리와 헷갈리는 함정). 힙에서 정렬된 순서를 얻으려면 루트를 계속 꺼내며 재구성하는 힙 정렬(Heap Sort) 과정이 필요하다.

📌시험 빈출 포인트

  • 전위=루트→왼쪽→오른쪽, 중위=왼쪽→루트→오른쪽, 후위=왼쪽→오른쪽→루트 — 순서만 정확히 외우면 어떤 트리든 손으로 풀림
  • 순회 문제는 반드시 그려서 풀 것 — 암산으로 하면 서브트리 경계를 놓치기 쉽다
  • 이진탐색트리(BST)를 중위 순회 → 오름차순 정렬 결과 (힙과 헷갈리지 말 것)
  • 힙은 완전이진트리 + 부모자식 대소관계만 보장, 형제 간 순서는 무관
  • 트리 vs 그래프: 트리는 사이클 없음, 그래프는 사이클 가능
