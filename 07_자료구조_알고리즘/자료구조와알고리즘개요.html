자료구조와 알고리즘 개요

선형/비선형 분류 · 알고리즘의 조건 · 시간복잡도 · 순환(재귀) · PART 04. 자료구조론

핵심 요약

자료구조는 데이터 사이의 관계가 1:1이면 선형(배열·리스트·스택·큐), 1:n 또는 n:m이면 비선형(트리·그래프)이다.

알고리즘의 성능은 시간복잡도(Big-O)로 표현하고, 순환(재귀)은 결국 스택에 함수 호출을 쌓았다 꺼내는 것이다.

💡주요 개념 — 자료구조의 분류

선형 구조 vs 비선형 구조 📖 기출문제집 p.431

구분관계정의예시
선형(Linear)1 : 1데이터 항목 사이의 선후 관계가 하나의 "선"으로 명확하게 이어짐배열, 연결리스트, 스택, 큐
비선형(Non-linear)1:n 또는 n:m하나의 항목이 여러 항목과 관계를 가짐 (그래프적 구조)트리, 그래프
함정 주의: "이진 트리(Binary Tree)"는 이름에 "트리"가 들어가니 당연히 비선형이다 — "선형 자료구조가 아닌 것은?" 문제의 단골 정답.
비유: 선형 구조 = 기차처럼 한 줄로 서서 앞뒤만 아는 관계, 비선형 구조 = 가족 족보처럼 한 사람 밑에 여러 자식이 뻗어나가는 관계

알고리즘의 조건 📖 기출문제집 p.432

조건의미
입력 (Input)외부에서 제공되는 자료가 0개 이상 있을 수 있다
출력 (Output)반드시 1개 이상의 결과를 생성해야 한다
명확성 (Definiteness)각 명령은 모호하지 않고 명확해야 한다
유한성 (Finiteness)한정된 수의 단계 뒤에는 반드시 종료해야 한다
실제성 (Effectiveness)모든 명령은 실제로 실행 가능한 연산이어야 한다
유효성 (Feasibility)원칙적으로 모든 명령은 종이와 연필만으로도 수행 가능해야 한다
함정 주의: "알고리즘 단계들에는 순서가 정해져 있지 않다" → ❌ 틀림. 알고리즘은 정해진 순서대로 진행되어야 한다.

컴퓨팅 사고(Computational Thinking)의 4요소

  • 분해(Decomposition): 복잡한 문제를 작은 문제 여러 개로 쪼갬
  • 패턴 인식(Pattern Recognition): 작은 문제들 사이의 반복되는 패턴을 찾음
  • 추상화(Abstraction): 불필요한 부분을 제거하고 핵심 요소만 남김
  • 알고리즘(Algorithm): 문제 해결을 위한 절차를 정함

📈시간복잡도 (Big-O 표기법)

알고리즘이 "얼마나 빠른가"를 입력 크기 n이 커질 때 연산 횟수가 어떤 속도로 늘어나는지로 표현한 것이다. 여러 항이 섞여 있으면 차수가 가장 높은 항 하나만 남기고 나머지는 버린다 (예: 3nlogn+100 → O(nlogn)).

시간복잡도 크기 순서 (작은 것 → 큰 것):
O(1) < O(log n) < O(n) < O(n log n) < O(n²) < O(n³) < O(2ⁿ) < O(n!) < O(nⁿ)

🔁순환 (재귀, Recursion) 📖 기출문제집 p.433~435

재귀함수는 자기 자신을 다시 호출하는 함수다. 컴퓨터 내부적으로는 함수를 호출할 때마다 그 상태(지역변수, 복귀주소)를 스택에 쌓고, 종료 조건(base case)에 도달하면 쌓인 순서의 반대로 하나씩 꺼내며(pop) 계산을 완성한다. 그래서 재귀는 "스택"과 뗄 수 없다.

계산 방법: factorial(4)를 재귀로 계산하는 과정

  1. factorial(4)를 호출 → 아직 답을 모르니 factorial(3)을 먼저 호출해야 함 → 스택에 factorial(4) 쌓임
  2. factorial(3) → factorial(2)를 호출해야 함 → 스택에 factorial(3) 쌓임
  3. factorial(2) → factorial(1)을 호출해야 함 → 스택에 factorial(2) 쌓임
  4. factorial(1) → factorial(0)을 호출해야 함 → 스택에 factorial(1) 쌓임
  5. factorial(0) = 1 (종료조건 도달) → 이제부터 스택에서 꺼내며(pop) 역순으로 계산 시작
  6. factorial(1) = 1 × factorial(0) = 1 × 1 = 1 → pop
  7. factorial(2) = 2 × factorial(1) = 2 × 1 = 2 → pop
  8. factorial(3) = 3 × factorial(2) = 3 × 2 = 6 → pop
  9. factorial(4) = 4 × factorial(3) = 4 × 6 = 24 → pop, 최종 답

계산 방법: fib(5) 호출 횟수와 결과값 구하기 📖 기출문제집 p.433

fib(n) = fib(n-1) + fib(n-2), fib(0)=0, fib(1)=1 일 때
  1. fib(5) = fib(4) + fib(3)
  2. fib(4) = fib(3) + fib(2), fib(3) = fib(2) + fib(1)
  3. 계속 쪼개면 fib(1)과 fib(0)이 나올 때까지 호출이 가지치기 됨
  4. 모든 호출을 다 세면 fib(5) 자신을 포함해 총 15번 호출됨
  5. 최종 결과값 fib(5) = 5
재귀 → 반복문 변환 팁: 재귀함수가 종료되는 조건(base case, 예: n==0)이 반복문에서는 루프를 멈추는 조건의 반대가 된다. factorial 재귀의 종료조건이 n==0이면, 반복문의 while 조건은 n>0이어야 한다.

📌시험 빈출 포인트

  • 선형(배열·리스트·스택·큐) vs 비선형(트리·그래프) 구분 — 이진 트리는 비선형
  • 알고리즘의 6가지 조건: 입력·출력·명확성·유한성·실제성·유효성 (순서가 없다는 표현은 오답)
  • 시간복잡도 여러 항이 섞이면 차수가 가장 높은 항만 남기고 표기
  • 이중 for문(중첩 반복문) → O(n²), 단일 for문 → O(n), 절반씩 줄여나가면 → O(log n)
  • 재귀 함수의 총 호출 횟수·최종 반환값을 손으로 직접 트리처럼 펼쳐서 계산하는 문제 (fib류)
  • 재귀함수를 반복문(while/for)으로 바꾸는 문제 — 종료조건의 반대가 반복 조건이 됨
