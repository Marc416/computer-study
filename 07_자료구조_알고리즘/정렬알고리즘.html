정렬 알고리즘

버블·선택·삽입 정렬 단계별 풀이, 시간복잡도 비교 · PART 04. 자료구조론

핵심 요약

시험에 나오는 정렬 문제는 대부분 "이 배열이 몇 단계 만에 이렇게 바뀌었다, 무슨 정렬이냐"를 묻는다. 그러니 각 정렬이 한 단계에서 뭘 하는지(비교? 교환? 어디를 건드리는지)를 손으로 직접 따라갈 수 있어야 한다.

💡주요 개념 — 정렬 알고리즘 한눈에

정렬한 줄 원리시간복잡도(평균)안정정렬
버블(Bubble)인접한 두 값을 비교해 크면 교환. 한 번 돌 때마다 최댓값이 끝으로 이동O(n²)O
선택(Selection)남은 것 중 최솟값을 찾아 맨 앞(현재 위치)과 교환O(n²)X
삽입(Insertion)정렬된 부분에 다음 값을 알맞은 위치로 밀어넣기O(n²) (거의 정렬된 데이터엔 O(n))O
퀵(Quick)피벗 기준으로 작은 값/큰 값 그룹으로 나눠 재귀 정렬O(n log n) (최악 O(n²))X
합병(Merge)반씩 쪼갠 뒤(분할) 정렬하며 합치기O(n log n)O
힙(Heap)힙 트리를 만들어 루트(최댓값)를 꺼내는 것을 반복O(n log n)X
셸(Shell)일정 간격(gap)씩 떨어진 값끼리 먼저 삽입정렬, 간격을 줄여가며 반복O(n^1.5) 근사X
기수(Radix)비교 없이 자릿수(낮은 자리부터) 기준으로 분배·수집 반복O(dn) (d=자릿수)O
함정 주의: "정렬 대상 크기만큼 추가 공간이 필요한 정렬" → 합병(Merge) 정렬이다 — 두 부분을 합칠 때 임시 배열이 필요하기 때문. 나머지 정렬은 대부분 제자리(in-place) 정렬이 가능.

🫧버블 정렬 — 실제 기출 예제로 손으로 따라가기 📖 기출문제집 p.498

배열 [5, 2, 3, 8, 1]을 오름차순 정렬. 버블 정렬은 왼쪽부터 인접한 두 칸씩 비교하며 왼쪽이 크면 교환 — 이걸 배열 끝까지 반복하는 게 "한 패스(pass)"다.

단계12345비고
초기52381-
1pass23518(5,2)(5,3)교환, (5,8)유지, (8,1)교환 → 최댓값 8 맨끝 확정
2pass23158(5,1)교환 → 5 확정
3pass21358(3,1)교환 → 3 확정 (여기까지가 실제 기출 문제 범위)
4pass12358(2,1)교환 → 완전 정렬 완료
패턴을 눈치챘는가? 버블 정렬은 한 패스마다 뒤에서부터 하나씩 제자리를 찾아간다 (초록색 칸이 오른쪽에서부터 채워짐). 그래서 n개짜리 배열은 최대 n−1번의 패스면 항상 끝난다.

🔍선택 정렬 — 실제 기출 예제 📖 기출문제집 p.502

배열 [34, 27, 19, 50, 2, 21, 13]. 선택 정렬은 매 단계마다 "남은 범위에서 가장 작은 값"을 찾아서 현재 위치와 교환한다.

단계1234567동작
초기3427195022113-
1단계2271950342113최솟값 2와 위치1(34) 교환
2단계2131950342127최솟값 13과 위치2(27) 교환
3단계213195034212719가 이미 제자리 → 교환 없음!
4단계2131921345027최솟값 21과 위치4(50) 교환
5단계2131921275034최솟값 27과 위치5(34) 교환
6단계2131921273450최솟값 34와 위치6(50) 교환 → 완료
이 문제의 함정: 3단계에서 배열이 안 바뀐 것처럼 보여서 "어? 정렬이 멈췄나?" 하고 오답을 고르기 쉽다. 사실은 "남은 범위의 최솟값(19)이 이미 제자리에 있어서 교환할 필요가 없었을 뿐" — 선택 정렬은 매 단계 반드시 최솟값을 찾기는 하지만, 교환은 필요할 때만 일어난다.

📥삽입 정렬 — 실제 기출 예제 📖 기출문제집 p.503

배열 [69, 30, 10, 2, 16, 8, 31, 22]. 삽입 정렬은 배열을 "정렬된 부분"과 "안 정렬된 부분"으로 나누고, 안 정렬된 부분의 맨 앞 값을 정렬된 부분의 알맞은 자리에 밀어 넣는다.

회전정렬된 부분안 정렬된 부분
초기693010216 8 31 22
1회전3069102168 31 22
2회전103069216831 22
3회전21030691683122
4회전21016306983122
  1. 초기: 첫 원소 69는 "정렬된 부분"이 1개짜리라고 취급하고 시작
  2. 1회전: 30을 꺼내 정렬된 부분[69]과 비교 → 30<69이므로 69 앞으로 삽입 → [30,69]
  3. 2회전: 10을 꺼내 [30,69]와 비교 → 10이 제일 작으므로 맨 앞 삽입 → [10,30,69]
  4. 3회전: 2를 꺼내 [10,30,69]와 비교 → 2가 제일 작으므로 맨 앞 삽입 → [2,10,30,69]
  5. 4회전: 16을 꺼내 [2,10,30,69]와 뒤에서부터 비교 → 69>16(밀림), 30>16(밀림), 10<16(멈춤) → 10 뒤에 삽입 → [2,10,16,30,69]
정답 확인: 4회전 후 전체 배열 = 2, 10, 16, 30, 69, 8, 31, 22 (정렬된 부분 5개 + 아직 안 건드린 나머지 8,31,22 그대로)

📌시험 빈출 포인트

  • 주어진 "단계별 배열 변화"만 보고 어떤 정렬인지 맞추는 문제 — 인접한 것끼리만 바뀌면 버블, 최솟값이 앞으로 튀면 선택, 뒤에서부터 하나씩 밀려나면 삽입
  • 선택 정렬은 이미 제자리인 값이면 교환 없이 넘어갈 수 있다 (교환 없다고 정렬 안 한 게 아님)
  • 합병 정렬만 유일하게 추가 메모리(임시 배열)가 필요한 정렬
  • 안정 정렬 여부: 버블·삽입·합병·기수 = 안정 / 선택·퀵·힙·셸 = 불안정
  • 평균 시간복잡도 O(n log n) 그룹: 퀵·합병·힙 / O(n²) 그룹: 버블·선택·삽입
