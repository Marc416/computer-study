그래프 순회와 최소비용 신장트리

그래프 표현 · BFS·DFS · 크루스컬/프림 · 위상정렬 · PART 04. 자료구조론

핵심 요약

BFS(너비우선탐색)는 큐(Queue)로 "가까운 곳부터 옆으로 넓게", DFS(깊이우선탐색)는 스택(Stack)으로 "한 방향으로 끝까지 파고들기"다.

최소비용 신장트리는 모든 정점을 사이클 없이 가장 싼 비용으로 연결하는 것 — 크루스컬은 간선을 싼 순서로, 프림은 시작 정점에서 트리를 키우며 고른다.

🎯이 단원을 왜 배우나

"연결 관계" 자체가 데이터인 세상

트리까지는 "위아래 계층"이 있는 구조였다. 그런데 현실의 많은 데이터는 계층이 없고 그냥 서로 얽혀 있다 — 지하철 노선도(역과 역), SNS 친구 관계(사람과 사람), 도로망(도시와 도시), 웹페이지 링크 구조. 이렇게 "무엇과 무엇이 연결되어 있는가"가 핵심인 데이터를 담는 그릇이 그래프다.

그래프를 배우면 세 가지 질문에 답할 수 있게 된다. ① "여기서 저기까지 갈 수 있나?" → 순회(BFS/DFS) ② "모든 곳을 연결하되 공사비를 최소로 하려면?" → 최소비용 신장트리(크루스컬/프림) ③ "선수과목을 지키며 수강 순서를 짜려면?" → 위상정렬. 시험에 나오는 그래프 문제는 사실상 이 셋이 전부다.

중요한 건 답을 외우는 게 아니라 손으로 굴릴 수 있느냐다. BFS·DFS 순서 문제도, 크루스컬 비용 계산도 전부 "규칙대로 한 단계씩 적어 내려가면" 반드시 맞는 문제다. 그래서 이 단원은 문제 풀이 절차를 몸에 익히는 것이 공부의 전부다.

외워두면 바로 점수: 간선 수 공식

  • 무방향 완전그래프(모든 정점이 서로 연결): 간선 수 = n(n−1)/2 — n개 중 2개를 고르는 조합이므로
  • 방향 완전그래프: 간선 수 = n(n−1) — 가는 방향·오는 방향을 따로 세므로 위의 2배
  • 신장트리(모든 정점 연결 + 사이클 없음): 간선 수 = n−1 (항상!)
  • 무방향 그래프에서 모든 정점의 차수 합 = 간선 수 × 2 (간선 하나가 양쪽 정점의 차수를 1씩 올리므로)

🕸️주요 개념 — 그래프 순회 (BFS vs DFS) 📖 기출문제집 p.483~488

아래 그래프(정점 A~F)를 예로 들어보자. "누구부터 방문할지 헷갈리면 안 되는" 시험 포인트: 인접한 정점이 여러 개면 알파벳(번호) 순서대로 고른다.

A에서 출발할 때 방문 순서 비교:

탐색법방문 순서왜 이 순서인가
BFS (큐, 가까운 곳부터)A → B → F → C → D → EA의 이웃(B,F)을 먼저 큐에 다 넣고, 그 다음 B의 새 이웃(C), 그 다음 F의 새 이웃(D,E) 순으로 "한 칸씩 넓게" 방문
DFS (스택, 한 방향으로 끝까지)A → B → C → D → E → FA→B로 간 뒤 B의 이웃 중 안 가본 곳(C)으로 계속 파고들고, C→D→E까지 막다른 길에 몰릴 때까지 직진, 마지막에 F
비유: BFS = 동심원을 그리며 퍼지는 물결(가까운 순서대로), DFS = 미로에서 한쪽 벽만 짚고 끝까지 가보는 것(막히면 되돌아옴)

왜 BFS는 큐, DFS는 스택인가 — 우연이 아니다

BFS의 목표는 "먼저 발견한 정점을 먼저 방문"하는 것이다. 먼저 넣은 걸 먼저 꺼내는 자료구조 = 큐(FIFO). A의 이웃 B, F를 큐에 넣으면, B와 F를 다 처리한 뒤에야 B의 이웃이 나온다 — 그래서 "거리 1인 정점 전부 → 거리 2인 정점 전부" 순으로 퍼진다.

DFS의 목표는 "가장 최근에 발견한 정점부터 파고들기"다. 나중에 넣은 걸 먼저 꺼내는 자료구조 = 스택(LIFO). 그래서 방금 도착한 정점의 이웃으로 계속 깊이 들어가고, 막히면 스택에서 하나씩 꺼내며(pop) 되돌아온다(백트래킹).

재귀 함수로 DFS를 짜면 스택을 직접 안 만들어도 된다. 함수 호출 자체가 시스템 스택에 쌓였다가 돌아오기 때문이다 — 그래서 "DFS는 재귀로 구현한다"는 말과 "DFS는 스택을 쓴다"는 말은 같은 뜻이다.

두 번째 예제 — 기출에 나온 7정점 그래프 📖 기출문제집 p.487

아래 그래프는 2017년 국가직 기출 그래프다. DFS와 BFS의 결과가 확연히 갈리는 좋은 예라 손으로 한 번 따라가 볼 가치가 있다.

DFS (A에서 출발, 알파벳 순):

  1. A 방문 → A의 이웃 {B, C} 중 알파벳 앞선 B로
  2. B 방문 → B의 이웃 {A(방문), D, E} 중 D로
  3. D 방문 → D의 이웃 {B(방문), G} → G로
  4. G 방문 → G의 이웃 {D(방문), E, F} 중 알파벳 앞선 E로
  5. E 방문 → E의 이웃 {B(방문), C, G(방문)} → C로
  6. C 방문 → C의 이웃 {A, E} 전부 방문함 → 막다른 길, 되돌아감(백트래킹) → E로, 또 막힘 → G로
  7. G에 돌아오니 아직 안 간 F가 남아있다 → F 방문 → 최종: A-B-D-G-E-C-F

BFS (A에서 출발):

  1. A 방문, 이웃 B·C를 큐에 넣음 → 큐: [B, C]
  2. B 꺼내 방문, 새 이웃 D·E 추가 → 큐: [C, D, E]
  3. C 꺼내 방문, 이웃 A·E는 이미 처리됨 → 큐: [D, E]
  4. D 꺼내 방문, 새 이웃 G 추가 → 큐: [E, G]
  5. E 꺼내 방문, 이웃 전부 처리됨 → 큐: [G]
  6. G 꺼내 방문, 새 이웃 F 추가 → 큐: [F] → F 방문 → 최종: A-B-C-D-E-G-F
결정적 차이: DFS는 A-B-D-G...로 한 줄기를 따라 깊이 내려가고, BFS는 A-B-C...로 A의 이웃을 먼저 싹 훑는다. 두 번째 방문 정점이 같아도 세 번째에서 갈린다는 걸 기억하면 선택지를 빨리 걸러낼 수 있다.

🌲주요 개념 — 최소비용 신장트리 📖 기출문제집 p.489~493

신장트리(Spanning Tree): 그래프의 모든 정점을 포함하면서 사이클이 없는 부분 그래프. 정점이 n개면 간선은 항상 n−1개다.

왜 하필 "사이클 없이 n−1개"인가

정점 n개를 모두 연결하려면 최소 n−1개의 간선이 필요하다(하나 연결할 때마다 간선 1개씩). 여기서 간선을 하나라도 더 붙이면 반드시 사이클이 생긴다 — 이미 연결된 두 정점을 또 잇는 꼴이기 때문이다.

그리고 사이클 안의 간선 하나는 없어도 연결이 유지되는 낭비다. "최소 비용으로 모두 연결"이 목표라면 낭비를 남길 이유가 없으니, 정답은 항상 사이클 없는 n−1개 = 신장트리 형태가 된다. 크루스컬이 "사이클이 생기면 버린다"고 하는 이유가 바로 이것이다.

크루스컬(Kruskal) — 간선을 싼 순서로 줍는다

동작 원리: ① 모든 간선을 가중치 오름차순으로 정렬 → ② 가장 싼 간선부터 하나씩 보면서, 사이클이 생기지 않으면 선택하고 사이클이 생기면 버린다 → ③ 간선을 (정점 수−1)개 선택하면 종료.

아래는 실제 기출(정점 6개) 그래프다. 간선 옆 숫자가 가중치다.

크루스컬 실행 과정을 한 줄씩 따라가기:

순서검토 간선가중치판정누적 비용
1(V1, V2)2✅ 채택 — 아직 아무것도 연결 안 됨2
2(V3, V4)3✅ 채택 — 다른 덩어리와 무관5
3(V0, V2)4✅ 채택 — V0가 {V1,V2} 덩어리에 합류9
—(V0, V1)5❌ 버림 — V0·V1 이미 같은 덩어리 → 사이클9
4(V1, V4)6✅ 채택 — {V0,V1,V2}와 {V3,V4} 두 덩어리를 연결15
—(V1, V3)8❌ 버림 — 이미 같은 덩어리 → 사이클15
5(V3, V5)9✅ 채택 — 마지막 정점 V5 합류 → 간선 5개 완성, 종료24
사이클 판정 요령: 간선의 양 끝 정점이 이미 같은 덩어리에 속해 있으면 사이클이다. 손으로 풀 때는 채택할 때마다 "지금까지 연결된 정점 묶음"을 옆에 적어두면 실수하지 않는다. (위 표의 "판정"열이 바로 그 기록이다.)

프림(Prim) — 시작 정점에서 나무를 키운다

프림은 접근이 다르다. 시작 정점 하나에서 출발해, 지금까지 만든 트리에 붙일 수 있는 간선 중 가장 싼 것을 계속 추가한다. 크루스컬처럼 여기저기 흩어진 덩어리를 만들지 않고, 항상 한 덩어리를 키워나간다는 점이 다르다.

위와 똑같은 그래프에서 V0부터 프림을 돌리면:

단계현재 트리붙일 수 있는 간선선택
1{V0}(V0,V2)=4, (V0,V1)=5(V0,V2) = 4
2{V0,V2}(V0,V1)=5, (V2,V1)=2(V1,V2) = 2
3{V0,V1,V2}(V1,V4)=6, (V1,V3)=8(V1,V4) = 6
4{V0,V1,V2,V4}(V4,V3)=3, (V1,V3)=8(V3,V4) = 3
5{V0,V1,V2,V3,V4}(V3,V5)=9(V3,V5) = 9 → 완성
중요한 관찰: 프림의 선택 순서는 크루스컬과 완전히 다르다(4→2→6→3→9 vs 2→3→4→6→9). 그런데 고른 간선 집합도, 총 비용 24도 똑같다. 최소비용 신장트리는 (가중치가 모두 다르면) 유일하기 때문이다. 시험에서 "몇 번째로 선택되는 간선"을 물으면 어느 알고리즘인지 반드시 확인해야 하는 이유가 여기 있다.

크루스컬 시간복잡도

간선 수를 n이라 하면: 간선 정렬 O(n log n) + 사이클 검사하며 n−1개 선택 O(n) = 전체 O(n log n).

함정 주의: "크루스컬 알고리즘의 시간복잡도는 O(n²)이다" → ❌ 틀림. 간선 정렬이 지배적이라 O(n log n)이 맞다. (이건 거의 매번 오답 선택지로 나온다.)

참고(교과서 지식): 출발점이 정해진 최단경로 문제는 다익스트라(Dijkstra) 알고리즘을 쓴다. MST와 헷갈리기 쉬운데, MST는 "전체 연결 비용의 합"을 최소로 하고, 다익스트라는 "특정 두 지점 사이 경로 길이"를 최소로 한다 — 목적이 다르다.

📚위상정렬 (Topological Sort) 📖 기출문제집 p.494

"A를 끝내야 B를 할 수 있다"는 선후 관계가 있는 작업들을 순서를 어기지 않게 한 줄로 늘어놓는 것이 위상정렬이다. 대표 예가 선수과목을 지키는 수강 순서다.

과목코드과목명선수과목
I1전산개론없음
I2이산수학없음
I3자바I1
I4알고리즘I1, I2, I3
I5수치해석I2
I6캡스톤디자인I3, I4, I5
  1. 진입차수가 0인 것(선수과목이 없는 것)부터 고른다 → I1, I2 (이 둘의 순서는 아무래도 상관없다)
  2. 고른 과목을 지우면 그것을 선수과목으로 삼던 과목들의 진입차수가 줄어든다 → I1을 지우면 I3가 수강 가능해짐
  3. 다시 진입차수 0이 된 것을 고른다 → I3, 이어서 I5(I2만 필요)
  4. I1·I2·I3가 모두 끝나야 하는 I4를 고르고, 마지막으로 I3·I4·I5가 전부 필요한 I6
  5. 가능한 답 중 하나: I2 → I1 → I3 → I4 → I5 → I6
핵심 두 가지: ① 위상정렬의 답은 여러 개일 수 있다(진입차수 0인 게 동시에 여러 개면 순서는 자유). ② 사이클이 있으면 위상정렬이 불가능하다 — "A 다음 B, B 다음 A"는 순서를 정할 수 없기 때문. 그래서 위상정렬은 방향이 있고 사이클이 없는 그래프(DAG)에서만 가능하다.

📌시험 빈출 포인트

  • 차수(degree) = 정점의 개수가 아니라 한 정점에 연결된 간선 수
  • 무방향 완전그래프 간선 수 = n(n−1)/2, 방향 완전그래프 = n(n−1)
  • 여러 이웃 중 방문 순서는 알파벳(번호) 순 — 문제에 명시된 규칙 꼭 확인
  • BFS = 큐(Queue) 사용, DFS = 스택(Stack)/재귀 사용 — 자료구조 짝 암기 필수
  • DFS 문제는 막다른 길에서 되돌아가는(백트래킹) 지점에서 오답이 갈린다
  • 신장트리의 간선 수 = 정점 수 − 1 (그래프가 아무리 복잡해도 항상 성립)
  • 크루스컬: 가중치 오름차순 정렬 후 사이클 생기면 무조건 버림
  • 크루스컬 시간복잡도는 O(n log n) (간선 정렬이 병목) — O(n²)는 오답
  • 크루스컬과 프림은 선택 순서는 다르지만 결과(총비용)는 같다
  • 위상정렬은 사이클이 없어야 가능하고, 답이 여러 개일 수 있다

문제 12025 소방경채 · 기출문제집 p.483

그래프에 대한 설명으로 옳지 않은 것은?

  1. 정점의 수를 차수라고 한다.
  2. 무방향 그래프에서 간선 (v0, v1)과 간선 (v1, v0)은 동일하다.
  3. 그래프는 정점의 집합과 간선의 집합으로 표현한다.
  4. 그래프의 탐색에는 깊이 우선 탐색과 너비 우선 탐색이 있다.
해설 보기

정답 ① — 차수는 정점 수가 아니라 간선 수다

차수(degree) = 한 정점에 연결된 간선의 개수다. 정점의 개수와는 전혀 다른 개념이다.

  1. 방향 그래프에서는 차수를 둘로 나눈다: 진입차수(들어오는 간선 수)와 진출차수(나가는 간선 수)
  2. ②는 맞는 말 — 무방향 그래프의 간선은 방향이 없으므로 (v0,v1)과 (v1,v0)은 같은 간선 하나다
  3. ③·④도 모두 그래프의 기본 정의·성질로 맞는 설명이다
문제 22010 계리직 · 기출문제집 p.484

본문 첫 번째 예제 그래프(A~F, 간선 A-B, A-F, B-C, B-F, C-D, C-F, D-E, D-F, E-F)를 A에서 출발해 BFS와 DFS로 방문할 때 순서로 옳은 것은? (둘 이상 선택 가능하면 알파벳 순)

  1. BFS: ABFCED / DFS: ABCDEF
  2. BFS: ABCDEF / DFS: ABFCED
  3. BFS: ABFCDE / DFS: ABCDEF
  4. BFS: ABCDEF / DFS: ABCDFE
해설 보기

정답 ③ BFS: ABFCDE / DFS: ABCDEF

BFS (큐):

  1. A 방문 → 이웃 B, F를 큐에 삽입 → 큐: [B, F]
  2. B 방문 → B의 이웃 A(방문), C, F(이미 큐에 있음) → C만 삽입 → 큐: [F, C]
  3. F 방문 → F의 이웃 중 안 들어간 D, E 삽입 → 큐: [C, D, E]
  4. 남은 것을 차례로 꺼내 방문 → C, D, E → A B F C D E

DFS (스택/재귀):

  1. A의 이웃 {B, F} 중 알파벳 앞선 B로
  2. B의 안 간 이웃 {C, F} 중 C로
  3. C의 안 간 이웃 {D, F} 중 D로
  4. D의 안 간 이웃 {E, F} 중 E로
  5. E의 안 간 이웃 {F} → F → 전부 방문 → A B C D E F

매 단계 F를 놔두고 알파벳 앞선 쪽으로 계속 내려갔기 때문에 F가 마지막이 된다.

함정: ①번은 BFS의 D·E 순서만 뒤바꾼 것(ABFCED)이다. 큐에 넣는 순간에도 알파벳 순으로 D 먼저 넣어야 한다.

문제 32017 하반기 국가직 · 기출문제집 p.487

본문 두 번째 예제 그래프(A-B, A-C, B-D, B-E, C-E, D-G, E-G, G-F)의 정점 A에서 DFS와 BFS를 수행할 때 방문 순서를 옳게 짝지은 것은? (안 간 인접 정점이 2개 이상이면 알파벳 오름차순)

  1. DFS: A-B-D-G-F-C-E / BFS: A-B-C-D-E-F-G
  2. DFS: A-B-D-G-F-C-E / BFS: A-B-C-D-E-G-F
  3. DFS: A-B-D-G-E-C-F / BFS: A-B-C-D-E-F-G
  4. DFS: A-B-D-G-E-C-F / BFS: A-B-C-D-E-G-F
해설 보기

정답 ④ DFS: A-B-D-G-E-C-F / BFS: A-B-C-D-E-G-F

DFS 판단 포인트 — G에서 E와 F 중 누구를 먼저?

  1. A→B→D→G까지는 선택지가 하나씩이라 모두 동일
  2. G의 안 간 이웃은 E, F → 알파벳 순이므로 E 먼저 (①②처럼 F를 먼저 가면 틀림)
  3. E→C로 내려간 뒤 C가 막히면 백트래킹 → G로 돌아와 마지막에 F → A-B-D-G-E-C-F

BFS 판단 포인트 — F와 G 중 누가 먼저 큐에 들어가나?

  1. A → B, C 삽입 / B → D, E 삽입 / C → 새로운 것 없음
  2. D를 처리할 때 G가 큐에 들어간다
  3. F는 G를 처리할 때 비로소 들어오므로 G가 F보다 먼저 → A-B-C-D-E-G-F

함정: BFS를 "그냥 알파벳 순(…E-F-G)"으로 착각하면 ①③을 고르게 된다. BFS 순서는 알파벳이 아니라 큐에 들어간 순서로 결정된다. F는 오직 G의 이웃이라 가장 늦게 발견된다.

문제 6기출문제집 p.490 (크루스컬)

본문의 6정점 가중치 그래프(간선 V1-V2=2, V3-V4=3, V0-V2=4, V0-V1=5, V1-V4=6, V1-V3=8, V3-V5=9)에 Kruskal 알고리즘을 적용할 때, 옳지 않은 설명은?

  1. 최소비용 신장트리의 비용은 24이다.
  2. 최소비용 신장트리에 네 번째로 추가되는 간선은 V1과 V4를 연결한 것이다.
  3. 그래프에서 간선의 수가 n개일 때 알고리즘 시간 복잡도는 O(n²)이다.
  4. 새로운 간선을 추가할 때마다 사이클이 형성되는지 확인한다.
해설 보기

정답 ③ — 크루스컬은 O(n²)이 아니라 O(n log n)이다

①·② 검증 (본문 표와 동일):

  1. 채택: 2(V1,V2) → 3(V3,V4) → 4(V0,V2) → [5 버림: 사이클] → 6(V1,V4)이 네 번째 → [8 버림: 사이클] → 9(V3,V5)
  2. 총 비용 = 2+3+4+6+9 = 24 → ① 맞음, ② 맞음

③이 틀린 이유: 크루스컬의 비용은 간선 정렬 O(n log n)이 지배한다. 정렬 후 간선을 훑으며 n−1개 고르는 건 O(n)이므로 전체는 O(n log n).

④가 맞는 이유: 사이클 검사야말로 크루스컬의 핵심 동작이다. 검사를 빼면 사이클이 생겨 트리가 아니게 된다.

해설 보기

  6. 총합 = 4+2+6+3+9 = 24

핵심 정리: 선택 순서는 크루스컬(2→3→4→6→9)과 완전히 다르지만, 고른 간선 집합과 총비용(24)은 똑같다. 그러므로 "몇 번째로 선택되는 간선"을 묻는 문제는 어떤 알고리즘인지부터 확인해야 한다. 총비용만 묻는다면 어느 쪽으로 풀어도 상관없다.
