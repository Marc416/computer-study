그래프 순회와 최소비용 신장트리

BFS·DFS, 크루스컬(Kruskal) 알고리즘 · PART 04. 자료구조론

핵심 요약

BFS(너비우선탐색)는 큐(Queue)로 "가까운 곳부터 옆으로 넓게", DFS(깊이우선탐색)는 스택(Stack)으로 "한 방향으로 끝까지 파고들기"다.

최소비용 신장트리는 모든 정점을 사이클 없이 가장 싼 비용으로 연결하는 것 — 크루스컬은 간선을 싼 순서로 정렬해서 하나씩 골라 담는다.

💡주요 개념 — 그래프 기초

그래프 용어

용어의미

함정 주의: "정점의 수를 차수라고 한다" → ❌ 틀림. 차수는 한 정점에 연결된 간선의 개수다. 정점의 수는 그냥 정점 수.

🕸️주요 개념 — 그래프 순회 (BFS vs DFS) 📖 기출문제집 p.483~484

아래 그래프(정점 A~F)를 예로 들어보자. "누구부터 방문할지 헷갈리면 안 되는" 시험 포인트: 인접한 정점이 여러 개면 알파벳(번호) 순서대로 고른다.

A에서 출발할 때 방문 순서 비교:

탐색법방문 순서왜 이 순서인가
BFS (큐, 가까운 곳부터)A → B → F → C → D → EA의 이웃(B,F)을 먼저 큐에 다 넣고, 그 다음 B의 새 이웃(C), 그 다음 F의 새 이웃(D,E) 순으로 "한 칸씩 넓게" 방문
DFS (스택, 한 방향으로 끝까지)A → B → C → D → E → FA→B로 간 뒤 B의 이웃 중 안 가본 곳(C)으로 계속 파고들고, C→D→E까지 막다른 길에 몰릴 때까지 직진, 마지막에 F
비유: BFS = 동심원을 그리며 퍼지는 물결(가까운 순서대로), DFS = 미로에서 한쪽 벽만 짚고 끝까지 가보는 것(막히면 되돌아옴)
구현 방법 암기: BFS = 큐(Queue)를 쓴다 (먼저 발견한 걸 먼저 방문, FIFO). DFS = 스택(Stack)을 쓴다 (재귀 호출도 결국 스택 구조라 DFS와 같은 원리).

🌲주요 개념 — 최소비용 신장트리(Kruskal 알고리즘) 📖 기출문제집 p.489~490

신장트리(Spanning Tree): 그래프의 모든 정점을 포함하면서 사이클이 없는 부분 그래프. 정점이 n개면 간선은 항상 n−1개다.

크루스컬(Kruskal) 알고리즘의 동작 원리: ① 모든 간선을 가중치 오름차순으로 정렬 → ② 가장 싼 간선부터 하나씩 보면서, 사이클이 생기지 않으면 선택하고 사이클이 생기면 버린다 → ③ 간선을 (정점 수−1)개 선택하면 종료.

실제 기출 예제(정점 6개, 아래는 선택 과정을 정리한 것 — 원본 그림의 정점 배치는 재구성):

  1. 모든 간선을 가중치 오름차순 정렬: 2, 3, 4, 5, 6, 8, 9, ...
  2. 가중치 2인 간선 선택 → 사이클 없음 → 채택 (누적 비용 2)
  3. 가중치 3인 간선 선택 → 사이클 없음 → 채택 (누적 비용 5)
  4. 가중치 4인 간선 선택 → 사이클 없음 → 채택 (누적 비용 9)
  5. 가중치 5인 간선 검토 → 이미 연결된 두 정점을 또 잇는다 → 사이클 발생 → 버림
  6. 가중치 6인 간선 선택 → 사이클 없음 → 채택 (누적 비용 15)
  7. 가중치 8인 간선 검토 → 사이클 발생 → 버림
  8. 가중치 9인 간선 선택 → 사이클 없음 → 채택 (누적 비용 24) → 정점 6개, 간선 5개 완성! 종료
검산: 채택된 간선 5개의 가중치 합 = 2+3+4+6+9 = 24 → 문제에서 "최소비용 신장트리의 비용은 24"라는 선택지가 정답이 되는 이유.

크루스컬 시간복잡도

간선 수를 n이라 하면: 간선 정렬 O(n log n) + 사이클 검사하며 n−1개 선택 O(n) = 전체 O(n log n).

함정 주의: "크루스컬 알고리즘의 시간복잡도는 O(n²)이다" → ❌ 틀림. 간선 정렬이 지배적이라 O(n log n)이 맞다.

📌시험 빈출 포인트

  • 차수(degree) = 정점의 개수가 아니라 한 정점에 연결된 간선 수
  • 여러 이웃 중 방문 순서는 알파벳(번호) 순 — 문제에 명시된 규칙 꼭 확인
  • BFS = 큐(Queue) 사용, DFS = 스택(Stack)/재귀 사용 — 자료구조 짝 암기 필수
  • 신장트리의 간선 수 = 정점 수 − 1 (그래프가 아무리 복잡해도 이 공식은 항상 성립)
  • 크루스컬: 가중치 오름차순 정렬 후 사이클 생기면 무조건 버림
  • 크루스컬 시간복잡도는 O(n log n) (간선 정렬이 병목)
