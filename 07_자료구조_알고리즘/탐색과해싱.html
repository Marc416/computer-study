탐색과 해싱

순차탐색 vs 이진탐색, 해싱과 충돌 해결 · PART 04. 자료구조론

핵심 요약

순차탐색은 처음부터 하나씩(O(n)), 이진탐색은 정렬된 데이터에서 절반씩 잘라가며 찾는다(O(log n)).

해싱은 계산으로 바로 위치를 찾아가는 방식(이상적으로 O(1))이지만, 서로 다른 값이 같은 위치로 몰리는 충돌(Collision)이 생기면 느려진다.

🔎주요 개념 — 순차탐색 vs 이진탐색

구분순차탐색 (Sequential)이진탐색 (Binary)
전제 조건없음 (정렬 불필요)반드시 정렬된 데이터여야 함
탐색 방식처음부터 끝까지 하나씩 비교중간값과 비교 후 범위를 절반으로 줄임
시간복잡도O(n)O(log₂n)

이진탐색 실제로 손으로 풀어보기 📖 기출문제집 p.513

정렬된 배열 [4, 6, 11, 12, 15, 17, 18, 20, 21] (인덱스 1~9)에서 21을 찾는다고 하자. 중간 인덱스는 (low+high)÷2를 내림(floor)해서 구한다.

함정 주의: "순차탐색이 이진탐색보다 평균적으로 빠르다" → ❌ 틀림. 이진탐색은 O(log n), 순차탐색은 O(n)이라 데이터가 많을수록 이진탐색이 압도적으로 빠르다. (단, 순차탐색은 정렬이 필요 없다는 장점은 있음)

🗂️주요 개념 — 해싱(Hashing) 📖 기출문제집 p.517~519

해싱은 "계산 한 번으로 저장 위치를 알아내는" 방식이다. 가장 흔한 방법은 제산법(Division): 해시주소 = 키값 % 배열크기.

실제 기출 예제: 제산법으로 충돌 찾기

11칸짜리 배열에 데이터 111, 112, 113, 220, 221, 222를 키 % 11로 저장한다면?

키계산해시주소
111111 % 111
112112 % 112
113113 % 113
220220 % 110
221221 % 111
222222 % 112
결과: 111과 221이 둘 다 해시주소 1 → 충돌. 112와 222가 둘 다 해시주소 2 → 충돌. 나머지(113→3, 220→0)는 겹치지 않아 충돌 없음.

충돌(오버플로) 해결 방법 2가지

방식원리세부 기법
폐쇄 주소법 (Closed Addressing)처음 계산된 해시주소는 그대로 두고, 그 자리에 연결리스트(체인)로 계속 이어붙임체이닝 (Chaining)
개방 주소법 (Open Addressing)충돌 나면 다른 빈 자리를 찾아 해시주소를 다시 계산해서 옮김선형조사법, 이차조사법, 이중해싱, 재해싱
비유: 체이닝 = 같은 우편함에 편지가 여러 통 오면 묶어서 꽂아두는 것. 개방주소법(선형조사) = 내 우편함이 찼으면 바로 옆 빈 우편함을 찾아 넣는 것.
자주 나오는 함정: "선형 조사법(Linear Probing)은 연결리스트를 사용한다" → ❌ 틀림! 연결리스트를 쓰는 건 체이닝(폐쇄주소법)이다. 선형조사법은 개방주소법이라 배열 안에서 다음 빈 칸을 순서대로 찾아간다.

해싱 성능 요약

  • 충돌이 전혀 없으면 탐색 시간복잡도는 O(1) — 계산 한 번으로 바로 찾음
  • 충돌이 발생한 최악의 경우 시간복잡도는 O(n)
  • 해시 함수 종류: 제산법(나머지), 폴딩법(부분을 나눠 더하거나 XOR), 중간제곱법, 숫자분석법
  • 키 공간(가능한 키의 수)이 저장 공간보다 훨씬 크므로 충돌은 필연적으로 발생한다

📌시험 빈출 포인트

  • 이진탐색은 정렬된 데이터에서만 가능 — 정렬 안 된 데이터라고 하면 함정
  • 이진탐색 비교 횟수 계산: n개 데이터면 최대 ⌈log₂n⌉번
  • 제산법 해시 충돌 찾기: 두 키를 배열크기로 나눈 나머지가 같으면 충돌
  • 체이닝=연결리스트(폐쇄주소법), 선형조사법=배열 안에서 빈칸 탐색(개방주소법) — 절대 뒤바꾸지 말 것
  • 충돌 없을 때 O(1), 충돌(최악) 있을 때 O(n) — 순차탐색 O(n)과 헷갈리지 말 것

⚖️헷갈리는 개념 비교

구분체이닝 (폐쇄주소법)선형조사법 (개방주소법)
자료구조연결리스트배열 (다음 빈 칸 탐색)
원래 해시주소그대로 유지충돌 시 새 주소로 이동
