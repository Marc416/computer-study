# 캐시 기억장치 (Cache Memory)

## 핵심 요약
> CPU와 주기억장치(RAM) 사이의 **속도 차이를 줄이기 위한** 고속 기억장치.
> CPU가 자주 쓰는 데이터를 미리 가져다 놓는 **임시 저장소**.

## 주요 개념

### 캐시가 필요한 이유
- CPU는 매우 빠르고, RAM은 상대적으로 느림
- 이 속도 차이 때문에 CPU가 RAM을 기다리면 성능이 떨어짐
- **캐시가 중간에서 자주 쓰는 데이터를 미리 저장**해두면 CPU가 빠르게 접근 가능

> 비유: 서재(RAM)에서 매번 책을 가져오는 대신, 자주 보는 책을 **책상 위 메모지(캐시)**에 정리해두는 것

### 캐시의 계층 구조

| 구분 | 위치 | 속도 | 용량 | 특징 |
|------|------|------|------|------|
| **L1 캐시** | CPU 코어 내부 | 가장 빠름 | 가장 작음 (수십 KB) | 각 코어 전용 |
| **L2 캐시** | CPU 코어 내부 | 빠름 | 중간 (수백 KB~수 MB) | 각 코어 전용 |
| **L3 캐시** | CPU 칩 내부 | 상대적으로 느림 | 가장 큼 (수 MB~수십 MB) | 여러 코어가 공유 |

> **시험 포인트:** L1, L2, L3 모두 물리적으로는 CPU 칩 안에 있지만, 시험에서는 **논리적 계층**에서 "CPU와 주기억장치 사이"로 표현함

### 캐시의 핵심 원리: 지역성 (Locality)

| 종류 | 설명 | 비유 |
|------|------|------|
| **시간적 지역성** (Temporal) | 최근 사용한 데이터를 다시 사용할 확률이 높음 | 방금 본 메모를 또 볼 가능성이 높음 |
| **공간적 지역성** (Spatial) | 사용한 데이터 근처의 데이터를 사용할 확률이 높음 | 책 한 페이지를 보면 다음 페이지도 볼 가능성이 높음 |

### 캐시 적중과 실패

- **캐시 적중 (Cache Hit):** CPU가 원하는 데이터가 캐시에 있음 → 빠르게 처리
- **캐시 실패 (Cache Miss):** 캐시에 없어서 RAM까지 가야 함 → 느려짐
- **캐시 적중률 (Hit Ratio):** 적중 횟수 / 전체 접근 횟수 → 높을수록 좋음

### 캐시 교체 알고리즘 (캐시가 꽉 찼을 때 어떤 데이터를 빼는가)

| 알고리즘 | 설명 |
|----------|------|
| **LRU** (Least Recently Used) | 가장 오래 전에 사용된 것을 제거 |
| **FIFO** (First In First Out) | 가장 먼저 들어온 것을 제거 |
| **LFU** (Least Frequently Used) | 사용 횟수가 가장 적은 것을 제거 |
| **Random** | 무작위로 제거 |

### 캐시 쓰기 정책

| 정책 | 설명 |
|------|------|
| **Write-Through** | 캐시와 주기억장치에 동시에 기록 (느리지만 안전) |
| **Write-Back** | 캐시에만 기록하고 나중에 주기억장치에 반영 (빠르지만 불일치 위험) |

## 시험 빈출 포인트
- "CPU와 주기억장치 사이에서 속도 차이를 줄이는 기억장치" → **캐시**
- 캐시의 원리 → **지역성 (시간적, 공간적)**
- 캐시 적중률 계산 문제
- 캐시 교체 알고리즘: LRU, FIFO, LFU 구별
- Write-Through vs Write-Back 차이

## 헷갈리는 개념 비교

| 구분 | 캐시 기억장치 | 주기억장치 (RAM) | 보조기억장치 (HDD/SSD) |
|------|--------------|-----------------|---------------------|
| **속도** | 매우 빠름 | 보통 | 느림 |
| **용량** | 매우 작음 | 보통 | 매우 큼 |
| **가격** | 매우 비쌈 | 보통 | 저렴 |
| **위치** | CPU 칩 내부 | CPU 외부 (메인보드) | 외부 장치 |
| **휘발성** | 휘발성 | 휘발성 | 비휘발성 |

## 주기억장치란?

| 종류 | 설명 | 휘발성 |
|------|------|--------|
| **RAM** | 읽기/쓰기 가능, 프로그램 실행 시 사용 | 휘발성 (전원 꺼지면 데이터 사라짐) |
| **ROM** | 읽기 전용, BIOS 등 저장 | 비휘발성 |

> **시험에서 "주기억장치"라고 하면 대부분 RAM을 의미**
