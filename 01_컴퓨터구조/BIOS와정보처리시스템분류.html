BIOS · 정보처리 시스템 · 마이크로프로세서 분류

부팅 과정, 운영체제 처리방식 분류, RISC vs CISC · PART 01. 전자계산기구조론

핵심 요약

BIOS는 ROM에 저장되어 부팅 시 하드웨어를 점검·초기화하고 운영체제를 불러오는 역할을 한다.

운영체제의 처리 방식은 일괄처리·다중프로그래밍·시분할·실시간·분산처리로 나뉘고, 마이크로프로세서는 CISC와 RISC로 구분된다.

💡주요 개념

BIOS(Basic Input Output System) 📖 기출문제집 p.23~24

  • 운영체제가 입출력장치·주변장치를 구동하기 위한 가장 기본적인 루틴들의 집합
  • IBM-PC 호환기종에서는 ROM에 저장 → 흔히 롬바이오스(ROM-BIOS)라 부름
  • 구성: 스타트업 루틴(POST), 서비스 처리 루틴(입출력 기본 서비스), 하드웨어 인터럽트 처리 루틴
함정 주의: CMOS 셋업(메인보드에서 값 설정)은 BIOS가 부팅 중에 "항상 하는 일"이 아니다 — POST·시스템 초기화·부트스트랩 로더 로드와 구분할 것.

정보처리 시스템(운영체제 처리방식)의 분류 📖 기출문제집 p.25

방식정의비고
일괄 처리 시스템 (Batch)일정 기간·양의 작업을 모아 한꺼번에 처리CPU와 I/O 속도차로 CPU 유휴시간 많음
다중 프로그래밍 (Multi-programming)여러 프로그램을 주기억장치에 적재해두고 하나의 CPU를 번갈아 사용목적: CPU 활용의 극대화(처리량 증가)
시분할 시스템 (Time Sharing)CPU 시간을 일정 간격(타임 슬라이스)으로 쪼개 여러 사용자에게 순차 할당목적: 응답시간 최소화. 선점(preemptive) 스케줄링 사용
실시간 시스템 (Real Time)정해진 시간 내 반드시 응답을 보장예: 심장 모니터링, 좌석 예약. 선점 스케줄링 사용
분산 처리 시스템 (Distributed)네트워크로 연결된 여러 컴퓨터가 작업을 분산 처리네트워크 구축이 반드시 필요, 신뢰도·확장성 향상
함정 주의: "CPU 운영 시간을 잘게 쪼개 여러 사용자에게 공평하게 제공"하는 것은 분산 처리 시스템이 아니라 시분할 시스템에 대한 설명이다.

다중 프로세서 시스템의 결합 방식

구분밀결합 (Tightly-Coupled)약결합 (Loosely-Coupled)
통신 방식공유 기억장치(Shared Memory) 이용각자 지역 기억장치를 갖고 네트워크로 통신
대응 개념다중처리(Multi-processing)분산처리(Distributed Processing)

다중 프로세서 시스템에서는 각 프로세서의 로컬 캐시 간 데이터 일치를 보장하는 캐시 일관성(Cache Coherence) 문제를 반드시 고려해야 한다.

📌시험 빈출 포인트

  • BIOS는 ROM에 저장, 운영체제는 보조기억장치에 저장되어 있다가 부팅 시 주기억장치로 적재
  • 부팅 순서: POST → BIOS 정보 RAM 복사 → 부트스트랩 로더가 OS 적재
  • 다중프로그래밍 목적 = CPU 활용 극대화, 시분할 목적 = 응답시간 최소화 (목적 구분 문제)
  • 시분할 시스템은 선점 스케줄링 (비선점 아님 — 자주 나오는 오답 함정)
  • "CPU 시간을 잘게 쪼개 공평 배분" → 시분할 (분산처리로 헷갈리지 않기)
  • 밀결합=공유기억장치, 약결합=네트워크 통신 — 다중처리 vs 분산처리와 대응
  • RISC는 명령어 종류가 적고, 레지스터 수는 많고, 고정 길이 명령어 사용
  • RISC가 CISC보다 파이프라이닝·슈퍼스칼라 구현에 더 유리
