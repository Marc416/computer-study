보수와 실수 표현 (IEEE 754)

1의 보수·2의 보수, 고정소수점, 부동소수점 표준 · PART 01. 전자계산기구조론

핵심 요약

컴퓨터는 음수를 2의 보수로 표현한다 — "0은 1로, 1은 0으로" 바꾼 뒤(1의 보수) +1을 더한다.

실수는 IEEE 754 표준으로 부호(1비트) + 지수(바이어스 적용) + 가수 3부분으로 저장한다.

💡주요 개념

보수(Complement) 표현법 3가지 📖 기출문제집 p.49

방식표현 규칙 (4비트, -4 예시)
부호와 절대치최상위 비트=부호(1=음수), 나머지는 절대값 그대로 → 1100
1의 보수양수 절대치의 모든 비트를 반전(0↔1) → 0100 반전 → 1011
2의 보수1의 보수에 +1 → 1011 + 1 = 1100

계산 방법: -35를 8비트 2의 보수로 바꾸는 순서 📖 기출문제집 p.51

  1. 35를 2진수(절대치)로 변환: 00100011
  2. 모든 비트 반전(1의 보수): 00100011 → 11011100
  3. +1 (2의 보수 완성): 11011100 + 1 = 11011101
2의 보수 → 10진수로 되돌리기 (예: 10111100)
최상위 비트가 1 → 음수. 2의 보수를 취해(1의 보수 후 +1) 절대값을 구한다.
10111100 → 1의 보수 01000011 → +1 → 01000100(=68) → 결과 -68

2의 보수를 쓰는 이유 — 뺄셈을 덧셈으로

  • A - B 연산을 A + (B의 2의 보수)로 바꿔서 덧셈 회로 하나로 가감산 모두 처리
  • 예: 7 - 3 → 3의 2의 보수를 구해 7에 더한다
  • 최상위 자리에서 캐리(carry)가 발생하면 결과는 양수, 발생하지 않으면 결과는 2의 보수 형태의 음수

표현 범위와 오버플로

비트 수2의 보수 표현 범위
n비트-2ⁿ⁻¹ ~ +(2ⁿ⁻¹ - 1)
4비트 예시-8 ~ +7
함정 주의: 최댓값(2ⁿ⁻¹-1)과 최솟값(-2ⁿ⁻¹)의 합은 항상 -1이다. 2의 보수는 0을 한 가지로만 표현하므로(부호와 절대치·1의 보수 대비) 음수 범위가 하나 더 넓다.

오버플로(Overflow): 덧셈 결과가 표현 범위(-2ⁿ⁻¹~2ⁿ⁻¹-1)를 벗어날 때 발생 — 마지막 캐리와 그 앞 비트의 캐리를 XOR해서 1이면 오버플로.

고정소수점 vs 부동소수점

구분고정소수점부동소수점
표현 대상정수실수
구조부호 + 절대치(또는 보수)부호 + 지수부 + 가수부

IEEE 754 부동소수점 표준 📖 기출문제집 p.54

정규화된 형태 ±1.bbb...b × 2±E 로 표현하며, 아래 3부분으로 저장한다.

구분단일 정밀도 (32비트)이중 정밀도 (64비트)
부호부1비트1비트
지수부8비트 (바이어스 127)11비트 (바이어스 1023)
가수부23비트52비트
  • 부호 비트: 0=양수, 1=음수
  • 지수부에는 실제 지수 + 바이어스 값을 저장 (음수 지수를 양수로 표현하기 위함)
  • 가수부에는 정규화된 "1." 을 제외한 나머지 소수 부분만 저장
  • 가수부 비트가 많을수록 정밀도(정확도)가 높아짐
  • 0은 특별한 값으로 모든 비트를 0으로 표현

계산 방법: 10진수 -2.75 → IEEE 754 단정도 변환 순서 📖 기출문제집 p.55

  1. 2진수로 변환: 2.75 = 10.11₂
  2. 정규화(소수점을 맨 앞자리 1 뒤로 이동): 10.11 → 1.011 × 2¹
  3. 부호 결정: 음수이므로 부호비트 = 1
  4. 지수 계산: 실제 지수 1 + 바이어스 127 = 128 = 2진수 10000000
  5. 가수 채우기: 정규화된 가수 "011" 뒤에 0을 채워 23비트로: 01100000000000000000000
  6. 합치기: 1 10000000 01100000000000000000000

부동소수점의 사칙연산 규칙 📖 기출문제집 p.58

연산규칙
덧셈/뺄셈① 0인지 검사 → ② 지수가 큰 쪽에 맞춰 작은 쪽 가수 위치 조정 → ③ 가수 연산 → ④ 결과를 다시 정규화
곱셈지수를 더한다
나눗셈지수를 뺀다
함정 주의: 지수를 맞출 때는 항상 "지수가 작은 수"의 가수 위치를 조정한다 (지수가 큰 수를 기준으로 삼음). 반대로 알면 오답.

📌시험 빈출 포인트

  • 10진수를 2의 보수 n비트로 변환하는 계산 문제 (절대치 → 1의 보수 → +1 순서)
  • 2의 보수 값을 다시 10진수로 해석하는 문제 (최상위 비트=부호 확인 먼저)
  • 2의 보수 n비트 표현 범위 = -2ⁿ⁻¹ ~ 2ⁿ⁻¹-1, 최댓값+최솟값 = -1
  • 뺄셈을 2의 보수 덧셈으로 바꿔 계산하는 문제, 오버플로 판정 문제
  • IEEE 754 단정도=32비트(부호1·지수8·가수23), 배정도=64비트(부호1·지수11·가수52)
  • 바이어스 값: 단정도=127, 배정도=1023
  • 부동소수점 덧셈/뺄셈은 "지수가 큰 쪽" 기준으로 정렬, 곱셈=지수 덧셈, 나눗셈=지수 뺄셈
  • 같은 비트 수라면 IEEE 754와 2의 보수 정수가 표현 가능한 "개수"는 동일(2ⁿ개) — 표현 "범위"만 다름
