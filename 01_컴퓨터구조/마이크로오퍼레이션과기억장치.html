마이크로 오퍼레이션과 기억장치

명령어 사이클의 최소 동작 단위와 기억장치의 종류·계층 · PART 01. 전자계산기구조론

핵심 요약

마이크로 오퍼레이션 = 한 클럭 펄스 동안 실행되는 가장 작은 동작 단위. 명령어 하나는 여러 개의 마이크로 오퍼레이션으로 구성된다.

기억장치는 레지스터 > 캐시 > 주기억장치(RAM) > 보조기억장치 순으로 빠르고, 이 순서대로 용량은 커지고 가격은 싸진다.

💡주요 개념 — 마이크로 오퍼레이션과 명령어 사이클

마이크로 오퍼레이션이란?

  • 한 개의 클럭 펄스 동안 실행되는 기본 동작 (레지스터 전송, 시프트, 로드 등)
  • 하나의 명령어는 여러 개의 마이크로 오퍼레이션이 순서대로 동작해야 실행된다 (하나만으로 끝나지 않음)
  • 마이크로 오퍼레이션 수행 시간(마이크로 사이클 타임)은 CPU 속도를 나타내는 척도로 쓰인다

명령어 사이클의 구성

명령어 사이클 = 인출(Fetch) → (간접, 필요시) → 실행(Execute) → (인터럽트, 필요시) 사이클 순서로 진행

사이클내용
인출 (Fetch)주기억장치의 정해진 위치에서 명령어를 읽어옴
간접 (Indirect)간접 주소지정 방식일 때 유효 주소를 찾는 과정 (필요한 경우만)
실행 (Execute)해독된 명령어 코드에 따라 필요한 연산을 수행
인터럽트 (Interrupt)인터럽트 요구가 있을 때만 수행, 끝나면 다시 인출 사이클로
인출 사이클의 마이크로 오퍼레이션 예시:
t0: MAR ← PC (현재 명령어 주소를 MAR로)
t1: MBR ← M[MAR], PC ← PC + 1 (기억장치에서 읽어와 MBR에 적재, PC는 다음 명령어를 가리키도록 +1)
t2: IR ← MBR (읽어온 명령어 코드를 명령 레지스터로 이동)

시스템 버스의 3요소

버스방향역할
주소 버스 (Address Bus)단방향읽기/쓰기 대상 주기억장치 위치(주소)를 전달
데이터 버스 (Data Bus)양방향실제 데이터를 주고받음
제어 버스 (Control Bus)-CPU ↔ 주기억장치·입출력장치 간 제어 신호 전달
함정 주의: "명령어 버스"는 시스템 버스의 종류가 아니다 — 시스템 버스는 주소·데이터·제어 버스 3가지뿐이다. 데이터 버스는 단방향이 아니라 양방향이다.

🗄️주요 개념 — 기억장치의 종류

기억장치 계층 구조

레지스터 → 캐시 → 주기억장치(RAM) → 보조기억장치(HDD/SSD) 순으로 계층이 낮아질수록 속도는 느려지고, 용량은 커지며, 비트당 가격은 싸진다.

캐시기억장치의 적중률·지역성·교체 알고리즘(LRU/FIFO/LFU)·쓰기 정책(Write-Through/Write-Back) 등 상세 내용은 캐시기억장치 문서를 참고.

SRAM vs DRAM

구분SRAM (Static RAM)DRAM (Dynamic RAM)
저장 방식플립플롭(flip-flop)축전기(capacitor)의 충전 상태
재충전(refresh)불필요필요 (전하가 시간이 지나면 방전되므로 주기적 재충전)
속도빠름느림 (SRAM 대비 약 1/5)
가격/소비전력비쌈저렴, 소비전력 적음
집적도낮음높음 (대용량에 유리)
주 용도캐시 기억장치주기억장치
휘발성휘발성휘발성
함정 주의: SRAM도 DRAM과 마찬가지로 휘발성이다 (비휘발성 아님). 전원이 공급되는 동안만 데이터를 유지한다.

ROM의 종류

종류특징
Mask ROM제작 시 데이터를 회로에 새겨 넣음. 내용 변경 불가능
PROMProgrammable ROM. 1회에 한해 사용자가 새로운 내용을 기록 가능
EPROMErasable PROM. 자외선으로 지우고 여러 번 재기록 가능
EEPROMElectrically Erasable PROM. 전기적으로 지우고 재기록 가능
플래시 메모리EEPROM의 한 종류지만 블록 단위로 데이터를 기록 (EEPROM은 바이트 단위)

플래시 메모리: NAND vs NOR

구분NAND FlashNOR Flash
셀 배치직렬병렬
용도대용량 데이터 저장형 (MP3, 카메라, USB, SSD)속도 빠른 코드 저장형 (휴대폰 등)
대용량화쉬움어려움
읽기/쓰기 단위페이지(page) 단위바이트/워드 단위 임의 접근
지우기(erase) 단위블록(block) 단위블록 단위

공통점: 전원이 꺼져도 데이터 보존(비휘발성), 덮어쓰기(overwrite) 전에 반드시 지우기(erase) 선행 필요, 지우기 속도는 읽기보다 느림.

RAID (Redundant Array of Independent Disks)

여러 개의 디스크를 하나의 논리적 디스크처럼 묶어 신뢰성 또는 처리 속도를 향상시키는 기술.

레벨기법특징
RAID 0스트라이핑 (Striping)데이터를 여러 디스크에 분산 저장. 속도↑ 하지만 중복 저장 없음 → 오류 복구 불가
RAID 1미러링 (Mirroring)모든 데이터를 복사해서 별도 디스크에 저장. 신뢰성 높지만 저장 효율 낮음(50%)
RAID 2비트 단위 분산 + 해밍코드여러 개의 패리티 디스크 사용 (해밍코드로 오류 검출·교정)
RAID 3비트 단위 분산 + 패리티전용 패리티 디스크 1개 사용
RAID 4블록 단위 분산 + 패리티전용 패리티 디스크 1개 사용 (패리티 디스크에 병목 발생)
RAID 5블록 단위 + 패리티 분산패리티를 여러 디스크에 분산 저장 (병목 해결)
RAID 6블록 단위 + 이중 패리티패리티를 2중으로 구성해 디스크 2개까지 장애 허용
암기팁: "0=속도만, 1=복사, 2~6=패리티로 복구" — 숫자가 커질수록(4→5) 패리티를 분산시켜 병목을 줄이는 방향으로 발전

메모리 인터리빙 (Memory Interleaving)

기억장치를 여러 개의 모듈로 나누고, 각 모듈에 독립적으로 동시에 접근할 수 있게 하여 CPU와 기억장치 사이의 실질적 대역폭을 늘리는 방법. 연속된 주소의 데이터를 한 번의 사이클에 병렬로 꺼낼 수 있다.

리틀 엔디안 vs 빅 엔디안

구분리틀 엔디안 (Little Endian)빅 엔디안 (Big Endian)
저장 순서하위 바이트를 낮은 주소에 저장상위 바이트를 낮은 주소에 저장
대표 CPUx86 계열일부 RISC, 네트워크 프로토콜

디스크 접근 시간

접근 시간(Access Time) = 탐색시간(Seek Time) + 회전지연시간(Rotational Latency) + 전송시간(Transfer Time)

용어의미
탐색시간 (Seek Time)헤드가 목표 트랙(실린더)까지 이동하는 시간
회전지연시간 (Latency)디스크가 회전해 목표 섹터가 헤드 밑에 올 때까지의 시간
전송시간 (Transfer Time)실제 데이터를 읽거나 쓰는 시간

가상기억장치 (개요)

  • 디스크 일부를 마치 주기억장치처럼 사용하는 기법 → 물리적 메모리 크기 제약 없이 프로그래밍 가능
  • 프로세스가 쓰는 가상 주소를 실제 물리 주소로 바꾸는 과정을 동적 주소 변환(DAT)이라 함
  • TLB(Translation Lookaside Buffer): 가상주소↔물리주소 변환 결과를 저장해두는 일종의 캐시
  • 고정 크기 블록 = 페이지(Paging) → 내부 단편화 발생 / 가변 크기 블록 = 세그먼트(Segmentation) → 외부 단편화 발생
  • 가상기억장치를 쓰면 프로세서 이용률·다중 프로그래밍은 좋아지지만, 수행 속도(응답시간)는 오히려 느려질 수 있음
가상기억장치의 페이지 교체 알고리즘(FIFO, LRU, Optimal 등)과 스래싱 등 상세 내용은 02_운영체제 파트에서 더 깊게 다룬다.

📌시험 빈출 포인트

  • 기억장치 속도 순서: 레지스터 > 캐시 > 주기억장치 > 보조기억장치
  • SRAM = 캐시용(재충전 불필요, 빠름), DRAM = 주기억장치용(재충전 필요, 느림) — 둘 다 휘발성
  • ROM 종류 중 몇 번 지우고 다시 쓸 수 있는지 구분: PROM(1회) → EPROM(자외선, 여러번) → EEPROM(전기적, 여러번)
  • 플래시 메모리 = EEPROM의 한 종류, 블록 단위 입출력이 특징
  • RAID 0=스트라이핑(속도만, 복구 불가), RAID 1=미러링(복사, 고신뢰성), RAID 4·5의 차이는 패리티 디스크 분산 여부
  • 디스크 접근시간 = 탐색시간 + 회전지연시간 + 전송시간 계산 문제
  • 가상기억장치는 응답시간을 오히려 느리게 만들 수 있음 (빠르게 만든다는 표현은 오답)
  • 시스템 버스는 주소·데이터·제어 버스 3가지, 데이터 버스는 양방향
