비트 논리연산과 디지털 논리

비트 논리연산 · 시프트 · 논리 게이트 · 연산자 우선순위 · PART 01. 전자계산기구조론

핵심 요약

OR = 세트(set), AND = 마스크(삭제), XOR = 선택적 보수(반전) — 원하는 비트만 골라 조작할 때 쓴다.

NAND, NOR는 그 자체만으로 모든 논리 게이트를 만들 수 있는 유니버설 게이트다.

🎯이 단원을 왜 배우나

"비트 하나만 건드리고 싶다"는 문제

CPU는 메모리를 바이트(8비트) 단위로만 읽고 쓴다. 그런데 실제로는 "8개 비트 중 3번째 비트만 1로 켜고 나머지는 그대로 두고 싶다" 같은 상황이 계속 생긴다. 예를 들어 상태 레지스터의 Carry 플래그만 켜기, 네트워크 IP 주소에서 네트워크 부분만 추출하기(서브넷 마스크가 바로 이것이다), 파일 권한에서 쓰기 권한만 빼기 같은 것들이다.

이때 쓰는 도구가 비트 논리연산이다. 핵심 아이디어는 이렇다 — "바꾸고 싶은 자리에는 1을, 그대로 두고 싶은 자리에는 0을 놓은 값(마스크)"을 하나 만들어서 연산한다. 어떤 연산을 쓰느냐에 따라 "바꾼다"의 의미가 켜기(OR)·끄기(AND)·뒤집기(XOR)로 달라질 뿐이다.

그래서 시험 문제도 항상 같은 모양이다: "A는 그대로 두고 특정 비트만 ○○하려면 B는 무엇이어야 하는가?" → 연산 종류를 보고 마스크를 역추적하면 된다.

💡주요 개념

기본 비트 논리연산의 용도 📖 기출문제집 p.60

연산용도원리
OR선택적 세트 (selective-set)특정 비트와 1을 OR하면 그 비트는 무조건 1이 됨, 0과 OR하면 원래 값 유지

XOR선택적 보수 (selective-complement)특정 비트와 1을 XOR하면 반전됨, 0과 XOR하면 원래 값 유지
암기: "OR는 켜고(1), AND는 끄고(0), XOR는 뒤집는다(반전)" — 마스크 B에 1이 놓인 자리에서만 "특별한 동작"이 일어난다고 기억

실제로 비트가 어떻게 바뀌는지 직접 보기

아래 세 표는 똑같은 A(1101 1110)에 똑같은 마스크 B(0000 1111)를 연산 종류만 바꿔 적용한 것이다. 마스크의 오른쪽 4비트가 1이므로, 오른쪽 4비트에서만 변화가 일어나고 왼쪽 4비트는 세 경우 모두 그대로인 것을 확인해라.

OR (선택적 세트)11011110
A (원본)11011110
B (마스크)00001111
A OR B11011111

→ 오른쪽 4비트가 전부 1로 세트됨 (원래 1110이었든 0000이었든 무조건 1111)

AND (마스크·삭제)11011110
A (원본)11011110
B (마스크)00001111
A AND B00001110

→ 이번엔 반대로 왼쪽 4비트가 전부 0으로 삭제되고, 마스크가 1인 오른쪽 4비트만 원본 그대로 살아남음. "필요한 부분만 남기고 나머지를 지우는" 추출(extract) 용도로 쓴다.

XOR (선택적 보수)11011110
A (원본)11011110
B (마스크)00001111
A XOR B11010001

→ 오른쪽 4비트(1110)가 반전되어 0001이 됨 = 그 부분의 1의 보수. 왼쪽은 그대로.

시험에서 역으로 묻는 방식: "A XOR B의 결과가 상위 4비트는 A의 1의 보수, 하위 4비트는 A와 같다. B는?" → 반전할 자리에 1, 유지할 자리에 0을 놓으면 되므로 B = 1111 0000. 아래 연습문제 1번이 바로 이 문제다.

논리 게이트 기호와 진리표 📖 기출문제집 p.63

회로도 문제에서는 게이트를 기호 모양으로 준다. 모양만 보고 어떤 게이트인지 바로 읽을 수 있어야 한다. 출력 쪽에 작은 동그라미(버블)가 붙어 있으면 "결과를 뒤집는다"는 뜻이다 — AND에 버블이 붙으면 NAND, OR에 버블이 붙으면 NOR.

유니버설 게이트 — NAND 하나로 전부 만들기

NAND와 NOR를 유니버설 게이트라고 부르는 이유는 말 그대로 그것 하나만 여러 개 있으면 AND·OR·NOT을 전부 만들 수 있기 때문이다. 실제 반도체 공장에서도 NAND 한 종류만 대량으로 찍어내 조합하는 편이 여러 종류를 따로 만드는 것보다 싸다. 아래가 그 증명이다.

  • NAND, NOR 게이트는 그 자체 하나만으로 AND, OR, NOT 등 모든 논리 게이트를 구현할 수 있다
  • 반대로 AND·OR·XOR 단독으로는 NOT을 만들 수 없다 → 유니버설이 아니다 (시험에서 "유니버설 게이트가 아닌 것" 문제의 정답 근거)
  • OR+DECODER, MULTIPLEXER 조합도 응용하면 유니버설 게이트 역할 가능

드모르간의 법칙 (De Morgan's Law) 📖 기출문제집 p.71

(A · B)′ = A′ + B′   — AND의 부정은 각각 부정해서 OR
(A + B)′ = A′ · B′   — OR의 부정은 각각 부정해서 AND

말로 이해하기

"(비가 오고 그리고 춥다)가 아니다" = "비가 안 오거나 춥지 않다" — 둘 중 하나만 어긋나도 전체가 거짓이 되니까 OR로 바뀐다.

"(비가 오거나 춥다)가 아니다" = "비도 안 오고 춥지도 않다" — 둘 다 아니어야 하니까 AND로 바뀐다.

규칙 한 줄 요약: 괄호 밖의 부정을 안으로 집어넣으면서 ·(AND) ↔ +(OR)를 서로 바꾼다. 각 항에는 부정을 하나씩 붙인다.

NAND/NOR로 구성된 회로의 논리식을 AND/OR/NOT 식으로 바꾸거나, 그 반대로 변환할 때 필수로 쓰인다. 위 유니버설 게이트 ③번 그림이 바로 드모르간을 회로로 옮긴 예다.

시프트 연산 — 논리 시프트 vs 산술 시프트 📖 기출문제집 p.61

시프트는 비트를 통째로 좌우로 밀어내는 연산이다. 왼쪽으로 1비트 밀면 값이 ×2, 오른쪽으로 1비트 밀면 ÷2가 되기 때문에 곱셈·나눗셈을 빠르게 대신하는 데 쓴다. 문제는 오른쪽으로 밀 때 왼쪽에 새로 생기는 빈칸을 무엇으로 채우느냐인데, 여기서 논리 시프트와 산술 시프트가 갈린다.

연산자 우선순위 (C 언어 기준) 📖 기출문제집 p.62

암기: "괄호 → 단항 → 산술 → 시프트 → 관계 → 비트논리 → 논리 → 조건 → 대입 → 콤마" 순서로 높다에서 낮다로. 산술이 관계·논리보다 먼저 계산된다는 것이 핵심.
실전 함정: a & b == c 는 a & (b == c) 로 계산된다 — 비트논리(&)가 관계(==)보다 낮기 때문이다. 의도대로 쓰려면 (a & b) == c 처럼 괄호를 반드시 써야 한다.

📌시험 빈출 포인트

  • "특정 비트를 세트(1로 고정)" → OR, "특정 비트를 삭제(0으로 고정)" → AND, "특정 비트를 반전" → XOR
  • 마스크 역추적 문제: 바꿀 자리에 1, 유지할 자리에 0을 놓으면 끝
  • 유니버설 게이트 = NAND, NOR (AND, OR, XOR 단독은 아님 — NOT을 못 만들기 때문)
  • NAND/XOR 등 비트 연산 결과를 직접 계산하는 문제 (2진수 → 결과 → 16진수 변환까지 이어지는 복합 문제)
  • 드모르간 법칙으로 논리식 간략화·게이트 변환하는 문제 매년 출제
  • 연산자 우선순위: 산술 > 시프트 > 관계 > 비트논리 > 논리 순서 헷갈리지 말 것
  • 산술 우측 시프트는 부호비트를 복사해 채운다 — 음수(1로 시작)는 왼쪽이 1로 채워짐

문제 12014 지방직 · 기출문제집 p.60

8비트 데이터 A와 B에 대해 A XOR B 연산을 수행하였더니, A의 값에 상관없이 연산 결과의 상위(왼쪽) 4비트는 A 상위 4비트의 1의 보수이고, 하위(오른쪽) 4비트는 A의 하위 4비트와 같았다. B의 값을 이진수로 표현한 것은?

  1. 00001111₂
  2. 11110000₂
  3. 10010000₂
  4. 00001001₂
해설 보기

정답 ② 11110000₂

XOR의 성질부터 정리하자. 1과 XOR하면 반전, 0과 XOR하면 그대로다.

  1. 상위 4비트는 "1의 보수(= 반전)"가 되어야 한다 → 그 자리의 B는 1111
  2. 하위 4비트는 "A와 같다(= 유지)"여야 한다 → 그 자리의 B는 0000
  3. 합치면 B = 1111 0000

함정: ①번(00001111)은 상하위를 거꾸로 생각한 경우다. "반전할 자리에 1"이라는 방향을 반드시 확인할 것.

문제 22013 국가직 · 기출문제집 p.60

다음 두 이진수에 대한 NAND 비트 연산 결과는?
10111000₂ NAND 00110011₂

  1. 00110000₂
  2. 10111011₂
  3. 11001111₂
  4. 01000100₂
해설 보기

정답 ③ 11001111₂

NAND = AND한 다음 전부 반전. 두 단계로 나눠 풀면 실수하지 않는다.

  1. 먼저 AND: 10111000 AND 00110011 → 각 자리에서 둘 다 1일 때만 1 → 00110000
  2. 그 결과를 반전(NOT): 00110000 → 11001111

함정: ①번(00110000)은 AND까지만 하고 반전을 빼먹은 오답이다. NAND·NOR 문제는 "마지막에 뒤집기"를 잊지 않는 것이 전부다.

문제 32016 계리직 · 기출문제집 p.61

2진수 11110000과 10101010에 대해 XOR 논리 연산을 수행한 결과값을 16진수로 바르게 표현한 것은?

  1. 5A
  2. 6B
  3. A5
  4. B6
해설 보기

정답 ① 5A

  1. XOR 수행 (같으면 0, 다르면 1):
    11110000
    10101010
    → 01011010
  2. 16진수 변환은 4비트씩 끊어서 한다: 0101 | 1010
  3. 0101₂ = 5, 1010₂ = A → 5A

함정: ③번 A5는 4비트 묶음의 앞뒤를 바꿔 읽은 오답이다. 항상 왼쪽 묶음이 앞자리다.

문제 42023 지방직 · 기출문제집 p.61

2의 보수로 표현된 부호 있는 8비트 2진 정수 10110101을 2비트만큼 산술 우측 시프트(arithmetic right shift)한 결과는?

  1. 00101101
  2. 11010100
  3. 11010111
  4. 11101101
해설 보기

정답 ④ 11101101

  1. 맨 왼쪽 비트가 1이므로 음수다 → 산술 시프트에서는 왼쪽 빈칸을 1(부호비트)로 채워야 한다
  2. 원본: 1011 0101 — 오른쪽 끝 2비트(01)는 밀려나 버려진다
  3. 남은 6비트(101101)를 오른쪽으로 2칸 밀고, 왼쪽에 생긴 2칸을 11로 채운다
  4. 결과: 11 + 101101 = 11101101

함정: ①번(00101101)은 논리 시프트처럼 0으로 채운 오답 — 음수가 갑자기 양수가 되어버린다. 문제에 "산술"이라 쓰여 있으면 반드시 부호비트를 복사해야 한다.

문제 52007 국가직 · 기출문제집 p.62

프로그램의 연산자 실행 우선순위가 높은 것에서 낮은 순으로 옳게 연결한 것은?

  1. 괄호 안의 수식 → 산술 연산자 → 관계 연산자 → 논리 연산자
  2. 산술 연산자 → 관계 연산자 → 논리 연산자 → 괄호 안의 수식
  3. 괄호 안의 수식 → 산술 연산자 → 논리 연산자 → 관계 연산자
  4. 산술 연산자 → 관계 연산자 → 논리 연산자 → 괄호 안의 수식
해설 보기

정답 ① 괄호 → 산술 → 관계 → 논리

괄호는 항상 최우선이므로 ②·④번처럼 괄호가 맨 뒤에 오는 선택지는 바로 제외된다. 남은 ①·③ 중에서는 관계 연산자가 논리 연산자보다 먼저다.

이유를 생각하면 외우기 쉽다: if (a > 3 && b < 5) 에서 비교를 먼저 끝내야(a>3, b<5) 그 참·거짓을 논리 연산(&&)으로 묶을 수 있다. 순서가 반대면 애초에 계산이 불가능하다.

문제 6개념 확인 · 응용

어떤 8비트 값 A에서 상위 4비트만 남기고 하위 4비트는 0으로 지우고 싶다. 어떤 연산과 어떤 마스크를 써야 하는가?

해설 보기

정답: A AND 11110000₂

  1. "0으로 지운다(삭제)"가 목적 → AND 연산 (AND는 0과 만나면 무조건 0)
  2. AND에서는 1인 자리가 원본 유지, 0인 자리가 삭제된다 (OR·XOR와 반대 방향이라 헷갈리기 쉬움)
  3. 상위 4비트는 살려야 하므로 1111, 하위 4비트는 지워야 하므로 0000 → 마스크 = 11110000

정리: OR·XOR는 "1인 자리에서 동작", AND는 "0인 자리에서 동작"이다. 이 방향 차이만 확실히 잡으면 이 유형은 전부 맞힐 수 있다.
