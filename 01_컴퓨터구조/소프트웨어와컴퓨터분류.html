소프트웨어와 컴퓨터의 분류

시스템/응용 소프트웨어, 언어 번역 프로그램, 폰노이만 구조, 컴퓨터 발전 세대 · PART 01. 전자계산기구조론

핵심 요약

소프트웨어는 하드웨어를 동작시키는 시스템 소프트웨어와, 특정 업무를 처리하는 응용 소프트웨어로 나뉜다.

현재 컴퓨터의 기본 구조는 폰노이만 구조(프로그램 내장 방식)이며, 최초로 이 방식을 적용한 컴퓨터는 EDSAC이다.

🎯이 단원을 왜 배우나

"내가 짠 코드가 실행되기까지 누가 무슨 일을 하는가"

C 파일 하나를 작성하고 실행 버튼을 누르면 프로그램이 돌아간다. 그 사이에 컴파일러 → 링커 → 로더가 차례로 일을 하는데, 대부분 이 셋을 뭉뚱그려 "컴파일한다"고 부르기 때문에 시험에서 역할을 나눠 물으면 헷갈린다. 이 단원의 절반이 "이 작업은 셋 중 누구 담당인가"를 묻는 문제다.

나머지 절반은 컴퓨터가 지금 모습이 된 역사다. 특히 프로그램 내장 방식(폰노이만 구조)은 "명령어도 데이터처럼 메모리에 저장한다"는 한 줄짜리 아이디어인데, 이것 때문에 컴퓨터가 배선을 바꾸지 않고도 다른 일을 할 수 있게 됐다. 시험은 이 방식을 누가 처음 적용했는지(EDSAC)와 적용하지 않은 예외(ENIAC)를 집요하게 묻는다.

세대 구분·아날로그/디지털 분류는 순수 암기 항목이지만, 문제 수가 꾸준해서 표 한 장만 외워두면 확실한 득점 구간이 된다.

💡주요 개념

시스템 소프트웨어 vs 응용 소프트웨어 📖 기출문제집 p.19

구분정의예시
시스템 소프트웨어하드웨어를 동작시키고 응용SW의 실행 플랫폼을 제공운영체제(Windows·UNIX·LINUX), 장치 드라이버, 언어 번역기(컴파일러·어셈블러·인터프리터), 링커, 로더, 유틸리티
응용 소프트웨어사용자의 특정 업무 처리 목적워드프로세서, 스프레드시트(엑셀), 게임
함정 주의: 워드프로세서·스프레드시트는 "시스템 소프트웨어에 포함되지 않는 것"을 묻는 문제의 단골 정답(=응용 소프트웨어)이다.

언어 번역/실행 관련 프로그램 📖 기출문제집 p.20

용어역할
컴파일러 (Compiler)고급언어 프로그램을 한꺼번에 목적/기계어로 번역
인터프리터 (Interpreter)고급언어 프로그램을 한 문장씩 번역하면서 바로 실행
어셈블러 (Assembler)어셈블리어 → 기계어로 번역
프리프로세서 (Preprocessor)본 번역에 앞서 사전 처리·치환 작업을 수행하는 전처리기
디버거 (Debugger)프로그램 오류를 추적·탐지
링커 (Linker)컴파일된 목적 프로그램들과 라이브러리를 연결(linking)해 실행 가능한 로드 모듈로 통합
로더 (Loader)목적 프로그램을 주기억장치에 올려 실행: 할당(allocation)·재배치(relocation)·적재(loading)
함정 주의: "프리프로세서가 고급언어를 기계어로 번역한다"는 설명은 컴파일러에 대한 설명이다 — 프리프로세서는 번역기가 아니라 사전 처리기다.

소스코드가 실행되기까지 — 전체 파이프라인

이 도구들을 따로따로 외우면 반드시 헷갈린다. 소스코드 한 줄이 실행되기까지 어떤 순서로 손을 거치는지 흐름으로 보면 각자의 역할이 자연스럽게 구분된다.

각 단계가 왜 따로 존재하나

컴파일러가 만든 목적 프로그램(.o)은 그대로는 실행할 수 없다. 내 코드에서 printf를 불렀다면, 그 함수의 실제 코드는 내 파일에 없고 라이브러리에 있기 때문이다. 목적 파일에는 "여기서 printf를 부르는데, 주소는 나중에 채워주세요"라는 빈칸이 남아 있다.

링커가 그 빈칸을 메운다. 여러 개의 목적 파일과 라이브러리를 모아 서로의 주소를 연결해주면, 비로소 실행 가능한 로드 모듈이 된다. 그래서 링커의 키워드는 연결(linking)이다.

로더는 번역과 무관하다. 디스크에 있는 실행파일을 RAM에 올려놓고(적재), 올릴 자리를 잡아주고(할당), 실제 적재된 주소에 맞게 프로그램 안의 주소들을 조정(재배치)한다. 즉 "옮기고 자리 잡아주는" 일만 한다.

그래서 시험 함정: "링커와 로더에 관련된 작업이 아닌 것"을 고르라면 답은 코드 최적화다 — 최적화는 컴파일러의 일이지 링커·로더의 일이 아니다.

폰노이만(Von Neumann) 구조와 프로그램 내장 방식 📖 기출문제집 p.22

  • 프로그램과 데이터를 같은 내부 기억장치에 저장해두고, 명령어를 순서대로 꺼내(인출) 해독·실행하는 방식
  • 목적: 매번 배선판을 다시 세팅해야 하는 번거로움 해결
  • 데이터 메모리와 프로그램 메모리가 구분되지 않고 하나의 버스를 공유 → 이 때문에 폰노이만 병목(Von Neumann bottleneck) 현상 발생
컴퓨터방식비고
ENIAC프로그램 외장 방식스위치·배선판으로 프로그램 표현 (내장방식 아님)
EDSAC프로그램 내장 방식 (세계 최초)10진수 체계 사용
EDVAC프로그램 내장 방식최초로 2진수 사용
MARK I-배비지의 해석기관 개념을 스위치·전동기·종이테이프로 구현
함정 주의: "프로그램 내장 방식의 최초 컴퓨터는 ENIAC"이라는 설명은 틀렸다 — ENIAC은 프로그램 외장 방식이며, 내장 방식의 최초는 EDSAC이다.

컴퓨터의 발전 과정 📖 기출문제집 p.22~23

세대를 가르는 기준은 "무슨 부품(소자)으로 회로를 만들었나"다. 소자가 작아질수록 컴퓨터도 작고 빨라졌다고 이해하면 순서가 자연스럽게 외워진다.

세대주요 소자특징 · 대표 언어
1세대진공관 (Vacuum Tube)크고 열이 많음. 기계어·어셈블리어
2세대트랜지스터 (Transistor)소형화·안정화. 고급 언어(FORTRAN, COBOL) 등장
3세대집적회로 (IC)다중 프로그래밍, 시분할 시스템, OS 발전
4세대고밀도 집적회로 (LSI/VLSI)마이크로프로세서 → 개인용 컴퓨터(PC) 등장
5세대초고밀도 집적회로 (ULSI)인공지능, 패턴 인식 등 지능형 컴퓨터
최다 출제 함정: "포트란·코볼 같은 고급 언어는 집적회로(IC)가 적용된 3세대부터 사용되었다" → 틀림. 고급 언어는 2세대(트랜지스터)부터다. 3세대의 키워드는 IC와 운영체제·시분할이지 고급 언어가 아니다.
  • 애플사는 1970년대에 개인용 컴퓨터 출시
  • IBM PC는 1980년대에 출시
  • 1990년대에 월드와이드웹(WWW) 기술로 인터넷 사용자가 폭발적으로 증가
연도 암기: "애플 70년대 → IBM PC 80년대 → 웹 90년대" — 7·8·9로 10년씩 순서대로 올라간다.

📌시험 빈출 포인트

  • 워드프로세서·스프레드시트는 응용 소프트웨어 — "시스템 소프트웨어에 포함되지 않는 것" 문제의 정답으로 자주 나옴
  • 컴파일러는 한꺼번에 번역, 인터프리터는 문장 단위로 번역 후 즉시 실행
  • 링커=연결, 로더=할당·재배치·적재 — 역할 구분 문제
  • ENIAC = 프로그램 외장 방식(예외 함정), EDSAC = 프로그램 내장 방식 최초
  • 고급 언어(포트란·코볼) 도입 시기는 2세대 (3세대 아님 — 자주 나오는 오답 함정)
  • 애플 개인용컴퓨터=1970년대, IBM PC=1980년대, WWW 보급=1990년대 시기 순서 문제
  • 디지털 컴퓨터는 불연속 데이터, 아날로그 컴퓨터는 연속 데이터 사용

문제 12015 국가직 · 기출문제집 p.19

시스템 소프트웨어에 포함되지 않는 것은?

  1. 스프레드시트(spreadsheet)
  2. 로더(loader)
  3. 링커(linker)
  4. 운영체제(operating system)
해설 보기

정답 ① 스프레드시트

판별 기준은 하나다 — "하드웨어를 돌리거나 다른 프로그램을 실행시키려고 있는 것"이면 시스템 SW, "사람이 일을 처리하려고 쓰는 것"이면 응용 SW.

  1. 로더·링커는 프로그램을 실행 가능한 상태로 만드는 도구 → 시스템 SW
  2. 운영체제는 하드웨어를 관리하는 대표 주자 → 시스템 SW
  3. 스프레드시트는 사용자가 데이터를 입력·계산·관리하려고 쓰는 도구 → 응용 SW

같은 유형 정리: 워드프로세서, 엑셀, 게임, 웹브라우저 = 전부 응용 SW. 컴파일러·어셈블러·인터프리터·장치 드라이버·유틸리티 = 전부 시스템 SW.

문제 22007 국가직 · 기출문제집 p.20

다음 중 링커와 로더에 관련된 작업이 아닌 것은?

  1. 연결(linking)
  2. 재배치(relocation)
  3. 코드 최적화(code optimization)
  4. 적재(loading)
해설 보기

정답 ③ 코드 최적화

  1. 연결은 링커의 대표 기능이다.
  2. 재배치·적재(그리고 할당)는 로더의 3대 기능이다.
  3. 코드 최적화는 번역 과정에서 더 효율적인 기계어를 뽑아내는 작업 → 컴파일러의 일이다.

암기 한 줄: 링커 = 연결 / 로더 = 할·재·적(할당·재배치·적재) / 컴파일러 = 번역과 최적화. 이 세 묶음만 구분하면 이 유형은 끝난다.

문제 32021 국가직 · 기출문제집 p.21

소프트웨어에 대한 설명으로 옳지 않은 것은?

  1. 하드웨어에 대응하는 개념으로 우리가 원하는 대로 컴퓨터를 작동하게 만드는 논리적인 바탕을 제공한다.
  2. 운영체제 등 컴퓨터 시스템을 가동시키는 데 사용되는 소프트웨어를 시스템 소프트웨어라 한다.
  3. 문서 작성이나 게임 등 특정 분야의 업무를 처리하는 데 사용되는 소프트웨어를 응용 소프트웨어라 한다.
  4. 고급 언어로 작성된 프로그램을 한꺼번에 번역한 후 실행하는 것이 인터프리터 방식이다.
해설 보기

정답 ④ (한꺼번에 번역하는 것은 컴파일러 방식이다)

  1. 컴파일러: 프로그램 전체를 한꺼번에 번역해 목적 프로그램을 만들어 둔 뒤 실행 → 번역은 한 번, 실행은 빠름
  2. 인터프리터: 한 문장씩 번역하면서 곧바로 실행 → 목적 프로그램을 따로 만들지 않음, 실행은 상대적으로 느림

구분 요령: 번역 결과물(목적 프로그램)이 남으면 컴파일러, 안 남으면 인터프리터다. Python처럼 실행할 때마다 소스가 필요한 언어가 인터프리터 방식이다.

문제 42013 국가직 · 기출문제집 p.21

전통적인 폰 노이만(Von Neumann) 구조에 대한 설명으로 옳지 않은 것은?

  1. 폰 노이만 구조의 최초 컴퓨터는 에니악(ENIAC)이다.
  2. 내장 프로그램 개념(stored program concept)을 기반으로 한다.
  3. 산술논리연산장치는 명령어가 지시하는 연산을 실행한다.
  4. 숫자의 형태로 컴퓨터의 명령어를 주기억장치에 저장한다.
해설 보기

정답 ① (최초는 ENIAC이 아니라 EDSAC)

  1. ENIAC은 스위치와 배선판으로 프로그램을 표현하는 프로그램 외장 방식이다. 작업을 바꾸려면 배선을 다시 꽂아야 했다.
  2. 프로그램 내장 방식을 세계 최초로 구현한 것은 EDSAC(10진수 사용)이고, 이후 EDVAC이 최초로 2진수를 사용했다.
  3. ②·③·④는 폰노이만 구조의 정확한 서술이다. 특히 ④ "명령어를 숫자 형태로 저장"이 곧 내장 프로그램 개념이다.

암기: ENIAC = External(외장, 예외!) / EDSAC = Stored 최초 / EDVAC = 2진수 최초. 이름이 비슷해서 자주 바꿔 출제된다.

문제 52017 국가직 · 기출문제집 p.23

컴퓨터의 발전 과정에 대한 설명으로 옳지 않은 것은?

  1. 포트란, 코볼 같은 고급 언어는 집적회로(IC)가 적용된 제3세대 컴퓨터부터 사용되었다.
  2. 애플사는 1970년대에 개인용 컴퓨터를 출시하였다.
  3. IBM PC라고 불리는 컴퓨터는 1980년대에 출시되었다.
  4. 1990년대에는 월드와이드웹 기술이 적용되면서 인터넷에 연결되는 컴퓨터의 사용자가 폭발적으로 증가하였다.
해설 보기

정답 ① (고급 언어는 2세대부터)

  1. 고급 언어(FORTRAN, COBOL)가 등장한 것은 트랜지스터를 쓴 2세대다.
  2. 3세대(IC)의 키워드는 다중 프로그래밍·시분할 시스템·운영체제 발전이다.
  3. ②·③·④의 연도(70·80·90년대)는 모두 맞다.

함정 구조: 이 문제는 "그럴듯한 세대를 한 칸 밀어놓는" 전형적 수법이다. 2세대=고급언어, 3세대=OS만 붙잡고 있으면 흔들리지 않는다.

문제 62020 지방직 · 기출문제집 p.23

아날로그 컴퓨터에 대한 설명으로 옳지 않은 것은?

  1. 입력형식은 부호, 코드화된 숫자, 문자, 기호이다.
  2. 출력형식은 곡선, 그래프 등이다.
  3. 미적분 연산방식을 가지며, 정보처리속도가 빠르다.
  4. 증폭회로 등으로 회로 구성을 한다.
해설 보기

정답 ① (이것은 디지털 컴퓨터의 입력형식이다)

  1. 디지털 컴퓨터는 부호·코드화된 숫자·문자·기호처럼 불연속(이산) 데이터를 다룬다 → ①은 디지털 설명
  2. 아날로그 컴퓨터는 전압·온도 같은 연속적인 물리량을 다루고, 결과도 곡선·그래프로 낸다(②)
  3. 연산은 미적분 방식(③), 회로는 증폭회로(④)를 쓴다 — 모두 아날로그의 특징이 맞다

한 줄 구분: 아날로그 = 연속(곡선·증폭회로·미적분), 디지털 = 불연속(숫자·논리회로·사칙연산).

문제 7개념 확인 · 응용

여러 개의 .c 파일로 나눠 작성한 프로그램을 빌드했더니 "printf 참조를 찾을 수 없음(undefined reference)" 오류가 났다. 이 오류는 어느 단계에서 발생한 것인가?

해설 보기

정답: 링커(Linker) 단계

  1. 문법이 틀렸다면 컴파일러가 먼저 잡아낸다. 그런데 이 오류는 문법 오류가 아니다 — 컴파일은 통과했다는 뜻이다.
  2. 컴파일러는 printf를 "어딘가에 있을 함수"로 보고 주소를 비워둔 채 목적 파일을 만든다.
  3. 그 빈칸을 라이브러리와 연결해 채우는 것이 링커의 일 → 연결할 대상을 못 찾으면 링커가 오류를 낸다.

정리: "문법이 틀렸다" = 컴파일 오류, "부를 대상을 못 찾겠다" = 링크 오류, "실행파일을 메모리에 못 올리겠다" = 로드 오류. 오류 메시지만 보고도 단계를 짚을 수 있어야 한다.
