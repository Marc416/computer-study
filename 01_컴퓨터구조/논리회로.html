조합논리회로와 순서논리회로

가산기·멀티플렉서·디코더 / 플립플롭·카운터 · PART 01. 전자계산기구조론

핵심 요약

조합논리회로 = 현재 입력값만으로 출력이 결정 (기억 X). 순서논리회로 = 이전 상태(기억)를 함께 반영해 출력이 결정.

순서논리회로의 핵심 부품은 플립플롭(Flip-Flop) — 1비트를 저장할 수 있는 최소 단위.

🎯이 단원을 왜 배우나

게이트 몇 개로 "계산기"와 "기억장치"가 만들어진다

앞 단원에서 AND·OR·NOT 게이트를 배웠다. 그런데 게이트 하나는 그냥 스위치일 뿐이다. 이걸 어떻게 조합해야 실제로 덧셈을 하고, 값을 기억하는 물건이 되는가 — 그게 이 단원의 내용이다. 컴퓨터의 모든 부품은 결국 이 두 종류 회로의 조합일 뿐이다.

세상의 모든 디지털 회로는 딱 두 갈래로 나뉜다. 조합논리회로는 "지금 들어온 입력만 보고" 즉시 답을 내놓는다 — 계산기 같은 것이다. 순서논리회로는 "과거에 무슨 일이 있었는지"를 기억해서 답을 바꾼다 — 메모장 같은 것이다. CPU 안에서 ALU는 조합회로(더하기만 하면 되니 기억할 필요 없음), 레지스터는 순서회로(값을 붙들고 있어야 함)인 이유가 여기 있다.

시험에서는 거의 항상 "이 회로/부품이 둘 중 어느 쪽인가"를 묻는다. 판별법 한 줄만 확실히 잡으면 그 유형은 전부 맞힐 수 있고, 나머지는 각 부품(가산기·MUX·디코더·플립플롭)이 무슨 일을 하는지 외우는 문제다.

💡주요 개념

조합논리회로 vs 순서논리회로 판별법 📖 기출문제집 p.87~88

판별 기준: "지금 입력만 보고 답이 나오나?" → 조합논리회로 / "과거에 뭘 했는지 기억해야 답이 나오나?" → 순서논리회로 (카운터, 레지스터는 이전 값을 기억해야 하므로 순서논리회로)

반가산기, 전가산기플립플롭 (SR, JK, D, T)

왜 순서회로만 "기억"할 수 있나 — 되먹임(feedback)

결정적 차이는 출력이 다시 입력으로 되돌아가는 선(피드백 루프)이 있느냐다. 조합회로는 신호가 입력 → 게이트 → 출력으로 한 방향으로만 흐른다. 그래서 입력이 사라지면 출력도 즉시 사라진다.

순서회로는 출력선 하나를 뒤로 돌려 자기 입력에 물린다. 그러면 "내가 방금 낸 출력"이 다음 계산의 입력이 되므로, 입력이 없어져도 값이 계속 맴돌며 살아남는다. 이것이 1비트를 붙들어 두는 원리이고, 플립플롭이 바로 그 구조다. 아래 SR 래치 회로도에서 X자로 교차한 되먹임 선이 정확히 그 역할을 한다.

시험 표현 주의: "순서논리회로"와 "순차논리회로"는 같은 말(sequential logic circuit)이다. 문제마다 표기가 다르니 당황하지 말 것.

조합논리회로 ① 가산기 (Adder) 📖 기출문제집 p.85

종류입력기능
반가산기 (Half Adder)A, B (2개)합(S) = A⊕B, 자리올림(C) = A·B — 입력 캐리는 못 받음
전가산기 (Full Adder)A, B, 입력캐리(Ci) (3개)S = A⊕B⊕Ci, Co = AB + ACi + BCi — 반가산기 2개 + OR 게이트로 구성 가능

ALU의 핵심 회로: 4비트 병렬 가산기/감산기 📖 기출문제집 p.86~87

실제 CPU의 ALU가 "덧셈"과 "뺄셈"을 하나의 회로로 겸용하는 원리가 바로 이 회로다. 전가산기(FA) 4개를 사슬처럼 연결하고, B 입력 앞에 XOR 게이트를 하나씩 붙여 모드 신호 M으로 A+B와 A−B를 스위치처럼 전환한다.

계산 예제: 5 − 3 을 4비트 가산기/감산기로 계산하는 순서 📖 기출문제집 p.87
  1. A = 0101(5), B = 0011(3), M = 1(뺄셈 모드)로 설정
  2. M=1이므로 B가 XOR 게이트를 통과하며 비트 반전: B' = 1100 (B의 1의 보수)
  3. FA0의 최초 입력캐리 C0 = M = 1 → B'에 1을 더하는 효과 = 2의 보수 변환 완성 (1100 + 1 = 1101 = −3의 2의 보수)
  4. A(0101) + B'(1100) + C0(1) 을 FA0→FA3으로 캐리를 넘기며 순서대로 덧셈 수행
  5. 결과 S3S2S1S0 = 0010 (10진수 2), 최종 Cout=1(4비트 범위 안에서 정상, 오버플로우 아님) → 5−3=2 확인

조합논리회로 ② 선택 회로 📖 기출문제집 p.83~84

이름기능입력 → 출력
멀티플렉서 (MUX)여러 입력 중 선택선으로 고른 1개만 출력 (다대일)2ⁿ개 → 1개
디멀티플렉서 (DEMUX)1개의 입력을 선택선에 따라 여러 출력 중 하나로 분배 (일대다)1개 → 2ⁿ개
디코더 (Decoder)n비트 입력 → 2ⁿ개 출력 중 해당하는 하나만 1로 활성화n개 → 2ⁿ개
인코더 (Encoder)디코더의 반대, 2ⁿ개 입력 중 활성화된 것을 n비트 코드로 변환2ⁿ개 → n개
비유: 멀티플렉서 = 여러 채널 중 하나를 고르는 TV 리모컨, 디코더 = 우편번호(코드) 하나를 보고 해당 지역(출력선) 하나를 찾아가는 것
개수 세기 공식 (자주 나오는 계산):
MUX: 데이터 입력이 2ⁿ개면 선택선은 n개 (입력 4개 → 선택선 2개, 입력 8개 → 선택선 3개)
디코더: 입력이 n비트면 출력은 2ⁿ개 (3-to-8 디코더 = 입력 3비트, 출력 8개)
→ "입력 4개 + 선택선 2개 + 출력 1개"라고 문제에 쓰여 있으면 무조건 멀티플렉서다.

순서논리회로 — 플립플롭(Flip-Flop) 종류 📖 기출문제집 p.88~90

플립플롭은 1비트(0 또는 1)를 안정적으로 붙들어 두는 최소 단위 회로다. 출력이 Q와 Q'(반전) 두 개로 나오는 게 특징이고, 클록(CP) 신호가 들어오는 순간에만 값이 바뀐다. 아래 표의 4종류는 "입력을 어떻게 받느냐"만 다를 뿐 하는 일(1비트 저장)은 같다.

종류입력특징
SR 플립플롭S(Set), R(Reset)S=R=1인 경우 동작 불능(금지 상태) — 가장 큰 단점
JK 플립플롭J, KSR의 단점을 보완. J=K=1이면 이전 값을 반전(toggle) 출력 — 불능 상태 없음
D 플립플롭D(Data)입력된 값을 그대로 다음 상태로 저장 (지연, Delay)
T 플립플롭T(Toggle)T=1이면 매 클록마다 출력을 반전, T=0이면 유지 — 카운터에 주로 사용

JK 플립플롭 진리표 (기출 포인트) 📖 기출문제집 p.89

JK다음 출력 Q의미
00Q (그대로)이전 상태 유지
010리셋
101셋
11Q' (반전)토글 — SR의 금지상태를 대체

JK 진리표를 외우지 않고 유도하는 법

가운데 두 줄(J·K가 서로 다를 때)은 "Q는 J를 따라간다" 한 마디로 끝난다. J=0,K=1이면 Q=0. J=1,K=0이면 Q=1. J의 값이 그대로 출력이다.

바깥 두 줄만 따로 기억하면 된다: 둘 다 0이면 그대로(유지), 둘 다 1이면 뒤집기(토글). SR 플립플롭에서 "둘 다 1"은 쓸 수 없는 금지 상태였는데, JK는 그 자리를 토글로 바꿔 써먹은 것이 개선점이다.

한 줄 암기: "다르면 J를 따라가고, 00은 그대로, 11은 뒤집는다"

클록마다 값이 어떻게 변하는지 추적해보기

Q의 초기값이 0이라 할 때, 아래 입력이 순서대로 들어오면 Q가 어떻게 바뀌는지 직접 따라가 보자. 각 줄의 "다음 Q"가 그 다음 줄의 "현재 Q"가 된다는 점이 핵심이다.

클록JK현재 Q규칙다음 Q
1100다르면 J를 따라감 → 11
200100이면 유지1
311111이면 토글 → 반전0
411011이면 토글 → 반전1
5011다르면 J를 따라감 → 00
관찰: 3·4번 클록처럼 J=K=1을 계속 넣으면 0↔1이 번갈아 나온다. 클록 2번에 한 번씩 1이 나오므로 주파수가 절반이 되는데, 이 성질을 이용한 것이 바로 카운터(T 플립플롭)다.

카운터(Counter)와 레지스터 📖 기출문제집 p.88

  • 레지스터: 플립플롭 여러 개를 나열해 여러 비트를 저장하는 장치 (8비트 레지스터 = 플립플롭 8개)
  • 카운터: 클록이 들어올 때마다 정해진 순서로 값이 변하는 레지스터 (동기식/비동기식)
  • 동기식 카운터: 모든 플립플롭이 같은 클록을 동시에 받음 → 빠르지만 회로 복잡
  • 비동기식(리플) 카운터: 앞 플립플롭의 출력이 뒤 플립플롭의 클록이 됨 → 회로는 간단하나 전파 지연이 누적되어 느림
  • 링 카운터(Ring Counter): 플립플롭들을 고리(ring) 모양으로 연결 — 마지막 플립플롭의 출력이 다시 첫 번째로 돌아감. 이전 값을 기억하므로 순서논리회로 (2024 지방직 출제)

📌시험 빈출 포인트

  • 주어진 회로/기능이 조합논리회로인지 순서논리회로인지 구분하기 (카운터·레지스터·플립플롭 = 순서논리)
  • 전가산기는 반가산기 2개 + OR 게이트 1개로 구성 가능 — "반가산기 2개만으로 구성"은 오답
  • 4비트 병렬 가감산기에서 M(모드) 값에 따라 덧셈/뺄셈이 결정되는 원리 (XOR + 2의 보수)
  • 가감산기에서 V=1이면 오버플로, Cout은 unsigned 연산의 자리올림일 뿐 오버플로 판단과 별개
  • SR 플립플롭의 불능(금지) 상태는 S=R=1일 때 발생 — JK가 이를 토글로 대체
  • JK 플립플롭 진리표 채우기: 00=유지(Q), 01=0, 10=1, 11=반전(Q′) — 매년 출제
  • 멀티플렉서·디멀티플렉서·디코더·인코더 기능 서로 구분하기 (MUX=다대일, DEMUX·디코더=일대다)
  • "입력 2ⁿ개 + 선택선 n개 + 출력 1개" → 멀티플렉서, "n비트 입력 → 2ⁿ개 중 하나만 1" → 디코더
  • 플립플롭의 용도 = 1비트의 0/1 두 상태 중 하나를 안정적으로 저장 (2016 국회 출제 문장 그대로 암기)
  • 링 카운터·동기식 카운터는 순서(순차)논리회로, 전가산기·MUX·디코더는 조합논리회로

✏️연습문제

먼저 스스로 풀어본 뒤 "해설 보기"를 눌러 확인하세요.

문제 12017 서울시 · 기출문제집 p.84

다음 전가산기 논리회로에 대한 설명으로 옳지 않은 것은?

  1. 전가산기는 캐리를 포함하여 연산처리하기 위해 설계되었다.
  2. S = (A⊕B)⊕Ci
  3. Co = AB + ACi + BCi
  4. 전가산기는 두 개의 반가산기만으로 구성할 수 있다.
해설 보기

정답 ④ — 반가산기 2개 + OR 게이트가 있어야 한다

  1. 반가산기 1: A, B를 더해 합 S1과 캐리 C1을 만든다
  2. 반가산기 2: S1과 입력캐리 Ci를 더해 최종 합 S와 캐리 C2를 만든다
  3. 여기서 캐리가 C1, C2 두 개 생긴다 — 둘 중 하나라도 1이면 출력캐리가 1이어야 하므로 OR 게이트로 묶어야 한다
  4. 따라서 전가산기 = 반가산기 2개 + OR 게이트 1개 → ④번이 틀렸다

함정: ②·③번 식은 모두 맞다. S는 세 입력의 XOR, Co는 "셋 중 둘 이상이 1일 때 1"을 뜻하는 식이다. 식이 맞는지 헷갈리면 A=B=1, Ci=0을 넣어 검산해보면 된다(S=0, Co=1로 올바름).

문제 22010 국가직 · 기출문제집 p.85

음수를 2의 보수로 표현한다고 가정할 때, 4비트 병렬 가감산기 회로(FA 4개 + B 입력마다 XOR)에서 입력 M의 값이 1일 때 수행하는 동작은?

  1. A − B
  2. A + B + 1
  3. A + B
  4. B − A
해설 보기

정답 ① A − B

  1. M은 B 쪽 XOR 게이트에 들어간다. M=1이면 B의 모든 비트가 반전되어 B의 1의 보수가 만들어진다
  2. 동시에 M은 맨 오른쪽 FA의 입력 캐리 C₀로도 들어간다 → 1의 보수에 +1이 더해진다
  3. 1의 보수 + 1 = 2의 보수 = −B
  4. 결국 회로는 A + (−B) = A − B를 계산한다

함정: ②번(A+B+1)은 "C₀에 1이 들어간다"만 보고 B 반전을 빠뜨린 경우다. XOR과 캐리 두 곳 모두 M이 들어간다는 점이 이 회로의 핵심이다. 참고로 M=0이면 B가 그대로 통과하고 캐리도 0이므로 단순한 A+B가 된다.

문제 32017 하반기 국가직 · 기출문제집 p.86~87

4개의 전가산기를 사용한 가감산기(M: 모드, Cout: 출력캐리, V: 오버플로 플래그)에서 오버플로우가 발생한 경우가 아닌 것은?

  1. M = 0, Cout = 1, 부호 없는(unsigned) 연산으로 해석
  2. M = 1, Cout = 1, 부호 없는 연산으로 해석
  3. M = 0, V = 1, 2의 보수를 사용하는 부호 있는(signed) 연산으로 해석
  4. M = 1, V = 1, 2의 보수를 사용하는 부호 있는 연산으로 해석
해설 보기

정답 ② M = 1, Cout = 1, 부호 없는 연산

오버플로 판단 기준이 부호 없는 연산과 부호 있는 연산에서 서로 다르다는 것이 이 문제의 핵심이다.

  1. 부호 없는(unsigned) 연산: 자리올림 Cout이 넘치면 값이 표현 범위를 벗어난 것 → Cout=1이 오버플로. 단 이것은 덧셈(M=0)일 때 이야기다
  2. 뺄셈(M=1)에서의 Cout=1은 의미가 다르다 — 2의 보수 뺄셈에서 마지막 캐리가 1로 나오면 결과가 0 이상(양수)이라 정상이라는 뜻이다. 오히려 Cout=0일 때가 음수(빌림 발생) 상황이다
  3. 부호 있는(signed) 연산: 오버플로는 V 플래그로 판단한다 → ③·④처럼 V=1이면 무조건 오버플로
  4. 따라서 오버플로가 아닌 것은 ②번

정리: unsigned는 Cout으로, signed는 V로 판단한다. 그리고 뺄셈에서의 Cout=1은 정상 신호다.

  2. ㄱ 조합논리회로 — ㄴ 순차논리회로

정답 ② ㄱ 조합논리회로 — ㄴ 순차논리회로

  2. 링 카운터 (ring counter)

  4. 디멀티플렉서 (demultiplexer)

문제 72022 지방직 · 기출문제집 p.89

다음은 정논리를 사용하는 JK 플립플롭의 진리표이다. (가)~(라)에 들어갈 내용으로 옳은 것은? (단, Q′은 Q의 반댓값)

CPJK다음상태 Q
↑00(가)
↑01(나)
↑10(다)
↑11(라)
  1. (가) Q, (나) 1, (다) 0, (라) Q′
  2. (가) Q′, (나) 1, (다) 0, (라) Q
  3. (가) Q, (나) 0, (다) 1, (라) Q′
  4. (가) Q′, (나) 0, (다) 1, (라) Q
해설 보기

정답 ③ (가) Q, (나) 0, (다) 1, (라) Q′

  1. (가) J=0, K=0 → 유지 → 이전 값 그대로 Q
  2. (나) J=0, K=1 → J·K가 다르므로 J를 따라감 → 0 (리셋)
  3. (다) J=1, K=0 → J를 따라감 → 1 (셋)
  4. (라) J=1, K=1 → 토글 → Q′

선택지 빠르게 거르는 법: (가)가 Q인 것(①·③)만 남기고, (나)가 0인 것을 고르면 ③ 하나만 남는다. "00은 유지"만 확실하면 2초 만에 풀린다.

함정: ①번은 (나)·(다)를 뒤집어 놓은 것이다. K가 1이면 리셋(0)이라는 방향을 헷갈리지 말 것 — K는 Kill(끄기)로 외우면 편하다.

문제 8개념 확인 · 응용

데이터 입력이 8개인 멀티플렉서를 만들려면 선택선(select line)은 몇 개가 필요한가? 또 3-to-8 디코더의 출력선은 몇 개인가?

해설 보기

정답: 선택선 3개, 디코더 출력선 8개

  1. MUX는 선택선 n개로 2ⁿ개 중 하나를 고른다 → 8개를 고르려면 2ⁿ = 8 → n = 3
  2. 디코더는 "n-to-2ⁿ"로 이름이 붙는다 → 3-to-8은 입력 3비트, 출력 8개 (이름에 답이 이미 적혀 있다)

정리: 두 회로 모두 2ⁿ 관계이지만 방향이 반대다. MUX는 많은 입력 → 1개 출력(선택선이 주소 역할), 디코더는 n개 입력 → 많은 출력(입력이 주소 역할). 메모리 주소 해독기가 바로 디코더다.
