조합논리회로와 순서논리회로

가산기·멀티플렉서·디코더 / 플립플롭·카운터 · PART 01. 전자계산기구조론

핵심 요약

조합논리회로 = 현재 입력값만으로 출력이 결정 (기억 X). 순서논리회로 = 이전 상태(기억)를 함께 반영해 출력이 결정.

순서논리회로의 핵심 부품은 플립플롭(Flip-Flop) — 1비트를 저장할 수 있는 최소 단위.

💡주요 개념

조합논리회로 vs 순서논리회로 판별법

판별 기준: "지금 입력만 보고 답이 나오나?" → 조합논리회로 / "과거에 뭘 했는지 기억해야 답이 나오나?" → 순서논리회로 (카운터, 레지스터는 이전 값을 기억해야 하므로 순서논리회로)
조합논리회로 (Combinational)순서논리회로 (Sequential)
반가산기, 전가산기플립플롭 (SR, JK, D, T)
인코더, 디코더레지스터
멀티플렉서(MUX), 디멀티플렉서(DEMUX)카운터 (동기식/비동기식, 링 카운터)

조합논리회로 ① 가산기 (Adder)

종류입력기능
반가산기 (Half Adder)A, B (2개)합(S) = A⊕B, 자리올림(C) = A·B — 입력 캐리는 못 받음
전가산기 (Full Adder)A, B, 입력캐리(Ci) (3개)S = A⊕B⊕Ci, Co = AB + ACi + BCi — 반가산기 2개 + OR 게이트로 구성 가능
4비트 병렬 가감산기: 전가산기 4개를 연결하고, B값을 XOR 게이트에 통과시켜 M(모드)이 0이면 A+B(덧셈), M이 1이면 B를 1의 보수로 바꾼 뒤 캐리에 M(=1)을 더해 2의 보수 가산 → 결국 A−B(뺄셈)이 된다.

조합논리회로 ② 선택 회로

이름기능
멀티플렉서 (MUX)여러 입력 중 선택선으로 고른 1개만 출력 (다대일)
디멀티플렉서 (DEMUX)1개의 입력을 선택선에 따라 여러 출력 중 하나로 분배 (일대다)
디코더 (Decoder)n비트 입력 → 2ⁿ개 출력 중 해당하는 하나만 1로 활성화
인코더 (Encoder)디코더의 반대, 2ⁿ개 입력 중 활성화된 것을 n비트 코드로 변환
비유: 멀티플렉서 = 여러 채널 중 하나를 고르는 TV 리모컨, 디코더 = 우편번호(코드) 하나를 보고 해당 지역(출력선) 하나를 찾아가는 것

순서논리회로 — 플립플롭(Flip-Flop) 종류

종류입력특징
SR 플립플롭S(Set), R(Reset)S=R=1인 경우 동작 불능(금지 상태) — 가장 큰 단점
JK 플립플롭J, KSR의 단점을 보완. J=K=1이면 이전 값을 반전(toggle) 출력 — 불능 상태 없음
D 플립플롭D(Data)입력된 값을 그대로 다음 상태로 저장 (지연, Delay)
T 플립플롭T(Toggle)T=1이면 매 클록마다 출력을 반전, T=0이면 유지 — 카운터에 주로 사용

JK 플립플롭 진리표 (기출 포인트)

JK다음 출력 Q의미
00Q (그대로)이전 상태 유지
010리셋
101셋
11Q' (반전)토글 — SR의 금지상태를 대체

카운터(Counter)와 레지스터

  • 레지스터: 플립플롭 여러 개를 나열해 여러 비트를 저장하는 장치
  • 카운터: 클록이 들어올 때마다 정해진 순서로 값이 변하는 레지스터 (동기식/비동기식)
  • 링 카운터(Ring Counter): 플립플롭들을 고리(ring) 모양으로 연결 — 마지막 플립플롭의 출력이 다시 첫 번째로 돌아감

📌시험 빈출 포인트

  • 주어진 회로/기능이 조합논리회로인지 순서논리회로인지 구분하기 (카운터·레지스터·플립플롭 = 순서논리)
  • 전가산기는 반가산기 2개 + OR 게이트 1개로 구성 가능
  • 4비트 병렬 가감산기에서 M(모드) 값에 따라 덧셈/뺄셈이 결정되는 원리 (XOR + 2의 보수)
  • SR 플립플롭의 불능(금지) 상태는 S=R=1일 때 발생 — JK가 이를 해결
  • JK 플립플롭에서 J=K=1이면 반전(toggle) — 자주 나오는 계산/진리표 문제
  • 멀티플렉서·디멀티플렉서·디코더·인코더 기능 서로 구분하기
