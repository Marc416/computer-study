# 메모리와 변수

## 핵심 요약
> 변수는 **주기억장치(RAM)**에 생성된다. 프로그램이 실행되면 RAM에 적재되고, 변수는 그 안에서 공간을 할당받는다.

## 주요 개념

### 변수란?
- 데이터를 저장하기 위해 이름을 붙인 **메모리 공간**
- 비유: RAM = 작업 책상, 변수 = 이름표 붙은 상자

### 프로그램 실행 과정과 변수
1. 소스코드는 **보조기억장치(HDD/SSD)**에 파일로 저장
2. 프로그램 실행 시 **주기억장치(RAM)**로 적재(Load)
3. 변수는 RAM 내에서 생성되고 CPU가 이를 읽고 처리

### 변수가 저장되는 RAM 내 메모리 영역

| 영역 | 저장되는 것 | 특징 | 예시 |
|------|-----------|------|------|
| **코드(Code)** | 실행할 명령어 | 읽기 전용 | 컴파일된 프로그램 코드 |
| **데이터(Data)** | 전역변수, static 변수 | 프로그램 시작~종료까지 유지 | `int count = 0;` (함수 밖) |
| **스택(Stack)** | 지역변수, 매개변수 | 함수 호출 시 생성, 종료 시 소멸 | `int a = 10;` (함수 안) |
| **힙(Heap)** | 동적 할당 변수 | 프로그래머가 직접 관리 | `malloc()`, `new` |

## 시험 빈출 포인트

- 변수는 **주기억장치(RAM)**에 생성됨 (보조기억장치 X)
- RAM은 **휘발성** 메모리 → 전원 꺼지면 변수도 사라짐
- 소스코드 파일 자체는 보조기억장치에 저장, 실행 시 RAM으로 적재
- 스택은 **LIFO(후입선출)** 구조로 동작
- 힙은 프로그래머가 할당/해제 관리 → 관리 안 하면 **메모리 누수** 발생

## 헷갈리는 개념 비교

| 구분 | 주기억장치 (RAM) | 보조기억장치 (HDD/SSD) |
|------|-----------------|---------------------|
| 속도 | 빠름 | 느림 |
| 휘발성 | 휘발성 (전원 OFF → 삭제) | 비휘발성 (전원 OFF → 유지) |
| 용도 | 실행 중인 프로그램, 변수 저장 | 파일, 프로그램 영구 저장 |
| 변수 생성 | O (여기서 생성됨) | X |

| 구분 | 스택(Stack) | 힙(Heap) |
|------|-----------|---------|
| 할당 방식 | 자동 (컴파일러) | 수동 (프로그래머) |
| 속도 | 빠름 | 상대적으로 느림 |
| 크기 | 제한적 | 상대적으로 큼 |
| 해제 | 자동 (함수 종료 시) | 수동 (`free`, `delete`) |
