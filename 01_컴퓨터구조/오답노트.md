# 컴퓨터구조 오답노트

---

## ❌ 파이프라인 자체가 뭔지 + 위험(Hazard) 3종류 구분 못 함
✅ **한 줄 정리**: 파이프라인 = 명령어 처리를 여러 단계로 쪼개서 **동시에 겹쳐** 실행 (컨베이어 벨트)
✅ **위험 구분**: **분기 → 제어 위험**, 데이터 의존 → 데이터 위험, 자원 충돌 → 구조적 위험
💡 **암기팁**: **"분기 = 제어"** — 분기 때문에 "다음에 뭘 할지 모르는" 상태!

| 위험 종류 | 원인 | 비유 |
|-----------|------|------|
| 구조적 위험 | 하드웨어 자원 부족 | 세탁기 1대에 2명 |
| 데이터 위험 | 앞 명령어 결과를 기다림 | 빨래 안 끝났는데 입으려 함 |
| **제어 위험** | **분기(if/jump) 명령어** | **어디로 갈지 몰라 멈칫** |

> 📌 출처: 모의고사 1회 (2026-03-31)

## ❌ 캐시 지역성 — 시간적 vs 공간적 헷갈림
✅ **한 줄 정리**: 시간적 = 같은 데이터를 **또** 씀, 공간적 = **옆** 데이터도 씀
💡 **암기팁**: **"시간=또, 공간=옆"**

| 지역성 | 의미 | 예시 |
|--------|------|------|
| 시간적(Temporal) | 최근 쓴 걸 **다시** 씀 | for문의 변수 i |
| 공간적(Spatial) | 쓴 것 **근처**도 씀 | 배열 a[0]→a[1]→a[2] |

> 📌 출처: 모의고사 1회 (2026-03-31)
