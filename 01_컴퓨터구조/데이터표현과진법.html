데이터의 표현과 진법

데이터 단위, 문자 코드 체계, 진법 변환 · PART 01. 전자계산기구조론

핵심 요약

데이터의 최소 단위는 비트이고, 8비트 = 1바이트, CPU가 한 번에 처리하는 단위는 워드다.

진법 변환은 2진 ↔ 8진 ↔ 16진을 자릿수 묶음(3비트=8진 1자리, 4비트=16진 1자리)으로 빠르게 변환하는 것이 핵심이다.

💡주요 개념

데이터 표현 단위

단위크기설명
비트 (bit)1자리 (0 또는 1)정보의 최소 단위. n비트로 2ⁿ개의 데이터 표시 가능
니블 (nibble)4비트16진수 1자리에 대응. 독립적으로 처리되지 않음
바이트 (byte)8비트문자 표현의 최소 단위, 기억용량의 기본 단위
워드 (word)컴퓨터마다 다름 (2/4/8바이트 등)CPU가 한 번에 처리·접근하는 데이터 단위
함정 주의: 니블은 4비트다 (2비트 아님 — 자주 나오는 오답 함정). 워드 크기는 컴퓨터 시스템마다 다를 수 있다(고정 아님).

문자 코드 체계별 비트 수

코드비트 수표현 가능 문자 수
BCD6비트2⁶ = 64개
ASCII7비트2⁷ = 128개
EBCDIC8비트2⁸ = 256개
유니코드 (Unicode)16비트2¹⁶개 (전 세계 문자 표현)
비트 수 크기 순서: BCD(6) < ASCII(7) < EBCDIC(8) < 유니코드(16)

진법 변환

2진 → 8진 → 16진 상호 변환은 자릿수를 묶어서 처리하면 빠르다.

변환규칙
2진 ↔ 4진2진수 2자리 = 4진수 1자리
2진 ↔ 8진2진수 3자리 = 8진수 1자리
2진 ↔ 16진2진수 4자리 = 16진수 1자리
예: 8진수 (2001)₈ → 2진수
2 → 010, 0 → 000, 0 → 000, 1 → 001
합치면 010 000 000 001 → 앞의 0 생략 → 10000000001₂
예: 16진수 (302)₁₆ → 2진수
3 → 0011, 0 → 0000, 2 → 0010
합치면 0011 0000 0010 → 앞의 0 생략 → 1100000010₂

N진수 → 10진수 변환 (자릿값 곱해서 더하기)

예: 16진수 (1B4.C)₁₆ → 10진수
1×16² + B(11)×16¹ + 4×16⁰ + C(12)×16⁻¹
= 256 + 176 + 4 + 0.75 = 436.75
예: 8진수 (13754)₈ → 10진수
1×8⁴ + 3×8³ + 7×8² + 5×8¹ + 4×8⁰
= 4096 + 1536 + 448 + 40 + 4 = 6124

10진수 → 2진수 변환

정수부: 2로 계속 나누어 나머지를 역순으로 읽는다.
소수부: 2를 계속 곱해서 정수부로 넘어가는 값을 순서대로 읽는다.

예: 45.1875 → 정수부 45 = 101101₂, 소수부 0.1875 = 0.0011₂ → 101101.0011₂

📌시험 빈출 포인트

  • 서로 다른 진법으로 표현된 값들 중 실제 크기가 다른 것 찾기 유형 (10진수로 통일해서 비교)
  • 10진수 ↔ 2진수 변환 계산 문제 (정수부는 나눗셈, 소수부는 곱셈)
  • 2진 ↔ 8진(3비트 묶음), 2진 ↔ 16진(4비트 묶음) 빠른 변환
  • 문자 코드 체계별 비트 수 순서: BCD(6) < ASCII(7) < EBCDIC(8) < 유니코드(16)
  • 니블 = 4비트 (2비트 아님), 바이트 = 8비트, 워드 크기는 시스템마다 다름
  • N비트로 표현 가능한 정수 개수는 2ⁿ개 (0~2ⁿ-1의 범위)
