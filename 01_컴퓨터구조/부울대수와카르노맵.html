부울대수와 카르노맵

논리식 간략화 두 가지 방법 · PART 01. 전자계산기구조론

핵심 요약

논리식을 간단하게 줄이는 방법은 두 가지 — 대수적으로 법칙을 적용하거나, 카르노맵(K-map)에 표로 그려서 눈으로 묶는다.

시험에서는 결과 확인용으로 부울대수, 정답을 빨리 찾는 용도로 카르노맵을 함께 쓰는 게 효율적이다.

🎯이 단원을 왜 배우나

논리식 한 글자가 곧 전선 한 가닥, 게이트 한 개다

논리식 AB + AB' + A'B를 그대로 회로로 만들면 AND 게이트 3개, OR 게이트 2개, NOT 게이트 2개가 필요하다. 그런데 이걸 간략화하면 A + B — OR 게이트 딱 1개로 끝난다. 똑같이 동작하는데 부품이 7개에서 1개로 줄어든 것이다.

실제 CPU에는 수십억 개의 게이트가 들어간다. 게이트 하나를 줄이면 비용·전력·발열이 줄고 속도는 빨라진다. 그래서 논리식 간략화는 단순한 수학 퍼즐이 아니라 하드웨어 설계의 핵심 기술이다. 이 단원이 시험에 매년 나오는 이유이기도 하다.

간략화 방법은 두 가지다. 부울대수는 법칙을 하나씩 적용해 식을 줄이는 방식으로, 정확하지만 어디서 멈춰야 할지 판단이 어렵다. 카르노맵은 표에 그려놓고 눈으로 묶는 방식으로, 변수 4개까지는 압도적으로 빠르고 실수가 적다. 시험에서는 상황에 따라 골라 쓰되, 선택지를 역으로 대입해 보는 것이 가장 빠를 때도 많다.

💡주요 개념

부울대수 기본 법칙 📖 기출문제집 p.71

법칙내용
항등법칙A + 0 = A, A · 1 = A
지배법칙A + 1 = 1, A · 0 = 0
동일법칙A + A = A, A · A = A
보수법칙A + A' = 1, A · A' = 0
분배법칙A(B+C) = AB+AC, A+BC = (A+B)(A+C)
흡수법칙A + AB = A, A(A+B) = A
드모르간 법칙(A+B)' = A'B', (AB)' = A'+B'
가장 중요한 법칙 두 개: ① A + A' = 1 (보수법칙) — 변수를 통째로 소거하는 유일한 수단. ② A + BC = (A+B)(A+C) (OR에 대한 분배법칙) — 일반 수학에는 없는 형태라 낯설지만, 간략화 문제의 마지막 단계에서 거의 항상 등장한다.

외우기 힘든 세 가지를 직관으로 이해하기

① 흡수법칙 A + AB = A
"A이거나, (A이면서 B)" — 뒤쪽은 이미 A에 포함된다. A만 참이면 전체가 참이므로 B는 결과에 아무 영향이 없다. 큰 집합이 작은 집합을 삼켜버리는 것이라 "흡수"다.

② A + A'B = A + B (흡수법칙과 헷갈리는 형태)
여기선 뒤쪽이 A'B라 A에 포함되지 않는다. A가 참이면 전체 참, A가 거짓이면 A'=1이므로 결과는 B에 달렸다. 즉 "A거나 B". 증명은 분배법칙으로: A + A'B = (A+A')(A+B) = 1·(A+B) = A+B.
구분법: 뒤 항에 A'가 붙었으면 A+B, 그냥 A면 A로 흡수. 시험에 둘 다 나온다.

③ A + BC = (A+B)(A+C)
우변을 전개하면 AA + AC + AB + BC = A + AC + AB + BC = A(1+C+B) + BC = A + BC ✓. 일반 숫자 계산과 달리 OR도 AND에 대해 분배된다는 점이 부울대수의 특징이다.

대수적 간략화 예제 (기출) 📖 기출문제집 p.71~74

예제 1: AB + AB' + A'B
= A(B+B') + A'B = A + A'B = (A+A')(A+B) = A + B
예제 2: A(A'+B)
= AA' + AB = 0 + AB = AB
예제 3: ABC + AB'C + A'B'C
= (AB+AB'+A'B')C = (A+A'B')C = (A+A')(A+B')C = AC + B'C
풀이 팁: 공통 문자를 묶어 인수분해 → 보수법칙(X+X'=1)으로 소거 → 분배법칙으로 재정리. "같은 항이 두 번 곱해지면 지운다"는 흡수법칙을 가장 많이 쓴다.

"나머지 셋과 다른 것 찾기" 유형을 30초에 푸는 법

이 유형은 보기 4개를 전부 간략화해야 하는 것처럼 보이지만, 실전에서는 요령이 있다. 보기들이 대개 A 또는 A+B 둘 중 하나로 수렴하므로, 각 보기에서 A'(보수)가 등장하는지만 먼저 훑어라.

  • A(A+B), AB'+A, (A+B)(A+B') → A'가 없다 → 전부 A로 흡수됨
  • A + A'B → A'가 있다 → A+B로 확장됨 ← 혼자 다름

물론 항상 통하는 건 아니니 최종 확인은 필요하지만, 어느 것이 수상한지 먼저 찍고 그것만 검산하면 시간이 크게 절약된다.

카르노맵(K-map)이란? 📖 기출문제집 p.77~78

  • 진리표의 결과(참이 되는 항)를 격자 표에 옮겨 그린 것
  • 인접한 칸끼리는 변수 하나만 다르도록 배치 (그레이코드 순서: 00, 01, 11, 10)
  • 1이 적힌 칸들을 2, 4, 8, 16개 단위(2ⁿ)로 묶어서 공통 변수만 남기면 간략화된 식이 나옴
  • 무관 조건(Don't Care, X)은 0이든 1이든 편한 대로 해석해 최대한 크게 묶는 데 활용

카르노맵 예제 — F(A,B) 2변수

AB \ 값결과
000
011
111
100

01과 11 두 칸이 인접(B=1로 공통) → 간략화 결과 F = B

카르노맵 예제 — F(A,B,C,D) 4변수, Don't Care 활용

AB＼CD00011110
001001
0101X0
1101X0
101001

계산 방법: 위 카르노맵을 곱의 합(SOP)으로 간략화하는 순서

  1. 1이 있는 칸을 모두 확인: (00,00), (00,10), (01,01), (01,11=X), (11,01), (11,11=X), (10,00), (10,10)
  2. 가장 큰 묶음부터 찾기 — 가운데 2×2 블록(01·11행 × 01·11열)에서 X를 1로 취급하면 4칸 묶음 완성
  3. 이 묶음에서 값이 안 변하는 변수만 남긴다: 두 행 모두 B=1, 두 열 모두 C=1 → BC
  4. 남은 1칸들(네 모서리)을 묶기 — 표를 원통처럼 감으면 4칸이 인접 → 이 묶음도 4칸 묶음
  5. 이 묶음에서 값이 안 변하는 변수만 남긴다: 두 행 모두 B=0, 두 열 모두 D=0 → B'D'
  6. 모든 1을 다 덮었으므로 두 묶음을 OR로 연결 → F(A,B,C,D) = BC + B'D'

카르노맵 풀이 순서

  1. 진리표에서 결과가 1인 항을 카르노맵에 표시
  2. 가장 큰 묶음(8개 → 4개 → 2개 → 1개 순)부터 찾기
  3. 묶음 안에서 값이 변하지 않는 변수만 남기고 나머지는 제거
  4. 모든 1을 포함할 때까지 묶음을 OR로 연결
  5. Don't Care(X)는 묶음을 더 크게 만들 수 있을 때만 1로 사용, 아니면 무시

묶음 크기와 남는 변수 개수의 관계 — 이것만 알면 검산이 된다

4변수 카르노맵에서 묶음 크기에 따라 몇 개의 변수가 살아남는지가 정해져 있다.

묶음 크기사라지는 변수남는 변수 개수 (4변수 기준)
1칸0개4개 (예: AB'CD)
2칸1개3개 (예: AB'C)
4칸2개2개 (예: BD)
8칸3개1개 (예: A')

그래서 답이 A' + BD + B'D'라면 "8칸 묶음 1개 + 4칸 묶음 2개"로 만들어졌다는 뜻이다. 선택지를 보고 역으로 묶음 크기를 추측하면 어디를 묶어야 하는지가 먼저 보인다.

묶을 때 지켜야 할 규칙: ① 크기는 반드시 2ⁿ(1, 2, 4, 8, 16)개. 3칸·6칸 묶음은 없다. ② 반드시 직사각형 모양(L자 불가). ③ 겹쳐도 된다 — 이미 다른 묶음에 들어간 1을 또 묶어 더 크게 만들 수 있다. ④ 표의 상하·좌우 끝은 서로 이어져 있다(원통/도넛처럼).

✏️연습문제

먼저 스스로 풀어본 뒤 "해설 보기"를 눌러 확인하세요.

문제 12018 계리직 · 기출문제집 p.71

불 대수(Boolean Algebra)에 대한 최소화로 옳지 않은 것은?

  1. A(A + B) = A
  2. A + A'B = A + B
  3. A(A' + B) = AB
  4. AB + AB' + A'B = A
해설 보기

정답 ④ (AB + AB' + A'B = A + B 이므로 틀림)

  1. ④ AB + AB' + A'B = A(B+B') + A'B = A·1 + A'B = A + A'B
  2. 여기서 멈추면 안 된다. A + A'B = (A+A')(A+B) = A + B ≠ A
  3. ① A(A+B) = AA + AB = A + AB = A(1+B) = A ✓ (흡수법칙)
  4. ② A + A'B = A + B ✓ (위와 동일한 변형)
  5. ③ A(A'+B) = AA' + AB = 0 + AB = AB ✓

이 문제의 핵심: ④는 중간 단계(A + A'B)에서 멈추면 A로 착각하게 만드는 함정이다. A' 항이 남아 있으면 아직 끝난 게 아니라는 신호다.

문제 22016 국가직 · 기출문제집 p.72

나머지 셋과 다른 부울 함수를 표현하는 것은?

  1. F = A + A'B
  2. F = A(A + B)
  3. F = AB' + A
  4. F = (A + B)(A + B')
해설 보기

정답 ① (①만 A+B, 나머지는 전부 A)

  1. ① A + A'B = (A+A')(A+B) = A + B ← 혼자 다름
  2. ② A(A + B) = AA + AB = A + AB = A(1+B) = A
  3. ③ AB' + A = A(B' + 1) = A·1 = A
  4. ④ (A + B)(A + B') = AA + AB' + AB + BB' = A + AB' + AB + 0 = A(1+B'+B) = A

30초 풀이: 보기 중 A'가 등장하는 것은 ①뿐이다. A'가 있으면 A에 흡수되지 않고 식이 확장되므로, 계산 전에 ①을 의심하고 그것만 검산하면 된다.

문제 32023 지방직 · 기출문제집 p.72

부울 변수 X, Y, Z에 대한 등식으로 옳지 않은 것은? (· 은 AND, + 는 OR, ' 는 NOT)

  1. X + (Y · Z) = (X + Y) · (X + Z)
  2. X · (X + Y) = X · X + Y
  3. (X + Y) + Z = X + (Y + Z)
  4. (X + Y)' = X' · Y'
해설 보기

정답 ② (X·(X+Y) = X 이지 X·X + Y 가 아니다)

  1. ② 좌변: X·(X+Y) = XX + XY = X + XY = X(1+Y) = X
  2. ② 우변: X·X + Y = X + Y
  3. X ≠ X + Y 이므로 등식이 성립하지 않는다 → 정답
  4. ① 은 OR에 대한 분배법칙 ✓
  5. ③ 은 결합법칙 ✓ (OR끼리는 순서·묶음 자유)
  6. ④ 는 드모르간 법칙 ✓

함정 구조: ②는 분배를 잘못 적용한 형태다. X·(X+Y)를 전개하면 XX + XY이지 XX + Y가 아니다 — 괄호를 풀 때 바깥 항을 각 항에 모두 곱해야 한다.

문제 42018 교육청 · 기출문제집 p.72

부울 대수식 A + B·C 와 진리값이 다른 것은?

  1. (A + B) · (A + C)
  2. B·C + A·(A + B)
  3. A + A·C + B·C
  4. A + B·(B + C)
해설 보기

정답 ④ (A + B·(B+C) = A + B)

  1. ④ B(B+C) = BB + BC = B + BC = B(1+C) = B → 전체는 A + B ≠ A + BC
  2. ① (A+B)(A+C) = A + BC ✓ (분배법칙 그 자체)
  3. ② A(A+B) = A 이므로 BC + A = A + BC ✓
  4. ③ A + AC + BC = A(1+C) + BC = A + BC ✓

포인트: ④에서 B(B+C)가 B로 흡수되면서 C가 통째로 사라지는 것이 핵심이다. B와 C가 AND로 묶여 있어야 하는데, ④는 B만 남아 C 없이도 참이 되는 더 느슨한 식이 된다.

문제 52011 국가직 · 기출문제집 p.73

다음 부울 함수식 F를 간략화한 결과로 옳은 것은?
F = ABC + ABC' + AB'C + AB'C' + A'B'C + A'B'C'

  1. F = A' + B
  2. F = A + B'
  3. F = A'B
  4. F = AB'
해설 보기

정답 ② F = A + B'

항이 6개나 되지만 C와 C'가 짝지어 나오는 구조를 발견하면 순식간에 줄어든다.

  1. C끼리 짝지어 묶기: AB(C+C') + AB'(C+C') + A'B'(C+C')
  2. C + C' = 1 이므로: AB + AB' + A'B'
  3. 앞 두 항 묶기: A(B+B') + A'B' = A + A'B'
  4. 분배법칙: A + A'B' = (A+A')(A+B') = 1·(A+B') = A + B'

카르노맵으로 검산: 1이 되는 minterm 6개 중 A=1인 4칸(ABC, ABC', AB'C, AB'C')이 4칸 묶음 → A, B=0인 4칸(AB'C, AB'C', A'B'C, A'B'C')이 4칸 묶음 → B'. 합치면 A + B' ✓ 두 방법이 일치한다.

문제 62013 국가직 · 기출문제집 p.74

다음 부울 함수식 F를 간략화한 결과로 옳은 것은?
F = ABC + AB'C + A'B'C

  1. F = AC + B'C
  2. F = AC + BC'
  3. F = A'C + B'C
  4. F = A'C + BC
해설 보기

정답 ① F = AC + B'C

  1. 모든 항에 C가 공통이므로 먼저 빼낸다: (AB + AB' + A'B')·C
  2. 괄호 안: A(B+B') + A'B' = A + A'B'
  3. 분배법칙: A + A'B' = (A+A')(A+B') = A + B'
  4. 다시 C를 곱하면: (A + B')C = AC + B'C

빠른 확인법: 원래 식의 모든 항이 …C로 끝난다 → C가 0이면 F도 반드시 0이다. 따라서 답에도 모든 항에 C가 있어야 한다. ②(BC')와 ④는 C'가 섞여 있어 이 조건을 위반 → 즉시 탈락. 남은 ①③ 중 A' 여부만 확인하면 된다.

문제 72012 계리직 · 기출문제집 p.71

다음 논리 연산식을 간략화하면 어떤 게이트 하나로 표현되는가?
(A + B)(A + B')(A' + B)

  1. A와 B의 OR 회로
  2. A와 B의 NAND 회로
  3. A와 B의 AND 회로
  4. A와 B의 XOR 회로
해설 보기

정답 ③ AND 회로 (F = AB)

  1. 앞의 두 괄호부터 전개: (A+B)(A+B') = AA + AB' + AB + BB'
  2. AA = A, BB' = 0 → A + AB' + AB = A(1 + B' + B) = A
  3. 남은 것과 곱하기: A(A' + B) = AA' + AB = 0 + AB = AB
  4. AB는 A와 B의 논리곱(AND) → ③

검산(진리표로 확인): A=1,B=1일 때만 세 괄호가 모두 1이 된다. A=1,B=0이면 (A'+B) = 0+0 = 0, A=0,B=1이면 (A+B') = 0+0 = 0 → 확실히 AND ✓

문제 82008 국가직 · 기출문제집 p.76

다음 카르노맵을 간략화한 결과를 논리식으로 올바르게 표현한 것은?

  1. A' + BD + B'D'
  2. A + BD + B'D'
  3. D + AB + B'D'
  4. D' + AB + B'D'

정답 ① A' + BD + B'D'

  1. 8칸 묶음 먼저: AB = 00, 01 두 행(=A가 0인 영역) 8칸이 전부 1 → 변하는 B·C·D는 버리고 A'만 남는다
  2. 남은 1 찾기: AB=11 행의 CD=01, 11 두 칸과, AB=10 행의 CD=00, 10 두 칸이 아직 안 덮였다
  3. BD 묶음: AB=01·11 행 × CD=01·11 열의 4칸을 묶는다(위쪽 행과 겹쳐도 무방) → 공통은 B=1, D=1 → BD
  4. B'D' 묶음: AB=00·10 행 × CD=00·10 열의 네 귀퉁이 4칸을 묶는다(표의 상하·좌우가 이어짐) → 공통은 B=0, D=0 → B'D'
  5. 세 묶음을 OR: A' + BD + B'D'

선택지로 검산하기: AB=10, CD=00 칸(=A·B'C'D')이 1이다. ②처럼 A가 답에 있으면 A=1인 AB=11 행의 CD=00 칸도 1이어야 하는데 실제로는 0 → ② 탈락. 이런 식으로 0인 칸 하나를 골라 선택지를 대입하면 계산 없이 걸러낼 수 있다.

포인트: 이 문제처럼 한 변수가 0인 절반이 통째로 1인 패턴은 매우 흔하다. 카르노맵을 받으면 "통째로 1인 행/열이 있나"부터 확인하는 습관을 들일 것.

📌시험 빈출 포인트

  • 주어진 논리식을 대수법칙으로 단계별로 줄여서 보기와 맞는 답 고르기 (분배·보수·흡수법칙 활용)
  • 카르노맵을 보고 최소화된 곱의 합(SOP) 형태 논리식 고르기
  • Don't Care(X) 조건은 간략화에 유리할 때만 1로 사용 — 무조건 1로 치지 않음
  • 드모르간 법칙으로 NAND/NOR 게이트로만 구현된 회로 ↔ AND/OR/NOT 식 서로 변환
  • 부울 함수 중 "나머지와 다른 것"을 고르는 유형 — 각 보기를 모두 간략화해서 비교
