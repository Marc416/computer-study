# 입출력 포트와 USB

## 핵심 요약
> **직렬** = 1비트씩 순서대로 전송 (USB, SATA)
> **병렬** = 여러 비트 동시 전송 (옛날 프린터 포트)
> **USB** = 직렬 방식의 플러그 앤 플레이 인터페이스

## 주요 개념

### 직렬 전송 vs 병렬 전송

| 구분 | 직렬 (Serial) | 병렬 (Parallel) |
|------|-------------|----------------|
| **전송 방식** | 1비트씩 순서대로 | 여러 비트(보통 8비트) 동시에 |
| **비유** | 1차선 고속도로 | 8차선 도로 |
| **케이블** | 얇고 간단, 저렴 | 두껍고 복잡, 비쌈 |
| **고속에서** | 간섭 없어 안정적 | 신호 간섭(스큐) 발생 |
| **대표 예시** | USB, SATA, RS-232 | LPT(프린터), IEEE 1284 |
| **현재 추세** | 주류 (현대 인터페이스 대부분) | 거의 사라짐 |

> 병렬이 동시에 보내니까 더 빠를 것 같지만, 고속에서는 신호 간섭 때문에 오히려 직렬이 유리

### 플러그 앤 플레이 (Plug and Play, PnP)

- **정의:** 하드웨어 장치를 컴퓨터에 연결하면 **자동으로 인식하고 설정**해주는 기능
- 사용자가 드라이버를 수동 설치하거나 시스템 설정을 변경할 필요 없음
- **꽂으면(Plug) 바로 사용(Play)**
- USB가 대표적인 플러그 앤 플레이 장치

### USB (Universal Serial Bus)

| 항목 | 내용 |
|------|------|
| **전송 방식** | 직렬 (Serial) |
| **특징** | 플러그 앤 플레이, 핫 플러그(전원 켠 상태에서 연결/해제 가능) |
| **전원 공급** | 케이블을 통해 장치에 전원 공급 가능 |
| **연결 방식** | 하나의 포트에 허브로 최대 127개 장치 연결 가능 |

#### USB 버전별 속도

| 버전 | 속도 | 별명 |
|------|------|------|
| USB 1.1 | 12 Mbps | Full Speed |
| USB 2.0 | 480 Mbps | Hi-Speed |
| USB 3.0 | 5 Gbps | SuperSpeed |
| USB 3.1 | 10 Gbps | SuperSpeed+ |
| USB 4.0 | 40 Gbps | - |

### USB 플래시 드라이브

- 우리가 흔히 쓰는 **USB 메모리**
- 플래시 메모리(비휘발성)를 이용한 이동식 저장장치
- "대용량"은 과거 이동식 저장장치(플로피 1.44MB) 대비 상대적 표현

| 이동식 저장장치 | 용량 |
|---------------|------|
| 플로피 디스크 | 1.44 MB |
| CD | 700 MB |
| USB 플래시 드라이브 | 4 GB ~ 1 TB |

### 핫 플러그 (Hot Plug)

- 컴퓨터 **전원이 켜진 상태에서** 장치를 연결하거나 분리할 수 있는 기능
- USB, SATA(일부)가 지원
- 과거 직렬/병렬 포트는 전원을 꺼야 연결 가능했음

## 시험 빈출 포인트
- "직렬 전송 방식의 플러그 앤 플레이 인터페이스" → **USB**
- 직렬 vs 병렬 전송의 차이
- USB의 특징: 직렬, PnP, 핫 플러그, 최대 127개 장치
- USB 버전별 전송 속도
- 플러그 앤 플레이의 정의

## 헷갈리는 개념 비교

| 구분 | USB | IEEE 1394 (FireWire) | RS-232 |
|------|-----|---------------------|--------|
| **방식** | 직렬 | 직렬 | 직렬 |
| **PnP** | O | O | X |
| **핫 플러그** | O | O | X |
| **용도** | 범용 | 영상/음향 장비 | 옛날 모뎀, 마우스 |
