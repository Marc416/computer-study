컴퓨터 시스템 개요

컴퓨터의 기본 구조와 성능 측정 단위 · PART 01. 전자계산기구조론

핵심 요약

컴퓨터는 입력·출력·기억·연산·제어 5대 장치로 구성되고, CPU는 제어장치 + 연산장치(ALU)다.

시스템 버스는 CPU와 주기억장치만 직접 접근하며, 입출력장치는 DMA·채널을 거쳐야 한다.

💡주요 개념

컴퓨터의 5대 구성 장치

장치역할
입력장치외부 → 컴퓨터 내부로 데이터 전송 (키보드, 마우스 등)
출력장치내부 → 외부로 데이터 전송 (모니터, 프린터 등)
기억장치주기억장치(RAM/ROM), 보조기억장치(HDD/SSD), 캐시로 구성
연산장치 (ALU)산술·논리 연산 수행. 누산기 등을 포함
제어장치 (CU)주기억장치의 명령어를 꺼내 해독하고 각 장치에 제어신호 전달
비유: 제어장치는 "지휘자", 연산장치는 "연주자". 지휘자가 악보(명령어)를 읽고 신호를 주면 연주자가 실제 연산을 한다.

중앙처리장치(CPU) = 제어장치 + 연산장치(ALU) + 레지스터

시스템 버스와 데이터/제어 흐름

  • 시스템 버스에 직접 접근 가능한 것은 CPU와 주기억장치뿐
  • 입출력장치는 DMA, 채널, 인터럽트 구동 I/O 등을 통해서만 버스에 접근 가능
  • 데이터 흐름: 입력장치→주기억장치, 주기억장치↔연산장치, 주기억장치→출력장치
  • 제어 흐름: 제어장치 → 각 장치로 뻗어나가는 신호
함정 주의: "입출력장치가 CPU와 직접 데이터를 교환한다"는 표현은 틀렸다 — 반드시 제어장치의 입출력 제어(DMA/채널/인터럽트)를 거쳐야 한다.

컴퓨터 성능 측정 단위

용어의미
처리량 (Throughput)단위 시간당 처리하는 작업(또는 트랜잭션)의 양
응답 시간 (Response Time)입력이 들어오고 반응이 시작되기까지 걸리는 시간
반환 시간 (Turn Around Time)작업 제출부터 최종 결과를 받기까지 걸리는 전체 시간
병목 현상 (Bottleneck)자원이 용량/처리량의 최대 한계에 도달해 성능이 정체되는 현상
자원 이용도 (Utilization)전체 시간 중 자원이 실제로 사용된 시간의 비율

처리 속도 단위

단위의미
MIPSMillion Instructions Per Second — 초당 처리하는 백만 개 명령어 수
FLOPSFLoating point Operations Per Second — 초당 부동소수점 연산 수
클록(Clock)모든 부품의 동작 기준이 되는 신호. 클록 수가 높을수록 처리속도가 빠름
계산 공식 (매년 출제):
클록 주기 = 1 / 클록 주파수
명령어 1개 실행 시간 = 클록 주기 × CPI (Cycle Per Instruction)
전체 실행 시간 = 명령어 수 × CPI × 클록 주기

집적회로(IC) 집적도 분류

구분이름게이트 수(1칩 기준)

📌시험 빈출 포인트

  • 입출력장치는 시스템 버스에 직접 접근 불가 — DMA/채널을 통해서만 접근
  • 캐시기억장치는 주기억장치보다 용량이 작아야 한다 (크면 접근시간·비용 증가)
  • CPU 구성요소 고르기: 제어장치·연산장치·레지스터는 O, PCI·DRAM·메인보드는 X
  • 레지스터는 플립플롭으로 구성 (DRAM 아님 — 자주 나오는 오답 함정)
  • RISC는 CISC보다 명령어 종류가 적고 고정 명령어 형식 (반대로 헷갈리기 쉬움)
  • 클록 주파수·CPI·실행시간 3요소 중 2개를 주고 나머지 계산하는 문제 매년 출제
  • 정보량 단위 크기 비교 정렬 문제 (GB < TB < PB < EB < ZB < YB)
  • SRAM도 DRAM과 마찬가지로 휘발성 (비휘발성 아님 — 자주 나오는 오답 함정)
