컴퓨터 시스템 개요

컴퓨터의 기본 구조와 성능 측정 단위 · PART 01. 전자계산기구조론

핵심 요약

컴퓨터는 입력·출력·기억·연산·제어 5대 장치로 구성되고, CPU는 제어장치 + 연산장치(ALU)다.

시스템 버스는 CPU와 주기억장치만 직접 접근하며, 입출력장치는 DMA·채널을 거쳐야 한다.

🎯이 단원을 왜 배우나

"누가 누구에게 말을 걸 수 있는가"의 지도

컴퓨터 안에는 CPU, 메모리, 키보드, 하드디스크 같은 부품이 잔뜩 들어있다. 그런데 이 부품들이 아무나 아무 때나 서로 데이터를 주고받을 수 있는 게 아니다. 도로(버스)는 하나뿐인데 여러 부품이 동시에 쓰려 들면 충돌하기 때문이다. 그래서 "버스를 직접 쓸 수 있는 특권층(CPU·주기억장치)"과 "중개인을 거쳐야 하는 나머지(입출력장치 → DMA·채널)"가 나뉜다.

이 단원 문제의 절반 이상이 이 한 가지 구조에서 나온다. "입출력장치가 시스템 버스에 직접 접근한다", "입출력장치가 CPU와 직접 데이터를 교환한다" 같은 선택지는 전부 오답이다. 구조도만 머릿속에 정확히 그려두면 선택지를 읽자마자 걸러낼 수 있다.

나머지 절반은 성능을 숫자로 재는 법이다. "이 컴퓨터가 얼마나 빠른가"를 클록 주파수·CPI·MIPS로 계산하고, "얼마나 담을 수 있나"를 KB~YB 단위로 환산한다. 둘 다 공식 하나에 숫자만 갈아끼우는 계산 문제라 한 번 손에 익히면 매년 공짜 점수가 된다.

💡주요 개념

컴퓨터의 5대 구성 장치 📖 기출문제집 p.11

장치역할
입력장치외부 → 컴퓨터 내부로 데이터 전송 (키보드, 마우스 등)
출력장치내부 → 외부로 데이터 전송 (모니터, 프린터 등)
기억장치주기억장치(RAM/ROM), 보조기억장치(HDD/SSD), 캐시로 구성
연산장치 (ALU)산술·논리 연산 수행. 누산기 등을 포함
제어장치 (CU)주기억장치의 명령어를 꺼내 해독하고 각 장치에 제어신호 전달
비유: 제어장치는 "지휘자", 연산장치는 "연주자". 지휘자가 악보(명령어)를 읽고 신호를 주면 연주자가 실제 연산을 한다.

중앙처리장치(CPU) = 제어장치 + 연산장치(ALU) + 레지스터

시스템 버스와 데이터/제어 흐름

  • 시스템 버스에 직접 접근 가능한 것은 CPU와 주기억장치뿐
  • 입출력장치는 DMA, 채널, 인터럽트 구동 I/O 등을 통해서만 버스에 접근 가능
  • 데이터 흐름: 입력장치→주기억장치, 주기억장치↔연산장치, 주기억장치→출력장치
  • 제어 흐름: 제어장치 → 각 장치로 뻗어나가는 신호
함정 주의: "입출력장치가 CPU와 직접 데이터를 교환한다"는 표현은 틀렸다 — 반드시 제어장치의 입출력 제어(DMA/채널/인터럽트)를 거쳐야 한다.

컴퓨터 성능 측정 단위 📖 기출문제집 p.14

용어의미
처리량 (Throughput)단위 시간당 처리하는 작업(또는 트랜잭션)의 양. 보통 안정된 상태에서 측정
응답 시간 (Response Time)입력이 주어지고 반응이 시작되기까지 걸리는 시간
반환 시간 (Turn Around Time)작업 제출부터 최종 결과를 받기까지 걸리는 전체 시간
병목 현상 (Bottleneck)자원이 용량/처리량의 최대 한계에 도달해 성능이 정체되는 현상
자원 이용도 (Utilization)전체 시간 중 자원이 실제로 사용된 시간의 백분율

응답 시간과 반환 시간 — 이 둘만 확실히 구분하면 된다

패스트푸드점에 비유하면 이렇다. 응답 시간은 "주문하고 나서 직원이 '네, 주문 접수됐습니다'라고 반응을 보이기까지"의 시간이다. 반환 시간은 "주문하고 나서 햄버거를 손에 받기까지"의 전체 시간이다. 당연히 반환 시간이 더 길다.

중요한 건 반환 시간에는 컴퓨터가 실제로 일한 시간뿐 아니라 줄 서서 기다린 시간(대기 시간)까지 전부 포함된다는 점이다. 그래서 비용 분석이나 실효 능률을 따질 때 반환 시간을 쓴다.

시험 함정: "응답 시간은 작업이 시스템에 도착한 시점부터 출력이 사용자에게 제출되는 시점까지"라는 선택지가 나오면 — 이건 응답 시간이 아니라 반환 시간의 정의다. 아래 연습문제 3번이 정확히 이 함정이다.

처리 속도 단위

단위의미
MIPSMillion Instructions Per Second — 초당 처리하는 백만 개 명령어 수
FLOPSFLoating point Operations Per Second — 초당 부동소수점 연산 수
클록(Clock)모든 부품의 동작 기준이 되는 신호. 클록 수가 높을수록 처리속도가 빠름
계산 공식 (매년 출제) 📖 기출문제집 p.17
클록 주기 = 1 / 클록 주파수
명령어 1개 실행 시간 = 클록 주기 × CPI (Cycle Per Instruction)
전체 실행 시간 = 명령어 수 × CPI × 클록 주기 = 명령어 수 × CPI ÷ 클록 주파수

주파수와 주기는 서로 뒤집은 관계다

주파수(Hz)는 "1초에 클록이 몇 번 뛰는가", 주기(초)는 "클록 한 번에 몇 초 걸리는가"다. 2GHz라면 1초에 20억 번 뛰므로, 한 번에 걸리는 시간은 1/20억 초 = 0.5ns다. 둘은 항상 역수이므로 문제에서 뭘 주든 즉시 뒤집어 쓸 수 있어야 한다.

단위 접두어를 외워두면 계산이 순식간에 끝난다:

접두어기호크기역수(주기)
기가G10⁹ (10억)n (나노, 10⁻⁹초)
메가M10⁶ (백만)μ (마이크로, 10⁻⁶초)
킬로k10³ (천)m (밀리, 10⁻³초)

즉 GHz ↔ ns, MHz ↔ μs, kHz ↔ ms가 짝이다. "1GHz = 1ns 주기"만 외워두면 2GHz는 0.5ns, 4GHz는 0.25ns로 바로 나온다.

예제 1. 클록 주파수 2GHz, CPI=1, 명령어 100만 개 프로그램의 실행 시간은? (2012 국회)

  1. 클록 주기 계산: 1 / 2GHz = 1 / (2×10⁹) = 0.5ns (나노초)
  2. 명령어 1개 실행 시간: 클록주기 × CPI = 0.5ns × 1 = 0.5ns
  3. 전체 실행 시간: 명령어 수 × 명령어 1개 실행 시간 = 100만 × 0.5ns
  4. = 1,000,000 × 0.5ns = 500,000ns = 500μs = 0.5ms

예제 2. 클록 주파수 1GHz, 명령어 15만 개, CPI=5 인 프로그램의 CPU 시간은? (2013 국가직)

  1. 클록 주기: 1 / 1GHz = 1ns
  2. 명령어 1개 실행 시간: 1ns × CPI 5 = 5ns
  3. 전체: 150,000 × 5ns = 750,000ns
  4. 750,000ns = 750μs = 0.75ms

예제 3. 클록 4GHz, CPI=4, 명령어 10¹⁰개일 때 실행 시간은? (2021 국가직)

  1. 클록 주기: 1 / 4GHz = 0.25ns
  2. 명령어 1개: 0.25ns × 4 = 1ns (CPI와 주기가 딱 상쇄되어 1ns)
  3. 전체: 10¹⁰ × 1ns = 10¹⁰ × 10⁻⁹초 = 10초
거꾸로 묻는 유형도 있다: "컴퓨터 A(2GHz)에서 10초 걸리던 프로그램이, 컴퓨터 B에서는 클록 사이클 수가 1.5배로 늘었지만 6초에 끝났다. B의 클록 주파수는?" → ① A의 총 사이클 수 = 2×10⁹ × 10초 = 2×10¹⁰개 ② B의 사이클 수 = 1.5배 = 3×10¹⁰개 ③ 이걸 6초에 처리했으므로 주파수 = 3×10¹⁰ ÷ 6 = 5×10⁹ = 5GHz. 아래 연습문제 5번이 이 유형이다.

외우는 법과 계산하는 법

순서 암기: "킬가 메가 기가 테라 페타 엑사 제타 요타" — 앞글자만 따서 "킬메기테페엑제요". 한 칸 올라갈 때마다 지수가 정확히 10씩 늘어난다(2¹⁰ → 2²⁰ → 2³⁰ …).

환산 계산의 핵심: 1024 = 2¹⁰ 이라는 것 하나만 쓰면 된다. 예를 들어 1024² TB가 몇 바이트인지 물으면:

  • 1024² = (2¹⁰)² = 2²⁰
  • TB = 2⁴⁰ B
  • 둘을 곱하면 2²⁰ × 2⁴⁰ = 2⁶⁰ B (= 1EB)

지수가 음수여도 똑같다: 1024⁻¹ ZB = 2⁻¹⁰ × 2⁷⁰ = 2⁶⁰ B. 지수끼리 더하기만 하면 끝이다. 이 유형(연습문제 4번)은 전부 2의 지수로 바꿔놓고 더하기만 하면 계산 실수가 사라진다.

📌시험 빈출 포인트

  • 입출력장치는 시스템 버스에 직접 접근 불가 — DMA/채널을 통해서만 접근
  • 캐시기억장치는 주기억장치보다 용량이 작아야 한다 (크면 접근시간·비용 증가)
  • CPU 구성요소 고르기: 제어장치·연산장치·레지스터는 O, PCI·DRAM·메인보드는 X
  • 레지스터는 플립플롭으로 구성 (DRAM 아님 — 자주 나오는 오답 함정)
  • RISC는 CISC보다 명령어 종류가 적고 고정 명령어 형식 (반대로 헷갈리기 쉬움)
  • 클록 주파수·CPI·실행시간 3요소 중 2개를 주고 나머지 계산하는 문제 매년 출제
  • 정보량 단위 크기 비교 정렬 문제 (GB < TB < PB < EB < ZB < YB)
  • SRAM도 DRAM과 마찬가지로 휘발성 (비휘발성 아님 — 자주 나오는 오답 함정)

문제 12012 국가직 · 기출문제집 p.11

컴퓨터의 주요 장치에 대한 설명으로 옳은 것은?

  1. 입력장치는 시스템 버스를 통하여 컴퓨터 내부에서 외부로 데이터를 전송하는 장치이다.
  2. 기억장치 중 하나인 캐시기억장치는 주기억장치와 동일한 용량을 가져야 한다.
  3. 제어장치는 주기억장치에 적재된 프로그램의 명령어를 하나씩 꺼내어 해독하는 기능을 가지고 있다.
  4. 연산장치는 산술/논리 연산을 수행하는 장치로 누산기, 명령 레지스터(IR), 주소 해독기 등으로 구성된다.
해설 보기

정답 ③

제어장치(CU)의 정의 그대로다 — 주기억장치에서 명령어를 인출(fetch) → 해독(decode)하고 제어신호를 발생시킨다.

  1. ①은 방향이 반대. 입력장치는 외부 → 내부로 보낸다. 게다가 입력장치는 시스템 버스에 직접 접근할 수 없다(DMA 같은 입출력 제어기를 거쳐야 함) — 이중으로 틀린 선택지.
  2. ②는 캐시의 존재 이유를 부정한다. 캐시를 크게 하면 적중률은 오르지만 주소 해독 회로가 복잡해져 접근 시간과 비용이 늘어난다. 그래서 캐시는 주기억장치보다 반드시 작다.
  3. ④는 소속 부서를 바꿔놓은 함정. 누산기(AC)는 연산장치 소속이 맞지만, 명령 레지스터(IR)는 제어장치 소속이다.

해설 보기

정답 ② ㄷ, ㄹ, ㅂ (ALU · 레지스터 · 제어장치)

CPU = 제어장치(CU) + 연산장치(ALU) + 레지스터. 이 셋만 고르면 된다.

  1. PCI는 CPU와 주변기기를 연결하는 로컬 버스 규격이다. CPU 바깥에 있는 통로일 뿐 CPU의 일부가 아니다.
  2. DRAM은 주기억장치에 쓰이는 메모리 소자다. CPU 안에 있는 임시 저장소는 레지스터(플립플롭으로 구성)이지 DRAM이 아니다.
  3. 메인보드는 이 모든 부품을 꽂는 주기판이다. CPU 소켓이 메인보드에 있을 뿐, 메인보드가 CPU 안에 있는 게 아니다.

함정 정리: CPU "안"과 CPU "에 연결된 것"을 구분하는 문제다. 버스·메모리·기판은 전부 바깥이다.

문제 32010 계리직 · 기출문제집 p.14

컴퓨터 시스템의 성능을 측정하는 척도에 대한 설명으로 알맞지 않은 것은?

  1. 처리량(throughput)은 보통 안정된 상태에서 측정되며 하루에 처리되는 작업의 개수, 시간당 처리되는 온라인 처리의 개수 등으로 측정된다.
  2. 병목(bottleneck) 현상은 시스템 자원이 용량 또는 처리량에 있어서 최대 한계에 도달할 때 발생될 수 있다.
  3. 응답 시간(response time)은 주어진 작업의 수행을 위해 시스템에 도착한 시점부터 완료되어 그 작업의 출력이 사용자에게 제출되는 시점까지의 시간으로 정의된다.
  4. 자원 이용도(utilization)는 일반적으로 전체 시간에 대해 주어진 자원이 실제로 사용되는 시간의 백분율로 나타낸다.
해설 보기

정답 ③ (응답 시간이 아니라 반환 시간의 정의다)

  1. ③이 설명하는 "도착 시점 ~ 결과 제출 시점까지 전체"는 반환 시간(turn around time)이다.
  2. 응답 시간은 입력이 주어지고 반응이 시작되기까지의 시간 — 결과를 다 받을 때까지가 아니다.
  3. ①·②·④는 모두 교과서적 정의 그대로라 손댈 곳이 없다.

암기 한 줄: 응답 = "대답이 오기까지", 반환 = "물건을 받기까지". 반환이 항상 더 길다.

문제 42021 계리직 · 기출문제집 p.16

클라우드 서버에 저장된 데이터 용량이 1024PB일 때, 이 데이터와 동일한 크기가 아닌 저장 용량은? (단, 1KB는 1024Byte)

  1. 1024⁻¹ ZB
  2. 1024² TB
  3. 1024⁻³ YB
  4. 1024⁴ MB
해설 보기

정답 ③ 1024⁻³ YB

모두 2의 지수로 바꿔놓고 더하면 실수가 없다. 1024 = 2¹⁰ 이므로 1024ⁿ = 2¹⁰ⁿ.

  1. 기준값: 1024PB = 2¹⁰ × 2⁵⁰ = 2⁶⁰ B (= 1EB)
  2. ① 1024⁻¹ ZB = 2⁻¹⁰ × 2⁷⁰ = 2⁶⁰ ✓ 같음
  3. ② 1024² TB = 2²⁰ × 2⁴⁰ = 2⁶⁰ ✓ 같음
  4. ③ 1024⁻³ YB = 2⁻³⁰ × 2⁸⁰ = 2⁵⁰ ✗ 다름 (2⁶⁰의 1/1024)
  5. ④ 1024⁴ MB = 2⁴⁰ × 2²⁰ = 2⁶⁰ ✓ 같음

요령: 각 단위의 지수(KB=10, MB=20, GB=30, TB=40, PB=50, EB=60, ZB=70, YB=80)를 외워두고, 거기에 10×n만 더하면 된다. ③만 50이 나온다.

문제 52018 지방직 · 기출문제집 p.18

클록 주파수가 2GHz인 CPU를 사용하는 컴퓨터 A에서 프로그램 P를 실행하는 데 10초가 소요된다. 더 높은 클록 주파수의 CPU를 쓰는 컴퓨터 B에서 P를 실행하면, 소요되는 클록 사이클 수는 A 대비 1.5배로 증가하나 실행 시간은 6초로 감소한다. 컴퓨터 B의 클록 주파수는?

  1. 3GHz
  2. 4GHz
  3. 5GHz
  4. 6GHz
해설 보기

정답 ③ 5GHz

"실행 시간 = 총 클록 사이클 수 ÷ 클록 주파수"라는 관계 하나로 풀린다. 뒤집으면 주파수 = 사이클 수 ÷ 시간.

  1. A의 총 사이클 수 = 주파수 × 시간 = 2×10⁹ × 10초 = 2×10¹⁰개
  2. B의 사이클 수 = A의 1.5배 = 2×10¹⁰ × 1.5 = 3×10¹⁰개
  3. B는 이걸 6초에 처리 → 주파수 = 3×10¹⁰ ÷ 6 = 5×10⁹ Hz = 5GHz

함정: "시간이 10초 → 6초로 줄었으니 주파수는 10/6배겠지"라고 단순 비례로 풀면 ①번(약 3.3GHz)이 나온다. 사이클 수가 1.5배로 늘었다는 조건을 반드시 곱해줘야 한다.

문제 62017 국가직 · 기출문제집 p.13

컴퓨터 구조에 대한 설명으로 옳지 않은 것은?

  1. 폰노이만이 제안한 프로그램 내장방식은 프로그램 코드와 데이터를 내부기억장치에 저장하는 방식이다.
  2. 병렬처리방식 중 하나인 SIMD는 하나의 명령어를 처리하기 위해 다수의 처리장치가 동시에 동작하는 다중처리기 방식이다.
  3. CISC 구조는 RISC 구조에 비해 명령어의 종류가 적고 고정 명령어 형식을 취한다.
  4. 파이프라인 기법은 하나의 작업을 다수의 단계로 분할하여 시간적으로 중첩되게 실행함으로써 처리율을 높인다.
해설 보기

정답 ③ (CISC와 RISC의 설명이 뒤바뀌었다)

  1. RISC(Reduced Instruction Set Computer) — 이름 그대로 명령어를 줄인(Reduced) 구조. 종류가 적고 길이가 고정이다.
  2. CISC(Complex Instruction Set Computer) — 복잡한(Complex) 명령어를 많이 갖고, 길이도 가변이다.
  3. 따라서 "CISC가 명령어 종류가 적고 고정 형식"은 정반대 서술이다.

암기 한 줄: 이름에 답이 있다 — Reduced = 적다, Complex = 많다. 헷갈리면 풀네임을 떠올려라.

문제 7개념 확인 · 응용

어떤 CPU가 500MHz로 동작하고, 평균 CPI가 2이다. 이 CPU의 MIPS 값은 얼마인가?

해설 보기

정답: 250 MIPS

MIPS = "초당 실행하는 명령어 수(백만 개 단위)"이므로, 먼저 1초에 명령어를 몇 개 실행하는지부터 구한다.

  1. 1초에 뛰는 클록 수 = 500MHz = 5×10⁸ 사이클
  2. 명령어 1개당 2사이클(CPI=2)이 필요하므로, 1초에 실행 가능한 명령어 수 = 5×10⁸ ÷ 2 = 2.5×10⁸개
  3. MIPS는 백만(10⁶) 단위로 환산 → 2.5×10⁸ ÷ 10⁶ = 250 MIPS

공식으로 정리: MIPS = 클록 주파수 ÷ (CPI × 10⁶). CPI가 클수록(명령어 하나에 손이 많이 갈수록) MIPS는 작아진다.
