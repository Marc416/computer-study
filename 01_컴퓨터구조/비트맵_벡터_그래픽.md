# 비트맵 vs 벡터 그래픽

## 핵심 요약
> **비트맵** = 점(픽셀)의 모음 → 사진에 적합, 확대하면 깨짐
> **벡터** = 수학 명령어의 모음 → 로고/삽화에 적합, 확대해도 깨끗

## 주요 개념

### 비트맵 (Bitmap / Raster)

- 이미지를 **수많은 점(픽셀)**으로 표현
- 각 픽셀마다 색상 정보를 저장
- 확대하면 **픽셀이 보여서 깨짐 (계단 현상)**
- 사진처럼 복잡한 색상 표현에 유리

> 비유: 모자이크 타일화 — 타일 하나하나가 픽셀

**대표 파일 형식:**

| 형식 | 특징 |
|------|------|
| BMP | 무압축, 용량 큼 |
| JPEG/JPG | 손실 압축, 사진에 적합, 용량 작음 |
| PNG | 무손실 압축, 투명 배경 지원 |
| GIF | 256색 제한, 애니메이션 가능 |
| TIFF | 고품질, 인쇄용 |

### 벡터 (Vector)

- 이미지를 **수학적 수식(점, 선, 곡선, 도형)**으로 표현
- 좌표와 공식이 저장됨
- 확대하면 **수식을 다시 계산해서 그리므로 절대 깨지지 않음**
- 로고, 아이콘, 삽화 등 단순하고 깔끔한 이미지에 유리

> 비유: 레시피(설명서) — "가운데에 반지름 5cm 원을 빨간색으로 그려라"

**대표 파일 형식:**

| 형식 | 특징 |
|------|------|
| SVG | 웹용 벡터 (XML 텍스트 기반) |
| AI | Adobe Illustrator 전용 |
| EPS | 인쇄용 벡터 표준 |
| WMF/EMF | Windows 메타파일 |

**벡터 파일의 실제 내용 (SVG 예시):**
```xml
<svg>
  <circle cx="100" cy="100" r="50" fill="red"/>
  <!-- "좌표(100,100)에 반지름 50, 빨간 원을 그려라" -->

  <rect x="10" y="10" width="80" height="60" fill="blue"/>
  <!-- "좌표(10,10)에서 80x60 파란 사각형을 그려라" -->
</svg>
```

## 비트맵 vs 벡터 비교 ⭐

| 구분 | 비트맵 (Bitmap) | 벡터 (Vector) |
|------|---------------|--------------|
| **저장 방식** | 픽셀(점)의 색상 정보 | 수학적 수식 (좌표, 곡선) |
| **확대 시** | 깨짐 (계단 현상) | 깨지지 않음 (재계산) |
| **파일 크기** | 해상도에 비례 (클 수 있음) | 상대적으로 작음 |
| **색상 표현** | 복잡한 색상 변화 가능 | 단순한 색상에 적합 |
| **편집** | 픽셀 단위 편집 | 도형/선 단위 편집 |
| **적합한 용도** | **사진, 풍경, 인물** | **로고(CI), 캐릭터, 삽화, 아이콘** |
| **대표 형식** | JPG, PNG, GIF, BMP | SVG, AI, EPS |
| **대표 프로그램** | 포토샵 (Photoshop) | 일러스트레이터 (Illustrator) |

## 시험 빈출 포인트

### ⭐ 가장 중요한 출제 포인트
> **로고(CI), 캐릭터, 간단한 삽화** → **벡터**가 적합 (비트맵 아님!)
> **사진, 풍경, 복잡한 이미지** → **비트맵**이 적합

### CI (Corporate Identity)가 벡터인 이유
- 기업 로고는 명함(작게)부터 건물 간판(크게)까지 다양한 크기로 사용
- 크기를 자유롭게 변경해도 깨지지 않아야 함
- 따라서 **벡터 방식이 필수**

### 기타 빈출 포인트
- 비트맵은 확대하면 **계단 현상(앨리어싱)** 발생
- 벡터는 파일 크기가 이미지 복잡도에 비례 (해상도와 무관)
- JPEG는 **손실 압축**, PNG는 **무손실 압축**
- GIF는 **256색 제한**, 애니메이션 가능

## 헷갈리는 개념 비교

| 시험 함정 | 정답 |
|----------|------|
| "비트맵이 CI 표현에 적합하다" | ❌ **벡터**가 적합 |
| "벡터가 사진 표현에 적합하다" | ❌ **비트맵**이 적합 |
| "비트맵은 확대해도 깨지지 않는다" | ❌ 깨짐, **벡터**가 안 깨짐 |
| "벡터는 픽셀로 이미지를 표현한다" | ❌ **수학 수식**으로 표현 |
