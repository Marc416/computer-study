# 관계대수 (Relational Algebra)

## 핵심 요약
> 관계대수 = **릴레이션을 조작하는 연산들의 집합**
> 절차적 언어: "어떻게" 가져올지 순서를 명시
> 비유: 요리 레시피처럼 단계별로 지시하는 것

## 주요 연산 종류

### 일반 집합 연산 (수학 집합과 동일)

| 연산 | 기호 | 의미 | 조건 |
|------|------|------|------|
| **합집합** | A ∪ B | A 또는 B에 있는 투플 전부 (중복 제거) | 합병 가능해야 함 |
| **교집합** | A ∩ B | A와 B 양쪽 모두에 있는 투플 | 합병 가능해야 함 |
| **차집합** | A - B | A에는 있고 B에는 없는 투플 | 합병 가능해야 함 |
| **카티션 곱** | A × B | A와 B의 모든 조합 | 조건 없음 |

> **합병 가능(Union Compatible)** = 두 릴레이션의 속성 수(차수)가 같고, 대응하는 속성의 도메인이 같아야 함

### 순수 관계 연산 (관계대수 전용)

| 연산 | 기호 | 의미 |
|------|------|------|
| **셀렉트** | σ (시그마) | 조건에 맞는 **행(투플)** 선택 (WHERE절과 유사) |
| **프로젝트** | π (파이) | 원하는 **열(속성)** 추출 (SELECT절과 유사) |
| **조인** | ⋈ | 두 릴레이션을 공통 속성으로 합침 |
| **디비전(나눗셈)** | ÷ | B의 **모든 값과 짝이 되는** A의 나머지 속성 추출 |

## 각 연산 상세 설명

### 셀렉트 (σ) — 행 고르기
```
σ 조건 (릴레이션명)
```
- **σ** = "골라라" (조건에 맞는 행을 선택)
- **조건** = WHERE절과 동일 (등급='gold' ∧ 나이≥25)
- **(릴레이션명)** = "어디에서?" → SQL의 FROM에 해당

> ⚠️ **(릴레이션명)이 없으면?** → "어느 테이블에서 찾으라는 건지" 알 수 없음!
> SQL로 치면 `SELECT * WHERE 조건` 처럼 FROM이 빠진 것과 같다.

**예시:**
```
σ 등급='gold' ∧ 나이≥25 (고객)
```
↓ SQL로 변환하면
```sql
SELECT * FROM 고객 WHERE 등급='gold' AND 나이>=25
```

비유: 뷔페에서 "고기 종류만 골라담기" → 가로로 거르기

#### 셀렉트 조건에 쓰는 논리 연산자

| 관계대수 기호 | 의미 | 프로그래밍 | SQL | 외우는 법 |
|:---:|:---:|:---:|:---:|:---:|
| **∧** | AND | && | AND | 산(∧) 모양 = **A**를 닮음 → **A**ND |
| **∨** | OR | \|\| | OR | 컵(∨) 모양 = 둘 중 하나 담기 |
| **¬** | NOT | ! | NOT | 부정 기호 |

#### 기출 함정: 셀렉트 표기 순서 (2022 국가직 67번)

| 보기 | 표기 | 정답여부 | 이유 |
|:---:|------|:---:|------|
| ① | σ고객(등급='gold' ∧ 나이≥25) | ❌ | 릴레이션과 조건 위치가 뒤바뀜 |
| **②** | **σ 등급='gold' ∧ 나이≥25 (고객)** | **⭕** | **올바른 형식: σ 조건 (릴레이션)** |
| ③ | π고객(등급='gold' ∧ 나이≥25) | ❌ | π는 열 선택이지 행 선택이 아님 |
| ④ | π 등급='gold' ∧ 나이≥25 (고객) | ❌ | π는 조건 검색용이 아님 |

### 프로젝트 (π) — 열 고르기
```
π(이름, 학과)(학생)
→ 학생 테이블에서 이름, 학과 열만 추출
```
비유: 명부에서 "이름이랑 전화번호만 복사하기" → 세로로 거르기

### 조인 (⋈) — 테이블 합치기
```
학생 ⋈ 수강 (공통 속성: 학번)
→ 학번이 같은 행끼리 합침
```

### 디비전 (÷) — 가장 어려운 연산 ⭐⭐⭐

**핵심: "B의 모든 값과 빠짐없이 짝이 되는 것만 남긴다"**

비유: **"모든 필수과목을 수강한 학생만 졸업 가능"**

#### 디비전 풀이 방법

**A ÷ C를 구하려면:**
1. C에 있는 속성을 확인 (C의 속성 = 검사 대상)
2. A에서 C에 없는 속성이 결과 후보
3. 결과 후보의 각 값이 C의 **모든 값**과 조합되어 A에 존재하는지 확인
4. 하나라도 빠지면 탈락!

#### 디비전 예제 1 (기출 - 2017 교육학)

**A 테이블:**

| Name | Dept |
|------|------|
| 강감찬 | 국어 |
| 안중근 | 영어 |
| 윤동주 | 과학 |
| 이순신 | 영어 |

**C 테이블:**

| Name |
|------|
| 강감찬 |
| 이순신 |

**A ÷ C = ?**

C에 없는 속성 = Dept → 결과 후보는 {국어, 영어, 과학}

각 Dept가 C의 모든 Name(강감찬, 이순신)과 짝이 되는지 확인:

| Dept | (강감찬, Dept) A에 있나? | (이순신, Dept) A에 있나? | 둘 다 있나? |
|------|----------------------|----------------------|-----------|
| 국어 | ⭕ | ❌ | ❌ 탈락 |
| 영어 | ❌ | ⭕ | ❌ 탈락 |
| 과학 | ❌ | ❌ | ❌ 탈락 |

**결과: 공집합 (아무것도 없음)**

> C에 없는 사람(윤동주, 안중근)은 검사하지 않는다! C에 있는 값만 전부 확인!

#### 디비전 예제 2 (이해용)

**수강 테이블:**

| 학생 | 과목 |
|------|------|
| 김철수 | 수학 |
| 김철수 | 영어 |
| 이영희 | 수학 |
| 박민수 | 수학 |
| 박민수 | 영어 |

**필수과목 테이블:**

| 과목 |
|------|
| 수학 |
| 영어 |

**수강 ÷ 필수과목 = ?**

| 학생 | (학생, 수학) 있나? | (학생, 영어) 있나? | 전부 있나? |
|------|-----------------|-----------------|----------|
| 김철수 | ⭕ | ⭕ | ⭕ 통과! |
| 이영희 | ⭕ | ❌ | ❌ 탈락 |
| 박민수 | ⭕ | ⭕ | ⭕ 통과! |

**결과: {김철수, 박민수}** → 모든 필수과목을 수강한 학생만 남음!

## 시험 빈출 포인트

### 자주 나오는 문제 유형
1. 관계대수 연산 결과 구하기 (특히 ∪, ∩, -, ÷)
2. "올바르지 않은 결과는?" → 디비전 함정 주의
3. σ와 π의 차이 묻기

### 함정 보기 패턴
- 디비전에서 C의 각 값을 개별로 가져온 결과 → ❌ (전부 짝이 되어야 함)
- 합집합에서 중복 투플 포함 → ❌ (릴레이션은 집합이니까 중복 제거)
- 차집합 방향 반대 (A-B ≠ B-A) → 방향 주의!

## 헷갈리는 개념 비교

| 구분 | 셀렉트 (σ) | 프로젝트 (π) |
|------|-----------|-------------|
| 방향 | 가로 (행 선택) | 세로 (열 선택) |
| SQL 대응 | WHERE절 | SELECT절 |
| 결과 | 조건 맞는 행 | 원하는 열 |

| 구분 | 관계대수 | 관계해석 |
|------|---------|---------|
| 방식 | 절차적 (어떻게) | 비절차적 (무엇을) |
| 비유 | 레시피 (순서 있음) | 주문 (결과만 말함) |
