관계대수 트리와 테이블 변환

σ·π·÷ 연산이 실제 표를 어떻게 바꾸는지 그림으로 보기 · PART 05. 데이터베이스론

핵심 요약

기호(σ, π, ⋈, ÷)의 뜻과 문제 풀이 절차는 관계대수 문서에 이미 있다. 이 문서는 실제로 표가 어떻게 변하는지 눈으로 보여주는 데 집중한다.

💡주요 개념 — 연산 트리로 보는 복합 질의

여러 연산을 조합하면 "트리"가 된다

실무에서는 관계대수 연산을 하나만 쓰지 않고 조합한다. 예를 들어 "고객 테이블에서 등급이 gold인 사람의 이름만 뽑아라"는 셀렉트 후 프로젝트를 조합한 질의이고, DBMS 내부에서는 이걸 나무(트리) 구조로 표현한다. 트리는 아래에서 위로 실행된다.

디비전(÷) 연산 — 표가 실제로 어떻게 줄어드는지

관계대수 문서의 "수강 ÷ 필수과목" 예제를 표 변환 과정으로 다시 보면:

수강 (원본)

학생과목
김철수수학
김철수영어
이영희수학
박민수수학
박민수영어

필수과목 (÷ 기준)

과목
수학
영어

수강 ÷ 필수과목 (결과)

학생
김철수
박민수
  1. 필수과목 테이블에 있는 과목: {수학, 영어} — 이 두 개를 전부 갖고 있는지가 통과 조건
  2. 김철수: 수강 테이블에 (김철수,수학)도 있고 (김철수,영어)도 있음 → 통과
  3. 이영희: (이영희,수학)만 있고 (이영희,영어)는 없음 → 탈락
  4. 박민수: (박민수,수학), (박민수,영어) 둘 다 있음 → 통과
  5. 결과 테이블에는 "학생" 컬럼만 남고, 통과한 김철수·박민수만 행으로 남는다
디비전은 결과 테이블의 컬럼 수가 줄어든다는 점에서 셀렉트(σ, 컬럼 그대로)와 다르다. "과목"이라는 컬럼은 사라지고 "학생"만 남는 이유는, 필수과목 테이블의 컬럼(과목)을 검사에만 쓰고 결과에서는 제외하기 때문이다.

📌시험 빈출 포인트

  • 연산 트리는 아래(원본)에서 위(결과)로 실행 순서를 읽는다
  • 디비전 결과는 나눈 테이블(÷ 뒤)의 컬럼이 제외된 컬럼만 남는다
  • 셀렉트(σ)는 행 수만 줄고 컬럼 수는 그대로, 프로젝트(π)는 컬럼 수만 줄고 행 수(중복 제거 후)가 변할 수 있음
