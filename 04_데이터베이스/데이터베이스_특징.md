# 데이터베이스의 특징 (4대 특징)

## 핵심 요약
> 4대 특징 암기법: **"실계동내"** (실시간 접근성, 계속적 변화, 동시 공유, 내용 참조)

## 주요 개념

### 1. 실시간 접근성 (Real-time Accessibility)
- 사용자가 데이터를 요청하면 **즉시 응답**할 수 있는 구조
- 배치 처리(모아서 한꺼번에)가 아니라 **요청 즉시 처리 가능**
- **정형적 질의**(매달 자동 돌리는 정해진 보고서)든 **비정형적 질의**(즉석에서 만든 새로운 질문)든 모두 즉시 응답
- ⚠️ "비정형적" = 자연어(한국어)라는 뜻이 아님! **미리 안 만들어둔 즉석 질의(Ad-hoc Query)**라는 뜻
- 비유: 편의점(즉시 구매) vs 택배(모아서 배송) → DB는 편의점 방식

### 2. 계속적 변화 (Continuous Evolution)
- 데이터가 계속 **삽입, 삭제, 수정**되면서 최신 상태 유지
- 상태가 **정적이 아니고 동적**이므로 현재의 정확한 데이터를 유지
- 비유: 실시간으로 업데이트되는 전광판 (고정된 인쇄물이 아님)

### 3. 동시 공유 (Concurrent Sharing)
- **여러 사용자가 동시에** 같은 데이터에 접근(CRUD) 가능
- 동시성 제어(Lock, 격리수준 등)를 통해 충돌 방지
- 비유: 엑셀은 한 명만 편집 가능, DB는 여러 명이 동시에 사용 가능

### 4. 내용에 의한 참조 (Content Reference)
- 데이터의 물리적 위치(주소)가 아니라 **값(내용)**으로 검색
- "참조한다" = "찾는다"로 이해하면 쉬움
- `WHERE 이름 = '홍길동'` 처럼 내용 기반으로 찾음
- 비유: 도서관에서 "A구역 3열 5번"(주소)이 아니라 "해리포터"(내용)로 찾는 것

## 시험 빈출 포인트

### ⚠️ 단골 함정 모음

| 함정 유형 | 틀린 표현 | 맞는 표현 |
|-----------|-----------|-----------|
| 종속성 바꿔치기 | 3단계 스키마 → 데이터 **종속성** 제공 ❌ | 3단계 스키마 → 데이터 **독립성** 제공 ✅ |
| 참조 방식 바꿔치기 | **주소**에 의한 참조 ❌ | **내용**에 의한 참조 ✅ |

### 3단계 스키마 구조
| 스키마 | 설명 | 비유 |
|--------|------|------|
| 외부 스키마 | 사용자가 보는 뷰 | 앱 화면 |
| 개념 스키마 | DB 전체 논리적 구조 | 설계도 |
| 내부 스키마 | 물리적 저장 구조 | 실제 서버/디스크 |

### 데이터 독립성 2가지
| 구분 | 의미 |
|------|------|
| 논리적 독립성 | 개념 스키마 변경 → 외부 스키마 영향 없음 |
| 물리적 독립성 | 내부 스키마 변경 → 개념 스키마 영향 없음 |
