정보기술 동향

VoIP·RFID·유비쿼터스컴퓨팅·AR/VR·클라우드·가상화·빅데이터·IoT · PART 03. 데이터통신론

핵심 요약

이 파트는 "이 기술의 정의를 정확히 아는가"를 묻는 용어 매칭형 문제가 대부분이다 — 비슷한 이름의 기술을 정확히 구분하는 게 핵심.

빅데이터 3V = 규모(Volume)·속도(Velocity)·다양성(Variety) — "시각화(Visualization)"는 3V가 아니라 자주 나오는 함정.

📡주요 개념 — 통신·인식 기술

VoIP (Voice over Internet Protocol)

음성을 IP 패킷으로 변환해 인터넷망으로 전화 통화를 가능케 하는 기술. 게이트웨이로 기존 공중전화망(PSTN)과도 연결된다.

QoS 파라미터의미
지연 (Delay)패킷이 송신지→수신지 도달하는 데 걸리는 시간
지터 (Jitter)패킷 도착 간격의 불규칙한 변동 — 크면 음성이 끊기거나 왜곡
패킷 손실전송 중 일부 패킷 유실 — 실시간 통신이라 복구 어려움
무음 억제무음 구간엔 패킷을 안 보내 대역폭 절약
함정 주의: "지터는 도착시간 간격이 규칙적인 경우"라는 표현은 ❌ 틀렸다 — 지터는 불규칙한 변동을 의미한다.

RFID (Radio Frequency IDentification)

무선주파수로 태그에 저장된 정보를 리더기가 비접촉으로 읽는 인식 기술.

구분능동형 태그수동형 태그
전원배터리 내장배터리 없음 — 리더기 전자기 유도로 작동
인식 거리길다짧다
가격비쌈저렴
수명배터리 수명에 제한반영구적
함정 주의: "RFID 태그는 항상 배터리가 필요하다" → ❌ 수동형은 배터리 불필요. ARP는 IP→MAC 변환, RARP는 반대로 MAC→IP 변환(순서 헷갈리기 쉬움).

QR코드 vs 바코드 vs RFID

구분바코드QR코드RFID
방식굵기가 다른 막대(1차원)가로·세로 2차원 격자무선주파수
정보량적음많음 (숫자 최대 7,089자)많음 + 반영구 저장
인식광학(빛)으로 스캔광학 스캔전파로 비접촉 인식
오류 정정없음있음 (손상돼도 복원)-

🕶️주요 개념 — 실감기술: 어디까지가 진짜인가

가상현실(VR) · 증강현실(AR) · 디지털트윈 · 메타버스 스펙트럼

구분정의
증강현실 (AR)현실 세계 위에 컴퓨터가 만든 가상 정보를 겹쳐서 보여줌
가상현실 (VR)현실과 무관한 완전한 가상 공간을 오감으로 체험
디지털 트윈현실의 사물·시스템을 가상공간에 똑같이 복제해 실시간 반응(시뮬레이션·예측에 활용)
메타버스가상공간에서 아바타로 사회·경제·문화 활동까지 하는 3차원 플랫폼
NFT블록체인으로 디지털 콘텐츠에 고유 소유권을 표시하는 토큰
함정 주의: "노매딕 컴퓨팅이 현실과 가상화면을 결합"이라는 설명은 ❌ 그건 증강현실(AR)의 정의다. 노매딕 컴퓨팅은 "장소 상관없이 다양한 정보기기가 편재되어 굳이 휴대할 필요가 없는" 개념.

유비쿼터스 컴퓨팅의 세부 유형 (헷갈리는 이름들)

유형정의
노매딕(Nomadic) 컴퓨팅장소 상관없이 정보기기가 편재 → 사용자가 휴대할 필요 없음
퍼베이시브(Pervasive) 컴퓨팅컴퓨터가 도처에 편재되도록 하는 기술
감지(Sentient) 컴퓨팅센서로 사용자·환경 상황을 인식해 필요 정보 제공
엑조틱(Exotic) 컴퓨팅스스로 생각해 현실·가상 세계를 연계
디스포절(Disposable) 컴퓨팅값싸게 만들어 한 번 쓰고 버리는 컴퓨팅
웨어러블(Wearable) 컴퓨팅옷·안경처럼 착용하는 컴퓨팅
임베디드(Embedded) 컴퓨팅사물에 마이크로칩을 내장해 서비스 기능 수행

☁️주요 개념 — 클라우드와 가상화

공용 클라우드 vs 사설 클라우드

구분공용 클라우드 (Public)사설 클라우드 (Private)
운영 주체서비스 제공업체기업 자체
사용자불특정 다수 공유해당 기업 전용
보안상대적으로 낮음높음(데이터를 외부에 맡기지 않음)

가상화(Virtualization)와 하이퍼바이저

가상화는 하나의 물리적 하드웨어를 여러 개의 가상 자원처럼 나눠 쓰는 기술이다. 이를 관리하는 소프트웨어가 하이퍼바이저(가상 머신 모니터).

함정 주의: "가상 머신 모니터를 쓰면 반드시 호스트 운영체제가 필요하다" → ❌ Type-1은 호스트 OS 없이 하드웨어에서 직접 실행된다.

📊주요 개념 — 빅데이터와 IoT

빅데이터의 3V

요소의미
Volume (규모)데이터의 방대한 양
Velocity (속도)데이터가 생성·처리되는 빠른 속도 (생성 주기가 짧음)
Variety (다양성)정형·비정형 등 다양한 형태의 데이터
함정 주의: 3V에 "시각화(Visualization)"나 "가상화(Virtualization)"를 끼워넣는 오답이 매년 나온다 — 3V는 Volume·Velocity·Variety뿐.

사물인터넷(IoT) 보안 위협

  • 취약한 인증(기본 비밀번호 그대로 사용), 데이터 유출, 공급망 공격, DDoS 봇넷 악용, 물리적 피해
함정 주의: "저사양 IoT 장치는 구조가 단순해서 보안이 안전하다" → ❌ 오히려 보안 기능을 넣기 어려워 취약하다.

HTML5의 특징

  • 플러그인 없이 비디오·오디오 재생 가능 (Flash 등 외부 플러그인 불필요)
  • <canvas>: 즉시모드 2D 그래픽 그리기 API / <svg>: XML 기반 2D 벡터 그래픽
  • 오프라인 저장소(로컬 DB) 지원, GPS·카메라 등 디바이스 하드웨어 제어 가능
함정 주의: "HTML5는 디바이스에 접근할 수 없어 보안이 철저하다" → ❌ 오히려 HTML5는 GPS·카메라 등 디바이스 기능에 직접 접근 가능한 게 특징이다.

📌시험 빈출 포인트

  • 능동형 RFID 태그(배터리O, 인식거리 김) vs 수동형(배터리X, 저렴)
  • ARP(IP→MAC) vs RARP(MAC→IP) 변환 방향 구분
  • AR(현실+가상정보), VR(완전가상), 디지털트윈(현실 복제), 메타버스(가상 사회활동) 정의 구분
  • 노매딕/퍼베이시브/감지/엑조틱/디스포절 컴퓨팅 등 유비쿼터스 세부유형 이름-정의 매칭
  • 빅데이터 3V = Volume·Velocity·Variety (시각화·가상화 아님)
  • Type-1(베어메탈, 호스트OS 불필요) vs Type-2(호스트OS 위에서 실행) 하이퍼바이저 구분
  • HTML5는 플러그인 없이 멀티미디어 재생 + 디바이스 하드웨어 직접 제어 가능
