핵심 요약

이 파트는 "이 기술의 정의를 정확히 아는가"를 묻는 용어 매칭형 문제가 대부분이다 — 비슷한 이름의 기술을 정확히 구분하는 게 핵심.

빅데이터 3V = 규모(Volume)·속도(Velocity)·다양성(Variety), AI ⊃ 머신러닝 ⊃ 딥러닝, 블록체인은 탈중앙·투명·불변. 이 세 덩어리가 최근 출제의 절반이다.

🎯이 단원을 왜 배우나

가장 새로운 단원이자, 가장 "공짜 점수"인 단원

컴퓨터구조·운영체제는 40년째 같은 내용이 나온다. 반면 이 단원은 최근 5년 사이 출제 비중이 급격히 늘어난 영역이다. 2021년 이후 국가직·지방직·계리직·소방경채 어디를 봐도 블록체인·인공지능·빅데이터 문제가 최소 1~2문항씩 들어간다. 시험 출제위원 입장에서 "요즘 기술을 아는가"를 묻기 가장 쉬운 곳이기 때문이다.

그런데 다행인 점은 계산도 없고 깊은 이해도 요구하지 않는다는 것이다. 문제 형태가 거의 고정되어 있다 — ① "다음에서 설명하는 기술은?" (정의 → 용어 찾기), ② "○○에 대한 설명으로 옳지 않은 것은?" (4개 중 딱 하나만 미묘하게 틀림). 즉 용어와 정의를 1:1로 정확히 외우면 그대로 점수다.

함정도 패턴이 정해져 있다. 비슷한 이름의 기술을 뒤바꾸기(ARP↔RARP, 노매딕↔증강현실, 능동형↔수동형 태그), 3V 같은 정해진 목록에 엉뚱한 항목 끼워넣기(Volume·Velocity·Variety 자리에 Visualization·Virtualization·Verification), "반드시/항상/없다" 같은 단정어 넣기(가상화에 호스트OS가 반드시 필요하다 → 거짓). 이 세 가지만 경계하면 오답률이 확 떨어진다.

📡주요 개념 — 통신·인식 기술

VoIP (Voice over Internet Protocol) 📖 기출문제집 p.391~392

음성을 IP 패킷으로 변환해 인터넷망으로 전화 통화를 가능케 하는 기술. 원래 음성(전화망)과 데이터(인터넷망)는 완전히 분리된 두 개의 네트워크였는데, VoIP는 이 둘을 하나의 IP 네트워크로 통합했다. 게이트웨이를 두면 기존 공중전화망(PSTN)과도 연결된다. 관련 표준 프로토콜은 ITU H.323과 IETF SIP(Session Initiation Protocol).

왜 VoIP는 품질 관리(QoS)가 까다로운가

인터넷은 원래 "최선을 다해 보내되 보장은 안 한다"(best effort)는 철학으로 만들어졌다. 웹페이지는 0.5초 늦게 떠도 상관없다. 그런데 음성은 실시간이라 0.2초만 늦어도 대화가 어긋나고, 패킷 하나가 사라져도 재전송할 시간이 없다(재전송된 "여보세요"가 3초 뒤 도착하면 의미가 없다).

그래서 VoIP에서는 아래 파라미터를 관리한다. 특히 지터(Jitter)는 "평균 지연"이 아니라 도착 간격이 들쭉날쭉한 정도라는 점이 시험 포인트다. 패킷이 모두 100ms씩 일정하게 늦으면 통화는 멀쩡하지만, 어떤 건 50ms 어떤 건 300ms로 흔들리면 음성이 끊긴다.

QoS 파라미터의미
지연 (Delay)음성 패킷이 송신지→수신지 도달하는 데 걸리는 시간
지터 (Jitter)패킷 도착 간격의 불규칙한 변동 — 일정하지 않으면 음성이 끊기거나 왜곡
패킷 손실 (Packet Loss)전송 중 일부 패킷 유실 — 실시간이라 복구 어려움, "손실 은폐" 기법으로 보완
대역폭 (Bandwidth)최소 전송 용량이 부족하면 품질 저하
무음 억제 (Silence Suppression)말하지 않는 구간엔 패킷을 안 보내 대역폭 절약 (단, 음질엔 영향 가능)
함정 주의: "지터는 패킷이 도착하는 시간 간격이 규칙적인 경우" → ❌ 정반대다. 지터 = 불규칙한 변동.

RFID (Radio Frequency IDentification) 📖 기출문제집 p.395~397

무선주파수로 태그에 저장된 정보를 리더기가 비접촉으로 읽는 인식 기술. 구성요소는 태그(tag) + 안테나(antenna) + 리더기(reader) + 서버(server). 제2차 세계대전 때 전투기 피아 식별용으로 개발된 것이 기원이다. 충돌 방지 기능이 있어 여러 개의 태그를 동시에 읽을 수 있고, 대용량 저장·반영구 사용이 가능하다.

구분능동형 태그 (Active)수동형 태그 (Passive)
전원배터리 내장배터리 없음 — 리더기의 전자기 유도로 전원 공급
인식 거리길다짧다
가격비쌈저렴
수명배터리 수명에 제한반영구적
함정 주의 3종: ① "RFID는 접촉식 식별 기술" → ❌ 비접촉식. ② "태그는 종류에 관계없이 항상 전원 공급 필요" → ❌ 수동형은 배터리 불필요. ③ "수동형 태그가 내장 배터리로 신호 발생" → ❌ 그건 능동형. 능동형·수동형을 바꿔치기하는 문제가 매년 나온다.
암기: "능동 = 스스로 움직임 = 배터리 있음 = 멀리 감 = 비쌈" 한 줄로 묶어서 외우면 나머지는 전부 반대로 채우면 된다.

🕶️주요 개념 — 실감기술: 어디까지가 진짜인가

가상현실(VR) · 증강현실(AR) · 디지털트윈 · 메타버스 📖 기출문제집 p.393~399

구분정의문제에 나오는 표현
증강현실 (AR)현실 세계 위에 컴퓨터가 만든 가상 정보를 겹쳐서 보여줌"실제 환경에 가상 사물을 합성해 원래 존재하는 것처럼"
가상현실 (VR)현실과 무관한 완전한 가상 공간을 오감으로 체험"현실에서 경험하지 못하는 상황을 간접 체험"
디지털 트윈현실의 물리 시스템을 가상공간에 똑같이 복제해 실시간으로 서로 반응"똑같이 복제하고 실시간으로 서로 반응"
메타버스가상공간에서 아바타로 정치·경제·사회·문화 활동까지 하는 3차원 플랫폼"현실과 비현실이 공존하는 생활형·게임형 가상세계"
NFT블록체인으로 디지털 콘텐츠에 고유 소유권을 인증하는 대체 불가 토큰"디지털 콘텐츠에 고유한 표식, 소유권자 인증"
구별 요령: 지문에 "겹쳐서/합성" → AR, "실시간 반응/복제" → 디지털트윈, "사회·경제 활동" → 메타버스, "소유권" → NFT. 이 네 단어만 찾으면 끝난다.

유비쿼터스 컴퓨팅의 세부 유형 (이름이 다 비슷해서 함정) 📖 기출문제집 p.400~401

☁️주요 개념 — 클라우드와 가상화

클라우드 컴퓨팅이란 📖 기출문제집 p.394

서로 다른 물리적 위치에 존재하는 컴퓨터 자원들을 가상화 기술로 통합해 인터넷을 통해 빌려주는 기술. 핵심은 "내 컴퓨터가 아닌 남의 컴퓨터를 필요한 만큼 빌려 쓴다"는 것이다.

구분공용 클라우드 (Public)사설 클라우드 (Private)
운영 주체서비스 제공업체기업 자체 (내부 데이터센터)
사용자불특정 다수의 기업·개인이 공유해당 기업 전용
보안상대적으로 낮음높음 (데이터를 외부에 맡기지 않음)
비용저렴 (쓴 만큼 지불)구축 비용 큼
함정 주의: "공용 클라우드는 한 기업의 정보 보안을 위해 내부 데이터센터 기능을 강화한 형태" → ❌ 그건 사설(private) 클라우드의 설명이다. 이 뒤바꾸기가 단골이다.

보충: 클라우드 서비스 모델 3종 (IaaS · PaaS · SaaS)

기출문제집 본문엔 직접 출제되지 않았지만, 학부 과정과 최근 시험 경향상 반드시 알아야 하는 분류다. "어디까지를 남이 관리해 주느냐"로 나뉜다.

  • IaaS (Infrastructure as a Service): 서버·스토리지·네트워크 등 인프라만 빌려줌. OS부터는 내가 설치·관리. 예) AWS EC2
  • PaaS (Platform as a Service): OS·미들웨어·런타임까지 준비된 개발 플랫폼을 빌려줌. 나는 코드만 올림. 예) Google App Engine
  • SaaS (Software as a Service): 완성된 소프트웨어를 그냥 씀. 설치·관리 전혀 없음. 예) Gmail, 구글 문서

암기: I → P → S 순서로 남이 해주는 범위가 넓어지고, 내가 손댈 자유는 줄어든다.

가상화(Virtualization)와 하이퍼바이저 📖 기출문제집 p.404~406

가상화는 하나의 물리적 자원을 여러 개의 가상 자원처럼 나눠 쓰거나, 반대로 여러 자원을 하나처럼 통합해 쓰는 기술이다. 목적은 자원 이용률(utilization) 극대화, 비용 절감, 보안 격리. 이를 관리하는 소프트웨어가 하이퍼바이저(= 가상 머신 모니터, VMM)다.

가상화 종류내용
서버 가상화한 대의 고성능 물리 서버를 여러 대의 가상 서버로 분리
클라이언트 가상화VDI 등으로 여러 사용자가 한 장비를 공유 — 논리적 분리이지 물리적 분리가 아님
애플리케이션 가상화앱이 서버에서 실행되고 사용자 PC는 입출력 장치 역할만
함정 주의 3종: ① "VMM을 쓰면 반드시 호스트 OS가 필요하다" → ❌ Type-1은 불필요. ② "VMM은 호스트 OS 위에서만 실행된다" → ❌ 같은 이유로 거짓. ③ "가상 머신에서 동작되는 게스트 OS가 실제 머신보다 효율적" → ❌ 한 단계를 더 거치므로 느리다. ④ "게스트 OS를 특정 하이퍼바이저용으로 반드시 수정해야 한다" → ❌ 필요 없다(전가상화).
가상 머신을 쓰는 이유가 아닌 것: "서버의 성능을 증가시킬 수 있다" → ❌ 가상화는 자원 이용률을 높이는 것이지 하드웨어 성능 자체를 올리지 않는다. 오히려 오버헤드로 약간 느려진다.

📊주요 개념 — 빅데이터와 NoSQL

빅데이터의 3V 📖 기출문제집 p.407~409

기존의 관리·분석 체계로는 처리하기 어려운 막대한 양의 정형 또는 비정형 데이터 집합, 그리고 그로부터 가치를 추출·분석하는 기술. 더그 레이니(Doug Laney)가 정의한 3대 특징이 3V다.

요소의미주의
Volume (규모)데이터의 방대한 양-
Velocity (속도)데이터가 생성·수집·분석되는 빠른 속도 — 생성 주기가 짧다"생성 주기가 길다" → 오답
Variety (다양성)정형·반정형·비정형 등 다양한 형태-
함정 주의 (매년 출제): 3V 자리에 Visualization(시각화)·Virtualization(가상화)·Verification(검증)·Sensor를 끼워넣는 문제가 반복된다. V로 시작하는 단어 3개는 Volume·Velocity·Variety뿐. 시각화는 3V가 아니라 분석 결과 표현 기술일 뿐이다.

데이터의 3분류 — 정형 / 반정형 / 비정형 📖 기출문제집 p.410

구분정의예시
정형 (Structured)행·열 스키마가 정해져 있고 연산 가능관계형 DB 테이블, 스프레드시트
반정형 (Semi-structured)구조에 대한 메타데이터(스키마)를 자체 포함하지만 연산은 불가XML, HTML, JSON (XML로 된 IoT 센서 데이터 등)
비정형 (Unstructured)형태도 없고 연산도 불가능소셜 데이터, 웹문서 텍스트, 영상, 이미지, 음성
함정 주의: "크롤링으로 얻은 웹문서 텍스트는 정형 데이터" → ❌ 비정형이다. 반면 XML·JSON은 반정형(태그라는 구조 정보를 스스로 갖고 있음)이라는 점이 자주 나온다.

빅데이터 처리 기술과 분석 파이프라인

기술역할단계
크롤링 (Crawling)웹 페이지를 가져와 데이터 추출수집
ETL (Extraction·Transformation·Loading)여러 소스의 데이터를 추출·변환·적재수집
로그 수집기시스템 로그 수집수집
하둡 (Hadoop)저가 서버 클러스터로 대용량 분산 처리하는 오픈소스 자바 프레임워크저장·처리
HDFS하둡의 분산 파일 시스템 (대량 데이터 저장)저장
맵리듀스 (MapReduce)Map·Reduce 함수로 대용량 데이터를 분산 병렬 처리하는 방법론처리 (수집 아님!)
텍스트마이닝·군집분석비정형 데이터 분석 기법분석
함정 주의: "데이터 수집 기술이 아닌 것은?" → 정답은 맵리듀스. 맵리듀스는 이미 모인 데이터를 처리하는 기술이다. 하둡의 필수 핵심 구성요소는 HDFS + MapReduce 두 가지.

개인정보 비식별 조치 📖 기출문제집 p.413

방법예시
가명 처리홍길동, 25세 → 임꺽정, 20대
총계 처리개인별 키 목록 → 평균키 165cm
데이터 삭제주민번호 911207-1234567 → 90년대생, 남자
데이터 범주화25세 → 20~30세
데이터 마스킹홍길동 → 홍OO, 한국대 → OO대학
함정 주의: "데이터 복호화"는 비식별 조치가 아니다 — 복호화는 오히려 감춘 것을 다시 드러내는 행위다. 비식별 5종(가명·총계·삭제·범주화·마스킹)만 정답.

NoSQL — 관계형이 아닌 데이터베이스 📖 기출문제집 p.411~412

NoSQL = "Not Only SQL". 전통적인 RDBMS와 다른 방식으로 데이터를 저장·관리하는 비관계형 DB다. 동적(유연한) 스키마를 지원하고 비정형 데이터를 잘 다루며, 대용량·고속 처리에 적합하다. 대신 관계형 DB만큼 ACID를 엄격히 지키지 않는다(속도·확장성을 얻는 대신 일관성을 일부 양보).

함정 주의: ① "문서 기반 DB는 컬럼 기반을 확장한 형태" → ❌ 키-값 모델을 확장한 것이다. ② "NoSQL은 대용량 처리에 적합하지 않다" → ❌ 바로 그걸 위해 만들어졌다. ③ "NoSQL은 RDBMS 중 하나" → ❌ 비관계형이다.

🤖주요 개념 — 인공지능 · 머신러닝 · 딥러닝

포함 관계부터 잡고 간다 📖 기출문제집 p.414

세 용어가 뒤섞여 나오는데, 포함 관계 하나만 정확히 잡으면 관련 문제 대부분이 풀린다.

머신러닝의 3가지 학습 방법 📖 기출문제집 p.422

구분학습 데이터대표 기법한 줄 요약
지도학습 (Supervised)입력 + 정답 쌍분류, 회귀분석정답지를 주고 시킨다
비지도학습 (Unsupervised)입력만 (정답 없음)군집화(clustering)정답 없이 패턴을 스스로 찾는다
강화학습 (Reinforcement)행동에 대한 보상/벌게임 플레이, 제어잘하면 상, 못하면 벌을 줘서 학습
함정 주의: "지도학습의 대표 기법에 군집화가 있다" → ❌ 군집화는 비지도학습. "보상을 받는 학습이 지도학습" → ❌ 강화학습. 분류·회귀 = 지도, 군집화 = 비지도, 보상 = 강화. 이 세 쌍만 외우면 된다.

인공 신경망의 기초

용어내용
퍼셉트론 (Perceptron)프랭크 로젠블라트가 고안한, 인공신경망·딥러닝의 기반 알고리즘. 여러 입력에 가중치를 곱해 합이 임계값을 넘으면 1을 출력
단층 퍼셉트론의 한계AND·OR·NAND는 학습 가능하지만 XOR은 학습 불가 → 층을 더 쌓은 다층 퍼셉트론으로 해결
다층 신경망입력층 + 하나 이상의 은닉층(hidden layer) + 출력층으로 구성
학습 방법뉴런 간 연결 가중치(weight)를 조정해서 학습
활성화 함수입력신호×가중치의 총합을 출력신호로 변환, 다음 층으로 넘기기 전에 거치는 함수
손실/오차/비용 함수예측값과 실제값의 차이 (활성화 함수와 혼동 금지)
CNN (합성곱 신경망)입력의 영역과 필터의 가중치를 내적해 특징 맵 생성 — 이미지 처리에 사용
RNN / LSTM순차 데이터용. LSTM은 장기 의존성 학습 가능 (음성인식, 언어모델링)
텐서플로우구글이 공개한 AI 개발용 오픈소스 프레임워크 (C++로 작성, Python API 제공)
ChatGPTOpenAI가 개발한 생성형 AI 기반 대화형 서비스
딥페이크딥러닝을 이용한 영상·이미지 합성 기술
함정 주의: "단층 퍼셉트론은 XOR(배타적 합)을 학습할 수 있다" → ❌ 못 한다. 이것이 1970년대 신경망 연구가 한번 꺾였던 유명한 이유이고, 다층 신경망이 등장한 계기다.

⛓️주요 개념 — 블록체인

블록체인의 구조와 원리 📖 기출문제집 p.419~421

거래 기록을 중앙 서버가 아니라 네트워크 참여자 모두가 나눠서 저장·검증하는 분산 컴퓨팅 기술. 한 번 기록되면 누구도 임의로 수정할 수 없고 누구나 결과를 열람할 수 있다.

특징설명
탈중앙성 (분산성)중앙 기관 없이 P2P 네트워크의 모든 노드가 데이터를 분산 저장·관리
투명성저장된 모든 거래 기록을 참여자 누구나 열람 가능
보안성해시(SHA-256)로 위·변조 방지, 데이터 무결성 제공
불변성한 번 기록되면 수정·삭제 불가 (고치려면 이후 모든 블록을 다 바꿔야 함)
용어의미
제네시스 블록블록체인의 맨 첫 번째 블록
채굴 (Mining)공공 원장(블록체인)에 거래 기록을 추가하는 과정 — 보상으로 코인 지급
비트코인 반감기채굴 보상을 절반으로 줄이는 장치, 대략 4년에 한 번
스마트 컨트랙트실세계의 계약을 블록체인에서 자동 실행되게 하는 기술
하드포크소프트웨어 업그레이드로 네트워크를 갈라내는 것 — 참여자가 결정 (대표 기업이 아님)
퍼블릭/프라이빗 블록체인공개 범위에 따른 구분
합의 알고리즘내용
작업증명 (PoW, Proof of Work)계산 능력으로 문제를 풀어 블록 생성 권한 획득 (비트코인)
지분증명 (PoS, Proof of Stake)보유한 지분에 비례해 권한 부여
위임 지분증명 (DPoS)지분 보유자가 대표를 뽑아 위임
비잔틴 장애 허용 (BFT)장애·거짓 응답 노드가 전체의 1/3을 넘지 않으면 정상 합의 가능
함정 주의: ① "블록은 중앙 서버를 통해 전파되고 검증 후 중앙 서버로 다시 전송" → ❌ 블록체인은 중앙 서버가 없다(탈중앙). ② "모든 거래는 거래 당사자만 확인할 수 있다" → ❌ 참여자 누구나 열람 가능(투명성). ③ "하드포크는 대표 기업이 결정" → ❌ 참여자가 결정. ④ "비트코인 반감기는 5년" → ❌ 약 4년.

🌐주요 개념 — IoT와 HTML5

사물인터넷 (IoT) 📖 기출문제집 p.403

각종 사물에 센서와 통신 기능을 내장해 인터넷에 연결하는 기술. M2M(Machine to Machine)이 인터넷 구조로 확장된 개념으로, 사람의 개입 없이 기기들이 알아서 정보를 주고받는다.

IoT 보안 위협내용
취약한 인증·접근통제기본 비밀번호를 그대로 쓰거나 인증 절차 부족
악성코드·랜섬웨어기기 원격 제어, 데이터 암호화 후 금전 요구
데이터 유출위치·건강·생활 패턴 등 민감 개인정보 수집 → 사생활 침해
공급망 공격부품·SW 공급망의 취약점 하나가 전체 기기에 영향
DDoSIoT 기기를 봇넷으로 활용해 서버 마비
물리적 피해물리 환경과 연결돼 있어 해킹이 실제 사고로 이어짐
함정 주의: "저사양 장치는 구조가 단순하여 보안이 안전하다" → ❌ 정반대다. 성능이 낮아 암호화·보안 기능을 넣기 어려워 더 취약하다.

HTML5의 특징 📖 기출문제집 p.402

  • 플러그인(Flash·ActiveX) 없이 비디오·오디오 재생 가능
  • <canvas>: 즉시모드(immediate mode) 2D 그래픽 그리기 API — 동적 그래픽·애니메이션
  • <svg>: XML 기반 2차원 벡터 그래픽
  • 시멘틱 요소(header, nav, article 등)로 문서 구조를 의미 있게 표현
  • 오프라인 처리·로컬 저장소·DB·파일 접근 지원 → 네트워크 없이도 웹 앱 동작
  • GPS·카메라·모션센서 등 디바이스 하드웨어를 웹에서 직접 제어 가능
  • 쌍방향 통신(실시간 채팅·온라인 게임), 비동기 통신·멀티스레딩으로 성능 향상
  • 스마트폰 일반 응용프로그램도 HTML5로 개발 가능
함정 주의: "HTML5는 디바이스에 접근할 수 없어서 보안을 철저히 유지" → ❌ 오히려 디바이스 하드웨어에 직접 접근할 수 있는 것이 HTML5의 대표 특징이다.

📌시험 빈출 포인트

  • 지터 = 도착 간격의 불규칙한 변동 (규칙적 ❌)
  • RFID: 비접촉식, 능동형(배터리O·멀리·비쌈) vs 수동형(배터리X·가까이·저렴·반영구)
  • ARP = IP→MAC, RARP = MAC→IP (방향 뒤집기 단골)
  • QR코드는 오류 정정 기능 있음, 일본 덴소웨이브 개발, 숫자 최대 7,089자
  • 와이브로 = 이동 중 인터넷(방송 ❌) / DMB = 이동 방송 / 텔레매틱스 = 자동차 / GIS = 지리정보
  • AR(겹침) · VR(완전가상) · 디지털트윈(복제+실시간반응) · 메타버스(사회활동) · NFT(소유권)
  • 노매딕(휴대 불필요) vs 감지(센서 인식) vs 디스포절(일회용) vs 엑조틱(스스로 생각) 구분
  • 공용 클라우드(업체가 불특정 다수에게) vs 사설 클라우드(기업 내부 전용·보안↑)

VoIP QoS에 영향을 주는 파라미터에 대한 설명으로 옳지 않은 것은?

  1. 지연(Delay)은 데이터를 전송하는 데 지연되는 시간을 말한다.
  2. 지터(Jitter)는 패킷이 도착하는 시간 간격이 규칙적인 경우를 말한다.
  3. 패킷 손실이 발생한 경우 서비스에 따라 패킷 손실 은폐 방법을 사용하기도 한다.
  4. 무음 억제는 패킷 수를 줄이기 위해 무음이 지속되는 기간 동안 음성 패킷 생성을 억제한다.
해설 보기

정답 ② (지터는 불규칙한 변동이다)

지터(Jitter)는 패킷 간 도착 시간의 변동을 말한다. 도착 간격이 일정하지 않을 때 음성이 끊기거나 왜곡된다. 즉 "규칙적인 경우"가 아니라 불규칙한 정도가 지터다.

왜 헷갈리나: 지연(Delay)은 "느린 것"이고 지터는 "들쭉날쭉한 것"이다. 모든 패킷이 똑같이 100ms씩 늦으면 통화는 멀쩡하지만, 50ms·300ms·80ms로 흔들리면 목소리가 끊긴다. 평균이 아니라 변동폭이 문제라는 게 핵심.

나머지 ①③④는 모두 맞는 설명이다.

  4. 지그비(ZigBee)는 저비용·저전력 무선 네트워크 기술로 센서 네트워크에서 사용할 수 있다.

  2. 수동형(Passive) 태그: 배터리 없음. 리더기 안테나의 전자기 유도로 전원을 공급받아 동작 → 통신거리 짧음, 저렴, 반영구적
  3. 문제는 "수동형"이라 써놓고 능동형의 설명을 붙였으므로 틀렸다

암기법: "능동 = 스스로 움직임 = 배터리 있음 = 멀리 간다 = 비싸다"를 한 덩어리로 외우고, 수동형은 전부 반대로 채우면 된다.

정답 ③ 디지털 트윈

지문의 결정적 단어는 "똑같이 복제"와 "실시간으로 서로 반응"이다. 쌍둥이(twin)라는 이름 그대로, 현실의 기계·공장·도시를 가상에 복제해 두고 센서 데이터를 실시간으로 흘려보내 고장 예측·시뮬레이션에 쓴다.

오답 구별:

  • ①가상현실 — 현실과 무관한 가상공간. 복제가 아니다.

  • ④유비쿼터스 컴퓨팅 — 언제 어디서나 컴퓨터를 쓸 수 있는 환경. 가상 복제와 무관.
문제 52016 국가직 · 기출문제집 p.400

유비쿼터스 컴퓨팅에 대한 설명으로 옳지 않은 것은?

  1. 감지 컴퓨팅은 컴퓨터가 센서 등을 이용하여 사용자의 행위 또는 주변 환경을 인식하여 필요 정보를 제공하는 기술이다.
  2. 노매딕(nomadic) 컴퓨팅은 현실 세계와 가상 화면을 결합하여 보여주는 기술이다.
  3. 퍼베이시브(pervasive) 컴퓨팅은 컴퓨터가 도처에 편재되도록 하는 기술이다.
  4. 웨어러블(wearable) 컴퓨팅은 컴퓨터 착용을 통해 컴퓨터를 인간 몸의 일부로 여길 수 있도록 하는 기술이다.
해설 보기

정답 ② (현실+가상 화면 결합은 증강현실(AR))

노매딕(nomadic)은 "유목민의"라는 뜻이다. 유목민은 짐을 들고 다니지 않고 가는 곳마다 있는 것을 쓴다 — 마찬가지로 노매딕 컴퓨팅은 어디에나 정보기기가 이미 깔려 있어 사용자가 기기를 휴대할 필요가 없는 환경이다.

"현실 세계와 가상 화면을 결합"은 증강현실(AR)의 정의를 그대로 가져다 붙인 것이다.

이 유형을 푸는 법: 유비쿼터스 세부 유형은 전부 영어 단어 뜻이 곧 정의다. nomadic(유목민), pervasive(스며드는), sentient(감각 있는), disposable(일회용), wearable(착용), embedded(내장). 단어 뜻만 알면 틀린 설명이 바로 눈에 띈다.

가상 머신(Virtual Machine)에 대한 설명으로 옳지 않은 것은?

  1. 단일 컴퓨터에서 가상화를 사용하여 다수의 게스트 운영체제를 실행할 수 있다.
  2. 가상 머신은 다른 가상 머신의 동작에 간섭을 주지 않는 격리된 실행환경을 제공한다.
  3. 가상 머신 모니터(VMM)를 사용하여 가상화하는 경우 반드시 호스트 운영체제가 필요하다.
  4. 자바 가상 머신은 자바 바이트 코드가 다양한 운영체제 상에서 수행될 수 있도록 한다.
해설 보기

정답 ③ (Type-1은 호스트 OS가 없어도 된다)

  1. Type-1 (베어메탈): 하이퍼바이저가 하드웨어 위에서 직접 실행 → 호스트 OS 불필요. 예) KVM, ESXi
  2. Type-2 (호스트형): 이미 설치된 호스트 OS 위에서 하나의 응용프로그램처럼 실행 → 호스트 OS 필요. 예) VirtualBox
  3. 따라서 "반드시 호스트 OS가 필요"는 거짓

같은 함정의 변형: 2021 지방직에서는 "가상 기계 모니터는 호스트 운영체제 위에서만 실행된다"로 출제됐다. 표현만 바꿨을 뿐 같은 오답이다.

단정어 경보: "반드시", "항상", "~에서만", "절대" 같은 단어가 보이면 일단 의심하라. 이 단원 오답의 상당수가 이 패턴이다.

가상 머신(Virtual Machine)을 사용하는 이유로 가장 옳지 않은 것은?

  1. 여러 운영체제에서 실행되는 다양한 응용 프로그램들을 하나의 서버에서 실행할 수 있다.
  2. 서버의 성능을 증가시킬 수 있다.
  3. 하나의 물리적 서버에 여러 개의 가상 머신을 실행할 수 있다.
  4. 물리적 서버에 비하여 설치 시간을 단축시킬 수 있다.
해설 보기

정답 ② (성능이 아니라 이용률이 올라간다)

가상화는 놀고 있는 하드웨어 자원을 꽉 채워 쓰게 하는 기술이다. CPU 10%만 쓰던 서버 한 대에 가상 머신 5개를 올려 50%를 쓰게 만드는 식이다. 이것은 이용률(utilization) 향상이지 하드웨어 성능 향상이 아니다.

오히려 하이퍼바이저라는 중간 계층이 하나 더 끼어들기 때문에 개별 가상 머신의 성능은 물리 머신보다 약간 느려진다.

가상화의 진짜 장점: 자원 이용률↑, 비용 절감, 빠른 설치·배포, 보안 격리, 서로 다른 OS 동시 운용.

문제 82018 서울시 · 기출문제집 p.409

빅데이터에 대한 설명으로 가장 옳지 않은 것은?

  1. 디지털 환경에서 생성되는 데이터로 규모가 방대하고, 생성 주기가 길며, 형태가 다양하다.
  2. 하둡(Hadoop)과 같은 오픈 소스 소프트웨어 시스템을 빅데이터 처리에 이용하는 것이 가능하다.
  3. 보건·금융 분야의 빅데이터는 유용하나 프라이버시 침해 대비가 필요하다.
  4. 구글·페이스북·아마존은 이용자 성향과 패턴을 분석해 맞춤형 광고를 제공한다.
해설 보기

정답 ① (생성 주기는 짧다)

3V를 그대로 대입해 보면 바로 보인다.

  1. 규모가 방대하다 → Volume ✔
  2. 생성 주기가 길다 → ✘ Velocity는 "빠른 속도, 짧은 생성 주기"를 뜻한다
  3. 형태가 다양하다 → Variety ✔

SNS·센서·로그는 초 단위로 쏟아진다. 생성 주기가 길다면 애초에 "빅"데이터가 되지도 않는다.

3V 변형 함정 모음: Visualization(시각화), Virtualization(가상화), Verification(검증), Sensor — 전부 3V가 아니다.

  4. NoSQL과 Hadoop은 대규모 비정형 데이터 처리에 적합하다.

정답 ① (웹문서 텍스트는 비정형)

구분 기준은 "구조 정보를 갖고 있는가"다.

  1. 정형: 행·열이 딱 정해져 있고 연산 가능 → RDB 테이블, 엑셀
  2. 반정형: 스키마·메타데이터를 자기 안에 태그로 갖고 있지만 바로 연산은 불가 → XML, HTML, JSON
  3. 비정형: 정해진 구조가 아예 없음 → 웹문서 본문 텍스트, 이미지, 영상, 음성, SNS 글

웹페이지를 크롤링해 얻은 줄글 텍스트에는 "3번째 칸이 나이"같은 약속이 없다. 그래서 비정형이다. 같은 웹에서 온 데이터라도 XML 형식이면 반정형이 되는 것이 포인트.

NoSQL의 데이터 모델 분류에 대한 설명으로 가장 옳지 않은 것은?

  1. 컬럼 기반 데이터베이스는 컬럼 패밀리와 키의 쌍으로 데이터를 저장하는 형태를 의미한다.
  2. 그래프 기반 데이터베이스는 연관 데이터 추천이나 소셜 네트워크 친구 찾기 질의에 적합하다.
  3. 문서 기반 데이터베이스는 컬럼 기반 데이터 모델을 확장한 형태로 JSON, XML 등 반정형 데이터를 저장한다.
  4. 키-값 데이터베이스는 키와 값의 쌍으로 데이터를 저장하는 구조를 갖는다.
해설 보기

정답 ③ (문서형은 키-값 모델의 확장이다)

문서 기반 DB는 키-값 저장소의 "값" 자리에 문서(JSON/XML)를 통째로 넣은 구조다. 즉 키-값의 확장이지 컬럼 기반의 확장이 아니다.

유형저장 구조대표 제품
키-값키 1개 ↔ 값 1개 (가장 단순, 초고속)Redis, DynamoDB
문서키 ↔ JSON/XML 계층 문서MongoDB, CouchDB
컬럼행이 아닌 열 중심으로 모아 저장Cassandra, HBase
그래프노드 + 관계(엣지) + 속성Neo4j

제품명으로 외우기: MongoDB = 문서, Redis = 키-값, Cassandra = 컬럼, Neo4j = 그래프. 제품명이 지문에 나오면 유형이 바로 정해진다.

  2. (가) 인공지능 — (나) 딥러닝 — (다) 머신러닝
  3. (가) 머신러닝 — (나) 인공지능 — (다) 딥러닝
  4. (가) 머신러닝 — (나) 딥러닝 — (다) 인공지능

정답 ③ (가)머신러닝 — (나)인공지능 — (다)딥러닝

정답 ② (블록체인은 누구나 열람 가능 — 투명성)

블록체인의 4대 특징은 탈중앙성 · 투명성 · 보안성 · 불변성이다. 그중 투명성은 "네트워크 참여자 누구나 거래 기록을 열람·확인할 수 있다"는 뜻이므로, "당사자만 확인 가능"은 정반대다.

정답 ① (저사양일수록 더 취약하다)
