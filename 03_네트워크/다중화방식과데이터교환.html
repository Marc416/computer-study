다중화 방식과 데이터 교환 방식

FDM·TDM·CDMA, 회선교환·메시지교환·패킷교환 · PART 03. 데이터통신론

핵심 요약

다중화(Multiplexing)는 "하나의 회선을 여러 사람이 나눠 쓰는 방법", 교환 방식은 "데이터가 목적지까지 가는 경로를 잡는 방법"이다.

다중화는 주파수로 나누면 FDM, 시간으로 나누면 TDM, 코드로 나누면 CDMA다.

💡주요 개념

다중화(Multiplexing) 방식 📖 기출문제집 p.289

전용회선 하나를 사람마다 새로 깔면 비용이 어마어마하다. 다중화는 하나의 물리적 회선을 여러 채널로 "쪼개서" 동시에 여러 명이 쓰게 하는 기술이다.

방식분할 기준특징
FDM (Frequency Division)주파수채널 간 보호대역(guard band) 필요, 여러 채널 동시 전송
TDM (Time Division)시간동기식(STDM): 데이터 없어도 슬롯 할당(낭비) / 비동기식(ATDM): 필요할 때만 할당(효율적)
CDMA (Code Division)코드FDM+TDM 혼합, 대역확산 사용, 압축·에러복구 용이
함정 주의: "TDMA는 대역확산 기법을 사용한다" → ❌ 대역확산은 CDMA의 특징이다. TDMA는 시간을 슬롯으로 나눌 뿐이다.

데이터 교환 방식 📖 기출문제집 p.290~291

다중화가 "회선을 나눠쓰는 법"이라면, 교환 방식은 "내 데이터가 목적지까지 어떤 경로로 가는가"의 문제다.

구분회선교환메시지교환패킷교환
연결 방식통신 전 전용 경로 설정경로 설정 없이 저장 후 전달패킷 단위로 저장 후 전달
회선 점유독점 (연결 내내)공유공유
전송 지연적음많음(전체 메시지 저장 후 전달)중간(패킷 단위라 상대적으로 적음)
적합한 통신실시간(음성·영상)비실시간 대용량대화형 데이터통신
대표 예전화망이메일(구형 방식)인터넷
함정 주의: "회선교환이 패킷교환보다 더 많은 동시 접속자를 수용한다" → ❌ 틀림. 회선을 독점하는 회선교환은 오히려 동시 접속자 수가 적다. 회선을 나눠 쓰는 패킷교환이 더 많은 사용자를 수용한다.

📌시험 빈출 포인트

  • FDM=주파수 분할, TDM=시간 분할, CDMA=코드 분할(대역확산) — 분할 기준으로 구분
  • 동기식 TDM(STDM)은 슬롯 낭비, 비동기식 TDM(ATDM)은 필요한 채널에만 할당해 효율적
  • 회선교환=경로 독점·저지연·실시간용, 패킷교환=경로 공유·효율적·인터넷용
  • "더 많은 동시 접속자 수용" → 회선을 공유하는 패킷교환이 정답
  • 패킷교환은 데이터그램 방식과 가상회선 방식으로 다시 나뉜다는 점 기억
