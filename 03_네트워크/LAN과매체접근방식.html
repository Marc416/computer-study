LAN과 매체접근방식

토폴로지, CSMA/CD·CSMA/CA, 토큰 방식, 무선랜 표준, 근거리 무선기술 · PART 03. 데이터통신론

핵심 요약

유선 LAN(이더넷)은 CSMA/CD, 무선 LAN(Wi-Fi)은 CSMA/CA를 매체접근 방식으로 쓴다 — 이름은 비슷해도 원리가 다르다.

LAN 토폴로지는 성형·버스형·링형 3가지가 기본이고, 이더넷은 버스형 토폴로지에서 발전했다.

🎯이 단원을 왜 배우나

"선 하나를 여럿이 나눠 쓴다"는 문제

LAN의 본질은 여러 대의 컴퓨터가 하나의 전송 매체(케이블 또는 전파)를 공유한다는 것이다. 공유하면 반드시 생기는 문제가 있다 — 두 대가 동시에 말하면 신호가 뒤섞여 둘 다 망가진다(충돌). 회의실에서 두 사람이 동시에 말하면 아무 말도 안 들리는 것과 같다.

그래서 "누가 언제 말할 것인가"를 정하는 규칙이 필요한데, 그게 매체접근제어(MAC)다. 방식은 크게 두 갈래다.

  • 눈치껏 하기(경쟁 방식) — 일단 조용한지 들어보고 비었으면 말한다. 겹치면 그때 수습. → CSMA/CD, CSMA/CA
  • 순서 정하기(비경쟁 방식) — "발언권 토큰"을 돌려서 토큰 가진 사람만 말한다. 충돌이 원천적으로 없다. → 토큰링, 토큰버스

경쟁 방식은 한산할 때 빠르지만 붐비면 충돌이 급증하고, 토큰 방식은 한산해도 차례를 기다려야 하지만 붐벼도 성능이 일정하다. 이 트레이드오프가 두 방식의 장단점을 전부 설명한다. 그리고 유선에서 잘 되던 CSMA/CD가 무선에서는 왜 안 통하는지(숨은 터미널 문제)까지 이해하면 이 단원은 끝난다.

🚦주요 개념 — CSMA/CD (유선, 이더넷)

CSMA/CD = Carrier Sense Multiple Access with Collision Detection. "회선이 비었는지 확인하고 보내되, 충돌 나면 감지하고 다시 시도"하는 임의접근(경쟁) 방식. 이더넷(Ethernet, IEEE 802.3)의 매체접근방식이다.

이름을 뜯어보면 동작이 보인다

  • Carrier Sense(반송파 감지) — 보내기 전에 회선에 신호가 흐르는지 "들어본다"
  • Multiple Access(다중 접근) — 여러 노드가 같은 매체를 공유한다
  • Collision Detection(충돌 감지) — 보내는 도중에도 계속 들으면서, 내가 보낸 것과 다른 신호가 섞이면 충돌로 판단

충돌을 감지하면 즉시 전송을 중단하고, 모든 노드에 충돌을 알린 뒤, 임의(random)의 시간만큼 기다렸다가 다시 시도한다. 여기서 "임의"가 핵심이다 — 만약 정해진 시간만큼 기다리면 충돌한 두 노드가 또 동시에 재시도해서 영원히 충돌한다. 무작위로 기다려야 서로 어긋난다.

바로 이 "임의 대기" 때문에 언제 전송이 성공할지 예측할 수 없다는 단점이 생긴다. 시험에서 "지연시간을 정확히 예측할 수 있다"는 서술이 나오면 무조건 오답이다.

함정 주의: CSMA/CD는 충돌이 발생하면 지연시간을 예측하기 어렵다(임의 대기 때문). "지연시간을 정확히 예측할 수 있다"는 오답. 또한 CSMA/CD는 토큰을 사용하지 않는다 — 토큰 방식(토큰링/토큰버스)과 헷갈리지 말 것.
함정 주의 2: "하나의 스테이션이 고장나면 네트워크 전체가 마비된다" → 버스형에서는 ❌ 틀림. 개별 노드 고장은 무관하고, 공용 회선 자체가 고장나야 전체가 마비된다.
왜 프레임에 최소 길이 제한이 있나: 충돌을 감지하려면 내가 아직 보내는 중일 때 충돌 신호가 돌아와야 한다. 프레임이 너무 짧으면 전송이 이미 끝난 뒤에 충돌이 도착해 감지하지 못한다. 그래서 이더넷은 최소 프레임 크기(64바이트)를 강제한다.

📶주요 개념 — CSMA/CA (무선 LAN)

유선처럼 충돌을 "감지"하기 어려운 무선 환경에서는 애초에 충돌을 회피(Avoidance)하는 CSMA/CA를 쓴다. IEEE 802.11(Wi-Fi) 계열의 매체접근방식.

무선에서 CSMA/CD가 안 통하는 두 가지 이유

① 보내면서 동시에 들을 수 없다. 무선 장치가 송신할 때 내보내는 전파는 자기 수신기 입장에서 어마어마하게 크다. 그 와중에 멀리서 오는 미약한 남의 신호를 구분해 듣는 것은 사실상 불가능하다 — 즉 충돌 "감지" 자체가 안 된다.

② 숨은 터미널(hidden terminal) 문제. 아래 그림처럼 A와 B가 AP를 사이에 두고 멀리 떨어져 있으면, 서로의 신호가 상대에게 닿지 않는다. 둘 다 "회선이 비었네"라고 판단하고 동시에 전송하면, 정작 가운데 AP에서는 신호가 겹쳐 충돌이 난다. 그런데 A도 B도 그 사실을 모른다.

그래서 무선은 부딪히고 나서 수습하는 대신, 부딪히지 않도록 미리 조율하는 쪽을 택했다 — 임의 백오프로 시작 시점을 흩뜨리고, RTS/CTS로 채널을 예약하고, 잘 받았으면 ACK로 확인해준다.

  • 채널이 비어있어도 임의의 백오프(backoff) 값만큼 기다렸다가 전송 (동시전송 확률을 낮춤)
  • 수신측은 프레임을 오류 없이 받으면 ACK를 전송해 확인 (무선은 충돌 감지가 안 되므로, ACK가 안 오면 실패로 간주)
  • RTS/CTS(Request to Send / Clear to Send)로 채널을 미리 예약해 숨은 터미널 문제를 해결
RTS/CTS 비유: A가 AP에게 "저 30초만 말할게요(RTS)"라고 하면, AP가 모두에게 들리도록 "A가 30초간 말합니다(CTS)"라고 방송한다. B는 A의 목소리는 못 들어도 AP의 방송은 들리므로 그동안 조용히 기다린다. 서로 안 들리는 문제를 가운데 있는 AP가 중계해서 푼 것이다.
함정 주의: IEEE 802.11b는 CSMA/CD가 아니라 CSMA/CA를 쓴다. "CSMA/CD 방식을 IEEE 802.11b의 MAC 방식으로 사용" → 오답. CSMA/CD는 IEEE 802.3(이더넷)의 것이다.

🎫주요 개념 — 토큰 방식 (비경쟁 방식)

경쟁 방식(CSMA)의 반대편에는 충돌을 아예 발생시키지 않는 방식이 있다. 토큰(token)이라는 특수한 프레임을 돌려가며, 토큰을 가진 노드만 전송하게 하는 것이다. 발언권 막대를 돌리는 회의와 같다.

방식토폴로지표준특징
토큰 링(Token Ring)링형IEEE 802.5링을 따라 토큰이 순환, 받은 노드만 전송 후 토큰을 다음으로 넘김
토큰 버스(Token Bus)버스형IEEE 802.4물리적으로는 버스지만 논리적으로 링처럼 토큰을 순환시킴
FDDI이중 링ANSI 표준광섬유 사용, 멀티토큰 방식의 이중 링 — 반송파 감지(CSMA)를 하지 않는다

경쟁 방식 vs 토큰 방식 — 언제 뭐가 유리한가

  • 한산할 때: CSMA/CD 압승. 아무도 안 쓰면 즉시 보낼 수 있다. 토큰 방식은 자기 차례(토큰)가 올 때까지 괜히 기다려야 한다.
  • 붐빌 때: 토큰 방식 압승. CSMA/CD는 충돌이 폭증해 재시도만 반복하며 성능이 급락하지만, 토큰 방식은 차례대로 돌아가므로 성능이 일정하게 유지된다.
  • 지연 예측: 토큰 방식은 "최대 몇 초 안에 내 차례가 온다"를 계산할 수 있어 실시간 제어(공장 자동화 등)에 적합하다. CSMA/CD는 불가능.

그럼에도 현실에서 이더넷이 이긴 이유는 구현이 단순하고 값싸며, 스위치가 보편화되면서 충돌 자체가 거의 사라졌기 때문이다(각 포트가 독립 회선이 되어 충돌 도메인이 분리됨).

함정 주의: "이더넷은 토큰 패싱 방식을 사용한다" → ❌ 틀림. 이더넷은 CSMA/CD다. 반대로 "반송파 감지를 하지 않는 것"을 고르라면 토큰 방식인 FDDI·토큰링이 답이다.

기타 무선기술

  • Wi-Fi: IEEE 802.11 기반 WLAN 제품에 주어지는 인증마크 (2.4GHz/5GHz)
  • AP(Access Point): 무선망을 유선망에 연결해주는 중계 장치 — 유선망을 무선으로 확장시켜주는 역할
  • WiBro: 한국에서 개발한 무선인터넷 서비스(2.3GHz 대역), 이동 중에도 초고속 인터넷 이용 가능
  • LTE / 5G: 5G는 초고속·초저지연·초연결이 특징, 저지연 고신뢰 전송과 초광대역 GHz급 전송을 지원
  • MANET(애드혹 네트워크): AP 없이 노드끼리 자율 구성, 각 노드가 호스트+라우터 역할 동시 수행
함정 주의: "MANET은 동적 토폴로지 구성을 위해 AP 같은 중재자가 필요하다" → ❌ 틀림. MANET의 핵심은 AP 없이 노드들이 자율적으로 망을 구성한다는 것. 또 "AP 없이는 두 컴퓨터가 통신할 수 없다" → ❌ 틀림, 애드혹 모드로 직접 통신 가능하다.

📌시험 빈출 포인트

  • 이더넷 = CSMA/CD = IEEE 802.3, Wi-Fi = CSMA/CA = IEEE 802.11 — 네 쌍을 세트로 암기
  • CSMA/CD는 충돌 감지 후 임의 대기 → 지연시간 예측 불가, 토큰 미사용
  • 무선에서 CSMA/CD가 안 되는 이유: 송신 중 수신 불가 + 숨은 터미널 문제
  • 숨은 터미널 해결책 = RTS/CTS 채널 예약
  • 버스형 토폴로지: 개별 노드 고장은 무관, 공용회선 고장이 전체 마비 원인
  • 반송파 감지를 하지 않는 방식 = 토큰 계열(FDDI, 토큰링, 토큰버스)
  • 802.11 표준별 대역/속도/기술: a(5GHz·54M) b(2.4GHz·11M) g(2.4GHz·54M) n(MIMO) ax(OFDMA)
  • 블루투스 = 802.15.1, ZigBee = 802.15.4 — 표준번호까지 묻는다
  • MANET은 AP 없이 자율 구성, 각 노드가 라우팅 기능도 겸함

다음의 조건을 모두 만족하는 다중 접근방식은?

· 임의접근(Random Access) 방식 중의 하나임
· 회선 사용 상태를 감지하는 캐리어를 사용하고 충돌이 발생하면 임의시간 대기 후 전송함
· 이더넷의 접근방식으로 사용됨

  1. FDMA
  2. ALOHA
  3. Token Ring
  4. CSMA/CD
해설 보기

정답 ④ CSMA/CD

지문의 조건이 CSMA/CD의 정의를 그대로 풀어 쓴 것이다.

  1. "캐리어(반송파)로 회선 상태 감지" = Carrier Sense
  2. "임의접근 방식" = Multiple Access (경쟁 방식)
  3. "충돌 발생 시 임의시간 대기 후 재전송" = Collision Detection 후 백오프
  4. "이더넷의 접근방식" = 결정적 단서 (이더넷 = IEEE 802.3 = CSMA/CD)

오답 정리: ③ Token Ring은 비경쟁 방식(충돌 없음)이라 "임의접근"이 아니다. ① FDMA는 주파수를 나눠 쓰는 다중화 방식이고, ② ALOHA는 캐리어 감지 없이 일단 보내고 보는 원시적 방식이다(CSMA의 조상격).

문제 22009 지방직 · 기출문제집 p.361

CSMA/CD 방식에 대한 설명으로 옳지 않은 것은?

  1. 각 스테이션은 충돌을 감지하는 즉시 전송을 취소한다.
  2. 모든 스테이션에 보내고자 하는 메시지를 브로드캐스트 한다.
  3. 하나의 스테이션이 고장나면 네트워크 전체가 마비된다.
  4. 모든 스테이션은 전송매체에 동등한 접근 권리를 갖는다.
해설 보기

정답 ③ (개별 스테이션 고장은 전체와 무관)

CSMA/CD는 버스형 토폴로지 기반이다. 버스형에서는 노드들이 공용 회선에 매달려만 있기 때문에, 노드 하나가 죽어도 나머지 통신에는 영향이 없다.

  1. 버스형에서 전체가 마비되는 경우는 공용 회선(백본 케이블) 자체가 끊겼을 때뿐
  2. "노드 하나 고장 = 전체 마비"가 맞는 토폴로지는 링형(순환이 끊김)이나, 중앙 장치가 죽은 성형이다

①②④는 모두 맞는 설명이다 — 충돌 감지 즉시 전송 중단, 공유 매체이므로 브로드캐스트 성격, 모든 노드가 동등한 경쟁 권한(우선순위 없음).

문제 32023 소방경채 · 기출문제집 p.361

이더넷(ethernet)에 관한 설명으로 옳지 않은 것은?

  1. IEEE 802.3 국제표준이다.
  2. 매체 접근 제어 방식은 CSMA/CD이다.
  3. 호스트에서 전송할 데이터가 많아질수록 충돌 발생 빈도가 증가한다.
  4. 호스트가 채널의 상태를 감지해 충돌을 피하는 토큰 패싱(token passing) 매체 접근 제어 방식을 사용한다.
해설 보기

정답 ④ (이더넷은 토큰 패싱을 쓰지 않는다)

④는 서로 다른 두 방식을 뒤섞어 놓은 문장이라 주의해야 한다. "채널 상태를 감지"는 CSMA의 특징이고 "토큰 패싱"은 토큰링의 특징인데, 둘은 정반대 진영이다.

  1. 이더넷 = CSMA/CD = 경쟁 방식 (충돌이 발생할 수 있음)
  2. 토큰 패싱 = 토큰링/토큰버스 = 비경쟁 방식 (충돌이 없음)
  3. 충돌이 없는 방식이라면 ③(충돌 빈도 증가)과도 모순된다 — 선택지끼리 비교해도 ④가 이상함을 알 수 있다

①②③은 옳다. 특히 ③은 경쟁 방식의 본질적 약점 — 부하가 늘수록 충돌이 늘어 성능이 떨어진다.

문제 42015 국가직 · 기출문제집 p.362

이더넷의 MAC 방식인 CSMA/CD에 대한 설명으로 옳지 않은 것은?

  1. CSMA 방식에 충돌 검출 기법을 추가한 것으로 IEEE 802.11b의 MAC 방식으로 사용된다.
  2. 충돌 검출을 위해 전송 프레임의 길이를 일정 크기 이상으로 유지해야 한다.
  3. 전송 도중 충돌이 발생하면 임의의 시간 동안 대기하기 때문에 지연시간을 예측하기 어렵다.
  4. 전송 요구량이 증가하면 회선의 유효 전송률이 낮아진다.
해설 보기

정답 ① (802.11b가 아니라 802.3)

  1. CSMA/CD는 IEEE 802.3(유선 이더넷)의 MAC 방식이다
  2. IEEE 802.11b는 무선랜 표준이고 CSMA/CA를 쓴다
  3. 무선에서 CD(충돌 감지)가 불가능한 이유는 송신 중 수신 불가 + 숨은 터미널 문제 때문

나머지는 모두 옳은 설명이며, 각각 CSMA/CD의 중요한 특성이다.

  • ②: 프레임이 너무 짧으면 전송이 끝난 뒤에 충돌이 도착해 감지할 수 없다 → 최소 프레임 길이 제한 필요
  • ③: 임의(random) 백오프 때문에 언제 성공할지 예측 불가
  • ④: 부하가 늘면 충돌·재전송이 늘어 실효 전송률이 떨어짐
문제 52008 국가직 · 기출문제집 p.362

IEEE 802.11 방식의 무선 LAN에 사용되는 물리매체 제어방식은?

  1. CDMA
  2. CSMA/CD
  3. CSMA/CA
  4. ALOHA
해설 보기

정답 ③ CSMA/CA

  1. IEEE 802.11 = 무선랜(Wi-Fi) → 무선은 충돌 감지가 불가능
  2. 따라서 충돌을 회피(Avoidance)하는 CSMA/CA를 사용
  3. 전송 전 임의 백오프 + RTS/CTS 예약 + 수신 시 ACK 응답이 핵심 장치

오답 정리: ② CSMA/CD는 802.3(유선). ① CDMA는 이동통신의 다중접속(코드분할) 방식으로 무선랜 MAC과는 다른 개념. ④ ALOHA는 캐리어 감지조차 없는 초기 방식.

세트 암기: 802.3 → CSMA/CD → 유선 / 802.11 → CSMA/CA → 무선

문제 62011 지방직 · 기출문제집 p.363

MAC(Medium Access Control) 부계층에서 반송파 감지(carrier sense)를 하지 않는 것은?

  1. FDDI(Fiber Distributed Data Interface)
  2. Fast Ethernet
  3. Ethernet
  4. IEEE 802.11b
해설 보기

정답 ① FDDI

"반송파 감지를 한다" = CSMA 계열이라는 뜻이다. 즉 CSMA가 아닌 것을 찾는 문제다.

  1. ②③ Ethernet·Fast Ethernet → 버스형, CSMA/CD (IEEE 802.3) → 감지함
  2. ④ IEEE 802.11b → 무선랜, CSMA/CA → 감지함(CA도 CS는 한다)
  3. ① FDDI → 광섬유 이중 링, 멀티토큰 방식(ANSI 표준) → 토큰으로 순서를 정하므로 반송파를 감지할 필요가 없다 ✅

주의: CSMA/CA도 이름에 CS(Carrier Sense)가 들어 있다. "CA는 감지를 안 한다"고 착각해 ④를 고르기 쉽다. CA가 안 하는 것은 CD(충돌 감지)이지 CS(반송파 감지)가 아니다.

문제 72014 지방직 · 기출문제집 p.363

다양한 장치들이 서로 통신할 수 있게 하는 PAN(Personal Area Network)을 위한 통신 규격으로, IEEE 802.15.1 표준으로 채택된 통신 방법은?

  1. 블루투스(Bluetooth)
  2. Wi-Fi(Wireless-Fidelity)
  3. RFID(Radio Frequency IDentification)
  4. USB(Universal Serial Bus)
해설 보기

정답 ① 블루투스

  1. IEEE 802.15 계열 = PAN(개인 영역 네트워크) 표준군
  2. 802.15.1 = 블루투스 (10m 내외, 약 3Mbps, 간편한 페어링)
  3. 802.15.4 = ZigBee (저속·저전력 센서망) — 끝자리로 구분

오답 정리: ② Wi-Fi는 802.11(WLAN이지 PAN이 아님), ③ RFID는 태그를 읽는 인식 기술, ④ USB는 유선 인터페이스다.

문제 82018 국가직 · 기출문제집 p.365

IEEE 802.11 무선 랜에 대한 설명으로 옳은 것은?

  1. IEEE 802.11a는 5GHz 대역에서 5.5Mbps의 전송률을 제공한다.
  2. IEEE 802.11b는 OFDM 방식을 사용하여 최대 22Mbps의 전송률을 제공한다.
  3. IEEE 802.11g는 5GHz 대역에서 DSSS 방식을 사용한다.
  4. IEEE 802.11n은 다중입력 다중출력(MIMO) 안테나 기술을 사용한다.
해설 보기

정답 ④ 802.11n은 MIMO 안테나 기술 사용

표준별 3요소(대역·속도·기술)를 하나씩 바꿔 끼운 전형적인 문제다.

  1. ④(정답): 802.11n은 안테나 여러 개를 쓰는 MIMO를 도입해 속도를 크게 올렸다. 2.4GHz와 5GHz를 모두 쓴다 ✅
  2. ①: 802.11a는 5GHz·OFDM은 맞지만 속도는 54Mbps다 (5.5Mbps 아님) ❌
  3. ②: 802.11b는 11Mbps이고 OFDM이 아니다 (22Mbps 아님) ❌
  4. ③: 802.11g는 2.4GHz에서 54Mbps·OFDM이다 (5GHz·DSSS 아님) ❌

정리 표: a(5GHz·54M·OFDM) / b(2.4GHz·11M) / g(2.4GHz·54M·OFDM) / n(MIMO·양쪽 대역) — 이 네 줄만 외우면 이 유형은 전부 잡힌다.
