OSI 7계층

계층별 PDU·기능·프로토콜, 데이터링크 계층의 오류제어(ARQ) · PART 03. 데이터통신론

핵심 요약

OSI 7계층은 통신을 7단계로 쪼개서 각자 자기 일만 하게 만든 표준 설계도다. 아래(물리)로 갈수록 "선으로 실제 신호를 어떻게 보낼까"에 가깝고, 위(응용)로 갈수록 "사람이 쓰는 서비스"에 가깝다.

계층마다 부르는 데이터 단위(PDU)가 다르다: 비트→프레임→패킷→세그먼트→데이터 (물리→데이터링크→네트워크→전송→그 위).

💡주요 개념

왜 계층을 나눴을까?

비유: 택배를 보낼 때 "포장(응용이 만든 내용물) → 상자에 넣기(표현) → 운송장 붙이기(세션·전송) → 트럭에 싣기(네트워크) → 도로 위를 달리기(데이터링크) → 실제 도로와 바퀴(물리)"처럼, 각 단계가 자기 역할만 알고 아래 단계에 넘기면 되므로 한 계층만 바꿔도 나머지는 그대로 재사용할 수 있다. 이게 계층화(layering)의 목적이다.

데이터링크 계층의 오류제어 — 정지대기(Stop-and-Wait) ARQ 📖 기출문제집 p.299

데이터링크 계층은 한 프레임을 보내고 응답(ACK/NAK)이 올 때까지 기다렸다가 다음 프레임을 보낸다. 에러가 있으면 NAK를 받고 같은 프레임을 재전송한다.

프로토콜의 일반적 기능

  • 단편화·재합성: 큰 데이터를 작게 쪼개고, 받은 뒤 다시 합침
  • 캡슐화: 데이터에 제어정보(헤더)를 덧붙임
  • 연결제어: 연결형(TCP)/비연결형(UDP) 방식 선택
  • 흐름제어: 받는 쪽이 감당 못할 속도로 보내지 않게 조절
  • 오류제어: 에러 검출·재전송
  • 순서제어: 프레임 번호를 매겨 순서 보장
  • 동기화, 주소지정

📌시험 빈출 포인트

  • 계층별 PDU 암기: 물리=비트, 데이터링크=프레임, 네트워크=패킷, 전송=세그먼트 (그 위는 그냥 "데이터")
  • 표현 계층 = 변환·암호화·압축 (네트워크/전송 계층으로 바꿔치기하는 오답 주의)
  • 전송 계층 = 종단간(end-to-end) 신뢰성, 프로토콜은 TCP/UDP
  • 네트워크 계층 = 라우팅(경로선택), 장비는 라우터
  • 데이터링크 계층 = 인접 노드 간 프레임 전송, 오류·흐름제어, 장비는 브리지/스위치
  • 수신측 처리 순서는 하위→상위 (송신측은 상위→하위) — 반대로 서술하면 오답
  • 계층-프로토콜 매칭: RS-232C(물리) / HDLC·Ethernet(데이터링크) / IP·ICMP(네트워크) / TCP·UDP(전송) / HTTP·SMTP·Telnet(응용) / SSL·MPEG(표현)
