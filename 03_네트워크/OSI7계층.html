OSI 7계층

계층별 PDU·기능·프로토콜, 캡슐화, 데이터링크 계층의 오류제어(ARQ) · PART 03. 데이터통신론

핵심 요약

OSI 7계층은 통신을 7단계로 쪼개서 각자 자기 일만 하게 만든 표준 설계도다. 아래(물리)로 갈수록 "선으로 실제 신호를 어떻게 보낼까"에 가깝고, 위(응용)로 갈수록 "사람이 쓰는 서비스"에 가깝다.

계층마다 부르는 데이터 단위(PDU)가 다르다: 비트→프레임→패킷→세그먼트→데이터 (물리→데이터링크→네트워크→전송→그 위).

🎯이 단원을 왜 배우나

"통신"이라는 거대한 일을 7조각으로 쪼갠 이유

인터넷으로 메일 한 통을 보내려면 실제로는 수십 가지 일이 동시에 벌어져야 한다. 글자를 컴퓨터가 알아먹는 코드로 바꾸고, 너무 크면 조각내고, 상대방 주소를 찾고, 어느 길로 갈지 정하고, 전기 신호로 바꿔 선에 태우고, 중간에 깨진 조각이 있으면 다시 보내고… 이걸 하나의 거대한 프로그램으로 만들면 어떤 일이 벌어질까? 랜선을 와이파이로 바꾸는 순간 프로그램 전체를 다시 짜야 한다.

그래서 ISO는 이 일을 7개 계층으로 잘라서, 각 계층이 바로 위·아래 계층하고만 약속(인터페이스)을 지키게 만들었다. 그러면 물리 계층을 랜선에서 와이파이로 바꿔도 위쪽 6개 계층은 손댈 필요가 없다. 이게 계층화(layering)의 전부이고, 시험에서 "OSI 모델의 목적"을 물으면 답은 항상 이것이다.

공부 전략: 이 단원은 암기 과목이다. 단, 무작정 외우면 안 되고 "이 계층이 없으면 무슨 일이 안 되는가"를 기준으로 외우면 헷갈리지 않는다. 예: 네트워크 계층이 없으면 → 다른 동네로 못 간다(경로를 모름). 전송 계층이 없으면 → 도착했는지 확인할 수 없고, 같은 컴퓨터 안의 여러 프로그램 중 누구에게 줄지 모른다.

💡주요 개념

왜 계층을 나눴을까?

비유: 택배를 보낼 때 "포장(응용이 만든 내용물) → 상자에 넣기(표현) → 운송장 붙이기(세션·전송) → 트럭에 싣기(네트워크) → 도로 위를 달리기(데이터링크) → 실제 도로와 바퀴(물리)"처럼, 각 단계가 자기 역할만 알고 아래 단계에 넘기면 되므로 한 계층만 바꿔도 나머지는 그대로 재사용할 수 있다. 이게 계층화(layering)의 목적이다.

7계층 구조 한눈에 보기 📖 기출문제집 p.297~304

7계층 암기법: 아래(1)부터 "물·데·네·전·세·표·응" (물리-데이터링크-네트워크-전송-세션-표현-응용). 영어로는 "Please Do Not Throw Sausage Pizza Away" (Physical-Data link-Network-Transport-Session-Presentation-Application).

캡슐화(Encapsulation) — 데이터가 내려가면서 옷을 껴입는다

계층 구조에서 가장 중요한 동작이 캡슐화다. 송신측에서 데이터가 위에서 아래로 내려갈 때 각 계층이 자기 일에 필요한 정보(헤더)를 앞에 덧붙인다. 그래서 같은 데이터인데도 계층마다 이름(PDU)이 달라지는 것이다 — 붙은 헤더가 다르니까 다른 물건이다.

시험 포인트: 송신측은 상위→하위, 수신측은 하위→상위 순으로 처리한다. "수신측에서 패킷을 받으면 상위 계층에서 하위 계층 순으로 처리된다"는 서술은 매년 나오는 오답이다 (아래 연습문제 7번).

함정 주의: "네트워크 계층이 압축·암호화를 담당한다" → ❌ 그건 표현 계층의 일이다. 네트워크 계층은 경로선택(라우팅)만 한다. 시험에서 표현 계층 설명을 네트워크/전송 계층에 슬쩍 바꿔치기하는 문제가 매우 잦다.

가장 많이 틀리는 두 쌍: 데이터링크 vs 전송, 네트워크 vs 표현

① 데이터링크(2계층) vs 전송(4계층) — 둘 다 "오류제어·흐름제어"를 한다

기출 선지를 보면 두 계층 모두 "오류 제어와 흐름 제어를 수행한다"고 적혀 있어서 헷갈린다. 구분 기준은 딱 하나, "어디서 어디까지를 책임지는가"다.

  • 데이터링크 = 점대점(point-to-point), 인접 노드 간 — 내 PC에서 바로 옆 스위치까지, 그 스위치에서 다음 라우터까지처럼 한 구간씩 책임진다.
  • 전송 = 종단 간(end-to-end) — 중간에 라우터가 10개를 거치든 말든 출발 호스트에서 최종 도착 호스트까지 전체를 책임진다.

그래서 문제에 "인접한 노드", "점대점", "프레임"이 보이면 데이터링크, "종단 간", "종점 호스트 사이", "end-to-end"가 보이면 전송 계층이다. 이 키워드만 잡으면 이 유형은 전부 맞는다.

추가로 "종단 간 경로설정"은 데이터링크 기능이 아니다 — 경로설정 자체는 네트워크 계층 일이다(연습문제 4번).

② 네트워크(3계층) vs 표현(6계층) — 출제자가 가장 좋아하는 바꿔치기

"송수신 컴퓨터의 응용프로그램 간 송수신되는 데이터의 구문(syntax)과 의미(semantics)에 관련된 기능으로 변환·암호화·압축을 수행한다" — 이 문장은 100% 표현 계층의 정의다. 출제자는 이 문장 앞의 주어만 "네트워크 계층"으로 바꿔서 오답 선지를 만든다(연습문제 8번이 정확히 그것).

기억법: 압축·암호화에 들어가는 "축·호" → 표현. 경로·라우팅은 네트워크.

데이터링크 계층의 오류제어 — 정지대기(Stop-and-Wait) ARQ 📖 기출문제집 p.299

데이터링크 계층은 한 프레임을 보내고 응답(ACK/NAK)이 올 때까지 기다렸다가 다음 프레임을 보낸다. 에러가 있으면 NAK를 받고 같은 프레임을 재전송한다. 이때 오가는 프레임은 정보 프레임 / 긍정응답 프레임(ACK) / 부정응답 프레임(NAK) 세 종류다 ("비트 프레임"이라는 것은 없다 — 연습문제 5번의 함정).

📌시험 빈출 포인트

  • 계층별 PDU 암기: 물리=비트, 데이터링크=프레임, 네트워크=패킷, 전송=세그먼트 (그 위는 그냥 "데이터")
  • 표현 계층 = 변환·암호화·압축 (네트워크/전송 계층으로 바꿔치기하는 오답 주의)
  • 전송 계층 = 종단간(end-to-end) 신뢰성, 프로토콜은 TCP/UDP, "종점 호스트 사이" 키워드
  • 네트워크 계층 = 라우팅(경로선택)·트래픽 제어, 장비는 라우터
  • 데이터링크 계층 = 인접 노드 간(점대점) 프레임 전송, 오류·흐름·순서제어, 장비는 브리지/스위치
  • 데이터링크 기능이 아닌 것: 연결 제어, 종단 간 경로설정 (둘 다 상위 계층 일)
  • 수신측 처리 순서는 하위→상위 (송신측은 상위→하위) — 반대로 서술하면 오답
  • 계층-프로토콜 매칭: RS-232C(물리) / HDLC·Ethernet·SLIP·FDDI(데이터링크) / IP·ICMP·IGMP·X.25(네트워크) / TCP·UDP(전송) / HTTP·SMTP·Telnet(응용) / SSL·MPEG(표현)
  • 오류제어 프레임 3종: 정보 프레임 / ACK(긍정응답) / NAK(부정응답) — "비트 프레임"은 없는 용어
  • 프로토콜의 일반 기능에 "비동기화"는 없다 (동기화가 맞음)

문제 12016 국회 · 기출문제집 p.296

프로토콜은 컴퓨터 간 데이터 전송의 효율성과 신뢰성을 보장하기 위해 여러 가지 기능을 수행한다. 다음 중 프로토콜의 일반적인 기능에 해당하지 않는 것은?

  1. 주소 지정
  2. 오류 제어
  3. 데이터 분할 및 조합
  4. 비동기화
  5. 흐름 제어 및 캡슐화
해설 보기

정답 ④ 비동기화

프로토콜의 일반적 기능은 단편화와 재합성, 캡슐화, 연결 제어, 흐름 제어, 오류 제어, 순서 제어, 동기화, 주소 설정이다.

함정: "동기화"는 있지만 "비동기화"는 없다. 송수신측의 상태를 맞추는 것이 프로토콜의 일이지, 일부러 어긋나게 만드는 기능은 존재할 이유가 없다. 한 글자 붙여서 만든 전형적인 오답이니 선지를 끝까지 읽어야 한다.

정답 ② 데이터링크 계층

설명에 "프레임"이 세 번 나온다. PDU가 프레임인 계층은 데이터링크 계층 하나뿐이므로 다른 선지를 볼 것도 없다.

데이터링크 계층의 5대 기능(통째로 외우면 유리):

  3. 둘 다 데이터링크(2계층)와는 거리가 멀다 → ③이 정답

같은 유형: "데이터링크 계층 기능이 아닌 것" 문제에서 연결 제어(Connection control)가 정답으로 나온 적도 있다(2008 국가직). 데이터링크는 프레임·오류·흐름·순서·주소지정만 한다고 못 박아두자.

오류제어(정지대기 ARQ)에서 오가는 프레임은 딱 3종류다.

  2. 긍정 응답 프레임(ACK): 오류 없이 잘 받았다는 응답
  3. 부정 응답 프레임(NAK): 오류가 발생했으니 다시 보내라는 응답

함정: "비트"는 물리 계층의 PDU 이름이지 프레임의 한 종류가 아니다. 그럴듯한 단어를 조합해 만든 가짜 용어를 끼워넣는 전형적인 출제 방식이다.

정답 ① 전송 계층(transport layer)

결정적 키워드는 "종점 호스트 사이(종단 간)"다. 오류 제어·흐름 제어는 데이터링크도 하지만, 그건 인접 노드 간이다.

전송 계층의 추가 특징도 함께 정리해두자:

  • 네트워크 계층에서 올라온 데이터를 실제 운영체제의 프로그램(프로세스)과 연결한다 → 그래서 헤더에 포트 주소가 들어간다
  • 수신한 데이터의 순서를 재조립하고, 오류 패킷은 재전송시킨다
  • 연결형(TCP)과 비연결형(UDP) 두 가지 운용 모드를 모두 제공한다 (2020 지방직 기출의 정답 근거)

OSI(Open System Interconnection) 7계층에 대한 설명으로 옳지 않은 것은?

  2. 수신측에서 패킷을 수신하게 되면 상위 계층에서 하위 계층 순으로 처리된다.
  3. 전송 계층의 대표적인 프로토콜은 TCP, UDP 등이 있다.
  4. 네트워크 계층에서는 라우팅 및 패킷 전송의 기능을 수행한다.
  5. 응용 계층에서는 전자 사서함, 파일 전송 등의 서비스를 제공한다.
해설 보기

정답 ② (수신측은 하위 계층 → 상위 계층 순으로 처리된다)

캡슐화 그림을 떠올리면 바로 보인다.

  1. 송신측: 응용(7) → 물리(1). 내려가면서 헤더를 덧붙인다(캡슐화)
  2. 수신측: 물리(1) → 응용(7). 올라가면서 헤더를 벗긴다(역캡슐화)
  3. 수신측은 선에서 들어온 비트부터 받으므로, 당연히 가장 아래 물리 계층이 먼저 처리한다

함정: "수신측 = 상위→하위"는 매년 반복되는 오답이다. "받는 쪽은 밑에서부터"라고 한 문장으로 외워두자.

문제 82015 지방직 · 기출문제집 p.303

데이터 통신의 표준참조모델인 OSI 모델의 각 계층에 대한 설명으로 옳지 않은 것은?

  1. 물리 계층은 송수신 시스템의 연결에서 전송 매체의 종류, 송수신되는 신호의 전압 레벨 등을 정의한다.
  2. 네트워크 계층은 송수신 컴퓨터의 응용프로그램 간 송수신되는 데이터의 구문과 의미에 관련된 기능으로 변환, 암호화, 압축을 수행한다.
  3. 전송 계층은 연결된 네트워크의 기능이나 특성에 영향을 받지 않고 오류제어와 흐름제어 기능을 수행하여 신뢰성 있는 데이터 전송을 보장하며, 프로토콜은 TCP, UDP 등이 있다.
  4. 응용 계층은 최상위 계층으로 프로토콜은 FTP, HTTP 등이 있다.
해설 보기

정답 ② (변환·암호화·압축은 표현 계층의 기능)

②번 문장은 토씨 하나 안 틀린 표현(Presentation) 계층의 정의인데, 주어만 "네트워크 계층"으로 바꿔놓았다.

표현 계층의 3대 기능:

  1. 변환: 송신자 형식 → 표준 형식 → 수신자가 이해할 형식으로 번역 (이미지가 bmp인지 jpg인지 같은 "표현 방식")
  2. 암호화: 송신측 암호화 / 수신측 복호화로 보안 제공
  3. 압축: 전송률을 높이기 위해 압축, 수신측에서 압축 해제

비슷한 기출: 2019 국회·2023 소방경채에서도 "압축 및 암호화 담당 계층"을 묻고 답은 모두 표현 계층이었다. 반대로 네트워크 계층이 담당하는 건 경로 선택·트래픽 제어·패킷 전송·중계다.

문제 92022 국회 · 기출문제집 p.305

OSI 7계층과 해당 프로토콜을 연결한 것으로 옳지 않은 것은?

  1. 응용 계층 — HTTP, SMTP
  2. 표현 계층 — MPEG, SSL
  3. 전송 계층 — TCP, TELNET
  4. 네트워크 계층 — IP, ICMP
  5. 데이터링크 계층 — Ethernet, FDDI
해설 보기

정답 ③ 전송 계층 — TCP, TELNET

  1. 전송 계층 프로토콜은 TCP와 UDP 딱 두 개다
  2. TELNET은 원격접속 서비스로 응용 계층 프로토콜이다
  3. 따라서 ③이 잘못된 연결

같은 유형의 다른 답: 2008 국가직에서는 "전송 계층 — ISDN"이 오답이었다. 전송 계층 자리에 TCP·UDP가 아닌 뭔가가 끼어 있으면 그게 답이라고 생각해도 거의 맞는다.

참고로 ⑤의 FDDI(광섬유 토큰패싱 100Mbps LAN 기술)는 데이터링크 계층이 맞다. 이걸 네트워크/인터넷 계층에 넣은 오답도 자주 나온다(2025 법원직).

OSI 모형의 네트워크 계층 프로토콜에 속하지 않는 것은?

  1. ICMP
  2. IGMP
  3. IP
  4. SLIP
해설 보기

정답 ④ SLIP

SLIP(Serial Line Internet Protocol)은 전화선·RS-232 같은 직렬 회선으로 인터넷에 접속하기 위한 데이터링크 계층 프로토콜이다.

  • 오류 검출 기능, 링크 설정·절단 기능이 없고 IP 외의 프로토콜을 지원하지 않는 단점 때문에 현재는 PPP가 주류다
  • 나머지 ICMP(오류·상황 보고), IGMP(멀티캐스트 그룹 관리), IP는 모두 네트워크(인터넷) 계층이 맞다

구분법: 이름에 "Line/Link"(SLIP, PPP, HDLC)가 들어가면 데이터링크, "Internet"(IP, ICMP, IGMP)이 들어가면 네트워크 계층이라고 외우면 대부분 맞는다.

문제 112025 법원직 · 기출문제집 p.304

다음 설명 중 가장 옳지 않은 것은?

  1. OSI 7의 5계층은 세션 계층으로 응용 사이의 연결을 설정·관리·해제하는 통신제어 구조를 제공한다.
  2. OSI 7의 1계층은 데이터가 전송되는 동안 연결을 유지하거나 해제하는 기계적, 전기적, 기능적, 절차적 특성을 정의한다.
  3. OSI 7의 3계층은 단말기 사이에 오류수정과 흐름제어를 수행하여 신뢰성 있고 명확한 데이터를 전송하는 계층이다.
  4. OSI 7 계층은 상위계층과 하위계층으로 구분할 수 있다.
해설 보기

정답 ③ (오류수정·흐름제어로 신뢰성 있는 전송을 하는 것은 4계층=전송 계층)

  1. 3계층(네트워크)의 일은 경로 선택(라우팅)과 패킷 전달이다
  2. "단말기 사이(종단 간)에 오류수정·흐름제어로 신뢰성 보장" = 4계층(전송)의 정의
  3. 따라서 ③의 계층 번호가 틀렸다

이 유형의 공략법: 계층 번호가 함께 나오면 번호부터 확인한다. 설명 자체는 교과서 그대로 가져다 쓰고 번호만 한 칸 옮기는 방식이 가장 흔한 오답 제조법이다.

문제 12개념 확인 · 응용

송신 호스트에서 데이터가 캡슐화되는 과정에서, IP 헤더가 붙은 직후의 PDU 이름은 무엇이며, 그 다음 계층에서 추가로 붙는 것은 무엇인가?

해설 보기

정답: IP 헤더가 붙으면 패킷, 다음(데이터링크) 계층에서 프레임 헤더 + 트레일러가 붙어 프레임이 된다

  1. 응용~세션에서 내려온 데이터에 전송 계층이 TCP 헤더를 붙임 → 세그먼트
  2. 네트워크 계층이 IP 헤더를 붙임 → 패킷 (IP 헤더에 출발지·목적지 IP가 들어감)
  3. 데이터링크 계층이 앞에 프레임 헤더(MAC 주소), 뒤에 트레일러(오류검출용 FCS)를 붙임 → 프레임
  4. 물리 계층이 이 프레임을 비트(전기 신호)로 바꿔 전송

포인트: 헤더는 모든 계층이 앞에 붙이지만, 트레일러(뒤에 붙는 것)는 데이터링크 계층만 붙인다. 오류 검출을 위한 FCS를 맨 뒤에 둬야 프레임 전체를 다 받은 뒤 검사할 수 있기 때문이다.
