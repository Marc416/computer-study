데이터 전송 방식과 신호해석

통신 방향·동기화 방식, PCM(펄스부호변조), 네트워크 토폴로지 · PART 03. 데이터통신론

핵심 요약

통신은 방향에 따라 단방향·반이중·전이중으로, 아날로그→디지털 변환은 표본화→양자화→부호화(PCM) 순서로 이루어진다.

네트워크 연결 형태(토폴로지)는 성·버스·링·트리·메쉬 5가지로 나뉘고, 각각 고장 시 영향 범위가 다르다.

🎯이 단원을 왜 배우나

"소리를 어떻게 전선에 태워 보낼 것인가"의 문제

통신은 결국 전선(또는 공기) 한 가닥에 정보를 실어 보내는 일이다. 그런데 보내는 쪽과 받는 쪽은 서로 떨어져 있어서 아무것도 약속하지 않으면 아무 말도 통하지 않는다. 그래서 세 가지를 미리 정해야 한다.

  • 누가 언제 말할 것인가 → 통신 방향 (단방향·반이중·전이중)
  • 말의 시작과 끝을 어떻게 알릴 것인가 → 동기화 (비동기식·동기식)
  • 사람 목소리처럼 연속적인 신호를 0과 1로 어떻게 바꿀 것인가 → PCM (표본화·양자화·부호화)

여기에 "여러 대의 컴퓨터를 어떤 모양으로 연결할 것인가"(토폴로지)가 더해지면 데이터 통신의 기초가 완성된다. 이 단원의 모든 문제는 결국 이 네 가지 질문 중 하나다.

공부 순서 팁: 토폴로지는 "이 부분이 고장 나면 전체가 죽는가?"만 정리하면 절반은 맞힌다. PCM은 순서(표→양→부)와 나이퀴스트 ×2만 확실히 하면 된다.

직렬 전송 vs 병렬 전송

같은 8비트를 보내더라도 선 한 가닥으로 한 비트씩 줄 세워 보내느냐(직렬), 선 여덟 가닥으로 한꺼번에 보내느냐(병렬)가 다르다. 직관적으로는 병렬이 8배 빠를 것 같지만, 실제 장거리·고속 통신은 거의 전부 직렬이다.

구분직렬 전송 (Serial)병렬 전송 (Parallel)
전송 방식한 가닥으로 1비트씩 순차 전송여러 가닥으로 여러 비트 동시 전송
회선 비용저렴 (선 1~2가닥)비쌈 (비트 수만큼 선 필요)
장거리 적합성적합 — 원거리 통신의 표준부적합 — 거리 늘면 오차 발생
속도근거리에선 느림근거리에선 빠름
예시USB, 인터넷 회선, RS-232옛 프린터 포트, CPU 내부 버스

왜 장거리는 병렬을 안 쓸까 — 스큐(skew) 문제

선 8가닥으로 동시에 출발시켜도, 각 선의 길이·저항이 미세하게 달라서 도착 시각이 조금씩 어긋난다. 이걸 스큐(skew)라고 한다. 거리가 짧으면 무시할 수준이지만 길어지면 "먼저 도착한 비트"와 "늦게 도착한 비트"가 섞여 데이터가 깨진다.

게다가 선끼리 바짝 붙어 있으면 전자기 간섭(crosstalk)도 심해진다. 그래서 거리가 멀거나 속도가 아주 빠른 구간은 선을 하나로 줄이고 그 대신 한 가닥을 극도로 빠르게 굴리는 직렬이 이긴다. USB·SATA·이더넷이 전부 직렬인 이유다.

비동기식 vs 동기식 전송 📖 기출문제집 p.281~282

구분비동기식 (Asynchronous)동기식 (Synchronous)
전송 단위한 번에 한 문자씩여러 문자를 블록으로 묶어서
동기화 방법문자 앞뒤에 Start bit / Stop bit블록 앞에 동기 문자, 클럭 공유
효율비트 낭비 있음 (start/stop bit)유휴시간 없어 전송효율 높음
블록 사이 유휴시간있음 (문자마다 쉬었다 감)없음
용도저속, 근거리고속(2400bps 이상), 원거리

"효율이 높다"를 숫자로 확인하기

비동기식으로 8비트짜리 문자 하나를 보낸다고 하자. 앞에 start bit 1개, 뒤에 stop bit 1개가 붙으므로 실제로는 10비트를 전송한다. 즉 2/10 = 20%가 순수 오버헤드다. 1000자를 보내면 2000비트를 낭비한다.

동기식은 블록 앞에 동기문자 몇 개만 붙이고 나머지는 전부 데이터다. 블록이 1000자(8000비트)라면 동기문자 16비트를 쓴다 해도 오버헤드는 0.2%에 불과하다. 이것이 "동기식이 고속·원거리에 쓰인다"는 말의 실체다.

그럼 비동기식은 왜 쓰나? 키보드 입력처럼 데이터가 언제 올지 모르고 띄엄띄엄 오는 경우에는 블록이 찰 때까지 기다릴 수 없다. 이럴 땐 문자 하나씩 바로 보내는 비동기식이 맞다.

함정 주의: "start bit·stop bit를 사용하는 방식"이 아니라 "동기 문자로 블록 단위 동기화하는 방식"이 동기식이다 — start/stop bit는 비동기식 전용. 선택지에 "동기식은 Start Bit와 Stop Bit를 삽입한다"가 나오면 무조건 오답이다.

탄력적 트래픽 vs 비탄력적 트래픽 📖 기출문제집 p.282

네트워크에 흐르는 데이터는 "좀 늦게 도착해도 괜찮은가"를 기준으로 두 종류로 나뉜다. 이 구분이 QoS(서비스 품질) 설계의 출발점이다.

구분탄력적 트래픽 (Elastic)비탄력적 트래픽 (Inelastic)
지연 민감도둔감 — 조금 늦어도 무방민감 — 실시간성이 생명
재전송가능 (느려도 다시 받으면 됨)의미 없음 (이미 늦은 데이터는 버림)
예시전자우편, 파일 전송, 웹 문서 다운로드화상회의, 인터넷 전화(VoIP), 실시간 스트리밍
판단법: "1초 늦게 도착하면 서비스가 망가지는가?"를 물어보면 된다. 메일이 1초 늦게 오는 건 아무 문제 없지만(탄력적), 통화 음성이 1초 늦으면 대화가 불가능하다(비탄력적).

PCM(펄스부호변조) 과정 — 아날로그를 디지털로 📖 기출문제집 p.283~284

마이크로 들어온 아날로그 음성을 컴퓨터가 처리하려면 디지털(0과 1)로 바꿔야 한다. 그 변환 과정이 표본화 → 양자화 → 부호화 3단계다.

나이퀴스트(Nyquist) 표본화 정리 계산 예제 📖 기출문제집 p.284 — 원신호를 왜곡 없이 복원하려면 표본화 주파수가 최고 주파수의 2배 이상이어야 한다.
  1. 주어진 조건: 음성 신호의 최대 주파수 fm = 4KHz
  2. 나이퀴스트 표본화 주파수 공식: fs ≥ 2 × fm
  3. 계산: fs = 2 × 4,000Hz = 8,000회/초 (8000)

네트워크 토폴로지(연결 형태) 5종 📖 기출문제집 p.284~288

토폴로지구조장점치명적 약점
성(Star)중앙 허브에 모든 노드 연결관리·고장발견 쉬움중앙 노드 고장 → 전체 마비
버스(Bus)하나의 선형 케이블에 연결, 양끝 터미네이터설치 간단, 저렴, 노드 추가/삭제 쉬움케이블(회선) 절단 → 전체 마비
링(Ring)양 옆 노드와 고리 모양 연결충돌(collision) 없음회선 하나만 끊겨도 전체 마비 (이중화로 보완)
트리(Tree)성형의 변형, 허브를 계층적으로 연결확장 용이, 계층적 제어 적합중앙(상위 허브) 고장 시 하위 전체 영향, 병목 발생 가능
메쉬(Mesh)모든 노드가 서로 점대점 연결신뢰성 최고, 특정 회선 고장에 강함회선 수·비용이 노드 수 제곱으로 급증
함정 주의: "버스형은 각 노드의 고장이 전체에 영향을 주지 않는다"는 맞는 말이지만, "회선(케이블) 자체의 절단"은 전체를 마비시킨다 — "노드 고장"과 "회선 고장"을 구분해서 읽어야 하는 문제가 자주 나온다.

📌시험 빈출 포인트

  • 반이중(양방향 가능, 동시 불가) vs 전이중(양방향 동시 가능) 구분 — 무전기 vs 전화
  • 동기식 전송은 블록 단위 + 동기문자, 비동기식은 문자 단위 + start/stop bit
  • PCM 순서 암기: 표본화 → 양자화 → 부호화 (송신측), 복호화 → 역양자화 (수신측)
  • 나이퀴스트 표본화 주파수 = 최고주파수 × 2 계산 문제
  • 토폴로지별 "고장나면 전체가 마비되는 지점" 암기 (성=중앙노드, 버스=회선, 링=회선)
  • 트리형은 성형의 변형, 계층적 구조 — "순환형"이라는 설명이 나오면 오답(그건 링형)
  • 트리형은 중앙에 트래픽이 몰려 병목현상이 발생한다 — "병목이 없다"는 설명은 오답
  • 버스형은 노드 추가·삭제가 쉽다 — "어렵다"는 설명은 오답
  • FDDI = 광케이블 + 이중 링형 구조, 터미네이터 = 버스형, 허브 필요 = 성형·트리형
  • 탄력적(전자우편·파일전송) vs 비탄력적(화상회의·인터넷전화) 트래픽 구분

문제 12022 국가직 · 기출문제집 p.281

자료 흐름의 방향과 동시성 여부에 따라 분류한 통신 방식 중 다음에서 설명하는 통신 방식은?
통신하는 두 DTE가 시간적으로 교대로 데이터를 교환하는 방식의 통신으로, 한 DTE가 명령을 전송하면 다른 DTE가 이를 처리하여 그에 대한 응답을 전송하는 트랜잭션 처리 시스템에서 볼 수 있다.

  1. 단방향 통신
  2. 반이중 통신
  3. 전이중 통신
  4. 원거리 통신
해설 보기

정답 ② 반이중 통신

  1. "양방향으로 데이터가 오간다" → 단방향(①)은 제외
  2. "시간적으로 교대로" = 동시에는 못 보낸다 → 반이중
  3. 전이중(③)이었다면 명령과 응답이 동시에 오갈 수 있으므로 "교대로"라는 표현이 나올 수 없다

키워드 정리: 문제에 "교대로", "번갈아", "한쪽이 끝나야 다른 쪽이" 같은 말이 보이면 반이중이다. ④ 원거리 통신은 방향 분류가 아니라 거리 분류라 애초에 범주가 다르다.

문제 22019 계리직 · 기출문제집 p.282

동기식 전송(Synchronous Transmission)에 대한 설명으로 옳지 않은 것은?

  1. 정해진 숫자만큼의 문자열을 묶어 일시에 전송한다.
  2. 작은 비트블록 앞뒤에 Start Bit와 Stop Bit를 삽입하여 비트블록을 동기화한다.
  3. 2,400bps 이상 속도의 전송과 원거리 전송에 이용된다.
  4. 블록과 블록 사이에 유휴시간(Idle Time)이 없어 전송효율이 높다.
해설 보기

정답 ② (이것은 비동기식 전송의 설명이다)

  1. Start Bit / Stop Bit는 비동기식 전송이 문자 하나마다 붙이는 표시다
  2. 동기식은 블록 앞에 동기문자(SYN)를 붙여 한 번만 박자를 맞추고, 그 뒤로는 데이터를 통째로 흘려보낸다
  3. 나머지 ①③④는 모두 동기식의 올바른 특징 — 블록 단위 전송, 고속·원거리, 유휴시간 없음

이 유형의 공식: "start/stop bit" 다섯 글자가 보이면 무조건 비동기식. 동기식 문제에 이 단어가 섞여 있으면 그게 정답(틀린 선지)이다.

문제 32020 국가직 · 기출문제집 p.283

아날로그 신호를 디지털 신호로 변조하기 위한 펄스부호변조(PCM) 과정으로 옳지 않은 것은?

  1. 분절화(Segmentation)
  2. 표본화(Sampling)
  3. 부호화(Encoding)
  4. 양자화(Quantization)
해설 보기

정답 ① 분절화(Segmentation)

  1. PCM 송신측 3단계는 표본화 → 양자화 → 부호화 뿐이다
  2. ②③④가 모두 그 3단계에 해당하므로, 남은 ① 분절화가 정답
  3. 분절화(세그먼테이션)는 전송계층에서 데이터를 조각내는 작업으로, 신호 변환과는 무관한 개념이다

암기법: "표·양·부" 세 글자만 외우면 이 유형은 끝난다. 순서를 묻는 문제(2024 소방경채)도 같은 답이다.

문제 42018 교육청 · 기출문제집 p.284

다음 조건을 가장 만족하는 초당 표본추출(sampling) 횟수는?
• 디지털 신호로 변환하기 위한 아날로그 음성 신호의 최대 주파수는 4KHz이다.
• 표본추출된 디지털 신호를 아날로그 신호로 다시 변환할 경우 원래의 음성 신호로 복원되어야 한다.

  1. 1000
  2. 2000
  3. 4000
  4. 8000
해설 보기

정답 ④ 8000

  1. "원래 신호로 복원되어야 한다"는 조건 → 나이퀴스트 표본화 정리를 쓰라는 신호다
  2. 공식: 표본화 주파수 fs ≥ 2 × 최고 주파수(fm)
  3. fm = 4KHz = 4,000Hz 이므로 fs = 2 × 4,000 = 8,000회/초

함정: ③번 4000은 2배를 곱하지 않고 주파수를 그대로 쓴 오답이다. 실제로 전화망이 8KHz로 표본화하는 이유도 사람 음성의 최고 주파수를 약 4KHz로 보기 때문이다.

왜 하필 2배인가

파도 하나(1주기)를 표현하려면 최소한 산 하나와 골 하나, 즉 점 두 개는 찍어야 한다. 점을 하나만 찍으면 그 파동이 올라가는 중인지 내려가는 중인지 알 수 없어서 복원할 때 엉뚱한 파형이 나온다(이 현상을 에일리어싱이라 한다). 그래서 "1초에 4,000번 진동하는 신호 → 1초에 8,000번 찍기"가 최소 조건이 된다.

문제 52012 국가직 · 기출문제집 p.285~286

네트워크 토폴로지(topology)의 연결 형태에 대한 설명으로 옳지 않은 것은?

  1. 버스(bus) 토폴로지는 각 노드의 고장이 전체 네트워크에 영향을 주지 않는다.
  2. 스타(star) 토폴로지는 중앙 노드에서 문제가 발생하면 전체 네트워크의 통신이 곤란해진다.
  3. 링(ring) 토폴로지는 데이터가 한 방향으로 전송되기 때문에 충돌(collision) 위험이 없다.
  4. 메쉬(mesh) 토폴로지는 다른 토폴로지에 비해 많은 통신 회선이 필요하지만, 메시지 전송의 신뢰성은 높지 않다.
해설 보기

정답 ④ (메쉬형은 신뢰성이 매우 높다)

  1. 메쉬형은 모든 노드가 서로 직접 연결되어 있어, 회선 하나가 끊겨도 우회 경로가 여러 개 있다
  2. 따라서 회선 비용이 비싼 대신 신뢰성과 속도는 최고다 — "신뢰성이 높지 않다"는 완전히 반대 설명
  3. ①②③은 모두 맞는 설명: 버스형은 노드 고장엔 강하고, 성형은 중앙이 약점이며, 링형은 한 방향 전송이라 충돌이 없다

주의할 점: ①번은 "노드의 고장"이라 맞는 말이다. 만약 "회선(케이블)의 절단"이었다면 버스형도 전체가 마비되므로 틀린 말이 된다. 이 둘을 바꿔치기하는 함정이 자주 나온다.

문제 62014 계리직 · 기출문제집 p.286

네트워크 토폴로지에 대한 설명이다. ㉠~㉢에 들어갈 내용을 옳게 나열한 것은?
• FDDI는 광케이블로 구성되며 ( ㉠ ) 토폴로지를 사용한다.
• 허브 장비가 필요한 ( ㉡ ) 토폴로지는 네트워크 관리가 용이하다.
• 터미네이터가 필요한 ( ㉢ ) 토폴로지는 전송회선이 단절되면 전체 네트워크가 중단된다.

  1. 링형 / 버스형 / 트리형
  2. 링형 / 트리형 / 버스형
  3. 버스형 / 링형 / 트리형
  4. 버스형 / 트리형 / 링형
해설 보기

정답 ② 링형 / 트리형 / 버스형

  1. ㉠ FDDI는 광케이블 기반 100Mbps 전송 규격으로 이중 링(ring)형 구조를 쓴다 → 링형
  2. ㉢ 터미네이터(종단기)는 신호가 케이블 끝에서 되돌아오는 것을 막는 장치로, 케이블에 양 끝이 있는 버스형에만 필요하다 → 버스형
  3. ㉡ 남은 것은 트리형. 트리형은 중앙 허브에 2차 허브들이 붙는 구조라 허브 장비가 필수다 → 트리형

단서 암기: FDDI = 링형, 터미네이터 = 버스형, 허브 = 성형/트리형. 이 세 단어만 보고도 답을 고를 수 있다. 특히 ㉢은 "회선 단절 시 전체 중단"이라는 설명도 버스형의 특징과 일치한다.

문제 72024 국가직 · 기출문제집 p.288

네트워크 접속 형태 중 트리형 토폴로지에 대한 설명으로 옳지 않은 것은?

  1. 네트워크의 확장이 용이하다.
  2. 병목 현상이 나타나지 않는다.
  3. 분산처리 방식을 구현할 수 있다.
  4. 중앙의 서버 컴퓨터에 장애가 발생하면 전체 네트워크에 영향을 준다.
해설 보기

정답 ② (트리형은 병목 현상이 발생한다)

  1. 트리형은 하위 노드끼리 통신하려 해도 반드시 부모(상위) 노드를 거쳐야 한다
  2. 그 결과 상위로 갈수록 트래픽이 누적되어 중앙에 병목(bottleneck)이 생긴다
  3. ①③④는 모두 맞는 설명 — 가지를 붙이듯 확장이 쉽고, 계층적 분산처리에 적합하며, 중앙 장애 시 전체가 영향을 받는다

연결해서 기억하기: 같은 이유로 2011 국가직에서는 "계층 연결 구조에서 인접 형제 노드 간 통신은 부모 노드를 거치지 않고 이루어질 수 있다"가 틀린 선지로 출제됐다. 트리형은 무조건 부모를 경유한다는 점이 핵심이다.

문제 82017 서울시 · 기출문제집 p.288

네트워크 토폴로지 중 버스(Bus) 방식에 대한 설명으로 옳지 않은 것은?

  1. 네트워크 구성이 간단하고 작은 네트워크에 유용하며 사용이 용이하다.
  2. 네트워크 트래픽이 많을 경우 네트워크 효율이 떨어진다.
  3. 통신 채널이 단 한 개이므로 버스 고장이 발생하면 네트워크 전체가 동작하지 않는다.
  4. 노드의 추가·삭제가 어렵다.
해설 보기

정답 ④ (버스형은 노드 추가·삭제가 쉽다)

  1. 버스형은 하나의 공유 케이블에 그냥 갖다 붙이는 구조다 → 노드를 새로 달거나 떼기가 매우 쉽다
  2. ①②③은 모두 맞는 설명 — 구성이 간단하고, 공유 채널이라 트래픽이 몰리면 충돌로 효율이 떨어지며, 케이블 자체가 고장 나면 전체가 멈춘다

정리: 버스형의 약점은 "노드 추가"가 아니라 ①공유 케이블 고장 ②트래픽 증가 시 충돌 두 가지다. 장점(설치 간단·저렴·확장 쉬움)과 단점을 섞어 놓는 것이 이 유형의 전형적 함정이다.
