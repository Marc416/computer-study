인터네트워킹 장비

리피터·허브·브리지·스위치·라우터·게이트웨이 · PART 03. 데이터통신론

핵심 요약

네트워크 장비는 OSI 7계층 중 어느 계층에서 동작하는지로 구분한다 — 이것만 외우면 문제의 80%는 풀린다.

1계층: 리피터·허브 / 2계층: 브리지·스위치 / 3계층: 라우터 / 4계층 이상: 게이트웨이

🎯이 단원을 왜 배우나

"장비가 편지봉투를 어디까지 뜯어볼 수 있는가"

네트워크 데이터는 편지를 봉투에 넣고, 그 봉투를 다시 더 큰 봉투에 넣는 구조로 되어 있다(캡슐화). 맨 바깥 봉투에는 MAC 주소, 그 안쪽 봉투에는 IP 주소, 더 안쪽에는 포트 번호와 실제 내용이 적혀 있다.

네트워크 장비를 구분하는 기준은 딱 하나다 — 이 장비가 봉투를 몇 겹까지 뜯어볼 수 있는가.

  • 리피터·허브: 봉투를 전혀 못 뜯는다. 그냥 전기신호를 크게 만들어 그대로 넘긴다 → 1계층
  • 브리지·스위치: 바깥 봉투의 MAC 주소까지 읽는다 → "이건 저쪽 방 사람 것이네" 하고 골라 보낸다 → 2계층
  • 라우터: 안쪽 봉투의 IP 주소까지 읽는다 → "부산으로 가려면 이 길이 제일 빠르겠군" 하고 경로를 고른다 → 3계층
  • 게이트웨이: 내용물까지 읽고 아예 다른 형식으로 번역한다 → 4계층 이상

그래서 문제에 어떤 장비가 나오든 "이 장비는 무슨 주소를 읽을 수 있나?"만 물어보면 계층이 바로 나오고, 계층이 나오면 그 장비가 할 수 있는 일과 할 수 없는 일이 전부 결정된다. 시험 문제의 대부분은 장비와 계층을 일부러 어긋나게 짝지어 놓은 것을 골라내는 유형이다.

💡주요 개념

OSI 계층별 장비 매핑 📖 기출문제집 p.291~293

왜 계층으로 장비를 구분할까? 장비가 신호의 어떤 부분까지 "이해"하는지가 다르기 때문이다. 리피터는 전기신호만 알고, 브리지는 MAC 주소를 읽을 줄 알고, 라우터는 IP 주소를 이해하고 경로를 계산할 줄 안다 — 계층이 올라갈수록 장비가 "똑똑해진다."

장비OSI 계층하는 일모르는 것
리피터 (Repeater)1계층 (물리)약해진 신호를 증폭·재생해서 전송거리 확장주소 개념 자체가 없음 (그냥 신호 증폭기)
더미허브 (Dummy Hub)1계층 (물리)여러 포트로 신호를 그대로 복사해 전체에 전달목적지 구분 못 함 (전부 다 뿌림)
브리지 (Bridge)2계층 (데이터링크)MAC 주소를 보고 필요한 트래픽만 통과(필터링), LAN 2개를 연결IP 주소, 경로 최적화는 모름
스위치 (Switch)2계층 (데이터링크)브리지의 다중 포트 버전, 포트별로 MAC 주소 학습 후 전달IP 기반 라우팅 못 함
라우터 (Router)3계층 (네트워크)IP 주소를 보고 라우팅 테이블로 최적 경로 계산응용프로그램·프로토콜 종류는 모름

함정 주의 모음
• "리피터가 LAN 두 개를 연결해 하나로 만든다" → ❌ 그건 브리지의 역할. 리피터는 단순 증폭기.
• "리피터는 네트워크 단말기를 연결하는 집선 장치다" → ❌ 그건 허브의 설명.
• "게이트웨이는 데이터링크 계층에서만 동작한다" → ❌ 게이트웨이는 여러 계층(전송~응용)에서 동작하며 프로토콜을 변환한다.
• "게이트웨이는 동일 프로토콜의 네트워크를 연결한다" → ❌ 그건 라우터. 게이트웨이는 서로 다른 프로토콜을 잇는다.
• "모뎀은 신호증폭 장치다 / 모뎀은 게이트웨이의 일종이다" → ❌ 모뎀은 디지털↔아날로그 신호 변환 장치.
• "브리지는 목적지 주소와 무관하게 무조건 전달한다" → ❌ 브리지는 목적지 MAC 주소를 필터링해서 판단 후 전달한다.

허브 vs 스위치 — 왜 요즘은 허브를 안 쓰나 📖 기출문제집 p.294~296

둘 다 "여러 대의 컴퓨터를 한데 묶는 상자"처럼 생겼지만, 안에서 하는 일은 완전히 다르다. 이 차이를 이해하면 "허브는 왜 느린가", "스위치는 왜 보안에 유리한가"가 한 번에 풀린다.

"호스트가 늘어나면 허브는 왜 느려지나" — 대역폭 나눠쓰기

100Mbps 더미허브에 컴퓨터 10대를 물렸다고 하자. 허브는 신호를 모든 포트에 그대로 복사하므로 사실상 10대가 하나의 케이블을 공유하는 것과 같다. 동시에 쓰면 1대당 평균 10Mbps밖에 못 쓰고, 두 대가 동시에 말하면 충돌(collision)이 나서 둘 다 다시 보내야 한다. 그래서 호스트가 늘수록 속도가 급격히 떨어진다.

스위치는 포트마다 별도의 경로를 만들어 주므로 A→C 통신과 B→D 통신이 서로 간섭 없이 동시에 일어난다. 각 포트가 100Mbps를 온전히 쓰고 충돌도 없다. 오늘날 "허브"라고 파는 제품이 사실상 전부 스위칭 허브인 이유다.

보안 관점: 더미허브는 C에게 보낸 데이터가 B·D에게도 도달하므로, 악의적인 B가 패킷 스니핑(도청)을 할 수 있다. 스위치는 목적지에게만 보내므로 이런 도청이 기본적으로 차단된다.

라우터의 핵심 기능 — 라우팅 📖 기출문제집 p.292

라우터가 하는 일을 한 문장으로 하면 "IP 주소를 보고, 라우팅 테이블을 뒤져서, 가장 좋은 다음 경로로 패킷을 던진다"이다. 여기에 부수적으로 오류 패킷 폐기, 혼잡 제어 기능도 붙는다.

기능설명
경로 결정 (Routing)목적지 IP를 보고 라우팅 테이블에서 최적 경로를 선택
패킷 전달 (Forwarding)선택한 경로의 다음 라우터로 패킷을 넘김
오류 패킷 폐기손상되었거나 수명(TTL)이 다한 패킷을 버림
혼잡 제어특정 경로에 트래픽이 몰리면 우회시키거나 속도를 조절
네트워크 분리독립적인 네트워크를 구성해 인터넷에 연결 (브로드캐스트 차단)
브리지 vs 라우터의 결정적 차이: 브리지는 같은 네트워크 안에서 트래픽을 걸러 주는 장비이고, 라우터는 서로 다른 네트워크를 연결하는 장비다. 집의 공유기(라우터)가 "우리 집 네트워크"와 "인터넷"을 나누는 경계에 서 있는 것을 떠올리면 된다.

📌시험 빈출 포인트

  • 1계층=리피터/허브, 2계층=브리지/스위치, 3계층=라우터, 4계층이상=게이트웨이 — 순서로 암기
  • "OSI 계층과 장비를 짝짓는" 문제가 거의 매년 출제됨
  • 브리지·스위치는 MAC(물리) 주소 기준, 라우터는 IP(논리) 주소 기준으로 동작한다는 차이
  • 게이트웨이 = 서로 다른 프로토콜 네트워크를 연결 + 프로토콜 변환 (라우터와 혼동 주의)
  • 더미허브는 물리계층에서 신호를 단순 중계·복사, 스위칭허브는 MAC 학습 기능 있음
  • 물리계층 장치를 고르는 문제 → 리피터 + 더미허브가 정답 조합
  • "집선 장치 / 분배기 역할"이라는 표현이 나오면 허브 (리피터가 아님)
  • 더미허브는 호스트가 늘어날수록 속도가 감소한다 (대역폭 공유·충돌)
  • 브리지는 MAC 주소로 필터링해서 전달 — "무조건 전달"은 오답

문제 12012 계리직 · 기출문제집 p.292

다음 설명에 해당하는 네트워크 장비는?
• OSI 계층 모델의 네트워크 계층에서 동작하는 장비이다.
• 송신측과 수신측 간의 가장 빠르고 신뢰성 있는 경로를 설정·관리하며 데이터를 전달한다.
• 패킷이 지나가야 할 정보를 테이블에 저장하여 지정된 경로를 통해 전송한다.

  1. 게이트웨이 (gateway)
  2. 브리지 (bridge)
  3. 리피터 (repeater)
  4. 라우터 (router)
해설 보기

정답 ④ 라우터

  1. "네트워크 계층(3계층)" → 후보는 라우터뿐 (브리지=2계층, 리피터=1계층, 게이트웨이=4계층 이상)
  2. "경로를 설정·관리" → 라우팅 기능의 정의 그대로
  3. "테이블에 저장" → 라우팅 테이블을 가리킨다

키워드 3종 세트: 네트워크 계층 + 경로 선택 + 라우팅 테이블이 함께 나오면 무조건 라우터다. 반대로 "MAC 주소 + 필터링 + LAN 연결"이면 브리지다.

문제 22016 국가직 · 기출문제집 p.293

통신 연결 장치와 그 장치가 동작하는 OSI 계층이 바르게 짝지어진 것은?
ㄱ. 네트워크 계층  /  ㄴ. 데이터 링크 계층  /  ㄷ. 물리 계층

  1. 라우터 ㄱ  ·  브리지 ㄴ  ·  리피터 ㄷ
  2. 라우터 ㄴ  ·  브리지 ㄱ  ·  리피터 ㄷ
  3. 라우터 ㄴ  ·  브리지 ㄷ  ·  리피터 ㄱ
  4. 라우터 ㄷ  ·  브리지 ㄴ  ·  리피터 ㄱ
해설 보기

정답 ① 라우터=네트워크, 브리지=데이터링크, 리피터=물리

  1. 리피터는 전기신호만 증폭한다 → 주소를 모름 → 물리 계층(1)
  2. 브리지는 MAC 주소를 읽어 필터링한다 → 데이터 링크 계층(2)
  3. 라우터는 IP 주소를 읽고 경로를 고른다 → 네트워크 계층(3)

암기 순서: "리(1)-브(2)-라(3)-게(4↑)" — 리피터·브리지·라우터·게이트웨이가 계층 번호 순서와 그대로 일치한다. 이 한 줄이면 이 유형은 전부 맞힐 수 있다.

문제 32022 지방직 · 기출문제집 p.294

OSI 7계층 중 물리 계층에 해당하는 장치를 모두 고른 것은?
ㄱ. 리피터(Repeater)   ㄴ. 더미허브(Dummy Hub)   ㄷ. 라우터(Router)
ㄹ. 게이트웨이(Gateway)   ㅁ. 브릿지(Bridge)

  1. ㄱ, ㄴ
  2. ㄴ, ㄷ
  3. ㄷ, ㄹ
  4. ㄹ, ㅁ
해설 보기

정답 ① ㄱ(리피터), ㄴ(더미허브)

  1. 리피터: 신호를 변화 없이 단순 재생·증폭해 중계 → 물리 계층 ✓
  2. 더미허브: 들어온 신호를 그대로 재생해 모든 포트로 내보내는 집선 장치 → 물리 계층 ✓
  3. ㄷ 라우터=3계층, ㄹ 게이트웨이=4계층 이상, ㅁ 브릿지=2계층이므로 전부 제외

판단 기준: "주소를 전혀 읽지 않고 신호만 다루는가?"를 물어보면 된다. 리피터와 더미허브는 누구에게 가는 데이터인지 관심이 없다 — 그래서 물리 계층이다.

문제 42010 국가직 · 기출문제집 p.294

네트워크 통신 장치에 대한 설명으로 옳지 않은 것은?

  1. 리피터(Repeater)는 네트워크 각 단말기를 연결시키는 집선 장치로 일종의 분배기 역할을 한다.
  2. 브리지(Bridge)는 데이터링크 계층에서 망을 연결하며 패킷을 적절히 중계하고 필터링하는 장치이다.
  3. 라우터(Router)는 네트워크 계층에서 망을 연결하고 라우팅 알고리즘을 이용하여 최적의 경로를 선택하여 패킷을 전송한다.
  4. 게이트웨이(Gateway)는 두 개의 서로 다른 형태의 네트워크를 상호 연결시켜 주는 관문 역할을 하는 장치이다.
해설 보기

정답 ① (집선 장치·분배기는 허브의 설명이다)

  1. 리피터는 신호 증폭기다 — 거리가 멀어져 약해진 신호를 되살려 더 멀리 보내는 것이 유일한 역할
  2. "여러 단말기를 모아서 연결하는 집선 장치"는 포트가 여러 개인 허브다
  3. ②③④는 모두 올바른 설명 (브리지=2계층 필터링, 라우터=3계층 라우팅, 게이트웨이=이종 네트워크 관문)

구분 요령: 리피터는 포트가 보통 2개(들어오는 선 1, 나가는 선 1)뿐이라 "분배"라는 개념 자체가 없다. 반면 허브는 포트가 여러 개라 "집선·분배"라는 표현이 붙는다.

문제 52018 계리직 · 기출문제집 p.295

네트워크 장치에 대한 설명으로 옳지 않은 것은?

  1. 허브(Hub)는 여러 대의 단말 장치가 하나의 LAN에 접속할 수 있도록 지원하는 중계 장치이다.
  2. 리피터(Repeater)는 물리 계층에서 동작하며 전송 신호를 재생·중계해 주는 증폭 장치이다.
  3. 브리지(Bridge)는 데이터 링크 계층에서 동작하며 같은 MAC 프로토콜을 사용하는 LAN 사이를 연결하는 장치이다.
  4. 게이트웨이(Gateway)는 네트워크 계층에서 동작하며 동일 전송 프로토콜을 사용하는 분리된 2개 이상의 네트워크를 연결해주는 장치이다.
해설 보기

정답 ④ (이것은 라우터의 설명이다)

  1. ④의 설명 두 가지가 모두 라우터를 가리킨다 — "네트워크 계층에서 동작", "동일 프로토콜 네트워크 연결"
  2. 게이트웨이는 4계층 이상에서 동작하며, 서로 다른 프로토콜 사이를 변환해 준다
  3. ①②③은 모두 올바른 설명

한 글자 차이 함정: "동일 프로토콜" → 라우터 / "서로 다른 프로토콜" → 게이트웨이. 이 문제처럼 계층과 프로토콜 조건을 슬쩍 바꿔치기하는 방식이 가장 흔하니, 선지를 읽을 때 이 두 단어에 밑줄을 긋는 습관을 들여라.

문제 62019 서울시 · 기출문제집 p.296

네트워킹 장비에 대한 설명으로 가장 옳지 않은 것은?

  1. 라우터(router)는 데이터 전송을 위한 최선의 경로를 결정한다.
  2. 허브(hub)는 전달받은 신호를 그와 케이블로 연결된 모든 노드들에 전달한다.
  3. 스위치(switch)는 보안(security) 및 트래픽(traffic) 관리 기능도 제공할 수 있다.
  4. 브리지(bridge)는 한 네트워크 세그먼트에서 들어온 데이터를 그의 물리적 주소에 관계없이 무조건 다른 세그먼트로 전달한다.
해설 보기

정답 ④ (브리지는 MAC 주소를 보고 필터링한다)

  1. 브리지의 존재 이유가 바로 불필요한 트래픽을 걸러내는 것이다
  2. 목적지 MAC 주소를 확인해서 같은 세그먼트 안에 있으면 건너편으로 보내지 않고, 건너편에 있을 때만 전달한다
  3. "물리적 주소에 관계없이 무조건 전달"은 오히려 허브(②번)의 동작 방식이다

②번과 비교해서 읽기: 이 문제는 ②(허브=무조건 전부 전달)와 ④(브리지=무조건 전달)가 똑같은 동작을 말하고 있다. 두 장비가 같은 일을 한다면 브리지가 따로 존재할 이유가 없다 — 이 논리만으로도 ④가 틀렸음을 알 수 있다.

문제 72024 소방경채 · 기출문제집 p.296

네트워크 장비에 관한 설명으로 옳지 않은 것은?

  1. 더미허브(dummy hub)는 호스트가 증가하면 속도가 감소한다.
  2. 라우터(router)는 독립적인 네트워크를 구성하여 인터넷에 연결할 수 있다.
  3. 스위치(switch)는 목적지 주소로 패킷을 스위칭하여 네트워크 효율을 높인다.
  4. 리피터(repeater)는 랜(LAN)을 두 개 이상 연결하여 네트워크를 하나로 만든다.
해설 보기

정답 ④ (LAN을 연결해 하나로 만드는 것은 브리지다)

  1. 리피터는 전송 거리를 늘리기 위해 선로 중간에 두는 신호 증폭·정형 장치다
  2. "LAN 두 개 이상을 연결해 하나의 네트워크로" → 브리지의 정의
  3. ①은 맞는 설명 — 더미허브는 대역폭을 공유하므로 호스트가 늘면 1대당 속도가 줄고 충돌도 늘어난다
  4. ②③도 맞는 설명 (라우터의 네트워크 분리, 스위치의 목적지 기반 전달)

세트로 기억: 거리 연장 = 리피터, LAN 연결 = 브리지, 네트워크 분리·인터넷 연결 = 라우터. 이 셋을 서로 바꿔 놓는 것이 이 단원 오답의 90%다.

문제 8개념 확인 · 응용

사무실에서 더미허브를 스위치로 교체했더니 네트워크 속도가 눈에 띄게 빨라졌다. 그 이유를 계층 동작 원리로 설명하면?

해설 보기

정답: 허브는 신호를 모든 포트에 뿌려 대역폭을 공유하지만, 스위치는 MAC 주소를 읽어 목적지 포트로만 보내기 때문

  1. 더미허브(1계층)는 주소를 읽을 능력이 없어 들어온 신호를 모든 포트에 복사한다
  2. 그 결과 모든 호스트가 하나의 회선을 나눠 쓰는 셈이 되고, 둘 이상이 동시에 전송하면 충돌(collision)이 발생해 재전송이 필요하다
  3. 스위치(2계층)는 MAC 주소 테이블을 학습해 목적지 포트로만 전달한다
  4. 따라서 A→C와 B→D 통신이 서로 간섭 없이 동시에 일어나고, 포트마다 전용 대역폭을 쓰므로 속도가 올라간다

보너스: 같은 이유로 보안도 좋아진다. 허브 환경에서는 남에게 보낸 패킷이 내 랜카드에도 도달해 도청(스니핑)이 가능하지만, 스위치는 목적지에게만 보내므로 기본적으로 차단된다.
