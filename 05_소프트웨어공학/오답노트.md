## ❌ 폭포수 모델 vs 다른 개발 모델 혼동
✅ **한 줄 정리**: 폭포수 모델은 **순차적 진행 + 단계별 산출물 관리**가 핵심이다. 반복(X), 프로토타입(X), 동작하는 결과물 강조(X)
💡 **암기팁**: 폭포수 = 폭포처럼 **한 방향**으로만 흐른다 → 되돌아가기 어려움 → 그래서 **각 단계 산출물(문서)이 중요**

| 보기 | 설명 | 해당 모델 |
|------|------|-----------|
| 단계별 반복하여 품질 개선 | 반복적으로 개선 | 나선형/반복 모델 |
| 시제품(prototype) 활용 | 빠르게 시제품 만들어 확인 | 프로토타입 모델 |
| 실제 동작하는 결과물 강조 | 문서보다 실행 결과 중시 | 애자일(Agile) |
| **단계별 결과 산출물 관리 강조** | **각 단계 끝에 문서 산출물 필수** | **폭포수 모델 ✅** |

> 📌 출처: 2024 소방경채 기출

## ❌ PMBOK 조달 관리의 의미 혼동
✅ **한 줄 정리**: 조달 관리 = 외부에서 필요한 제품·서비스를 **사오는 것**이지, 완성된 소프트웨어를 고객에게 **전달하는 것이 아니다!**
💡 **암기팁**: **조달 = 조(사서)달(가져온다)** → 방향: 외부 → 프로젝트팀 (구매), 프로젝트팀 → 고객(납품)이 아님!
📝 **PMBOK 9대 영역 암기**: "**통 범인이 시원한 품질의 인의리(인절미)를 조달했다**" → 통합·범위·시간·원가·품질·인적자원·의사소통·리스크·조달

> 📌 출처: 2017 지방직 기출

## ❌ 나씨-슈나이더만을 계획 도구로 착각
✅ **한 줄 정리**: 나씨-슈나이더만 도표는 **설계 단계** 도구! 계획 도구(간트, CPM, FP 등)와 구분해야 한다.
💡 **암기팁**: **나씨 = 네모 상자 = 설계** (계획은 "일정/비용" 관련 도구만!)

- 계획 도구: 간트, CPM, WBS, COCOMO, 기능점수 → 전부 **"언제, 얼마나"**에 대한 것
- 나씨-슈나이더만: 프로그램 **논리 구조**를 상자로 표현 → **설계**

> 📌 관련: 2011 지방직 기출 (문제35)
