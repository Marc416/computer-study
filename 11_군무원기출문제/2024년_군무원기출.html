📊2024년 출제 경향

영역별 출제 분포 (총 25문항)

  • 데이터베이스·자료구조 6문항 — 후위 표기법, 이진트리 성질, 빅오 순서, 선택 정렬 코드까지 자료구조 비중이 특히 크다.
  • 컴퓨터구조 5문항 — EPROM, 문자 인코딩 비트 수, 플립플롭, 캐시용 메모리, 진법 변환.
  • 운영체제 5문항 — 스케줄링 2문항(개념+계산), chmod 권한, 디스크 할당, 페이징 주소 비트 계산.
  • 네트워크·정보보안 5문항 — 무선랜 규격, 공개키 암호, TCP/IP 계층, HDLC, 다중화.
  • 소프트웨어공학 2문항, 프로그래밍 1문항, 신기술 1문항(하이퍼바이저).

난이도 특징: 2025년과 달리 직접 계산해야 답이 나오는 문제가 4개(Q13 선점 SJF 평균 반환시간, Q15 페이징 비트 수, Q18 후위 표기 변환, Q23 진법 변환)로 늘었다. 암기만으로는 부족하고 손으로 풀어보는 연습이 필요한 해였다.

또 하나의 특징은 "숫자를 바꿔 쓴 함정"이다. Q9(아스키 7비트 vs 8비트, EBCDIC 8비트 vs 7비트, BCD 6비트 vs 5비트)가 대표적 — 비트 수를 한 칸씩 어긋나게 써놓았다. 코드체계별 비트 수는 반드시 정확히 외워야 한다.

문제 52024 군무원 · 기출문제집 p.825

EPROM(Erasable Programmable ROM)에 대한 설명으로 가장 적절하지 않은 것은?

  1. 비휘발성 메모리이다.
  2. 데이터 갱신 횟수의 제한이 없다.
  3. 데이터를 갱신하려면 저장되어 있는 데이터를 지워야 한다.
  4. 플래시 메모리는 EPROM의 한 종류이다.
해설 보기

정답 ② 갱신 횟수 제한이 없다 (→ 실제로는 제한이 있다)

EPROM·EEPROM·플래시 메모리는 모두 지우고 다시 쓰는 횟수에 물리적 한계가 있다. 전하를 가두는 절연막이 쓰기를 반복할수록 열화되기 때문이다. SSD에 수명(TBW)이 있는 이유가 바로 이것이다.

나머지가 참인 이유

  • ① ROM 계열이므로 전원이 꺼져도 유지된다 → 비휘발성 ✓
  • ③ 플래시는 덮어쓰기가 안 되고 반드시 지우기(erase)를 먼저 해야 한다 ✓
  • ④ 플래시 메모리는 EEPROM/EPROM 계열의 발전형이다 ✓

ROM 계열 정리: Mask ROM(공장에서 고정) → PROM(사용자가 1회만 기록) → EPROM(자외선으로 지움) → EEPROM(전기적으로 지움) → 플래시(EEPROM을 블록 단위로 지우도록 개선)

문제 92024 군무원 · 기출문제집 p.827

문자 인코딩 방법에 대한 설명으로 가장 적절한 것은?

  1. 아스키(ASCII) 코드는 8비트로 구성되어 2⁸(=256)개의 문자 표현이 가능하다.
  2. EBCDIC는 7비트로 구성되어 2⁷(=128)개의 문자 표현이 가능하다.
  3. BCD 코드는 5비트로 구성되어 2⁵(=32)개의 문자 표현이 가능하다.
  4. 유니코드(Unicode)는 16비트로 구성되어 2¹⁶(=65,536)개의 문자 표현이 가능하다.
해설 보기

정답 ④ 유니코드 16비트 = 65,536자

비트 수를 한 칸씩 어긋나게 써놓은 전형적 숫자 함정이다. 정확한 표는 이렇다:

코드비트 수표현 가능 문자구조
BCD6비트2⁶ = 64자존 2 + 디지트 4 (→ ③이 5비트라 했으니 오답)
ASCII7비트2⁷ = 128자존 3 + 디지트 4 (→ ①이 8비트라 했으니 오답)
EBCDIC8비트2⁸ = 256자존 4 + 디지트 4 (→ ②가 7비트라 했으니 오답)
Unicode16비트2¹⁶ = 65,536자전 세계 문자 통합 ✅

암기법: 6 → 7 → 8 → 16 순서로 커진다. "BCD(6) 아스키(7) EBCDIC(8) 유니코드(16)" 를 숫자 순서 그대로 외우면 절대 안 헷갈린다.

주의: "확장 아스키 8비트(256자)"라는 표현도 있지만, 시험에서 그냥 "아스키"라고 하면 7비트/128자가 정답이다.

문제 232024 군무원 · 기출문제집 p.833

2진수 10101001.11000011 을 16진수로 표현한 것으로 옳은 것은?

  1. A9.B3
  2. A9.C3
  3. A7.B3
  4. A7.C3
해설 보기

정답 ② A9.C3

  1. 소수점을 기준으로 4비트씩 묶는다. 정수부는 소수점에서 왼쪽으로, 소수부는 오른쪽으로 묶는 것이 원칙이다.
    1010 1001 . 1100 0011
  2. 정수부: 1010 = 8+2 = 10 = A, 1001 = 8+1 = 9
  3. 소수부: 1100 = 8+4 = 12 = C, 0011 = 2+1 = 3
  4. 결과: A9.C3

함정: ①의 B3, ③④의 A7은 4비트 묶음을 잘못 계산한 값이다. 1100을 B(1011)로 착각하거나, 1001을 7(0111)로 착각한 경우.

실수 방지 팁: 4비트 자리값을 8-4-2-1로 적어두고 1인 자리만 더하면 절대 틀리지 않는다. 1100 → 8+4 = 12 = C.

문제 12024 군무원 · 기출문제집 p.824

운영체제의 프로세스 스케줄링 방법에 대한 설명 중 가장 적절하지 않은 것은?

  1. 라운드 로빈(Round Robin) 스케줄링은 여러 프로세스를 일정 순서에 따라 단위시간씩 실행시킨다.
  2. FCFS(First Come First Serve) 스케줄링은 프로세스의 평균 대기 시간을 최적화하는 실행 방법이다.
  3. 우선순위 스케줄링은 프로세스별 등급에 따라 높은 순위를 먼저 실행시킨다.
  4. 다단계 큐 스케줄링은 상위 단계 큐의 프로세스를 하위 단계 큐의 프로세스보다 먼저 실행시킨다.
해설 보기

정답 ②

FCFS는 그냥 도착한 순서대로 처리할 뿐, 평균 대기시간을 최적화하지 않는다. 오히려 호위 효과(Convoy Effect) 때문에 평균 대기시간이 나빠지기 쉽다.

호위 효과란: 실행시간이 아주 긴 프로세스가 먼저 도착하면, 뒤에 온 짧은 프로세스들이 전부 그 뒤에서 하염없이 기다린다. 마트에서 카트 가득 채운 사람 뒤에 껌 하나 든 사람이 줄 선 상황과 같다.

그럼 평균 대기시간을 최소화하는 것은? → SJF(Shortest Job First)다. 짧은 작업부터 처리하면 평균 대기시간이 수학적으로 최소가 된다는 것이 증명되어 있다. "평균 대기시간 최적"이라는 표현이 나오면 SJF를 떠올려야 한다.

  2. 6.75

해설 보기

정답 ① 6.25

선점식 SJF = SRTF(Shortest Remaining Time First). 새 프로세스가 도착할 때마다 "지금 돌고 있는 것의 남은 시간"과 "새로 온 것의 실행시간"을 비교해 짧은 쪽에 CPU를 준다.

  1. t=0 — P1만 있으므로 P1 실행 시작 (남은 7)
  2. t=1 — P2 도착(3). P1 남은 시간 6 > 3 → P1을 밀어내고 P2 실행
  3. t=4 — P2 완료. 대기 중인 건 P1(남은 6)뿐 → P1 재개
  4. t=5 — P3 도착(2). P1 남은 5 > 2 → 또 P1을 밀어내고 P3 실행
  5. t=7 — P3 완료. 동시에 P4 도착(4). P1 남은 5 vs P4 4 → P4 실행
  6. t=11 — P4 완료. 남은 건 P1뿐 → P1이 남은 5를 채우고 t=16에 완료

반환시간 = 완료시각 − 도착시각

프로세스도착완료반환시간
P101616 − 0 = 16
P2144 − 1 = 3
P3577 − 5 = 2
P471111 − 7 = 4

평균 = (16 + 3 + 2 + 4) ÷ 4 = 25 ÷ 4 = 6.25

실수 포인트 2가지

  • 반환시간과 대기시간을 혼동하지 말 것. 반환시간 = 도착~완료 전체, 대기시간 = 반환시간 − 실행시간.
  • 선점이 일어나면 밀려난 프로세스의 남은 시간을 반드시 갱신해 적어둘 것. 머릿속으로만 하면 거의 틀린다 — 타임라인을 종이에 그려라.

문제 152024 군무원 · 기출문제집 p.830 · 계산 문제

페이징 기법을 사용하는 64비트 컴퓨터에서 페이지 크기가 4,096바이트일 때, 논리주소를 구성하는 페이지 번호의 비트 수와 페이지 변위(offset)의 비트 수로 올바른 것은?

  1. 40, 24
  2. 12, 52
  3. 42, 12
  4. 52, 12
해설 보기

정답 ④ 페이지 번호 52비트, 변위 12비트

논리주소는 [페이지 번호 | 변위] 두 부분으로 쪼개진다. 변위는 "한 페이지 안에서 몇 번째 바이트인지"를 가리키므로, 페이지 크기를 전부 가리킬 수 있는 비트 수가 필요하다.

  1. 페이지 크기 4,096바이트 = 212 → 한 페이지 안의 모든 바이트를 가리키려면 변위 = 12비트
  2. 전체 논리주소가 64비트이므로 나머지가 페이지 번호
  3. 페이지 번호 = 64 − 12 = 52비트

검산: 페이지 번호 52비트 → 252개의 페이지. 252 × 212바이트 = 264바이트 = 64비트 주소공간 전체 ✓

공식 한 줄: 변위 비트 = log₂(페이지 크기), 페이지 번호 비트 = 전체 주소 비트 − 변위 비트

함정: ②(12, 52)는 둘의 순서를 바꾼 오답이다. 문제가 "페이지 번호, 변위" 순으로 물었는지 확인하는 습관이 필요하다.

데이터 링크 계층의 프로토콜인 HDLC(High-level Data Link Control)에 대한 설명으로 가장 적절하지 않은 것은?

  1. 바이트 단위로 전송하는 동기 방식이다.
  2. 전이중(full duplex) 방식을 사용한다.
  3. 비트 스터핑(bit stuffing) 기능으로 투명성을 제공한다.
  4. HDLC 프레임의 플래그는 프레임 시작과 끝을 나타내며 동기화에 사용한다.
해설 보기

정답 ①

HDLC는 비트 지향(bit-oriented) 프로토콜로 블록(비트열) 단위로 전송한다. 바이트 단위가 아니다.

③번이 힌트다: "비트 스터핑"을 쓴다는 것 자체가 HDLC가 비트 단위로 데이터를 다룬다는 증거다. ①과 ③이 서로 모순되므로, 둘 중 하나가 틀렸다는 걸 눈치챌 수 있다.

비트 스터핑이란: HDLC의 플래그는 01111110(1이 6개)이다. 만약 데이터 안에 우연히 1이 6개 연속으로 나오면 수신 측이 "프레임 끝!"으로 오해한다. 그래서 송신 측은 1이 5개 연속되면 강제로 0을 하나 끼워 넣고, 수신 측은 그 0을 빼낸다. 덕분에 어떤 데이터든 안전하게 실어 보낼 수 있다 → 이것이 투명성(transparency)이다.

  2. 도메인(Domain)
  3. 일반 집합 연산자
  4. 엔터티(Entity)

정답 ② 도메인(Domain)

도메인 = 하나의 속성이 가질 수 있는 값들의 집합(= 허용 범위)이다. 지문의 "전압값이 가질 수 있는 제한 조건"이 정확히 도메인의 정의다.

  • ③ 일반 집합 연산자는 합집합·교집합·차집합·카티션프로덕트 등 관계대수의 연산이다.

문제 222024 군무원 · 기출문제집 p.832

SQL에 대한 설명으로 가장 적절하지 않은 것은?

  1. SQL은 비절차적 언어이며 다른 언어에 삽입되어 내장 SQL로도 사용 가능하다.
  2. SQL 뷰(view)는 하나 이상의 테이블로부터 만들어진 가상 테이블이다.
  3. SQL ALTER 문을 사용하여 테이블을 변경할 수 있다.
  4. SQL 뷰가 정의된 기본 테이블이 변경되어도 뷰는 변경되지 않는다.
해설 보기

정답 ④

뷰는 실제 데이터를 갖지 않는 가상 테이블이다. 기본 테이블을 바라보는 "창문"일 뿐이라, 창문이 바라보던 대상이 사라지면 창문도 함께 사라진다.

따라서 기본 테이블이 제거(DROP)되면 그 위에 정의된 뷰도 자동으로 제거되고, 기본 테이블의 데이터가 바뀌면 뷰를 조회할 때 바뀐 내용이 그대로 보인다.

뷰의 다른 중요 특징 (함께 외울 것)

  • 뷰는 ALTER 문으로 변경할 수 없다 — 고치려면 DROP 후 다시 CREATE 해야 한다.
  • 뷰를 통한 삽입·삭제·갱신에는 제약이 따른다 (집계함수·DISTINCT·GROUP BY가 포함된 뷰는 갱신 불가).
  • 장점: 보안(필요한 열만 노출), 논리적 독립성, 질의 단순화.

문제 182024 군무원 · 기출문제집 p.831 · 계산 문제

다음 수식을 후위 표기법으로 변환했을 때 가장 적절한 것은?

100 - 20 * 5 + 2
  1. 100 20 5 2 * - +
  2. 100 20 5 * 2 - +
  3. 100 20 5 * - 2 +
  4. 100 20 5 * - + 2
해설 보기

정답 ③ 100 20 5 * - 2 +

가장 확실한 방법: 괄호를 다 친 뒤 연산자를 괄호 뒤로 빼기

  1. 우선순위대로 괄호를 완전히 친다. *가 먼저, 그다음 -와 +는 왼쪽부터:
    ((100 - (20 * 5)) + 2)
  2. 가장 안쪽 괄호부터 연산자를 피연산자 뒤로 보낸다:
    (20 * 5) → 20 5 *
  3. 그다음 괄호: (100 - [20 5 *]) → 100 20 5 * -
  4. 마지막 괄호: ([100 20 5 * -] + 2) → 100 20 5 * - 2 +

검산법: 후위 표기식을 스택으로 계산해 원래 값과 맞는지 본다. 100 - 100 + 2 = 2 여야 한다.
100 넣고 20 넣고 5 넣음 → * 만나면 위 2개(20,5) 꺼내 100 넣음 → 스택 [100, 100] → - 만나면 100-100=0 → 2 넣음 → + 만나면 0+2 = 2 ✓

함정: ④(… - + 2)처럼 연산자가 마지막 피연산자보다 앞에 오는 형태는 후위 표기법상 성립할 수 없다. 후위식은 반드시 연산자로 끝난다.

이진 트리(binary tree)에 대한 설명으로 가장 적절하지 않은 것은? (단, 트리의 최상위 레벨이 깊이 1이다.)

  1. n개의 노드를 가진 이진 트리는 n−1개의 간선을 갖는다.
  2. 레벨 a에서의 최대 노드 수는 2a−1개이다.
  3. n개의 노드를 가진 이진 트리의 깊이는 최대 n−1이다.
  4. 깊이가 d인 이진 트리의 노드 수는 최대 2d−1개이다.
해설 보기

정답 ③ (최대 깊이는 n−1이 아니라 n)

최상위 레벨이 깊이 1이라는 단서가 핵심이다. 노드가 한 줄로 쭉 늘어선 편향 트리(skewed tree)가 가장 깊은 경우인데, 이때 노드 n개면 깊이도 그대로 n이다.

직접 세어보기: 노드 3개가 일직선(A→B→C)이면, A는 깊이 1, B는 깊이 2, C는 깊이 3 → 깊이 = 3 = n ✓ (n−1 = 2가 아니다)

나머지 공식 검증 (n=3, 완전이진트리 기준)

  • ① 간선 수 = n−1: 노드 3개면 간선 2개 ✓ (트리는 항상 이 성질을 가진다 — 루트를 뺀 모든 노드가 부모로 가는 간선 1개씩 갖기 때문)
  • ② 레벨 a의 최대 노드 = 2a−1: 레벨1 → 2⁰=1(루트), 레벨2 → 2¹=2, 레벨3 → 2²=4 ✓
  • ④ 깊이 d 트리의 최대 노드 = 2d−1: d=3 → 2³−1 = 7 (1+2+4) ✓

주의: "최상위 레벨을 0으로 둔다"는 다른 교재도 있다. 그 경우 공식이 전부 한 칸씩 달라지므로 문제의 단서를 반드시 먼저 확인해야 한다.

문제 242024 군무원 · 기출문제집 p.833

소프트웨어 모듈 설계의 평가에 대한 설명으로 가장 적절하지 않은 것은?

  1. 모듈의 결합도(coupling)는 모듈들이 서로 관련되거나 연결된 정도를 의미하며 낮을수록 좋다.
  2. 모듈의 응집도(cohesion)는 모듈 간에 기능적인 연관 정도를 의미하며 높을수록 좋다.
  3. 어떤 모듈이 다른 모듈을 호출하며 데이터를 넘겨주는 경우 이 모듈 간에 제어 결합도를 가진다고 한다.
  4. 모듈 내 모든 요소가 한 가지 기능을 수행하기 위해 구성되는 경우 이들 요소는 기능적 응집도로 묶여있다고 한다.
해설 보기

정답 ② (응집도는 "모듈 간"이 아니라 "모듈 내"의 연관 정도)

단어 하나만 바꿔놓은 함정이다. 응집도는 모듈 안쪽, 결합도는 모듈 사이 — 이 구분이 전부다. ②는 "높을수록 좋다"는 맞지만 "모듈 간에"가 틀렸다.

응집도 (낮음 → 높음, 높을수록 좋음)
우연적 < 논리적 < 시간적 < 절차적 < 교환적 < 순차적 < 기능적

결합도 (낮음 → 높음, 낮을수록 좋음)
자료 < 스탬프 < 제어 < 외부 < 공통 < 내용

③에 대한 보충 (헷갈릴 수 있는 부분): 엄밀히 말하면 순수한 데이터만 넘기는 것은 자료 결합도(data coupling)이고, 제어 결합도는 "이렇게 동작하라"는 플래그·제어신호를 넘길 때를 말한다. ③의 서술도 정확하다고 보기 어렵지만, 출제자가 의도한 명백한 오답은 ②다.
