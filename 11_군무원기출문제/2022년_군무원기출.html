문제 12022 군무원 · 기출문제집 p.847

다음 중 2진수 11010010의 1의 보수(one's complement)를 16진수로 표현한 것으로 옳은 것은?

  1. 2D₁₆
  2. 2C₁₆
  3. D3₁₆
  4. 2E₁₆
해설 보기

정답 ① 2D₁₆

  1. 1의 보수 = 모든 비트를 반전(1↔0): 1101 0010 → 0010 1101
  2. 16진수 변환은 4비트씩 묶어서: 0010 | 1101
  3. 0010₂ = 2, 1101₂ = D → 2D₁₆

함정: ③ D3은 두 묶음의 앞뒤를 바꿔 읽은 오답, ④ 2E는 1101(=13=D)을 1110(=14=E)으로 잘못 반전한 경우다. 보수를 먼저, 16진수 변환을 나중에 하는 순서를 지킬 것.

문제 22022 군무원 · 기출문제집 p.847

논리회로의 조합회로(combinational circuit)와 순차회로(sequential circuit)에 대한 설명 중 가장 올바르지 않은 것은?

  1. 조합회로는 현재의 입력에 의해서만 출력값이 결정된다.
  2. 순차회로는 현재의 입력과 저장된 값에 의해 출력값이 결정된다.
  3. 복호기(decoder)와 부호기(encoder)는 조합회로로 구성되는 것이 일반적이다.
  4. 멀티플렉서(multiplexer)와 디멀티플렉서(demultiplexer)는 순차회로로 구성되는 것이 일반적이다.
해설 보기

정답 ④ (멀티플렉서·디멀티플렉서는 조합회로다)

판별 기준은 하나다 — "과거 상태를 기억해야 하는가?"

  • 조합회로(기억 없음): 가산기, 인코더/디코더, MUX/DEMUX — 지금 들어온 선택신호만 보고 즉시 출력을 정한다
  • 순차회로(기억 있음): 플립플롭, 레지스터, 카운터 — 이전 값을 붙들고 있어야 동작한다

함정: MUX는 "선택"이라는 말 때문에 뭔가 상태를 기억할 것처럼 느껴지지만, 선택신호가 바뀌면 즉시 출력이 바뀔 뿐 아무것도 저장하지 않는다.

문제 152022 군무원 · 기출문제집 p.853

캐시 메모리에 대한 설명 중 가장 옳지 않은 것은?

  1. CPU 캐시 메모리는 주기억장치와 CPU 사이에 위치하여 두 장치 간의 속도 차에 의한 데이터 처리 지연을 해소한다.
  2. 주기억장치에 비하여 용량은 적으나 속도는 빠른 메모리를 사용한다.
  3. 멀티 코어 프로세서의 경우 각 코어별로 독립된 캐시 메모리를 가질 수 없다.
  4. 캐시 메모리는 데이터 지역성의 원리를 이용하여 작동한다.
해설 보기

정답 ③ (각 코어는 독립된 캐시를 가질 수 있다)

실제 멀티코어 CPU의 캐시 구성은 이렇게 되어 있다.

  • L1 캐시: 코어마다 전용으로 하나씩 (가장 빠름, 가장 작음)
  • L2 캐시: 보통 코어 전용
  • L3 캐시: 여러 코어가 공유

즉 "독립된 캐시"와 "공유 캐시"가 계층에 따라 둘 다 존재한다. ③처럼 "가질 수 없다"고 단정하면 틀린다.

문제 182022 군무원 · 기출문제집 p.854

다음에서 설명하는 RAID 방식으로 옳은 것은?

· 모든 데이터를 실시간으로 복구가 가능해 디스크 오류가 발생해도 중요한 데이터를 즉시 사용할 수 있다.
· 시스템 소프트웨어나 중요한 파일을 저장하는 용도로만 사용된다.
  1. RAID 0
  2. RAID 1
  3. RAID 2
  4. RAID 5
해설 보기

정답 ② RAID 1 (미러링)

"실시간 복구"라는 표현이 결정적 힌트다. 패리티로 계산해서 복원하는 방식(RAID 2·5)은 복구에 연산 시간이 걸리지만, 미러링은 똑같은 사본이 이미 있으므로 즉시 갖다 쓰면 된다.

레벨방식복구
RAID 0스트라이핑(분산 저장)복구 불가 — 중복 저장이 없음
RAID 1미러링(똑같이 복사)즉시 복구, 대신 용량 효율 50%
RAID 5블록 분산 + 패리티 분산패리티로 계산해 복구 (시간 소요)

함정: ① RAID 0은 속도만 빠르고 복구가 아예 안 된다 — "RAID니까 안전하겠지"라고 넘기면 틀린다.

문제 122022 군무원 · 기출문제집 p.852

DMA(Direct Memory Access) 입출력 기능에 대한 설명 중 가장 옳지 않은 것은?

  1. 하드웨어 하위시스템이 CPU와 독립적으로 메인시스템 메모리에 접근할 수 있게 해주는 기능이다.
  2. 장치 컨트롤러가 데이터의 한 블록을 이동시키는데 이 과정에서 CPU의 개입은 불필요하다.
  3. 데이터가 전송되는 동안 CPU는 다른 작업을 수행할 수 있게 되어 CPU 효율성이 향상된다.
  4. 메모리 간 복사 또는 데이터 이동에는 쓰일 수 없는 한계가 있다.
해설 보기

정답 ④ (DMA는 메모리↔메모리 복사에도 사용 가능하다)

DMA의 본질은 "CPU를 거치지 않고 버스를 직접 써서 데이터를 옮기는 것"이다. 옮기는 양쪽이 I/O와 메모리든, 메모리와 메모리든 상관없다. 실제로 memory-to-memory DMA 전송은 널리 쓰인다.

①②③은 모두 DMA의 정확한 정의다. DMA 문제는 대부분 "CPU가 개입하는가"를 묻는데, 정답은 항상 "블록 전송 중에는 개입하지 않고, 전송이 끝나면 인터럽트로 알린다"이다.

문제 142022 군무원 · 기출문제집 p.853

어떤 프로그램이 단일 프로세서로 실행하면 100초가 소요되며, 이 프로그램의 40%는 반드시 순차적으로 실행되어야 한다고 가정했을 때, 4개의 프로세서를 이용하여 실행할 경우 이론적으로 가능한 최단 시간에 가장 가까운 것은?

  1. 25초
  2. 55초
  3. 75초
  4. 100초
해설 보기

정답 ② 55초

암달의 법칙(Amdahl's Law) — 병렬화해도 순차 구간은 절대 줄지 않으므로 그 부분이 병목이 된다.

  1. 순차 구간: 100초 × 40% = 40초 → 프로세서를 아무리 늘려도 그대로 40초
  2. 병렬 구간: 100초 × 60% = 60초 → 4개로 나누면 60 ÷ 4 = 15초
  3. 총 시간 = 40 + 15 = 55초

공식으로 풀면: 향상 배수 = 1 / (순차비율 + 병렬비율/프로세서수) = 1 / (0.4 + 0.6/4) = 1/0.55 ≈ 1.82배 → 100 ÷ 1.82 ≈ 55초. 계산이 헷갈리면 위처럼 초 단위로 쪼개서 더하는 편이 실수가 적다.

함정: ① 25초는 100÷4로 전체를 병렬화했다고 착각한 오답이다. 또한 프로세서를 무한대로 늘려도 40초 밑으로는 절대 못 내려간다는 것이 이 법칙의 핵심 메시지다.

💡 관련: 입출력장치와 병렬처리

문제 162022 군무원 · 기출문제집 p.854

다중 프로그램 실행 환경에서 일련의 프로세스들이 서로가 가진 자원을 무한정 기다리며 더 이상 진행될 수 없는 상태를 일컫는 용어로 가장 옳은 것은?

  1. deadlock
  2. pipelining
  3. preemption
  4. mutual exclusion
해설 보기

정답 ① deadlock (교착상태)

선택지 넷이 전부 헷갈리게 배치돼 있으니 각각의 정확한 뜻을 잡아두자.

  • deadlock(교착상태): 서로의 자원을 기다리며 영원히 멈춘 상태 ← 정답
  • pipelining: 명령어 처리를 단계별로 겹쳐 실행하는 성능 향상 기법 (전혀 다른 개념)
  • preemption(선점): 실행 중인 프로세스에서 자원을 빼앗는 것 — 오히려 교착상태를 푸는 방법 중 하나
  • mutual exclusion(상호배제): 한 번에 하나만 쓰게 하는 원칙 — 교착상태의 필요조건 4가지 중 하나일 뿐, 교착상태 자체는 아님

함정: ④ 상호배제는 교착상태와 늘 같이 나오기 때문에 가장 많이 걸리는 오답이다. "조건"과 "결과"를 구분할 것.

문제 202022 군무원 · 기출문제집 p.855

운영체제의 발달과정 순서를 나열한 것으로 가장 옳은 것은?

  1. 일괄처리 → 다중모드 → 시분할 → 분산처리
  2. 일괄처리 → 시분할 → 다중모드 → 분산처리
  3. 시분할 → 일괄처리 → 분산처리 → 다중모드
  4. 시분할 → 분산처리 → 일괄처리 → 다중모드
해설 보기

정답 ② 일괄처리 → 시분할 → 다중모드 → 분산처리

발달 순서는 "컴퓨터가 한 번에 상대할 수 있는 사용자 수"가 늘어나는 흐름으로 이해하면 외우기 쉽다.

  1. 일괄처리: 작업을 모아 한꺼번에 처리 — 사용자는 기다릴 수밖에 없음 (가장 원시적)
  2. 시분할: CPU 시간을 잘게 쪼개 여러 사용자가 동시에 쓰는 것처럼 만듦
  3. 다중모드: 일괄·시분할·실시간·다중처리를 모두 통합해 제공 → 앞의 것들이 다 있어야 가능하므로 시분할보다 뒤
  4. 분산처리: 여러 대의 컴퓨터를 네트워크로 묶어 처리 (가장 발전된 형태)

함정: ①번은 다중모드를 시분할보다 앞에 두었다. "통합" 단계는 통합할 것들이 먼저 생긴 뒤에야 나올 수 있다는 논리로 걸러내면 된다.

💡 관련: 운영체제 정의

문제 212022 군무원 · 기출문제집 p.855

기억장치 배치 전략인 최초 적합(first-fit), 최적 적합(best-fit), 최악 적합(worst-fit)으로 각각 5K의 프로그램을 할당할 때, 할당 영역으로 가장 옳은 것은?

할당영역크기
운영체제—
14K 공백
215K 공백
310K 공백
45K 공백
520K 공백
  1. 2, 3, 2
  2. 2, 3, 5
  3. 2, 4, 5
  4. 2, 4, 1
해설 보기

정답 ③ 최초=2번, 최적=4번, 최악=5번

세 전략은 "5K가 들어갈 수 있는 곳"(4K 제외 → 2·3·4·5번) 중에서 무엇을 고르느냐만 다르다.

  1. 최초 적합: 위에서부터 훑어 처음 만나는 충분한 공간 → 1번(4K)은 5K가 안 들어가니 통과 → 2번(15K)
  2. 최적 적합: 들어갈 수 있는 곳 중 가장 작은 곳 (남는 공간 최소) → 15K·10K·5K·20K 중 4번(5K, 딱 맞아 남는 공간 0)
  3. 최악 적합: 들어갈 수 있는 곳 중 가장 큰 곳 → 5번(20K)

왜 "최악"이란 이름인데도 쓰는가: 큰 공간에 넣으면 남는 조각도 크게 남아 다음 프로그램이 들어갈 수 있다. 최적 적합은 자투리가 너무 작게 남아 아무도 못 쓰는 외부 단편화를 만들기 쉽다.

함정: ①②처럼 최적 적합을 3번(10K)으로 고르는 오답이 많다. "딱 맞는 5K가 있으면 그게 최적"임을 놓치지 말 것.

  2. l-다양성은 비식별 조치 과정에서 l개 이상 서로 다른 민감한 정보를 갖도록 동질 집합을 구성하는 것을 말한다.
  3. t-근접성은 동질 집합에서 특정 정보의 분포와 전체 데이터 집합에서 정보의 분포가 t 이하의 차이를 보이게 하는 것을 말한다.
  4. 정보주체의 동의 없이는 과학적 연구, 통계작성, 공익적 기록보존을 목적으로라도 가명정보를 활용할 수 없다.

정답 ④ (개인정보보호법상 동의 없이도 가명정보 처리 가능)

「개인정보 보호법」 제28조의2: 개인정보처리자는 통계작성 · 과학적 연구 · 공익적 기록보존 등을 위하여 정보주체의 동의 없이 가명정보를 처리할 수 있다. (단, 제3자 제공 시 특정 개인을 알아볼 수 있는 정보는 포함 금지)

①②③은 비식별화 3단계 모델의 정확한 정의다. 세 모델은 앞의 것의 약점을 뒤의 것이 보완하는 구조로 이해하면 순서가 외워진다.

  1. k-익명성: 같은 값이 최소 k개 있게 만들어 개인 특정을 막음 → 하지만 그룹 안 민감정보가 전부 똑같으면 그냥 뚫린다(동질성 공격)
  2. l-다양성: 그래서 그룹 안에 서로 다른 민감정보가 최소 l개 있게 함 → 하지만 그룹 분포가 전체와 너무 쏠려 있으면 또 추론된다(쏠림·유사성 공격)
  3. t-근접성: 그래서 그룹 분포를 전체 분포와 t 이하 차이로 맞춤 (가장 강한 보호)

💡 암기팁: k(개수) → l(다양성) → t(분포 유사성) 순으로 점점 정교해진다.

숫자 0부터 n까지(n을 포함) 합을 구하는 함수를 C 언어로 구현하고자 한다. n은 0보다 크거나 같은 경우만 고려한다. /* 공란 */ 에 채워져야 할 코드로 가장 옳은 것은?

int sum(int n) {
  int result = 0;
  /* 공란 */
  return result;
}
  1. for (int i = 0; i++; i < n) result = result + i;
  2. for (int i = 0; i++; i <= n) result = result + i;
  3. for (int i = 0; i <= n; i++) result = result + i;
  4. for (int i = 0; i < n; i++) result = result + i;
해설 보기

정답 ③ for (int i = 0; i <= n; i++)

두 가지를 동시에 확인해야 한다.

  1. for문 구조는 for(초기식; 조건식; 증감식) 순서다 → ①②는 조건식 자리에 i++가, 증감식 자리에 비교식이 들어가 순서가 뒤바뀐 오답
  2. n을 포함해야 하므로 조건은 i <= n → ④의 i < n은 n을 빼먹어 합이 모자람

검산: n=3일 때 정답 코드는 i=0,1,2,3 → 0+1+2+3 = 6 ✓. ④번 코드는 i=0,1,2 → 3이 되어 틀린다.

문제 42022 군무원 · 기출문제집 p.848

다음 Java 프로그램의 Example 클래스 내부 코드 중에서 컴파일 오류를 일으키는 잘못된 코드는?

class C {}
class CS extends C {}
interface I {}
class CI extends C implements I {}
  1. static I i = new CI();
  2. static C ca = new CI();
  3. static CS cs = new C();
  4. static C cb = new CS();
해설 보기

정답 ③ static CS cs = new C();

대원칙: 변수 타입은 객체 타입과 같거나, 그보다 "더 넓은(부모)" 타입이어야 한다. 자식 타입 변수에 부모 객체를 넣는 것은 불가능하다.

  • 상속 관계: C(부모) ← CS(자식), C(부모) ← CI(자식, I 구현)
  • ① I i = new CI() — CI가 I를 구현했으므로 OK
  • ② C ca = new CI() — 부모 타입에 자식 객체, OK
  • ③ CS cs = new C() — 자식 타입(CS)에 부모 객체(C) → 컴파일 오류
  • ④ C cb = new CS() — 부모 타입에 자식 객체, OK

💡 직관적 이해: "모든 학생은 사람이다"는 참이므로 사람 p = new 학생()은 되지만, "모든 사람이 학생"은 아니므로 학생 s = new 사람()은 안 된다.

문제 192022 군무원 · 기출문제집 p.855

다음 파이썬 코드의 실행 결과로 옳은 것은?

list = [1, 2, 3, 4, 5, 6]
print(list[-2:-4:-1])
  1. [4, 3]
  2. [4, 3, 2]
  3. [5, 4]
  4. [5, 4, 3]
해설 보기

정답 ③ [5, 4]

음수 인덱스를 먼저 표로 그려놓고 시작하면 실수하지 않는다.

값123456
양수 index012345
음수 index-6-5-4-3-2-1
  1. [start:stop:step] = [-2 : -4 : -1] → -2번(값 5)에서 시작
  2. step이 -1이므로 역방향으로 한 칸씩 이동
  3. stop인 -4번(값 3)은 포함하지 않고 그 직전까지 → -2(5), -3(4)에서 멈춤
  4. 결과: [5, 4]

함정: ④ [5,4,3]은 stop을 포함시킨 오답이다. 파이썬 슬라이싱의 stop은 항상 배타적(포함 안 함)임을 기억할 것.
