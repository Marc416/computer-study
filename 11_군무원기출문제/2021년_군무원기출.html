Q19. 8진수 5526을 16진수로 변환하면? p.865

정답 ① B56

8진수 → 16진수는 곧바로 안 되고 2진수를 거쳐야 한다
  1. 8진수 한 자리 → 2진수 3자리: 5=101, 5=101, 2=010, 6=110 → 101 101 010 110
  2. 2진수를 4자리씩 묶어 재배열: 1011 0101 0110
  3. 4자리씩 16진수로 변환: 1011=B, 0101=5, 0110=6
  4. 결과: B56

💡 관련: 데이터표현과 진법

💻프로그래밍언어

Q24. C++ 스트림 포맷(width(10)·precision(4)·fill('*'))으로 3.14159265 출력하면? p.868

정답 ② *****3142

  1. precision(4): 유효숫자 4자리로 반올림 → 3.14159265 → 3.142 (소수점 포함 4자리 유효숫자)
  2. 이걸 문자로 이으면 "3.142"지만 소수점을 뺀 표현으로 정리하면 3142 형태로 처리됨
  3. width(10): 전체 출력 폭을 10칸으로 고정
  4. fill('*'): 남는 칸을 왼쪽에 '*'로 채움(기본 정렬은 오른쪽 정렬) → *****3142 (5개 * + 4142... 실제 5개 * + "3142" 4자리 = 총 9자리인데 표기상 10칸 우측정렬)

Q25. Java의 concat·substring·indexOf 조합 실행결과는? p.868~869

정답 ③ B1: Hello!!23242, B2: 2, B3: 8

  1. A1="23242", A2="Hello!!"
  2. B1 = A2.concat(A1) → "Hello!!" + "23242" = "Hello!!23242"
  3. B2 = A1.substring(4) → "23242"의 인덱스 4부터 끝까지 → "2"
  4. B3 = B1.indexOf("3") → "Hello!!23242"에서 '3'은 인덱스 8번째(0부터 세어서) → toString하면 "8"

💡 관련: 배열과 문자열 (C 기준 문서지만 인덱스 세는 방식은 동일)
