문제 12021 군무원 · 기출문제집 p.859

SRAM(Static RAM)과 DRAM(Dynamic RAM)에 대한 설명으로 옳지 않은 것은?

  1. SRAM은 캐시(cache) 메모리로 사용된다.
  2. DRAM은 메인(main) 메모리로 사용된다.
  3. SRAM은 DRAM에 비해 속도가 느리다.
  4. 동일 크기의 메모리인 경우, SRAM이 DRAM에 비해 가격이 비싸다.
해설 보기

정답 ③ (SRAM이 DRAM보다 빠르다)

논리적으로 따져보면 ③이 틀렸다는 걸 바로 알 수 있다 — ①에서 SRAM을 캐시로 쓴다고 했는데, 캐시는 "빠른 메모리"를 쓰는 자리다. 느린 메모리를 캐시로 쓸 이유가 없다.

구분SRAMDRAM
저장 소자플립플롭 (회로)축전기 (전하)
재충전(refresh)불필요필요 (전하가 새어나감)
속도빠름느림
가격·집적도비쌈 / 집적도 낮음쌈 / 집적도 높음
용도캐시주기억장치

💡 핵심 논리: DRAM은 축전기에 저장해서 주기적으로 재충전(refresh)하느라 시간을 뺏긴다 → 그래서 느리다. SRAM은 회로가 값을 붙들고 있어 재충전이 필요 없다 → 빠르지만 회로가 복잡해 비싸고 집적도가 낮다.

문제 42021 군무원 · 기출문제집 p.860

CPU와 메인 메모리의 속도 차이 때문에 발생하는 명령어 처리 성능 저하를 방지하기 위하여, CPU와 메인 메모리 사이에 설치하는 메모리로 옳은 것은?

  1. 레지스터(register)
  2. ROM(Read Only Memory)
  3. 캐시(cache)
  4. I/O 버퍼(buffer)
해설 보기

정답 ③ 캐시(cache)

"CPU와 주기억장치 사이"라는 위치 표현이 나오면 답은 거의 항상 캐시다.

  • 레지스터: CPU 내부에 있는 최상위 저장소 — "사이"가 아니라 CPU 안쪽
  • ROM: 비휘발성 읽기전용 메모리(BIOS 저장용) — 속도 완충과 무관
  • I/O 버퍼: CPU와 입출력장치 사이의 속도 차를 완충 — 대상이 메모리가 아님

💡 비슷한 개념 구분: "속도 차를 메운다"는 개념은 여러 곳에 나온다. 캐시는 CPU↔메모리, 버퍼는 CPU↔입출력장치, 스풀(SPOOL)은 CPU↔프린터(디스크를 버퍼로 씀). 어느 두 장치 사이인지로 구분하면 된다.

문제 192021 군무원 · 기출문제집 p.864~865

8진수 5526을 16진수로 변환한 값으로 적절한 것은?

  1. B56
  2. A56
  3. B46
  4. A57
해설 보기

정답 ① B56

8진수와 16진수는 직접 변환하지 않는다. 반드시 2진수를 거쳐 간다(8=2³, 16=2⁴라 묶는 단위가 다르기 때문).

  1. 8진수 → 2진수: 한 자리를 3비트씩 펼친다
    5 → 101, 5 → 101, 2 → 010, 6 → 110
    → 101 101 010 110
  2. 이어붙이면 101101010110 (12비트)
  3. 2진수 → 16진수: 오른쪽부터 4비트씩 다시 묶는다
    1011 | 0101 | 0110
  4. 1011₂ = 11 = B, 0101₂ = 5, 0110₂ = 6 → B56

함정: ② A56은 1011(=B)을 1010(=A)으로 잘못 읽은 경우다. 3비트씩 펼치고 → 4비트씩 다시 묶는다는 두 단계를 정확히 지키는 것이 전부다.

문제 222021 군무원 · 기출문제집 p.867

입출력 명령어를 전담해서 처리하는 장치로 적절한 것은?

  1. CPU(Central Processing Unit)
  2. GPU(Graphics Processing Unit)
  3. DMA(Direct Memory Access) 프로세서
  4. 벡터 프로세서(Vector Processor)
해설 보기

정답 ③ DMA 프로세서

DMA는 CPU의 명령을 받아 입출력 전송과 그에 필요한 메모리 접근을 CPU 대신 수행한다. 덕분에 CPU는 전송이 진행되는 동안 다른 일을 할 수 있다.

  • CPU: 전체 연산·제어를 담당하지만 입출력 "전담"은 아니다 (전담시키면 오히려 비효율)
  • GPU: 그래픽·병렬 연산 전용 프로세서
  • 벡터 프로세서: 배열 데이터를 한 번에 처리하는 연산 장치 (SIMD 계열)

💡 같이 외울 것: 입출력 제어 방식은 프로그램에 의한 I/O → 인터럽트 구동 I/O → DMA → 채널 순으로 발전했고, 뒤로 갈수록 CPU의 개입이 줄어든다. 채널(Channel)은 DMA보다 더 발전해 아예 자체 입출력 명령어를 실행한다.

💡 관련: 입출력장치와 병렬처리

문제 32021 군무원 · 기출문제집 p.859

다중 스레드(thread)에 대한 설명으로 옳지 않은 것은?

  1. 문맥교환(context switching) 효율성이 프로세스 간에 이루어지는 것보다는 스레드 간에 이루어지는 것이 좋다.
  2. 다중처리환경에서 한 프로세스 내의 다중 스레드 단위로 병렬실행이 용이하다.
  3. 한 프로세스 내의 다중 스레드들은 그 프로세스에 할당된 자원(전역자원)을 공유하기 때문에 효율적이다.
  4. 통상적으로 프로세스를 LWP(Light Weight Process)라 하고, 스레드를 HWP(Heavy Weight Process)라고 한다.
해설 보기

정답 ④ (스레드가 LWP, 프로세스가 HWP — 완전히 반대로 서술됨)

이름의 뜻부터 생각하면 헷갈릴 일이 없다. Light Weight = 가볍다. 둘 중 무엇이 가벼운가?

  • 프로세스: 코드·데이터·힙·스택 + PCB까지 모든 자원을 독자적으로 보유 → 무겁다(HWP)
  • 스레드: 코드·데이터·힙은 공유하고 스택과 레지스터만 따로 가짐 → 가볍다(LWP)

①②③이 맞는 이유도 전부 이 하나에서 나온다 — 공유하는 게 많으니 문맥교환 시 갈아끼울 것이 적어 빠르고(①), 같은 자원을 쓰니 협업·병렬화가 쉽고(②③) 효율적이다.

문제 52021 군무원 · 기출문제집 p.860

운영체제가 프로세스를 생성하여 종료할 때까지 프로세스에 관련된 모든 정보를 담아 유지관리하는 구조체로 옳은 것은?

  1. FCB(File Control Block)
  2. PCB(Process Control Block)
  3. UCB(User Control Block)
  4. ACB(Access Control Block)
해설 보기

정답 ② PCB (Process Control Block)

PCB는 프로세스의 주민등록증이다. 프로세스가 생성될 때 함께 만들어지고, 종료될 때 함께 삭제된다.

PCB에 담기는 정보:

  • 프로세스 식별자(PID)와 현재 상태(준비·실행·대기 등)
  • 프로그램 카운터(다음에 실행할 명령어 주소)와 각종 레지스터 값 — 문맥교환 때 여기에 저장했다가 복원한다
  • 스케줄링 우선순위, 할당된 메모리·입출력 자원 정보, 부모/자식 프로세스 정보

함정: ① FCB는 파일 관리용 제어 블록으로, 이름이 비슷해 가장 많이 걸린다. "Process"인지 "File"인지만 확인하면 된다.

문제 72021 군무원 · 기출문제집 p.861

임계구역(critical region)에 대한 설명으로 옳지 않은 것은?

  1. 하나의 프로세스만 사용해야 임계구역 내의 자원의 무결성을 보장할 수 있다.
  2. 동시에 다수의 프로세스가 병렬적으로 실행할 수 있도록 하여 실행 효율성을 높일 수 있는 영역이다.
  3. 임계구역을 정의하기 위해서는 상호배제(mutual exclusion) 기법이 필요하다.
  4. 세마포어(P(s), V(s))는 임계구역 내에 하나의 프로세스만 허용하도록 하는 용도로 사용하는 기술이다.
해설 보기

정답 ② (임계구역은 병렬 실행을 막는 영역이다)

임계구역의 존재 이유는 "동시에 못 들어가게 하려고"다. ②는 목적을 정반대로 서술했다.

  1. 둘 이상이 동시에 쓰면 값이 깨지는 자원 = 임계자원 (예: 공유 변수, 공용 파일)
  2. 프로그램에서 그 자원을 건드리는 코드 구간 = 임계구역
  3. 한 프로세스가 임계구역에 들어가면 나머지는 모두 진입 금지 → 이 구간만큼은 직렬로만 처리된다
  4. 이를 강제하는 원칙이 상호배제, 구현 도구가 세마포어·뮤텍스

즉 임계구역은 성능을 희생해서 정확성을 지키는 장치다. "효율성을 높인다"는 말이 나오면 일단 의심할 것.

정답 ④

  1. 보안성(Security)

  3. 데이터 독립성(Data Independence)

문제 242021 군무원 · 기출문제집 p.868

다음 C++ 프로그램의 실행 결과는? (원문 선택지 일부가 스캔 손상되어 주관식으로 재구성)

ostream &set(ostream &stream) {
  stream.width(10);
  stream.precision(4);
  stream.fill('*');
  return stream;
}
main() {
  cout << set << 3.14159265;
}
해설 보기

정답 *****3.142

출력 서식 함수 세 개를 순서대로 적용하면 된다.

  1. precision(4) — 유효숫자를 4자리로 제한하고 반올림한다: 3.14159265 → 3.142 (3.141이 아님에 주의!)
  2. width(10) — 출력 전체 너비를 10칸으로 잡는다. "3.142"는 5칸이므로 5칸이 남는다
  3. fill('*') — 남는 칸을 *로 채운다. 기본 정렬은 오른쪽이므로 별이 앞쪽에 붙는다
  4. 결과: *****3.142 (별 5개 + 5글자 = 정확히 10칸)

함정 두 가지: ① precision을 소수점 이하 자릿수로 착각하면 3.1416이 나온다 — 기본 모드에서는 유효숫자 전체 개수다. ② 반올림을 빼먹고 잘라내면 3.141이 된다.

문제 252021 군무원 · 기출문제집 p.868~869

다음 Java 프로그램의 실행 결과로 가장 옳은 것은?

String A1 = "23242";
String A2 = "Hello!!";
String B1 = A2.concat(A1);
String B2 = A1.substring(4);
String B3 = Integer.toString(B1.indexOf("3"));
System.out.println("B1: " + B1);
System.out.println("B2: " + B2);
System.out.println("B3: " + B3);
  1. B1: 23242Hello!!, B2: 4, B3: 8
  2. B1: 23242Hello!!, B2: 2, B3: 7
  3. B1: Hello!!23242, B2: 2, B3: 8
  4. B1: Hello!!23242, B2: 4, B3: 7
해설 보기

정답 ③ B1: Hello!!23242, B2: 2, B3: 8

  1. B1 = A2.concat(A1) — A2 뒤에 A1을 붙인다(순서 주의!) → "Hello!!" + "23242" = Hello!!23242
    → ①②는 순서가 반대라 여기서 탈락
  2. B2 = A1.substring(4) — "23242"에서 인덱스 4번부터 끝까지. 인덱스는 0부터: 2(0) 3(1) 2(2) 4(3) 2(4) → "2"
    → ④는 여기서 탈락 (4는 인덱스이지 값이 아님)
  3. B3 = B1.indexOf("3") — "Hello!!23242"에서 문자 '3'이 처음 나오는 위치:
    H(0) e(1) l(2) l(3) o(4) !(5) !(6) 2(7) 3(8) → 8
  4. Integer.toString(8)으로 문자열 "8"로 변환해 출력

💡 메서드 정리: concat(뒤에 이어붙임) · substring(n)(n번째부터 끝까지) · indexOf(처음 나온 위치, 없으면 -1) · Integer.toString(숫자→문자열). 모든 인덱스는 0부터 센다는 것이 모든 함정의 출발점이다.

💡 관련: JAVA 기초와 객체지향
